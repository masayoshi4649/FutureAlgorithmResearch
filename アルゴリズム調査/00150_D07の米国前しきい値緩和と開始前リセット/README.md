B04は「少し弱い流れから準備し、浅い押戻りと小さな再反発で入る」方式です。米国前の参加は6→16夜、保有時間率は6.5→17.3%。一方、赤字夜の平均損失は28,000→43,000円。上位3黒字夜を除いても+307,000円ですが、米国前自体は赤字です。主担当の効率は0.35→0.25、戻り条件0.25→0.40R、再反発0.25→0.125R。Rの定義と他条件は[検証仕様](根拠/engine仕様150.md)・[第二巡仕様](根拠/engine追加仕様150.md)に記載しました。

発注直前の勢いを再確認するB05/B06も試しました。B05は10/21の悪い売りを一度止めても、約2分後に入り直して同じ4万円損失。別日に利益だった2取引も消え、A01より39,000円悪化しました。「一度見送れた」と「損失を防げた」は別でした。[具体時刻と価格](根拠/engine_第二巡の具体診断150.md)

A/B各案とS04は、開始15分前に全返済を判断します。後半は売買状態をリセットし、指標履歴は保持。最低15分静観し、主担当は開始22分後から元の条件へ戻します。23新条件の後半は25夜すべて同じ約定になり、前半変更の効果を分離できました。新条件はすべて前半赤字で、緩和だけによる黒字化は未達です。

10/26の取得済み途中データは別シートです。B04は確定+20,000円・含み+10,000円、最も活発なA16は確定+81,000円。指摘された波を一部取れるようになっても、過去25夜の安定性が改善するとは限りません。

詳しく確認する場合は、[B04の改善・悪化した4夜のチャートと全売買](根拠/B04_具体的な売買比較.md)、[初巡の損失原因](根拠/engine_前半閾値の具体診断150.md)、[20項目の反証・監査](根拠/最終の20項目監査.md)を参照してください。米国開始直後の変動拡大は[時刻別観測](根拠/時刻前後の診断要点150.md)で確認できましたが、それだけで静観の利益改善を証明したものではありません。

約定模型は判断後の次の正常なラージ売買気配で、miniの実約定や市場への影響は再現していません。原資料には独立した受信時計がなく、価格時計順の再生です。全25夜を既に研究で使用しており、第二巡は初巡の失敗から作った改良です。将来の未見成績とは区別します。
