# 00005 損小利大と時間帯別ルールの検証

**最初に見るファイル：[損小利大と時間帯の検証.html](損小利大と時間帯の検証.html)**

HTMLはダークテーマです。インターネット接続なしで、５分足と検知・新規・返済を確認できます。

読む順序：

1. HTML冒頭の結果と評価範囲。
2. 入口・出口・米国開始前後の対照比較。
3. 条件・銘柄・セッションを選び、５分足と売買明細を確認。
4. [検証結果.md](検証結果.md)で文章と集計を確認。
5. [資料](資料/)の条件一覧、全条件集計、監査記録を確認。

過去の00004は変更していません。今回の比較には前回の固定条件も含みます。

再計算はプロジェクトルートで `python work/wave_v10/research.py` を実行します。現在照合の保存データだけを再計算する場合は `python work/wave_v10/live_check.py --evaluate` です。一回取得済みなので、新しい取得は実行しません。資料内のPythonファイルは参照用で、その場所から直接実行する構成ではありません。
