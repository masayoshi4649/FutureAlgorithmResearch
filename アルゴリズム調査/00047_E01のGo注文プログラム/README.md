# E01のGo注文プログラム

最初に見るファイル：**[App/E01/README.md](../../App/E01/README.md)**。

読む順序：起動手順 → [取引設定](../../App/E01/conf/trade.toml) → [仕様](../../App/E01/docs/仕様.md) → [検証結果](../../App/E01/docs/検証結果.md)。

実装は利用者指定の `App/E01` に置き、この作業フォルダは調査一覧からの案内にしています。

- 5商品から1銘柄を選択し、片方向の同時保有上限をTOMLで指定。
- NK225/TOPIXの参照データ、取引商品の生板、登録・限月・セッション情報はkabus-controllerから取得。
- dryrunと実注文に対応。記録はセッション別CSV。既定はdryrun。
- [配布版](../../App/E01/dist/README.md) は `App/E01/dist`。Windows / Linux の実行ファイルと設定サンプルを同梱し、再ビルドで既存の実設定を保持。
- 実サーバーのPUSH受信による仮想運転を確認。実注文の送信試験は行っていません。

旧Python版と過去の損益レポートは変更していません。
