# 主玉の逆行を短期カバーで補う

**買い10枚・売り10枚、合計20枚を許して検証しました。この入口とカバー設定では改善しませんでした。** 主玉があるだけで反対の新規を拒否する仕様にはしていません。

最初に [主玉とカバーの全セッション損益.xlsx](主玉とカバーの全セッション損益.xlsx) を開いてください。「比較」の後に、各手法のシートで全53セッションと累計を確認できます。理由と測定条件は [検証記録.md](検証記録.md) にまとめています。

## 結果

日経mini、片方向10枚、手数料0。ラージの次の正常な売買気配を約定価格の代理に使用。金額は円、利益・損失は各玉の決済損益の正負合計です。

|手法|簡単な説明|利益|損失|収支|赤字場|
|---|---|---:|---:|---:|---:|
|S00|主玉を100円利確・50円損切り|45,290,000|76,690,000|−31,400,000|44/53|
|N00|主玉を100円利確・残りは場末、カバーなし|31,050,000|37,120,000|−6,070,000|31/53|
|H01|20円逆行ごとにカバー1枚、利益20円後に10円追尾|34,379,000|45,858,000|−11,479,000|39/53|
|H09|H01の追加間隔を60円へ|32,680,000|42,427,000|−9,747,000|37/53|
|H05|H01の追加間隔を40円へ|32,918,000|44,349,000|−11,431,000|38/53|

H01・H09・H05は前40場で固定した比較候補で、採用推奨ではありません。後13場でも赤字。カバー24案すべてが全53場の累計でN00を下回りました。全案に無取引2場があり、黒字に数えていません。

## 何が起きたか

**主玉が助かる反発で、残ったカバーが損失になる**のが一つの原因です。10月23日H01では、09:00の買い10枚が100円上昇を取り＋10万円になった同じ組で、カバーの合計は−14.7万円。主玉の回復だけでは全体の利益になりませんでした。

**カバーを新規直後から追尾して早く逃げる型も試しました。** 同じ20円間隔・10円追尾のH13は、カバー新規が3,286→12,538玉へ増え、全体収支は−1,147.9万→−2,679.1万円へ悪化。早い退出だけでは反復損失を防げませんでした。

一部には途中の損失を抑える効果がありました。例えばH12は場内最悪をN00の−161万円から−112.6万円へ縮めましたが、累計は−873万円、赤字38場。**保険としての効果と、安定して利益を生む効果は別**という結果です。

全53場は既知資料の開発比較です。実miniの約定実績ではなく、場末は既往指定に従い終了前6分以内の最後の正常気配で代理精算しています。絶対額は場末に残した損失玉の評価へ大きく依存します。一方、H01のN00に対する悪化は通常返済部分でも生じており、場末代理だけを原因とはできません。
