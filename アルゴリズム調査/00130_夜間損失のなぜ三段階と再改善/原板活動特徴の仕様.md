# 原板活動特徴の確定仕様

対象は保存済み21夜間のNK225／TOPIXラージ。各行を既存入力の `ready.seq` で原JSONLの0始まり行番号へ対応させます。売買結果は作らず、入口で使う観測値だけを計算します。

| 出力 `activity` 列 | 内容 |
| --- | --- |
| 0 | 正常気配中値の30秒差。値上がりを正とする |
| 1 | 窓内の公表出来高正増分合計 |
| 2 | 買い方向代理量 − 売り方向代理量 |
| 3 | 全条件が既知なら1、未知なら0 |

判断行の価格時計を `t` とし、`t−30秒` より**厳密に前**の最後の行を始端とします。その始端が `t−30秒` より30秒超古ければ未知です。始端の次行から判断行までの公表量増分を加えます。**既知の場合の実際の観測区間は30秒超〜60秒以内**です。これは厳密な30.000秒間の量ではなく、この始端規則に基づく差です。

公表出来高増が正の原行について、その行の最終約定値が前行の売り気配以上なら買い代理、前行の買い気配以下なら売り代理、間内なら曖昧量とします。曖昧量も列1へ含めますが、列2の符号量には足しません。実際の成行発注方向は公開されておらず、**これは真の買い・売り成立量ではありません**。

必要値の欠測、気配不正、原行番号の飛び、公表出来高の逆戻りが一つでも窓内にあれば、列0〜2を欠測・列3を0とします。欠測を0量へ置き換えません。汚染した接続が窓から抜ければ復帰できます。全体の価格時計が非有限又は逆行する入力は明示的に拒否します。同時計は許可し、原行順で加算します。後続の同時計原行を先取りしません。

候補となる入口条件は、売買方向を買い `+1`、売り `−1` としたとき、**既知・方向×列0＞0・方向×列2＜0・列1＞0** の全成立です。満たさない入口候補の扱いと、その後の全売買経路は別の注文核で検証します。この特徴の集計だけで見送り後の利益を主張しません。

`prepared/*.npz` には原行時刻・番号、始端番号、買い代理量／売り代理量／曖昧量／未知接続件数／始端古さも保存しました。全原板ファイル、既存入力、出力のSHA256は [非金融準備の一覧](../../work/night_why130_20261020/原板活動の非金融準備.json) にあります。

純人工では63項目を確認しました。未来切断・未来価格毒化・同時計後続行・上下対称・欠測・出来高逆戻り・原行飛び・不正時計の拒否を含みます。実保存親との二実装照合では、活動が既知の132親×6項目＝792値が一致しました。未知のため分類が変わった3親は [全親照合](../../work/night_why130_20261020/entry_book/全原行活動と全親分類の照合.json) に明示しています。

大口板の表示量や公表量から、ミニ・マイクロの板待ち、約定順番、実注文の滑りは評価していません。受信時刻もないため、ここでいう「30秒」は保存された価格時計に基づきます。
