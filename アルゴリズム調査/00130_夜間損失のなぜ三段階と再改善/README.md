## 実装と会計

四巡12新条件を、それぞれ両商品・全21夜間で検証した。新規金融再生は504商品場。旧日中3条件・夜間3条件の258商品場を引用し、HTMLは計18条件・762商品場の保存会計を表示する。これは762個の独立したセッションという意味ではない。日中はTOPIX DV07・日経DV05を初期表示し、新たに再生していない。

TOPIXミニ5枚／日経マイクロ10枚、追加なし。部分返済型は2＋3枚／5＋5枚。同じ新規建玉の部分返済と残玉を、全手数料後で合算する。片道料率41.8円／11円、各注文の円未満切捨て。各場で全返済する。

公表時計と原行順の範囲で過去資料だけを使う。約定は次の正常原行のラージ売買気配で代用する。公表価格時計は受信時計ではなく、実受信順での二市場資料の同時利用可能性、ミニ・マイクロの実約定、通信遅延は未検証。「30秒」は30秒前より古い起点を使う基準窓で、活動量の実観測区間は30秒超〜60秒以内。記録上の過去参照と未見データでの有効性検証は別であり、全43場は既知の開発資料である。[前提](調査の前提.md)も参照。
