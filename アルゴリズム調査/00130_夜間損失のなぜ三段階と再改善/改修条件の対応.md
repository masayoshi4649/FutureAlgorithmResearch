# 改修条件の対応

どの条件も上昇・下落で売買を反転した同じ規則を使う。後から判定した「上昇場／下落場」で方式を切り替えない。Rは準備開始時の幅で、当時のATRとラージの4呼値分の大きい方を固定する。新規はTOPIXミニ5枚／日経マイクロ10枚。今回の追加建てはない。

## 元の入口と出口

**NV01：方向が揃った進行を確認する入口。** 自市場が過去20分の終値範囲を抜け、方向効率が0.35以上、相手の5分・20分が同方向なら準備する。60秒以上経過し、両市場の30秒基準方向と120秒基準方向、相手の5分・20分が支持する場合に発注資格を確認する。新規価格には通常の気配幅・現在値乖離の条件もある。

**NV25：抜けた線への戻りと再進行を確認する入口。** 準備時に固定した線から0.75R以上進んだ後、別の原行で0.25R以内へ戻り、さらに別の原行で戻りの極値から0.25R以上再進行する。両市場の短い方向と相手の5分・20分の支持も必要。両市場の120秒の逆行幅が、それぞれ観測時点で公開済みのATRの0.25倍を超えたら、その候補を待たせず準備を破棄する。この逆行判定には準備開始時に固定したRを使わず、自己・相手それぞれの当時のATRを使う。相手市場の参照行は判断時刻より厳密に過去の行に限る。価格判断は中値。

両方とも米国株開始前後15分を避け、開始後22分以降に準備する夜間条件を比較した。原行ごとに判断し、元の入口は[00129の仕様](../00129_チャートと板からの失敗機構再検証/夜間再試験入口の仕様.md)と各固定条件JSONを継承している。

元の出口は初期1R損切り。清算できる気配で1R順行後、最高順行から0.75R戻る線を引き上げる。固定線の破綻と相手の長い方向による撤退、禁止時間・場末の全返済もある。返済後は300秒待ってから新しく準備する。停止線の値での約定を保証せず、判断後の次正常原行気配で返す。

## 今回変えた部分

| 条件 | 元の入口 | 変更 |
| --- | --- | --- |
| W01 / W04 | NV01 / NV25 | 1R起動前も、最高順行−1Rへ損失床を単調に引き上げる。 |
| W02 / W05 | NV01 / NV25 | 0.5R順行後、最高から0.25R戻ったら一度だけ半数を返す。残りは元の出口。 |
| W03 / W06 | NV01 / NV25 | 上記二つを併用。 |
| W07 / W08 | NV01 / NV25 | 元の発注資格に、逆向き出来高代理にも中値が進む条件を追加。不適格・未知なら全準備を破棄。 |
| W09 / W10 | NV01 / NV25 | W02/W05の部分返済に、両市場の30秒基準方向が建玉と逆であることを追加。元の出口は維持。 |
| W11 / W12 | W07 / W08 | 最初に見送った候補より不利な判断価格なら追わない。以下の価格記録を使う。 |

部分返済の「半数」は初回枚数を2で割り切り捨てるため、TOPIXは2枚、日経は5枚。残玉を含む親全体で損益を集計する。通常の全返済条件を部分返済より優先する。

## 価格記録の寿命

W11/W12は、活動が不適格だった最初の発注資格済み候補の判断気配・固定線・Rを買いと売りで別々に保存する。買いなら保存askより高いask、売りなら保存bidより低いbidでは準備を捨てる。同値・有利は許す。後の候補で保存価格を不利に更新しない。

自己価格が元の固定線を逆側へ0.25R以上越えた時、禁止時間、場末で記録を解除する。新規が成立しただけでは解除しない。活動や価格予算が発注後に変わっても、それを理由に発注を取り消さない。ただし、従来からある「禁止時間・場末に未保有の新規発注待機を取り消す」処理は維持する。

追加情報のために待った結果、悪い場所へ追随するのを防ぐ狙いであり、価格が戻らず続伸・続落する利益も失い得る。実際の次行約定は判断価格より悪くなる場合がある。

「30秒基準窓」と[出来高方向代理](原板活動特徴の仕様.md)の実観測・時計の限界を参照。条件は全て既知の過去資料で比較したもので、将来の勝ちを保証する法則ではない。
