# 原本全行の板観測と対照比較

最初に[比較と結論](原本全行の板観測と対照比較.html)を見てください。**原本の細かな板変化を追加しても、今回の主案は両市場で赤字でした。** 全260条件を検算し、黒字が残る既存候補の価値とは分けて記録しました。

読む順序：

1. [比較と結論](原本全行の板観測と対照比較.html) — 20基本方式の説明・損益と主／副の反証結果。
2. [全260条件の損益](全条件損益.html) — 各週・各セッション・全期間の利益／損失／収支、勝ち／負け／同値決済枚数。
3. [5分足と売買](５分足と売買.html) — 旧公開端点・原本全行の2品質・価格だけの固定4方式、各市場の全13セッション。
4. [今回の到達点](../../work/wave_v42/今回の到達点.md) — 観測を改善しても採用に至らなかった理由。

各市場1枚の情報比較です。大型先物の保存価格をTOPIXミニ（1pt＝1,000円）／NKマイクロ（1pt＝10円）へ換算。費用0・指定価格約定・場内全返済。既存候補の5枚／10枚の円利益とは単純比較しません。

全13セッションは既知です。原本の約定時刻が変わるまで同時刻ブロックを封印し、利用可能な公開行へ到達してから数量比率を使います。板の差分は約定量・取消量・同一参加者の補充を直接測った値ではありません。
