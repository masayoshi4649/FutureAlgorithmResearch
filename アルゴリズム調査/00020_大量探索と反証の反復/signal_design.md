# 120方向条件の設計と反証条件

新しい損益を参照する前に、15機序×8条件を `discovery_signals.py` の `catalog()` へ固定した。期間は60・120・300・600秒、閾値は広めと強確認の2段階で、根拠のない小刻みな利益最大化は行わない。各条件は一件ずつ生成でき、巨大な方向集合の保存を必須としない。

## 機序

| ID | 仮説と観測順序 | 反証する状態 |
|---|---|---|
| D000〜007 | 両市場でOFIと価格応答が同方向なら共通の進行が続く | 片方で吸収、価格反転、方向の不一致 |
| D008〜015 | 相手のフロー・価格進行を、自銘柄の短期価格が追い始める | 先行側が反転、自銘柄が追随せず独自に動く |
| D016〜023 | 同方向フローが価格へ伝わらず両市場が短期反転する | 吸収帯を同方向へ抜ける、一市場だけの反転 |
| D024〜031 | 現在と過去二時点でフロー方向が続き推定売買も一致する | 分割執行の終端、流れは続いても価格効果が消える |
| D032〜039 | フロー吸収を記録した後、価格が帯を抜ければ吸収失敗として順張り | 準備後に期限切れ、逆向きOFI、価格確認なし |
| D040〜047 | 補充代理を見た後、価格反発とOFIで初めて新規を許可する | 取消再提示だけで価格が伴わない、支えを価格が突破 |
| D048〜055 | 遠い板先行を準備し、その後に近い板と価格へ伝わる | 期限内に近い板が変わらない、逆方向へ動く |
| D056〜063 | 以前の長いフローに対し短いフローと価格が反転する | 新しい短期フローがすぐ消え、元方向が再開 |
| D064〜071 | 推定取引量当たり価格感応が過去より高く、板変化も同方向 | 一時的な薄さがすぐ回復、価格が戻る |
| D072〜079 | 急変後、板回復＋逆価格なら反転、未回復＋順価格なら継続 | どちらの確認も発生しない、反応が持続しない |
| D080〜087 | 時計でなく原本更新数を揃えると異なる取引密度を比較できる | 更新回数が実際の注文量と対応しない、時刻方式より悪化 |
| D088〜095 | 推定取引量が前区間より加速しフローと価格が一致する | 大口終了直前の急増、価格が伸びない |
| D096〜103 | 開始・米国開始帯は速い共通フロー、それ以外は効率比で切替 | 時間帯の差が再現しない、切替が雑音を増やす |
| D104〜111 | 価格の流れを認めた後の押し戻りから、価格とフローの再開を待つ | 押し戻りが本当の反転へ発展、確認前に失効 |
| D112〜119 | 過去帯を抜けた事実を記録し、後で帯内へ戻る価格と逆フローを見る | 強い方向相場で逆張りが連敗、帯内復帰が一瞬で終わる |

準備状態を使う機序では、準備時の価格・ATR・帯境界を保存し、別の後続イベントでだけ発火する。F43の前回監査で確認した「選択条件と同時刻の発火条件が逆」という問題を、説明だけで済ませず状態遷移として解消した。準備は有限の期限で失効する。発火した方向も有限の期限で失効し、反対OFIと短期価格が揃えば解除する。

方向には売り・買いを対称に持たせる。0は新規方向なしであり、利益と数えない。信号の切替や0が既存玉の返済につながるかは、組み合わせる注文管理の仕様による。セッションごとに状態を初期化する。

## 追加で確認した一次研究

- [Cont・Cucuringu・Zhang：Cross-Impact of Order Flow Imbalance in Equity Markets](https://arxiv.org/abs/2112.13213)。他銘柄の遅れたOFIが短期予測に情報を持つ可能性がある一方、その関係は時間とともに急減する。今回の両市場条件は、この仮説をOSEデータで反証するための独自仕様である。
- [Bechler・Ludkovski：Order Flows and Limit Order Book Resiliency on the Meso-Scale](https://arxiv.org/abs/1708.02715)。出来高を使う集計尺度、追加・取消に関する代理指標、板形状と回復を検討する。今回の更新時計・取引量加速・衝撃後状態の着想に使用し、原論文の性能は今回へ転用しない。
- [Gould・Bonart：Queue Imbalance as a One-Tick-Ahead Price Predictor](https://arxiv.org/abs/1512.03492)。最良数量比と次の価格変更方向の関係を調べた研究。次tickの予測力を数十分の保持利益と同一視しない。今回、板厚の言い換えだけで条件数を増やさず、後続の価格応答・時間順序を要求する根拠とした。
- [Xuほか：Limit-order book resiliency after effective market orders](https://arxiv.org/abs/1602.00731)。流動性ショック後の回復・継続の違いを調べる。今回の準備→回復または未回復→価格確認という分岐を検証する着想にした。

## 因果性と測れないもの

- 原本時刻ブロックの板特徴は、次時刻へ進んで解放されたseq以降でだけ使う。原本各行へはseqの過去asofで対応させる。
- 確定1分足は開始から120秒後に公開。入力末尾より未来の足を除く。相手銘柄は解放時刻からさらに60秒遅延し、過去asofだけで参照する。
- 過去窓または累積値だけを計算する。流動性感応の標準値も直前までの30分だけで作り、全セッション統計や将来価格を使わない。
- 板数量減少を約定と取消に分けること、同じ参加者の分割執行や返済を識別することはできない。補充・蓄積・共通因子は観測可能な代理仮説として扱う。
- 近遠の距離重みは重複した価格帯を含み、独立な証拠二つではない。今回は二段階の時間順序や、独立市場の後方情報で仮説を厳しくする。
- 毎分境界で途中入力が終わっても過去の結果が変わらないことを代表条件で監査する。検証結果は本資料末尾へ追記する。

## 一律近傍診断

`neighbor_specs(spec)` は主探索とは別IDの4条件を返す。フロー系閾値群（OFI・推定売買・近遠の準備/確認・補充）を全て0.8倍または1.2倍、価格系閾値群（価格進行・確認幅・吸収上限・衝撃幅）を全て0.8倍または1.2倍とする。条件ごとに使わない値を含む場合でも、一律の定義を変えない。主カタログ120件は不変であり、近傍の好成績を見て採用仕様を置換しない。

## 実装時の検証

- 全120条件について26入力の方向生成に成功。方向は原本行数と一致し、`int8`の−1/0/1である。全条件の生成は約18.79秒、巨大な方向集合は保存していない。
- 各機序の最初の代表条件15件について、9月22日ナイトと9月29日デイ、両銘柄、3切断点を比較した。180件のprefix比較が全て一致した。切断時刻は分境界へ丸めている。
- 同じ15代表条件で、将来側の原本価格・ATR・板フロー・補充・気配価格を大きく改変した。変更前時点までの方向60比較が全て一致した。
- 二段階の遠方→近傍条件について、4種類の近傍診断仕様も生成可能であることを確認した。
- この段階で新しい売買損益は参照していない。生成成功は収益性や市場原理の証明ではなく、売買再生・独立監査へ渡すための検査である。
