# 元手法への局所減枚と復元

**日中S01・夜間P05＋D07へ部分移植し、全53セッションで比較しました。今回の改修は元手法の総合改善には至らず、元手法を維持する判断です。**

最初に [全セッション損益.xlsx](元手法の局所減枚と復元の全セッション損益.xlsx) を開いてください。「比較」の後に、手法別シートで利益・損失・収支・累計を確認できます。条件と具体的な売買は [検証記録.md](検証記録.md) にまとめました。

## 取り込んだ部分と結果

前実験で見えた「カバーの利益より、主玉が減ったことによる損失軽減」を取り出しました。元の入口・追加・利確は保ち、逆行時だけ半分に減らす機能と、回復時に一度だけ元量へ戻す機能を比較しています。

日経mini片方向10枚相当をmicro100枚で計算。手数料0、ラージの次の正常気配で約定する仮定。金額は円です。

|手法|内容|53場収支|赤字場|場内最悪収支|
|---|---|---:|---:|---:|
|B00|元のS01／P05＋D07|+3,281,000|17/53|−203,000|
|D80|80円逆行で一度だけ半分へ|+2,505,500|16/53|−199,000|
|R80|80円逆行＋短期逆行で半分、回復確認で復元|+3,156,500|18/53|−196,000|
|C50|最初から常に半分の枚数|+1,640,500|17/53|−101,500|

D80は前40場で昼夜別に固定した案です。固定合成F00も今回はD80と同じ結果。R80は全8改修の中で累計が最も高かった比較案で、後半を見て選び直した採用案ではありません。全案に無取引はありません。

**赤字場が1場減っても、損失削減に成功したとは言えません。** D80の総損失は394.6万→395.7万円、総利益は722.7万→646.25万円。回復する玉を途中で減らした影響が大きい結果でした。

## 部品として何が分かったか

- **減枚は局所的には効きます。** 10月15日の日中の買いでは、損失を6.6万→4.2万円へ縮小しました。
- **減らしっぱなしでは、回復利益を失います。** 10月22日の日中の売りは、一時的な逆行で半量にしたため、親収支が36.1万→15.8万円になりました。
- **復元はその副作用を軽減しました。** 短期確認付き減枚G80に復元を加えたR80は、累計を48.3万円回復。ただし元B00より12.45万円少なく、赤字場は1場増加。復元だけで安定性が改善したとは認められません。

したがって、今回残せるのは「減枚を評価するときは、その後の回復を逃した額と復元時の往復損まで比較する」という知見です。既知53場の開発比較であり、未見データでの成績ではありません。
