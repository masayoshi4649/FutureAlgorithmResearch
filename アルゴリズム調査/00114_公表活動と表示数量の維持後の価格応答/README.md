# 公表活動と表示数量の維持後の価格応答

**全33場・66口座の非金融測定を完了。売買成績ではない。** 最新の金融成績は[00113](../00113_現在の注文活動と再進行から波の中間に参加/README.md)に掲載している。

最初に[説明と全33場の価格応答](表示数量を観測した後の方向応答.html)、次に[結論と未検証の売買](結論と未検証の売買.md)を確認する。[測定の問いと事前計画](../../work/quantity_response_20261015/source_review/固定価格の数量と公表活動後の価格応答を一回測る計画.md)は結果前の仮説。追加2場は対象外。

反対側数量が初期以上の群は、最初の活動代理方向へ両気配1呼値先着する率がTOPIX79.75%・日経80.85%。数量減少群の76.32%・78.50%より高かった。単純な「板が残るほど反転しやすい」という仮説とは逆だった。一方、最初の活動だけでも79.43%・81.34%であり、80%を数量追加の成果にしない。

売買・利確幅の調整を先に行わず、数量が持つ追加情報を切り分ける。表示の非減少を実際の同側補充と断定しない。テクニカルの形、参加者の保有建玉、注文主体、二市場の真の同時受信も今回の観測では特定しない。

[公開集計](数量後の価格応答の公開集計.json)は[修正版の測定結果](../../work/quantity_response_corrected_20261015/measurement/数量応答の結果.json)と同bytes。集計・全HTMLセルを[独立検算](../../work/quantity_response_corrected_20261015/audit_aggregation/数量公開六十六集計と先着分母及び表示の独立監査.json)、生成出力66件の分類と終点を[独立検算](../../work/quantity_response_corrected_20261015/audit_aggregation/六十六出力の数量分類と終点及び追加欄の独立監査.json)した。原入力をもう一度再生した独立実験ではない。

初版は保存列の逆写像を真偽フラグと誤認した資格検査で停止し、観測0。元の[False](../../work/quantity_response_20261015/measurement/False.json)と登録・sourceを保持した。修正版は生成元の定義へ訂正し、独立人工・別登録後に測定した。読取累計は停止時1＋修正版66。条件や閾値を市場成績に合わせて変更したものではない。
