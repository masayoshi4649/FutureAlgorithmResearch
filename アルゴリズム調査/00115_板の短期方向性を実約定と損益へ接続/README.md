## 検証範囲

2026年9月21日デイ〜10月13日デイの既知33場。TOPIXミニ片方向10枚・日経マイクロ片方向20枚、場内返済、各実注文の税込料を個別に切り捨て。判断当行の約定は許さず、新規は直後原行の一回だけ、返済は判断より後の執行正常行です。保有時間は固定していません。

原44列66入力・保存された公開feature66を各一回読み、12×33×2＝792口座を計算。未来の先着結果・終点・極値は入口へ渡していません。追加2場・実ミニ板・待ち行列・実遅延・5秒最悪条件・他指標による改善は未測定です。価格時計と原行順を使う模型であり、真の板受信時計を再現した証明ではありません。

独立会計検算は792口座・5,095完結親・5,262返済脚と主候補66台帳の376,912項目に合格しました。独立した金融標本を増やした検査ではありません。出口を変えると再参加・場停止も変わるため、条件間の収支差を同じ親の純粋な出口効果とはしません。
