# 00002 出口の利益保護の検証

まず [５分足の比較HTMLを開く](出口比較.html)。初期表示は9/23デイ・NK225・同じ入口での比較。[作業一覧へ戻る](../index.html)。

比較方法を「再エントリーを含む運用」へ切り替えると、早期返済後の再新規も含めた全取引が表示される。「有効な保護価格を表示」で、その足に存在していた逆指値水準を確認できる。表示は１分足開始ラベルで、足内の秒単位の約定時刻は未再現。

9/23の最初の売りは、元の９万円から候補の28万円へ増えた。再新規まで含む当日の収支は24万円。一方、５セッション合計ではNK225は189→159万円、TOPIXは62→70万円で、両銘柄を同時に上回る結果にはなっていない。金額はラージ１枚、往復２ティック控除後。

資料フォルダーには192条件、全取引、実装、計画、感度、監査の保存版を含む。図示した利益保護候補は比較のための事後選択で、採用決定ではない。元の研究とHTMLはそのまま残した。

再実行はプロジェクトルートの `work/wave_v6` にあるコードを使う。資料内コードは保存時点の記録であり、その配置のまま実行する入口ではない。データは前回の `アルゴリズム調査/00001_波検知と売買ポイントの調査/保存版` を参照し、現在セッションAPIへ接続しない。

資料内の過去監査記録は保存時点のパス・コード指紋を維持している。番号付きフォルダへの整理に伴い、現役コードの参照先だけを更新した。
