# 新候補2手法と基準の説明・セッション損益

最初に見るファイルは **[新候補2手法の説明と損益.html](新候補2手法の説明と損益.html)** です。

読む順序：

1. 冒頭の数量前提と全期間比較。
2. E01・E08・元の候補1のタブを選び、入口／途中／出口と各セッション・週・全期間の損益を確認。
3. 必要なら、勝ち枚数・負け枚数と機械条件を開く。

00042と同じ暗色テーマ・3段階の説明・TOPIXとNKの横並び表で整理しました。新候補はE01（初期損切り0.75ATR）とE08（初期損切り0.5ATR、0.5ATR順行から幅0.5ATRの追跡）。E00は00042の候補1 `F50_NONE__E11` と同じ比較基準で、新発見の手法ではありません。

対象は2026/09/21デイ〜10/06デイ、全23セッション・3週。ナイトは開始日の週に集計します。TOPIXミニ初回5枚・片方向上限10枚、NK225マイクロ初回10枚・上限20枚。増玉・減量後の復元はなく、実際の最大保有は5枚・10枚です。保存されたラージの価格をミニ／マイクロの円倍率で換算し、費用ゼロ・指定価格約定・場内全返済という従来の検証前提を維持しています。

最初の16場は00043の検証済み結果で、新候補の探索に使用したデータです。その後の7場は3方式の条件・枚数を固定した追加検証です。今回、2026/10/02ナイト、10/05デイ・ナイト、10/06デイの4場を保存原本から再生しました。現在セッションAPIの取得は0回。旧19場の全統計、旧原本114ファイル、00042・00043のHTMLが変わっていないことを確認しました。

追加4場の有効板1,109,773行を別実装で照合し、入力順・時刻・価格が完全一致。全138口座の損益と、各場・3週・全期間の表示972数値も独立検算しました。TOPIXの10/02ナイト05:30枠など、約定のない足は従来どおり補完していません。保存足と板の約定時刻集計のOHLC差は監査資料に記載しています。

今後の追加分は `work/wave_v50/追加結果一覧.json` に登録した検証済み結果から読み込みます。新たな原本を置いただけでは加算せず、同一条件での再生・会計検証を済ませた結果だけを取り込みます。最大途中下落は、セッションごとの最大値ではなく全原本行の時価損益を連結して再集計します。
