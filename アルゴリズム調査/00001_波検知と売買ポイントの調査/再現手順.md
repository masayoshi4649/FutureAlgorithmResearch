# 手法１の再現

このフォルダ内に保存した足２０ファイル、研究時の実装、主候補設定だけを使い、手法１の１２取引を再現します。現在セッションＡＰＩへは接続せず、全条件の再探索もしません。

Ｐｙｔｈｏｎ、ＮｕｍＰｙ、ｐａｎｄａｓが利用できる環境で、プロジェクトのルートから実行してください。

```powershell
python -X utf8 .\アルゴリズム調査\00001_波検知と売買ポイントの調査\手法1を再現.py
```

スクリプトは自身の所在を基準に読み込み先を決めるため、作業ディレクトリに依存しません。この調査フォルダを別の場所へコピーしても、内部の配置を保てば同じ手順を使えます。

最初に、保存された１分足・５分足２０ファイルのＳＨＡ２５６を、調査時点の `保存版/work/wave_v5/データ監査.json` と照合します。次に `方向主候補.json` の１条件を再生し、取引順序と全フィールドを保存済み１２取引と比較します。日時・数値型の表現のみそろえ、数値の丸めや許容誤差は使いません。不一致の場合は異常終了します。

出力は `再現確認/再現結果.json` と `再現確認/手法1の全取引.csv` です。ＪＳＯＮには入力照合、実装ハッシュ、実行環境、条件、全取引、比較差分を保存します。ＣＳＶには日本語列名で全取引と円換算収支を保存します。ＣＳＶの新規・返済時刻は成立した１分足の開始時刻であり、その秒に実際の約定があったことを示すものではありません。

手法１は価格累積和と足のＡＴＲだけを使うため、この再現では板特徴を読みません。他の手法では板や相手銘柄の特徴を使う場合があります。保存版には調査の成果物も含みますが、全探索をやり直すための全依存ファイルを収録したものではありません。

この確認は、保存データと保存条件から同じ仮想取引を得られることの確認です。条件を選ぶ際に使った期間の再生であり、将来の利益や実市場での同一約定を確認するものではありません。
