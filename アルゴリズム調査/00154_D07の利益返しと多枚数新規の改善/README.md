# D07の利益返しと多枚数新規の改善

**ご指摘の動きは実約定でも確認できた。昼の改修候補はS01。ただし、多枚数の初回新規まで解決したわけではない。**

最初に見るのは[全セッション損益.xlsx](D07の利益保護と段階投入の全セッション損益.xlsx)の「比較」、次に「日経_D07」「日経_S01」。当日の具体的な売買は[実運用で起きたこと](実運用で起きたこと.md)、条件と限界は[検証記録](検証記録.md)へ分けた。

## 原因

- **残り1枚は試し玉ではない。** 部分利確後の残玉へ、先に確定した利益を損失予算として再投入する設計だった。今日09:31の売りでは、先の利確＋9,560円を残1枚の−10,440円が消し、合計−880円になった。
- **5枚・3枚・2枚は確信度の差ではない。** 別々の担当の固定枠。今日10:37の売り5枚は、先行する2枚への追撃ではなく主担当の初回新規だった。主担当の、部分利確後に始まる利益保護はまだ働かず、−57,350円になった。

上記は日経miniの実約定、手数料前。11:21の停止は残1枚の手動決済による台帳不一致であり、売買手法の問題とは分ける。

## 改修候補S01

**主担当と追加担当は維持し、別入口の2枚枠だけを変更する。** 所定の利益へ到達したら、確定益と残玉含み益を合わせた最高利益の半分を返済の目安にする。さらに元D07を仮想で並行運転し、元の玉が残っている間は、早期利確で空いた枠から別の新規を始めない。

## 採らなかった変更

基準を含む23条件を二巡比較した。全担当を早期利確するG01は、今日の模型損失を減らす一方、過去51場の収支を＋327,000円まで減らした。初回1枚から段階追加するC03も＋1,910,000円へ低下。進行済みの波だけ少量にするJ系列も、伸び続ける勝ちの減少を補えなかった。

S01は全面的な優越ではなく、**利益の回収と再参加を一緒に直す候補**。主担当の初回5枚が逆行する損失は残る。今日12:08未満の模型時価は元D07−94,000円、S01−68,000円だったが、手動返済後の実口座成績を再現した数字ではない。

旧00145のD07研究と現行Goには売買経路・収支の差があるため、今回は現Goを同じ再生器で比較した。詳細は検証記録に記載。全資料は既知データであり、未見期間での改善は未確認。アプリ本体・配布版・稼働設定は変更していない。
