# 自動モード20方式で判断できる範囲

`modes/run.py`、`engine.py`、`features.py`、特徴定義、方式の事前固定書を読んだ設計レビュー。損益・注文明細は読んでいない。既存ファイルは変更していない。

この比較で確認できるのは、**事前に定めた追従・反復・見送りの区分と各注文ルールを組み合わせたときの結果**。自動選択が市場の将来を正しく見分けたことや、板情報そのものの予測力を、利益だけから断定することはできない。

| 比較 | 主に確認できること | 解釈の境界 |
|---|---|---|
| T00・R00・A00 | 追従の機会だけ／反復の機会だけ／両方を使う運転の比較 | T00・R00も同じモード判定器で対象外の時間は休む。常時追従・常時逆張りとの比較ではない。A00は単一保有のため、一方の保有が次の別モードの入口を塞ぐ。A00の利益が大きいだけでは選択精度を証明しない。 |
| T00→T01、R00→R01、A00→A01 | 板確認を新規入口へ加える効果 | 板の方向選別に加え、欠測・古い板・広い気配差の時間も除く。取引数・時刻・保有時間が変わるので、利益改善だけで板固有の予測力とは呼ばない。 |
| A01→A02 | 反復入口の板確認を、推定売買の逆行と補充・近傍変化の一致へ置き換える効果 | 追従入口の板条件は共通。吸収を付け足す比較ではなく、反復側の板条件の置換。個別注文の補充主体や隠れ注文を同定してはいない。 |
| A00→A03/A04、A03→A04 | 経過時間による短縮の有無、早い時刻と遅い時刻 | **追従1.5ATR／反復0.5ATRまで一度も順行していない取引には短縮が発動しない。** 初めから逆行する損失への早期撤退を試した比較ではない。 |
| A00→A05/A06、A05→A06 | 最高含み益価格の更新停止を短縮理由にする効果、停止10分と20分 | 同じく順行条件達成後だけ。A03とA05は時計だけでなく短縮幅の段階も異なるので、その差を「時間時計と更新停止時計だけの差」とは呼ばない。 |
| A00→A07 | 板逆行を利益保護の短縮理由にする効果 | これも順行条件達成後だけ。板が入口直後の誤りを検知して損切りを早める比較ではない。 |
| A01→A08/A09、A08→A09 | 板入口を共通にした複合出口、時間短縮と更新停止短縮の比較 | A08/A09は通常短縮と板逆行短縮を同時に加える。板入口ありの「時間だけ」「更新停止だけ」の対照がないため、複合改善を一部品だけの成果に割り当てられない。 |
| A00→A10/A11 | 反復の黒字トレール返済後に反対方向を狙う運転 | A10とA11は板確認の有無だけでなく、通常の価格条件・1呼値と0.2ATRの入口・待機の扱いも異なる。反復モード継続中、返済後120秒以内に限定され、全ての利確後に無条件反転するわけではない。 |
| A00→A12 | 非中立のモード変化・追従方向変化を認めて退出する効果 | 中立になっただけでは退出しない。A13は板入口・更新停止短縮・モード退出の組合せであり、A09との比較でも二つの出口要素が変わる。 |
| A00→SR01、SR01→SR02 | 反復入口を20分高安の端へ置き換える効果、追従入口へ突破を要求する追加効果 | SR01は平均からの乖離と現在価格による高安近傍の条件を置き換える。支持抵抗という概念の有無だけを比較したものではない。 |

モード判定は、過去20実分の価格効率、EMAの現在の方向、過去ATRとの比率、価格範囲を使う。両市場の最新EMA方向が一致した追従と、一定範囲の往復を示す反復を区分し、どちらにも合わない時間を休む。これは機械的に実行可能な**過去状態の分類**であり、その状態が次も続くことは結果を確かめる必要がある。

板は原本公開順を守る30～60秒の集計で、元観測から20秒以内などの鮮度条件を持つ。足が確定する前でも板条件は更新できるが、モード区分は遅延を置いた確定足に依存する。最初から全判断を生板だけで行う方式や、一注文ずつの主体・意図を復元する方式ではない。

今回だけでは未確認なのは、同じ取引回数・保有時間へ合わせた板なし対照、固定モードを相場区分に関係なく運転する対照、順行前からの時間損切り、各複合条件を全て一つずつ分離した比較、未見セッションでの再現性。単純な利益増加に加え、損失・最大下落・取引数・活動セッション数・追従側と反復側それぞれの損益を見ると、何が改善を生んだかを判断しやすい。

また、20方式は既存候補1の部分決済・仮想運転時計を使わない新しい共通試作器。既存候補1より利益が大きくても、その差の全てをモード選択だけの効果とは呼ばない。
