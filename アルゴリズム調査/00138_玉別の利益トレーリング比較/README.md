**改善は限定的。** 追撃28組のうち9組改善・3組悪化・16組同じ。元の負け追撃の改善は+72,000円、元の勝ち追撃の差引変化は−52,002円、差引+19,998円。10月13日デイの追撃ショートは09:53:19に67,590円で3枚新規。従来は部分利確後の残2枚を13:24:06に67,790円で返していたが、変更版は11:07:01に67,430円で返し、追撃全体−29,230→+42,770円。一方10月15日デイでは早い利確で追撃利益を78,000円削った。10月16日デイの場収支は−111,070→−71,072円。

0.5R順行から0.5R追尾する早期版C_A050W050は赤字を16場へ1場減らすが、累計は+1,454,284円へ低下。1枚・2枚だけの早期利確も一律改善ではない。入口2枚固定のP系列と、時計配分のC系列を混ぜずに比較する。C_段階短縮の買い収支+437,484円・売り+1,307,802円で、双方黒字でも売り側への寄与偏りは残る。

対象は9月21日デイ〜10月21日デイの既知45場。NK225mini、片方向上限10枚、主担当最大5枚、実測最大同時5枚、全場参加、片道38.5円/枚を注文ごと切捨て、倍率100円。24新条件1080会計、旧4対照は保存結果を再利用。利益/損失は初回＋追撃を一組として費用後損益を正負に分類した値。返済注文単位の正負とは区別する。

R=max(初回判断時公表ATR,20円)。追撃自身の建値以降、清算側BBOで順行幅と利益床を更新。判断後の次正常原行で約定し、元親返済が同じ行なら優先。利益床を飛び越すことがある。初回の損切りは変更せず、追撃を利確した後の再追加も行わない。

未検証：2→1→1→1枚のような複数回追加、初回損切りの拡大、TOPIXでの同条件、実mini板、Go本体の数量変化による後続判断、未知期間。この比較は既存の因果的な通知を固定した出口層の検証。稼働アプリ・dist設定は変更していない。API取得0、実注文0。
