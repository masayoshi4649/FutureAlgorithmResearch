# 毎日参加と両銘柄の利益率改善

最初に見る資料は、[全12条件と両商品41場の損益](毎日参加する三系統と全セッション損益.html)です。手数料0・全41場参加は達成しましたが、平均価格幅0.5%は全条件で未達です。

## 今回の指定

日経とTOPIXのそれぞれで各セッション1回以上の実新規を行い、平均で価格自体の0.5%の値幅を目指します。TOPIX4,000なら20ptです。数量可変の会計では収支÷（上限枚数×倍率）へ換算し、場初採用価格に対する割合を使います。無取引や極少枚数の飾り取引を成功へ数えません。

比較設計は、確定した各セッションでの通常数量参加を扱い、入口・継続・出口を検証します。最新指定に従い手数料は0とし、気配差・次原行約定・含み損を含め、両商品を分けて示します。TOPIXミニ上限10枚・日経マイクロ上限20枚を比較尺度として引き継ぎます。
