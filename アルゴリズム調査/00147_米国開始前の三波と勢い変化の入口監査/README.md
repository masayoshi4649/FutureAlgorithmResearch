## 計算と実際の利用を分ける

| 観点 | 現行D07 |
| --- | --- |
| 30秒・120秒・5分・20分・40分の価格変化 | 計算し、方向支持などに使用 |
| 移動平均の傾き | 日中の基本入口で使用。夜間基本は別の突破型 |

夜間は10枚のうち基本5枚枠が標準設定22:52まで新規禁止。残り5枚枠は40分価格帯を必要とし、最初に全特徴が揃ったのは17:42:14でした。このため「夕方から方向転換へ素早く参加する」設計にはなっていません。

## 傾きの変化は当時のデータから計算できる

今回、確定1分足だけから3・5・10・20本の回帰傾きと、その1分前・5分前との差を全区間で計算しました。足末＋60秒の公開条件を置き、未来値を変更しても過去値が不変であることを検査しています。

- 17:15の日経5本傾きは＋1pt/分。1分前比＋21で、負から正への変化がありました。
- 20:25は＋7pt/分、1分前比＋3。上向きが強まる状態を数値化できます。
- 19:05は−13pt/分、1分前比＋8。これは下落の減速で、上昇への転換とは別です。

これらの時刻はユーザーの指摘区間に合わせた事後の診断点です。傾きの変化から自動的に選んだ注文時刻ではありません。短期傾きは一つの大波の途中でも正負を繰り返します。「加速度が負だから売る」という単独条件は、上昇の一休みでも売ってしまいます。

## 改善を考える対象

米国開始前を独立した入口として設計するのが妥当です。方向の強さと、その強まり・弱まりを分け、40分帯突破と押戻りだけを必須入口にしないことが課題です。基本的な候補は、短期・中期の価格傾き、傾きの変化、二市場の支持、板圧力の推移から初動を判断し、減速だけでは反転扱いせず、反証とトレーリングで管理するものです。

今回は現在の欠けている判定と、取り逃しの原因を確認しました。新入口を組み込んだ損益改善はまだ測定しておらず、稼働中のアルゴリズム・設定は変更していません。日中や米国開始後の手法をこの3波に合わせて変える判断はしていません。
