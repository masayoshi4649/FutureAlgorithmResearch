# 昼夜別損益と夜間不調の検証

最初に見るファイルは [昼夜別の損益と検証方針](昼夜別の損益と検証方針.html) です。読む順序はHTML、[保存会計の再集計](../../work/daynight127_20261020/昼夜と方向及び前後半の保存会計再集計_最終.json)、[元調査](../00126_E01の損失抑制と方向偏りの再検証/README.md)です。

レビュアーの昼夜差の指摘を、既存43場のGU_Q・G_Qの注文別手数料差引会計で検証しました。新しい金融再生・原本読取・API接続は0です。二担当の独立集計で昼夜収支、黒赤場数、中央値、上位3黒字除外、前後半、週別を確認しました。日中の両候補44商品場は手法名以外の保存会計が完全一致します。

結論は、E01改修を日中候補として扱い、夜間の別設定・別手法を分離して検証すること。日中にも下落方向への収益偏りがあり、毎場安定の確立とは呼びません。夜間で成功する別手法は今回未検証です。

初回再集計では、黒字がない小区分でも最高収支の場を除外していました。最終版は黒字がなければ除外しない定義に統一。主要な全昼夜の比較値は変わらず、修正前資料も保存しています。
