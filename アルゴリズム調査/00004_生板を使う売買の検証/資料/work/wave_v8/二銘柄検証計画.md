# 二銘柄の板を併用する追加検証計画

ユーザーが追加した「NK225とTOPIX両方の板を見る」という範囲を、既存108条件とは別の追加48条件として検証する。本計画と条件コードを保存してから追加結果を計算する。既存108条件の集計結果を読んで追加閾値を調整しない。

## 情報を利用できる時刻

各銘柄の板特徴は、原本の次の異なる取引時刻を確認した後で解放する。他銘柄はその解放時刻からさらに60秒が経過するまで使わない。自銘柄の特徴解放時刻において、参照可能な他銘柄特徴のうち最新のものを過去方向のas-of結合で選ぶ。

- 基本条件: 他銘柄解放時刻 + 60秒 <= 自銘柄特徴解放時刻。
- 他銘柄の情報年齢: 自銘柄特徴解放時刻 − 他銘柄解放時刻 <= 180秒。
- 両銘柄とも、元ブロックの解放遅延が60秒を超える特徴は新規方向判定に使わない。
- 他銘柄が存在しない、古い、元ブロックが古い場合は全方式で方向ゼロとする。C09の中立許容も、他銘柄データ自体が無効な場合には適用しない。

ファイルを跨ぐ受信時刻は存在せず、両銘柄の行番号にも共通の時計はない。したがって厳密な同時観測・厳密な受信順の証明とは呼ばない。既に見えていた他銘柄情報だけを遅延付きで使う検証である。

方向は自銘柄特徴の解放時に更新する。その後の新規条件作成には既存共通実行器の最大60秒の自特徴鮮度制限がある。他銘柄の鮮度は方向判定時点の条件であり、各raw気配行で再計算しない。したがって基本条件では方向判定時180秒以内、注文条件作成時は最大240秒以内になる。作成済み条件注文は中立化だけでは直ちに取消さず、反対方向・25分失効・自特徴の陳腐化という共通規則で管理する。実約定までに同方向の板が残り続けることを条件にはしない。起動直後など他銘柄特徴が0行の場合も、例外ではなく全方向を中立にする。

## 追加する12系統

既存の単銘柄板方向を構成部品として使う。OFIは符号付き和/絶対値和の±0.15、気配更新方向は±0.15、純数量変化は±0.12、最良数量偏りは±0.20。直近窓は原則300秒、自OFI60だけ60秒。平均・比率は既存モデルの定義をそのまま使い、各板方向には30秒の同方向持続確認がある。

「多数決」はOFI・気配更新・純数量変化の三成分を、それぞれ±0.10で判定し、同方向二つ以上かつ逆向きゼロを求める既存B12とする。価格方向は確定足に追加待機を置いた既存CUSUMである。

| ID | 条件 |
| --- | --- |
| C01 | 両銘柄のOFI300秒が同方向 |
| C02 | 自銘柄のOFI60秒と他銘柄のOFI300秒が同方向 |
| C03 | 両銘柄の板フロー多数決300秒が同方向 |
| C04 | 両銘柄の最良数量偏り300秒が同方向 |
| C05 | 両銘柄の表示数量純変化300秒が同方向 |
| C06 | 自銘柄価格CUSUMと他銘柄OFI300秒が同方向 |
| C07 | 自銘柄価格CUSUMと他銘柄多数決300秒が同方向 |
| C08 | 自銘柄価格CUSUMと他銘柄気配更新300秒が同方向 |
| C09 | 自銘柄多数決300秒を使い、他銘柄多数決が逆なら見送る。他銘柄中立は許容 |
| C10 | 両銘柄価格CUSUMと自銘柄OFI300秒が全て同方向 |
| C11 | 他銘柄多数決300秒の方向だけを自銘柄の売買に使う |
| C12 | 両銘柄のOFI・気配更新・純数量変化の6方向中、同方向4票以上かつ逆向きゼロ |

各系統に入口2種類（逆指値/追跡1ATR）と出口2種類（利益保護/自銘柄の板反転併用）を掛け、48条件とする。群名は `２銘柄の板`。

両銘柄に同方向の傾向があることを仮定した方向確認・他銘柄先行の候補であり、片方の未来を先に読んだ売買ではない。二銘柄間の価格差の裁定、両建て、ペア逆張りを追加したものでもない。

## 約定・評価と選択

自銘柄の全有効raw気配を既存 `simulate` で再生し、入口・出口・費用・45分待機・セッション内返済は既存108条件と共通にする。板反転返済は自銘柄だけを見て既存の圧力反転条件を使う。

最初の2セッションから第3を評価し、その後も直前までの保存セッションだけで条件を選ぶ。選択規則は既存 `research.choose` と同一で、追加48条件の中だけで選択する。元の108条件と合わせた事後の条件選びにはしない。

全既知5セッションから選んだ候補も別掲する。以前に読み込まれた9/23ナイト部分は今回の板研究に対する新しい独立ホールドアウトとは呼ばない。

時間順で選ばれた条件と既知5セッションからの条件を対象に、約定遅延を次の有効raw行から2行後・次の取引時刻へ変更した感度を保存する。

他銘柄時計の感度では基本60秒で選択した条件を固定し、追加待機を120秒・300秒へ延長する。鮮度は「参照可能になってから120秒以内」で統一し、元時刻からの情報年齢上限はそれぞれ240秒・420秒とする。遅延ごとに条件を選び直さない。
