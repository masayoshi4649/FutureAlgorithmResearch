# 板特徴の作成方法

`raw_features.py` は保存された生板だけを読み、APIへ接続しない。最良買い気配には `Buy1`、最良売り気配には `Sell1` を使う。トップレベルの `BidPrice` / `AskPrice` は使わない。

## 未来の行を使わない処理

1. 原本の行順に読み、`CurrentPriceTime` が同じ連続行を一つのブロックとして集計する。
2. 次の異なる `CurrentPriceTime` の先頭行を読み込むまで、そのブロックの方向特徴は利用しない。
3. 解放される特徴は直前ブロックだけを参照する。`source_last_seq < seq`、`source_time_s < time_s` が必ず成立する。
4. 解放時の `bid` / `ask` は現在の先頭気配であり、方向特徴と区別する。
5. 最後のブロックは次の取引時刻を確認できないため破棄する。原本を途中で切っても、それ以前の解放済み特徴は変わらない。

受信時刻が記録されていないため、`CurrentPriceTime` は時間の代理である。同じ取引時刻に属する途中の板変化を、その時刻で知っていたことにはしない。ただし実際の受信間隔や通信・発注遅延そのものは復元できない。

## 計算する情報

| 列 | 計算・意味 |
| --- | --- |
| `imb1/imb5/imb10` | 上位1/5/10段の `(買数量−売数量)/(買数量＋売数量)` のブロック平均 |
| `micro_bias` | 最良数量加重価格とmidの差をspreadで割る。定義上 `imb1 / 2` と同じ情報 |
| `ofi_signed` | 最良買い・売り気配の価格と数量の変化から計算した標準OFIの和 |
| `ofi_abs` | 各行のOFI絶対値の和。符号付き合計の絶対値ではない |
| `quote_up/down` | 最良買い・売り気配が上方/下方へ動いた回数の合計 |
| `quote_move_ticks` | midの変化幅を呼値で割った符号付き合計 |
| `added_bid/removed_bid` | 前後両方の上位5段で見える同じ買い価格の数量増加/減少 |
| `added_ask/removed_ask` | 同じ条件の売り数量増加/減少 |
| `trade_pos/neg/unknown` | 累積出来高の増分をtick-ruleで分類した推定数量 |
| `source_mid_last` | 過去ブロック内の最後の有効mid |
| `block_delay_seconds` | 過去ブロックの取引時刻から、解放に使った次の取引時刻までの秒数 |

平均は有効なraw行に等しい重みを与えるイベント平均で、時間平均ではない。同じ板の再出現も平均に含むが、同じ板はOFI・数量差分を増やさない。

数量減少を取消と約定に分離する情報はない。`trade_pos/neg` も真の買い手・売り手主導分類ではない。約定価格が上がれば正、下がれば負、同値なら直近の非ゼロ変化方向を継承して出来高増分を分類する。

ロック板・交差板・最良数量不正は除外し、その前後を跨ぐ差分とtick-rule状態はリセットする。解放時先頭板が不正なら、その過去ブロックの方向特徴行を出力しない。欠損時刻行も状態をリセットする。原本時刻の逆行、または特徴に含まれる出来高時刻が解放時刻を超える場合は処理を停止する。

## 注文監視用の別系列

`約定系列_{銘柄}_{セッション}.npz` は、通常監視区間にある全有効raw気配を原本順で保存する。既存のストップ・追跡価格はこの全系列で監視する。同じ取引時刻ブロックの途中で発生した逆行を飛ばしてはいけない。

未解放末尾ブロックの気配もこの監視系列には含める。末尾気配で既存注文を監視することと、未確定ブロックから新しい方向特徴を作ることは別である。

## 再生成

```powershell
python -X utf8 work/wave_v8/raw_features.py
```

出力先は `work/wave_v8/features/`。各入力に特徴CSV、同列のNPZ、全気配NPZ、SHA256と除外件数などの監査JSONを保存する。

```python
from pathlib import Path
from raw_features import extract_features

quotes = []
frame, audit = extract_features(
    Path("book/NK225/2026-09-23_Day.jsonl"),
    "NK225", "2026-09-23_Day", max_rows=20000, quotes=quotes,
)
```

`max_rows` は先頭から読む原本行数。省略すると全件。`quotes` は省略可能な全気配出力用リスト。
