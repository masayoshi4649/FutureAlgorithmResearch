# 時間窓合議と入口の安定性

最初は [時間窓合議と入口の安定性.html](時間窓合議と入口の安定性.html) を確認する。元候補と多数決の比較を先頭に置き、細かな診断は折り畳んだ。

読む順序は次のとおり。

1. [結論と元候補との比較](時間窓合議と入口の安定性.html)
2. [全32条件のセッション別・週別損益](全条件の損益.html) — 利益・損失・収支の円、勝ち・負け・同値の決済枚数。
3. [５分足と売買](５分足と売買.html) — 単一中央／多数決中央×A0／C01の104画面。3窓の票と実際の入口、全新規・減量・復元・返済を表示。

狙いは、黒字候補H019の「判定の時間幅を変えた際の弱さ」を改善できるか確かめること。単一窓と、3つの時間幅による多数決・反対票拒否・全一致を、同じ注文管理と枚数で比較する。

入口12仕様×出口2種類に、主案の執行診断8条件を加えた32条件。今回の入力では同じ方向列になる2仕様があり、12個の独立予測とは数えない。全13セッションは既知データ。現在APIの追加取得は0回。

多数決の中央設定は両出口・両銘柄で黒字だが、元の単一中央より減益。時間幅を変えた場合の大勝ち依存も解消せず、今回の合議への置換は支持されなかった。従来C01の全13収支はTOPIXミニ＋543,000円／NK225マイクロ＋263,200円、多数決C01は＋510,000円／＋256,000円。初回5／10枚、片方向上限10／20枚、費用0・指定価格約定、場内全返済。
