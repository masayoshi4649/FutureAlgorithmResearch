# D07と比べて、何が直り、何が残ったか

**S01は一部改善、O01は収益拡大型です。ご指摘の入口・利益保護・短期回転をまとめて解決した新アルゴリズムは、まだできていません。** 前回の数量比較だけでは、この区別を説明できていませんでした。

最初にこの説明、数値の詳細は [D07と改修候補の日中損益.xlsx](D07と改修候補の日中損益.xlsx) の比較→手法別シートの順で見てください。[根拠と比較条件](検証記録.md)は別にまとめています。

## 同じ26デイでの比較

日経mini片方向上限10枚相当、手数料0、次正常ラージ気配での約定。2026/9/21〜10/26の保存済み26日中だけを比較し、夜間・10/27途中・10/28は含めません。

|手法|累計収支|赤字場|赤字場の平均損失|場内最悪収支|
|---|---:|---:|---:|---:|
|D07：改修前|+1,906,000円|8|65,875円|−203,000円|
|S01：別入口の利益保護を改善|+1,935,000円|8|53,500円|−203,000円|
|O01：支持で初回量を変え、順行時に追加|+3,336,800円|10|110,890円|−347,300円|
|F05：全玉を利益発生後20ptで追尾|−366,000円|14|33,571円|−104,000円|

場内最悪は確定損益＋全残玉の返済側気配による含み損益です。S01は当場の最高時価からの最大下落も373,000→294,000円へ減らしましたが、赤字8場と場内最悪−203,000円は変わりません。O01は増益しても、安定性の改善とはいえません。

「1〜2枚保有中に残玉含み益が正になり、その一連の売買が最終赤字になった」件数は、**D07の37/96件→S01の25/96件**へ減りました。同じ仕掛けの追加・部分返済をまとめた単位で、残り1枚だけの最終損益や、将来の勝率ではありません。

## ご指摘への回答

|ご指摘|原因と変更|現在の評価|
|---|---|---|
|1枚の利益を失う|確認した1枚は試し玉ではなく、部分利確後の残玉。D07には先の確定益を残玉の損失予算に使う設計があった。S01は別入口2枚枠で、所定利益から親最高益の半分を保護する|**一部改善**。主担当などの残玉まで全面修正していない|
|自信満々に大きく入り、すぐ損をする|D07の5・3・2枚は確信度ではなく担当別の固定枠。10/27の10:37の5枚売りも追撃ではなく別担当の初回。S01はこの配分を維持|**未解決**。新しい支持比例配分も、強い支持ほど勝つ裏付けが弱い|
|上がり切った所で買う|10/27 15:00前は確定足で前3分+110pt、直近2分0pt。停滞は当時検知可能だったが、主担当は短い再上昇を買い、停滞を拒否条件にしていなかった|**未解決**。停滞を一律拒否すると、その後伸びる勝ちも失った|
|利確が遅いのに損切りは早い|損切りは新規直後から有効だが、主担当の利益保護は黒字の部分返済後が中心。利益が乗っただけでは同じ保護が働かない|**未解決**。S01の別入口保護も、所定利益への到達前は起動しない|
|利益が乗った瞬間にトレールがない|全玉に即時の利益床と20pt追尾を付けたF05は検証済み。利益玉の赤字化は減ったが、26場収支は−366,000円|**機能は作れたが、収益性の解ではない**|
|1分内の値動きに反応しない|板受信に応じた判定でも、起動幅・継続確認・再参加制限を満たさなければ注文しない。S01には早期利確後の再参加を抑える仕組みもある|**短期回転として未解決**。早期利確後の再参加も検証したが、損失と気配差が増えた|

**O01は、これらの問題を直した版ではありません。** 元の入口・元玉の退出を残したまま数量を増減する研究案で、アプリへは導入していません。S01は導入済みの部分改修ですが、「最初から全玉の利益を守り、失速を見て降り、条件が戻ればすぐ入り直す」設計にはなっていません。

次に必要なのは、入口・追加・利益保護・再参加を別々の状態として設計し、個々の玉の利益返しと、その後の取引まで合わせて検証することです。単にトレールを狭める、枚数を変えるだけで解決したとは扱いません。

特に主担当は、元のATR基準トレールの開始が1.5ATR順行後、部分利確が2ATRです。初期損切りは最初から有効なので、例えば入口ATRが100ptなら+50ptでもこれらの利益保護は起動しません。通常の追尾幅も3ATRあり、起動しただけで建値以上を守るものではありません。これが「利益には鈍く、損失には早い」と見える具体的な設計理由です。

今回は既存の結果・コード・実約定の照合です。新しい売買判断の再生、現在セッションAPIの取得、アプリ・実口座の変更はしていません。
