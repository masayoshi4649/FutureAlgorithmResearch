1. [共通知見台帳](../共通/知見台帳/README.md)：現在の知見Markdown。
2. [試行履歴と事前照合](試行照合/README.md)：同じ試行を繰り返さないための記録とツール。

知見本文は共通のMarkdownへ移行しました。試行履歴・移行前JSON・照合コードは `試行照合/` に保管し、不要になった共通のHTML・JS・CSSは削除しました。検証記録の旧パスとSHA256は検査当時の証跡として保持しています。

同じ発想を繰り返しただけなのか、条件・対象データ・約定・実装を変えた検証なのかを区別します。未整理の過去試行は残っており、全履歴の重複を解消済みとは主張しません。
