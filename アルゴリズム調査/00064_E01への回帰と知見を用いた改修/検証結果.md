# E01と改修の結果

E01は候補として残る。16条件の部品比較では、新規時に両銘柄のEMA開始条件を再確認する **R01** が有望だった。入口以外は元E01と同じ。

初回TOPIXミニ5枚・日経マイクロ10枚、上限10/20枚、増玉なし。ラージ価格で換算。以下は全28セッション・手数料後。

| 手法 | TOPIXミニ | 日経マイクロ |
| --- | ---: | ---: |
| 元E01・観測値で全再運転 | +538,388円 | +209,700円 |
| R01・観測値で全再運転 | +615,981円 | +235,140円 |
| 元E01・同じ注文を売買気配に置換 | +370,888円 | +128,100円 |
| R01・同じ注文を売買気配に置換 | +436,981円 | +167,740円 |

気配置換は、注文時刻・数量を固定した価格感度。損切り線や再エントリーは再計算していない。小商品自身の気配、全枚数の板消化、発注遅延も再現していない。

R01は前16場だけで定めた選定基準により、指定価格・観測価格の両モデルで選ばれた。全28場の最大利益日を除いても、観測値版R01はTOPIX+324,897円／NK+155,260円。ただし後12場では、その最大利益日を除くとTOPIX−148,556円／NK−34,940円。全期間の黒字と後半の安定性を区別する。

後12場の気配置換では、元E01はTOPIX+17,443円／NK+10,920円、R01はTOPIX+37,528円／NK+8,640円。直近3場のR01はTOPIX−15,933円／NK−18,700円だった。改修があらゆる期間で元E01を上回った訳ではない。

観測値版R01の部分決済勝率は両銘柄約56%。95%には達していない。1枚平均利益／損失は約2.4倍／2.3倍。初回から全返済までの組勝率は部分決済勝率より低く、主HTMLで分けて表示している。

再参加時計を早い出口に合わせるR10は、観測値版でTOPIX−107,665円／NK+59,100円。1ATR順行から幅1ATRで追跡するR08は勝率約60%へ上がったが、全収支は元E01より小さい。強い確認を待つ0.5ATR新規R06も、日経で赤字へ悪化した。条件追加や早い出口だけで一律に改善する、という結果ではなかった。

旧E01の23場46口座は全注文・決済・組が元台帳と完全一致。追加5場の指標生成と、改修接続器の切断・未来変更検査、32条件1,792口座の独立FIFO会計は合格した。原板と保存足のOHLCが少数一致しない点は入力監査へ記録し、比較には元E01と同じ保存足を使った。

今回の位置づけは、既知データを含む時間順の再検証。将来の安定利益を証明したものではない。現在API取得・実注文0、既存App/E01は変更していない。
