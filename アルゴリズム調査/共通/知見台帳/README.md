前段の入口再点検は[00117の意味のある値幅と方向先着](../../00117_方向予測の有効幅と探索方針の再点検/README.md)。到達と逆行前到達の差、±0.05/0.1/0.2%の二起点採点、固定方向対照、価格資格による多数の打切を入口へ追加。解決例だけの55〜58%を全候補の正答率や取引勝率と呼びません。

各項目には、知見を得た調査、条件、確認できた結果、適用範囲と未確認点、詳細な根拠を記載します。割合は銘柄別の「何件中何件」を伴う実測値です。未確認の案は既知の事象と区別します。

## 出典と更新

- 5桁番号は、知見を得た**既存の調査フォルダ番号**です。知見そのものに新しい番号は付けません。
- 各項目の冒頭に、例として **出典：[00099_板の定着と進行失敗の入口検証](../../00099_板の定着と進行失敗の入口検証/README.md)** のように記載します。
- 検証した調査と後で分析した調査が異なる場合は、両方を記載します。未公開の作業資料には、存在しない調査番号を割り当てません。
- 追加検証は同じ事象の項目へ追記し、新たな調査フォルダを出典に加えます。
- 研究名単位ではなく、一つの条件と観測事象を単位にします。複合条件しか測れていない場合は、その限界を記載します。
- 新しい調査の前に関連項目と根拠を読み、何が未確認で、前回から何を変えるかを決めます。
