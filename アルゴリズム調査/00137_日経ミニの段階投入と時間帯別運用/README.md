## どの条件で追加するか

Wparentは現行と同じ入口でまず2枚。初回判断時の公開ATRと20円の大きい方をRとし、実際に返済できる気配が初回約定から0.25R以上順行し、初回から30秒以上が経過し、新しい相手観測を受けた上で、両市場の30秒変化が各0.05ATR以上・120秒変化が各0.2ATR以上の状態が15秒続けば3枚追加します。逆行中の追加はしません。条件を判断した次の正常原行で約定します。

元親が部分返済した後は追加しません。追加は1親1回。元の損切り・部分返済・利益追尾を初期玉と追加玉へそれぞれ整数配分して適用します。**追撃の独立停止をなくすことは、損切りをなくすことではありません。** 「支持が強い」はこの測定条件を指し、将来勝率を校正した確信度ではありません。

CWparentはこれに初回数量の切替を追加。寄付前・昼休み・米08:30前後15分・米現物寄付前後15分は1枚、それ以外は弱支持2枚、既に強支持なら5枚。警戒時間帯の追撃は控えます。米欧時計は地域別の夏時間に連動。保有玉を時刻だけで必ず返す設計ではありません。

## なぜ修正したか

第一巡のC02aは追加玉だけ0.5R停止にしていました。10月19日10:17に64,730円で3枚を追加し、64,580円で切って−45,230円。最初の2枚は+73,847円を残していました。これを含む39追撃は8勝31敗・−25,969円でした。

入口・枚数を固定し、追撃も元親の出口へ合わせた第三巡Wparentでは、同じ39追撃が22勝17敗・+755,035円。追加利益上位3親を除いても+357,725円。狭い追加停止が通常の押し戻りを切った機構を、同じ入口の対照で確認しました。初回玉の利益で追加赤字を隠す集計にはしていません。

## 時間帯を分ける案の結果

日本時間の寄付前・前場・昼休み・後場・現物引け後、夜間17〜19時・19時以後・米08:30前後・米現物前後・欧州引け前後を区分しました。19時境界は検証上の便宜的な区切りで、特定市場の開場時刻と断定していません。米08:30に毎日発表があるとも仮定していません。価格診断では現物祝日4場を通常19日と分離しましたが、今回の時刻切替の注文比較では休日専用の係数は設けていません。

米国現物開始前の観測高安幅中央値は日経550円。ただし二市場の2分・30秒支持だけで入る新案は、9月28日18:00の買いと18:10の売りの両方が往復で損切りになりました。米前最悪3場と全23親の内訳は別資料に記録しています。

第二巡では現行NV25の20分価格帯突破・戻り・再進行を使い、米前だけに参加する条件へ変更。2枚固定は米前単独で−93,232円、5枚固定は−233,072円、2枚から追加は−108,462円。各22夜で1黒・7赤・14無取引でした。米国後の元手法と組み合わせると全場参加を保ちますが、元の収益を減らしました。今回の入口を米前へ機械的に延長する案は採用保留です。

08:45〜09:00は既存ATRの初回公開が09:01:00〜01のため、R系でも新規0件でした。この区間の価格診断はありますが、早期専用入口の金融検証はできていません。細かい各区分を別手法に最適化した結果とも区別します。
