## 確認できたこと

- 指標を増やすだけでは安定しなかった。検討黒字だったI/Fの18区分中、確認でも黒字は2区分。テクニカル一般の不可能性を証明した結果ではない。
- 利益を早く守る部品には局所効果があった。日経10月16日日中の同入口では、I/Tの−20万円に対しFは0円。ただし後からその日だけFへ切り替えるのは不可。
- 指標出口も常に改善ではない。日経夜間の固定候補は、初回入口が一致する25場の各初回取引だけではIが−39万円、Tが−28万円。TOPIX夜間の11場の各初回取引だけではFが＋1万円、Iが−8.5万円、Tが−15万円。入口を揃えた範囲で効果が異なる。
- 0.01%の利益床は利益の保証ではない。判断後の次の正常気配までに戻され、0円返済になる例もあった。
