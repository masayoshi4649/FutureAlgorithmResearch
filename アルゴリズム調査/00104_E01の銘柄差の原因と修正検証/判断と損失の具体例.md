# E01の銘柄差と、何を直すべきか

**出口幅だけの調整ではTOPIXの赤字は解消しなかった。入口の方向票を厳しくすると両商品が黒字になった。全体の作り直しが必要だとは、今回の結果からは言えない。** ただし取引する場が少なく、毎場安定して利益を出す方法を確立した結果ではない。

## 同じ条件で日経がよかった理由

比較元は `E01_ANCHOR_W60_CONFIRM_D0_P1_L2_A1`。既知33場のTOPIXミニ・日経マイクロを、ラージの正常気配で次行約定させ、注文ごとの両側手数料を含めた。片方向上限は10／20枚、各新規は5／10枚以下で当時のATR・気配差・手数料に応じて数量を選ぶ。方向票は直近60秒の出来高更新と現在値・直前気配による代理で、真の買い／売り注文数ではない。時計も価格時計の代理。

| 比較元の完結取引 | TOPIXミニ | 日経マイクロ |
| --- | ---: | ---: |
| 勝ち／負け | 12／7 | 22／2 |
| 手数料前の収支 | −9,000円 | ＋4,200円 |
| 手数料後の収支 | −10,642円 | ＋3,386円 |
| 平均勝ち／平均負け | 911円／3,082円 | 270.5円／1,283円 |
| 負けのうち、保有中一度も費用後黒字にならなかった取引 | 6／7 | 2／2 |

日経も一敗は一勝より大きい。**日経がよかったのは小幅利確の成功回数が多かったため**で、損小利大の幅を備えていたからではない。日経の買い合計は＋4円、売り合計は＋3,382円。旧条件の好成績には売り方向への偏りがある。

料金を除いてもTOPIXは赤字。観測1呼値の粗利益に対する1枚の往復料はTOPIX16.4%、日経22%なので、単純な「TOPIXの手数料が重い」で説明できない。同じ純1呼値目標でも初期返済側気配から必要な順行は中央値0.336ATR／0.263ATRと異なるが、この尺度差だけでも全てを説明できない。

## 修正して全33場を再生した結果

出口の幅・利確尺度・利益保全の10条件と、入口の票強度・自己／相手価格応答の6条件を結果前に固定した。入口を変えた場合も、見送り後の再参加・実枚数・保有競合を順番に再生した。元の負け取引だけを削除した集計ではない。

| 同じ修正を両商品へ適用 | TOPIXの収支 | 日経の収支 | 判定 |
| --- | ---: | ---: | --- |
| 出口だけ10条件 | 全10条件が赤字 | 一部は黒字 | TOPIXの問題は出口調整だけでは解消せず |
| B01：票の釣合い0.25→0.5、出口維持 | ＋5,096円 | ＋4,706円 | TOPIXの一敗4,082円が平均黒字1,019.8円を超す |
| **B03：票の釣合い0.25→0.75、出口維持** | **＋7,342円** | **＋2,592円** | 数式上の三基準は両商品達成。ただし活動7／8場のみ |
| C01／C02：自己／相手の両気配10秒順行を追加 | いずれも赤字 | いずれも赤字 | 過去の価格順行を足すだけでは改善せず |

B03の平易な説明は、**元E01が出した候補でも、直近の方向票がほぼ一方向に揃うまで入らない。入った後の損切り・追跡返済は維持し、小さい純利益目標へ達したら残玉を返済してその場を終了する。** 少なくとも2方向票が必要。釣合い0.75は、既知の買い／売り票のうち注文方向が87.5%以上という比率条件で、将来の成功確率75%を意味しない。

TOPIXでは旧損失21,574円を避ける一方、旧利益4,508円も失い、後の新しい入口で918円を得た。日経では旧損失2,566円を避けたが、旧利益3,816円も失った。見送りの効果と失う機会の両方を含む。

## どこまで結論にできるか

B03はTOPIX7勝0敗・26無取引、日経8勝0敗・25無取引。利益上位3場を除いても＋3,088円／＋1,168円。買い・売り、前16場・後17場の集計も双方黒字になった。もっと緩いB01にも両商品黒字があるため、0.75だけに唯一の効果が現れたわけではない。

一方、B03は全場中央値0円で、無取引を勝ちとは数えない。15取引中7件は2票だけ、13件はナイト。デイの実績は各商品1取引しかない。高い票比率を多数の独立した支持とは解釈しない。

許容損失は依然TOPIX5,000円・日経2,000円、利確目標は初回受理枚数×観測1呼値相当。TOPIX10/12デイの売2枚は保有中の費用後清算が−3,166円から最終＋834円へ回復、日経9/23ナイトの売3枚も−1,566円から＋534円へ回復した。**無敗だったことは、将来の一敗も小さいという証明ではない。** 途中の最悪清算は事後に診断した値で、別の出口の実現損失ではない。前後期間も開発に使った既知データで、未見検証ではない。

現在優先する改修は入口の0.75条件。出口をさらに狭める一括改修や、過去の価格順行を重ねる改修は今回の対照では支持されなかった。観測対象はこの33場・このE01系列なので、TOPIX全般や板読み全般の無効を結論にはしない。
