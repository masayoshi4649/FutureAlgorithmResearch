# E01の銘柄差の原因と修正検証

最初に **[E01の銘柄差と修正後の全セッション損益.html](E01の銘柄差と修正後の全セッション損益.html)** を開いてください。基準・B01・B03を短く比較し、基準＋16条件の全33場を切り替えて表示します。

現在の比較元は [00103の利確調整版と全場表](../00103_往復帯の回避と損失後再参加の統合検証/枚数に合わせた利確修正と全セッション損益.html)。日経は総利益5,952円・総損失2,566円・収支+3,386円、TOPIXは10,932円・21,574円・−10,642円です。

**結論：出口だけの10修正ではTOPIXは全条件赤字。入口票の釣合いを0.75へ強めたB03は、TOPIX＋7,342円・日経＋2,592円で両商品三基準に合格しました。** ただし活動は7／8場、無取引26／25場。15取引中7件は2票、13件はナイトで、毎場安定利益の確立ではありません。

読む順序は次の通りです。

1. [説明と全セッション損益](E01の銘柄差と修正後の全セッション損益.html)：主比較と全場の金額・枚数。
2. [判断と損失の具体例](判断と損失の具体例.md)：TOPIX赤字上位3場の時刻・価格、改修の効果と限界。
3. [公開会計](E01の銘柄差と固定16対照の公開会計.json)：画面に表示した値と参照資料の指紋。

評価は [調査方針](../調査方針.md) の三基準。金額利益割合65%以上、赤字場20%以下、最大赤字を黒字場収支の平均で補えること。費用後の完結親netで金額割合を求め、銘柄を合算して片方の赤字を隠しません。無取引は勝ちに数えません。

入力は保存済みの同じ33場。実際のTOPIXミニ/日経マイクロ板と待ち順位は未観測、ラージ気配の価格代理で、受信時計ではなく価格時計の代理秒を使用します。前調査で現在セッションの一回取得は消費済み。今回のAPI再取得・実注文・ライブApp変更は0です。

B03は利益上位3場を除いても両商品黒字ですが、途中の費用後清算逆行は最大3,166円／1,566円。無敗だったことを、将来の一敗も小さい証拠とはしません。前16・後17も開発済みの既知期間です。
