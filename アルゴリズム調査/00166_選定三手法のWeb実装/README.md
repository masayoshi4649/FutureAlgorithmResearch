# 選定三手法のWeb実装

指定された3手法を `App/SessionTrader` に実装し、日経3商品の標準時間割に設定しました。

| 時間帯 | 手法ID |
| --- | --- |
| デイ | `NK225_D164_15` |
| ナイト開始〜米国開始15分前 | `NK225_P164_06` |
| 米国開始15分後〜ナイト終了 | `NK225_U165_03` |

米国開始前後15分は静観し、切替前の自己玉を返済・照合してから次の手法を開始します。通常の場末返済は設定に従い、標準は立会終了10分前です。

- 部分約定、取消再送、同一建玉IDの異なる建値、手動玉の拒否、片方向上限、11枚などの非整除配分、時間帯・設定変更を人工検査しました。`go test ./...` と `go vet ./...` は成功しました。
