## 午後に新規がない理由

午前限定のルールはありません。標準では主担当の新規は15:30未満まで可能、強制返済は15:35です。研究結果の新規は10:04:46と10:38:22、最後の返済は**12:41:07**でした。実際の約定時刻は今回未提示なので、これらは研究上の時刻です。

現在のE01系は、実際の建玉とは別に「同じ波の途中か」を追う内部の仮想建玉（通常影）を保持します。実玉の利確を早めても、この通常影が終了して5分経過するまでは次の新規準備を始めません。

当日の2回目は初期ATR約6.185pt。出口側は3ATR順行後に追尾幅を**約4.639pt**へ縮め、研究では12:41に全返済しました。一方、通常影の追尾幅は**約18.556pt**のままです。

10:38:22から15:35直前まで、安値からの最大戻りは18.5pt。呼値丸め後の通常影の返済線にも届きませんでした。初期損切り4,057.5に対して新規後最高値は4,054.5、最長保有360分の期限は16:38:22。途中の通常影の全返済条件は成立せず、**利確後も同じ下落の波が続いている扱いになり、再入場を抑止した**と保存経路・設定から説明できます。

午後に売り方向の情報が消えたわけではありません。保存入力では13時台の20,170行すべて、14時台の21,880行中19,209行で短期方向と二市場入口ゲートが売り側でした。ただし、方向資格は新規可能状態とは別です。この原行数を独立した試行数や取引の正答率とは扱いません。

12:30の補完担当も、主担当がその場で一度でも新規約定していれば動きません。今回は午前に参加済みのため追加しません。

## この待機を修正するべきか

**現行運用では維持し、利確後に限定した再参加を改修候補とする。待機の一律解除は勧めない。** 「波の終了」は市場の終点を予知する判定ではなく、旧手法の仮想建玉が終わるまで次の準備を抑える規則である。その幅が最適だと証明されたわけでもない。

最も近い旧対照は、二市場EMA確認を維持したR01と、出口側の終了から5分後に再準備するR11。00064の保存結果から日中14場だけを再集計すると以下のとおり。初回TOPIXミニ5枚・日経マイクロ10枚、片方向上限10枚・20枚、手数料後。

現在の主担当に近い00129でも、二市場逆行撤退後の1回再参加はTOPIX DV07→DV08で22日中収支＋522,633→＋466,797円、最大赤字79,172→107,090円。日経DV05→DV06も＋260,800→＋257,860円、最大赤字25,100→36,320円だった。これは逆行撤退後の対照であり、利確後の再参加を直接否定するものではない。

待機を短くする利点は、10月22日のように利確後も続く方向へ再び参加できること。欠点は、往復や転換で古い方向判断を使い続け、得た利益を再参加の損切りで返しやすくなること。手数料だけでなく建て直す価格と後続の損切りも変わる。

次に比較するなら、**損切り後は従来の待機を維持し、利確後だけ、新しい押し戻りと二市場の再進行を確認して最大1回再参加する**限定改修が候補。具体的な閾値は未固定、改善効果は未検証。追加取引の合計利益だけでなく、黒字場を赤字へ変えた件数、赤字の平均・最大、大勝ち除外後収支を現行と比較して採否を決める。今回、稼働アプリを変更していない。
