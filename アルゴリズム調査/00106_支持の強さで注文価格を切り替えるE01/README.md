# 支持の強さで注文価格を切り替えるE01

## 手法

両市場の主方向が一致する元E01候補を使い、対象市場の直近票で確認する。公開時の支持が強ければ不利1観測呼値まで、弱ければ公開価格までの一回FAK。範囲外なら追わず失効させ、次候補を待つ。数量は当時のATR・気配差・手数料からリスク予算内で選ぶ。途中の減量・損切り・追跡返済は元E01を維持し、費用後の小利益目標へ届いたら返済してその場を終える。全玉をセッション内で返済する。

## 改善と限界

一律のFAK0が勝ちまで逃し、後の負けへ参加してしまった00105の問題から改修した。8新条件は結果前に固定・登録し、新GU264・新政策528を一回実行。旧GU264／旧政策528の同値確認と、旧24結果の表示は追加の有効性標本ではない。

上位3場除外、前後半、買い・売りとも選択一組は黒字。ただしTOPIXのデイ活動は1／17場のみ。保有中には最大3,166円／1,566円の費用後清算損失があった。**確定損失0は、含み損0や将来無敗の意味ではない。** 未見データ、実商品の部分FAK・待ち順位、二市場共通の実受信順は未確認。日経の切替0.75／1.0はこの実績が同じで、二つの独立成功とは数えない。
