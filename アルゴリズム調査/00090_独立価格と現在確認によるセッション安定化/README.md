# 00090 独立価格と現在確認によるセッション安定化

最初に **[独立価格と現在確認の説明と全セッション損益.html](独立価格と現在確認の説明と全セッション損益.html)** を開いてください。読む順序は、結論→平均赤字・最大赤字と活動黒字率の比較→全セッション表です。

53手法を切り替え、TOPIXミニ片方向10枚・日経マイクロ片方向20枚以内の全31場の利益・損失・収支・決済枚数を確認できます。手法の入口・途中・出口は短く表示し、期間別・買売別・源別・中央値と下位25%・最大利益日除外は折り畳みにまとめました。

毎セッション安定して稼げる解は、今回も未達です。53条件を比較しましたが、両銘柄で金額利益80%を達成した条件は0でした。

比較参考はJ8（追従8枚／日経16枚）。両銘柄とも29活動場中17黒字。平均赤字はTOPIX 64,948円・日経 30,688円、最大赤字は190,004円・73,408円でした。

反発の追加はTOPIXの赤字をわずかに軽減しましたが、日経の平均赤字・最大赤字を増やしました。両銘柄共通の安定化としては採用できません。

主の下方偏差は全条件共通上限10／20枚の価格0.1%を比較単位にし、全評価場数を分母にします。実円額・設定数量・実最大保有も併記し、少枚数によるリスク縮小と手法の優位を区別します。無取引は勝ちではありません。目標は両銘柄の金額利益80%・損失20%と安定性です。

全31場は既知です。入力・未来検査の合格は収益成功の証明ではありません。価格観測と執行気配を別源で保持し、旧Q・OFIを救済せず、次有効ラージ気配で仮想約定。両側料金と全玉清算を含み、追加5秒劣化は含めません。実ミニ／マイクロ板、全数量約定、真の受信時計は未証明です。立会時間は[JPX](https://www.jpx.co.jp/derivatives/rules/trading-hours/)を参照しています。
