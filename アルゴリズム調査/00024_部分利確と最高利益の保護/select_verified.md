# 第五反復の選抜資料検証

研究候補は `python -X utf8 work/wave_v29/select_verified.py` で選抜する。元の `research_selection.py` を直接実行せず、資料検証を通してから同じ選抜関数を呼ぶ。準備は `--prepare`。現在データを読まず、追加取得もしない。

元の採用条件・順位・最大2案を変更していない。両銘柄とも、旧主案 H019__D273 と同じ入口の K000 の両方に対して、収支75%以上・含み損を含む最大下落80%以下が必要である。同入口 K000 は各銘柄で黒字かつ最大下落が正であることも必要とする。EMA両系列は同思想として扱う。

ガードは次を確認する。

- 全探索の入口×管理の完全な集合、候補の一意性、固定コードのSHA256。
- 一次反証の予定集合と全実体、26入力の会計集計、反証判定の再計算。
- 同一入口 K000 対照と全探索の該当 K000 の集計・台帳指紋の一致。割合保護だけ除去・追跡短縮だけ除去の対照も必須。
- 乱数2方式×64 seed の実体が全て一意に存在し、保存要約と再集計が一致すること。
- 指定4波×両銘柄の8行が一意に存在し、区間・方向・20分判定と要約が一致すること。
- 検証から選抜までの入力指紋の不変性と、再利用する選抜結果の監査来歴。

新損益・現在データを読まず、合成正常資料2件を受理し、不正資料20件を拒否した。別途、元の選抜関数を合成材料へ接続し、旧主案・同入口比較の等号境界、片銘柄だけの未達、K000の赤字・DD0・欠落、乱数・指定波・思想統合を含む23件を確認した。

検査記録は `select_verified_test.json` と `selection_boundary_test.json`。固定記録は `選抜整合ガードの固定.json`。波の固定区間は `episode_audit_fixed.json` に保存する。

このガードは保存された波の保有分を約定台帳から再積分するものではない。波の計測コード・固定区間・明細と要約を照合する。実保有分そのものは独立会計監査で補完する。また、資料整合の合格は未知相場の収益性を証明しない。既知13セッションの研究候補選抜である。
