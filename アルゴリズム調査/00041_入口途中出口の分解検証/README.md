# 00041 入口・途中判断・出口の分解検証

最初に見るファイルは **[8割の勝ちと損小利大.html](8割の勝ちと損小利大.html)** です。「全て勝つ必要はなく、損小利大で8割前後」という評価基準による補足です。セッション勝率と取引勝率を分け、既存12方式の同じ全14場を再集計しました。売買条件の再探索やAPI取得は行っていません。

読む順序：

1. [8割の勝ちと損小利大](8割の勝ちと損小利大.html)：黒字場の割合、取引勝率、平均利益と平均損失、再評価候補。
2. [分解と結論](分解と結論.html)：入口・途中判断・出口の結論、検証済みと未確定、統合結果。
3. [全条件の損益](全条件の損益.html)：各セッション・各週・全期間の利益／損失／収支、勝ち／負けの返済枚数。
4. [統合版の５分足と売買](統合版の５分足と売買.html)：追加9月29日ナイトの統合12方式。
5. [追加ナイトの５分足と売買](追加ナイトの５分足と売買.html)：従来の固定5方式。
6. [出口単独の比較](出口単独の比較.html)：同じ初回建玉から出口だけを変える13診断。独立した建玉実験のため、実運用口座の利益とは区別します。

## 検証の順序

既知13セッション（9月21日デイ〜29日デイ）で、入口26×管理3＝78条件、EMA暖機12×管理3＝36条件、途中判断13条件、同初回の出口13条件を比較しました。これらは一部に同じ中央条件を含み、独立した相場を増やしたわけではありません。

出口で残った2候補と元出口を、途中判断4方式に接続した12方式を単一口座で検証。さらに主方向窓だけ±20%とする24条件を検証し、中央12方式を保存済みの追加9月29日ナイトへ適用しました。

追加ナイトの21時以前は過去の一回照合で既読です。部品担当は追加ナイト未読で仕様を作りましたが、全体担当は従来方式の追加損益を先に確認しています。統合への適用を完全未見の検証とは呼びません。追加結果で条件を選び直していません。

## 会計と前提

- 費用0、指定価格約定。TOPIXミニ1pt＝1,000円、NK225マイクロ1pt＝10円。
- 初回はTOPIX5枚・NK10枚。片方向同時保有の上限はTOPIX10枚・NK20枚。
- 各場内で全返済。元の仮想運転も同じ場内返済条件で進めます。
- 勝ち枚数／負け枚数は返済した延べ枚数です。同時保有枚数ではありません。
- 1枚平均勝敗比＝（総利益÷勝ち返済枚数）÷（総損失÷負け返済枚数）。金額比は総利益÷総損失。
- 入口の先行価格診断、同初回の出口診断、実行可能な口座損益は別の評価です。
- 原本3フォルダは変更せず、現在セッションAPIの追加取得は0回です。
