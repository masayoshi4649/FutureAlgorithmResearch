# J02の日中改修と夜間の独立手法

まず[全セッション損益（xlsx）](J02改修と夜間独立手法の全セッション損益.xlsx)を参照。**全32手法を別IDにし、各手法27場の利益・損失・収支・累計を掲載した。昼夜で同じIDの中身を変えない。**

今回の結論は、**日中は損失回数と収益の交換条件、米国前は小幅改善、米国後は改修未達**。

|対象・手法ID|総利益|総損失|収支|赤字場|
|---|---:|---:|---:|---:|
|日中・D164_00＝元J02|3,773,400円|2,101,800円|+1,671,600円|10/27|
|日中・D164_01＝部分利確後の残玉保護|3,681,600円|1,989,600円|+1,692,000円|10/27|
|日中・D164_15＝前半で固定した防御候補|3,067,600円|1,819,100円|+1,248,500円|9/27|
|米国前・P164_00＝元P05|461,000円|77,000円|+384,000円|3/27|
|米国前・P164_06＝小量玉と追撃を分けて保護|427,000円|35,000円|+392,000円|1/27|
|米国後・U164_00＝元D07を維持|2,304,000円|1,204,000円|+1,100,000円|9/27|

表の正式IDはすべて `NK225_` を先頭に付ける。基準J02は00157第二巡のもの。

**D164_15**は、元J02に「黒字部分利確後の残玉保護」「追撃時の方向確認と50円損切り」「失速時の待機と、待機後に予定枚数を膨らませない制限」を加えた。赤字は1場減ったが、収支は423,100円減少。場内最悪赤字は−189,200→−177,600円で、大幅な改善ではない。収益重視ならD164_01も比較対象になるが、こちらは赤字場数を減らしていない。

**P164_06**は、元P05の入口を保ち、小量初回・追撃・部分利確後の残玉を分けて保護する。収支+8,000円・赤字3→1場。改善の中身は、負けた追撃2玉を早く閉じた+47,000円と、元の勝ち玉で失った39,000円の差。小量初回の早い利確自体は増益せず、米国前の無取引9場と場内最悪赤字−120,000円も残る。

夜間の時間割を **P164_06 → U164_00** とした合計は **+1,492,000円、赤字8/27場、無取引0場**。これは構成IDを明示した合計であり、新しい手法IDではない。米国後の改修は元D07を上回らず、今回の不満を全面解決したとは言えない。

枚数は買い・売りそれぞれ最大100マイクロ＝mini10枚相当、数量可変。手数料0、ラージの判断後の次正常板で買いAsk／売りBidを使用。基準期間は2026-09-21～2026-10-27の54セッション。第二巡は第一巡の結果を見た追加開発で、未見検証ではない。App・distは変更していない。
