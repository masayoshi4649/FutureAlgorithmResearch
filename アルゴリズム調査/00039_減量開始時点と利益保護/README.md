# 減量開始時点と利益保護

最初に [短い比較と結論](減量開始時点と利益保護.html) を見てください。

読む順序は次のとおりです。

1. [比較と結論](減量開始時点と利益保護.html)：元A0・元C01・固定主案の両銘柄比較。
2. [全条件の損益](全条件の損益.html)：主35条件と乱数128条件を選択し、各セッション・各週・全期間の利益／損失／収支を金額・決済枚数で確認。
3. [5分足と売買](５分足と売買.html)：固定3方式×26場銘柄の78図。エントリー・減量・復元・返済と、1.5初期ATRの順行到達を区別。

入口は元H019のままです。C01の「逆行したら一度減量し、回復後に残る枠を復元する」管理について、減量を許す時点だけを変えました。主案 `G150_F25_N1__V000` は、元の方向へ価格が1.5初期ATR進んだ後、別の新しい逆行判定で25%減量を最大1回行います。割合は現存枚数へ整数で適用します。初期損切り・部分利確・追跡返済・360分期限は残しています。

「1.5ATR」は価格の移動距離です。口座の利益額が1.5Rに達したという意味ではありません。主案以外の閾値・割合・回数でよい結果が出ても、事前に固定した主案の結果と入れ替えません。

TOPIXミニ初回5枚・片方向上限10枚、NK225マイクロ初回10枚・片方向上限20枚。費用は0で、指定価格の約定仮定を使います。決済枚数は再参加分も含む累計であり、同時保有数ではありません。大型先物の観測価格を各小型商品の倍率へ換算した検証です。

対象は保存済み13セッションです。後半7セッションも既知の資料で、未見データではありません。今回の現在API取得・保存ライブ使用はともに0です。
