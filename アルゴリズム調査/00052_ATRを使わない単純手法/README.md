## 今回の条件

当場の確定1分足だけで、始値からの一定割合、ボリンジャーバンドの突破・帯内復帰、直前20分高安の突破、EMA8/21交差を判定します。

入口5種類 × 管理幅4種類の20条件です。管理幅は当場の観測始値の0.05%・0.10%・0.20%、または判断時20分終値の標準偏差1倍です。2呼値未満は2呼値へ引き上げ、呼値単位で切り上げます。幅は判断時に固定し、初回約定直後から同じ幅でトレーリングします。目標利確、保有時間による返済、追加、半減、反対信号による返済は設けません。

ATRは特徴の計算・準備条件・入口・保有・出口・損益の単位のいずれにも使いません。標準偏差は別の変動尺度です。「ATRを使わない」と「変動尺度を使わない」は異なります。

TOPIXminiは5枚、NK225microは10枚で固定します。指定上限の片方向10枚・20枚以内です。費用0、判断後の次の有効原本行の最終価格で約定し、全建玉を当場で返済します。勝ち枚数・負け枚数は保有上限ではなく、利益・損失を出して返済した累計枚数です。

## 再実行

プロジェクトルートで以下を順に実行します。Python、NumPy、pandas、Numbaが必要です。

```powershell
python work/wave_v55/features.py
python work/wave_v55/backtest.py
python work/wave_v55/build_report.py
```

原本3フォルダは読み取り専用です。保存済み23場を使い、現在APIへのアクセスは行いません。新条件の損益を見る前にコードを固定していますが、データ自体は過去の研究で閲覧済みです。未知期間での成績ではありません。条件を変えて追加探索する場合は、過去の本作業を上書きせず新しい作業に分けます。

理論の補足は [単純化の狙い](../../work/wave_v55/theory/単純化の狙いと20条件.md) と [機械化の注意・一次資料](../../work/wave_v55/theory/機械化の注意と一次資料.md) にあります。
