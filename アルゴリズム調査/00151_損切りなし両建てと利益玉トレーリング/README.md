## 手法を簡単に言うと

**P05**：D07の米国前入口を緩めたB04が新規を判断したら同じ方向・数量で入る。実玉には価格損切りを置かず、返済可能価格で40ptの利益が出たら、最高利益から10pt戻りで返す。買売は対称。米国開始15分前には損益を問わず全返済し、後半は従来の損切りを持つS04で運転する。全夜を損切りなしにする方式ではない。

**N03**：前後半のB04新規通知を受け、買玉・売玉を独立保有。160pt利益で追尾を開始し、80pt戻りで利益玉を返す。米国開始前には清算せず、残玉は翌05:50の判断後に全返済する。片側上限10枚には未約定新規も含め、両側合計は最大20枚になり得る。

入口を出す仮想B04は元の損切り・売買状態を維持し、実玉だけ出口を変更しています。実玉を利確しても直ちに新規を強制しません。N06等の4条件だけは、実利確した側を価格の反発・反落で再新規に戻して反復します。詳細な固定条件は[検証仕様](根拠/engine仕様151.md)に記載しました。

## なぜ改善し、どこで失敗したか

P05の前半は、B04と**全38新規の時刻・価格・方向・枚数が同じ**です。前半収支は−113,000→+354,000円。元の損失玉17件が黒字になり、うち13件は従来の損切りより前の小利確、4件は元の返済時点を超えて回復を待った結果です。一方、元から利益だった17玉の利益は合計226,000円減りました。

**P05の同時両建て時間は0秒でした。改善の中心は早い利益回収であり、両建てが損失を自動的に補った証拠ではありません。** 前半だけでは16/25夜に参加し、無取引9夜。後半との組合せでは25夜すべてに新規があります。

N03は22/25夜が黒字、上昇12夜・下落13夜の合計もそれぞれ+1,016,000円・+1,469,000円。ただし10/20は、途中利確+297,000円に対して、朝に残った玉の清算が−647,000円で、夜全体は−350,000円でした。全期間で最大含み損656,000円、時価の最大落込み幅500,000円も発生しています。少ない負けを大きくする問題は解消していません。

再新規を増やしたN06は、利益追尾で+10,557,000円を確定しても、境界清算が差引−8,949,000円。全体黒字でも上位3夜を除くと赤字です。利確回数の多さと、残玉を含めた安定性は分けて評価します。

## 読み方と限界

- P05の前半は最大含み損90,000円、時価の最大落込み幅95,000円。後半の時価経路は再測定していないため、これを全夜リスクと呼びません。C00/B04の未測定リスクも0で埋めていません。
- 全手法の利益・損失は、新規実約定IDごとに全返済を合算して正負分類しました。過去の親取引単位の表とは分類が異なりますが、収支は一致しています。
- 判断後の次の正常なラージ気配で仮想約定します。miniの実約定・数量の市場影響・5秒遅延は今回再現していません。途中利確の利益判定でも、次の板で赤字約定する可能性は許しています。
- 10/26の取得済み途中データは別シートです。末尾で架空清算せず、確定・含みを分け、25完了夜の累計へ入れていません。
- 既知データで選んだ開発候補であり、未見成績ではありません。今回、実アプリの標準設定は変更していません。
