# 全赤字手法の売買反転を同条件で検証

最初に [売買反転の比較と全33セッション損益](売買反転した十二手法と全セッション損益.html) を開いてください。**反転した12条件とも、両銘柄で33場すべて赤字。売買方向の反転だけでは改善できませんでした。**

元115で事前に主候補としていたC＋半分利確・残り追尾の比較です。金額は各商品の全33場合計、実注文料込み。

| 比較 | TOPIXミニ10枚 | 日経マイクロ20枚 |
| --- | ---: | ---: |
| 元の手法 | −1,768,124円 | −590,720円 |
| 同じ時刻・枚数で全注文を反転 | −2,168,124円 | −745,720円 |
| 新規方向を反転し、出口・後続参加も再判定 | **−1,833,824円** | **−599,360円** |

同時刻の反転は保存された注文・両気配を使った参考再会計。最後の行が新しい12条件の運転です。利確・損切り・追尾・場停止を新建玉の損益で判定し直し、返済時刻や後の入口も変わります。両者を同じ成績として扱いません。

読む順序：

1. [全12条件の比較・全33場の利益／損失／収支と枚数](売買反転した十二手法と全セッション損益.html)。
2. [反転しても残った損失の具体例](反転しても残った損失の具体例.md)：中値移動・気配差・料の分解と、同じ公開時点から逆に入った2例。
3. [手法の簡単な説明](手法の簡単な説明.md)：二つの反転の違いと注文条件。
4. [同じ時刻の逆売買・全12条件全33場の参考表](../../work/quantity_reverse_20261015/mirror/固定時刻反転の参考計算と全33場.md)。
