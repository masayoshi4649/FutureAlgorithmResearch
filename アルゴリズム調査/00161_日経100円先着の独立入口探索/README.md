# 日経の「50円逆行する前に100円順行する入口」

最初に読むファイルはこのREADMEです。詳しい数字は[全セッションの先着率](全セッションの先着率.md)、条件と手順は[検証記録](検証記録.md)に分けました。

**既存手法から離れて58条件を調べましたが、高確度の入口は確認できませんでした。** 対象は2026/9/21〜10/27デイの53完了セッション。数量、利確、トレーリングによる回収は混ぜず、入口だけを測っています。

成功は、買いなら建値より100円高い返済気配へ、50円低い返済気配より先に届くこと。売りは上下反転です。50円ちょうどの逆行も失敗。固定保有時間を設けず、同じセッションの終端まで追います。

## 今回の重要な発見

最初の日中候補は、場末までなら**164回中146回で狙った方向へ100円到達**しています。しかし、**50円逆行より先に届いたのは31回**でした。残りの多くは、先に逆行してから戻っています。89%という到達率を、この入口の確度とは呼べません。

また、板の変化を平均化した指標に瞬間値のような閾値を置くと、ほぼ無信号になります。その設定を直して十分な件数を作っても、今回は100円先着の強い優位を確認できませんでした。板読み全般が無効、又はこの目標が不可能だと証明した結果ではありません。

## 数字の読み方

- 主評価は**日経ラージの次の正常な板で買Ask／売Bid**、その後は返済側気配で判定。手数料は0。Last補助は入口も経路もLastを使い、主評価と分けています。
- 追加日中881件には未到達1件を含み、成功率の分母から消していません。他の表内候補に未到達・次正常板なしはありません。
- 価格時計は受信時計ではありません。保存の空白中の経路や、実注文の約定を保証する値ではありません。
- 最初の13場も、今回の条件選択に使わなかっただけで、過去研究では既知の資料です。未来の成功確率を保証しません。
