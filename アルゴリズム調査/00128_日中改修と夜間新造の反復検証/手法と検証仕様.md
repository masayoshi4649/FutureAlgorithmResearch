# 手法と検証仕様

日中は「両市場の方向一致を確認する E01」を改修し、夜間は「米国開始後の価格帯突破」を独立した手法として作った。以下は第五巡までの比較条件の実装仕様であり、採用結果と各場の損益は別の結果資料に掲載する。

## 共通の取引条件

| 項目 | TOPIX | 日経 |
|---|---|---|
| 判断・約定価格の資料 | TOPIX ラージの原板・現在値 | NK225 ラージの原板・現在値 |
| 損益換算する商品 | TOPIX ミニ | 日経225マイクロ |
| 通常の初回枚数 | 5枚 | 10枚 |
| 片方向の許容上限 | 10枚 | 20枚 |
| 1pt・1枚の損益 | 1,000円 | 10円 |
| 片道・1枚の手数料 | 41.8円 | 11円 |

今回の手法は追加建て・両建て・減量後の枚数復元を行わない。したがって、許容上限が10枚・20枚でも、通常の実保有上限は5枚・10枚。日中の弱支持条件だけ、初回枚数をさらに減らす。

買いは売り気配、売りは買い気配で約定する。条件成立行より**後の最初の正常原行**で執行し、判断時の有利な価格へ遡らない。同じ秒でも別の後続原行なら約定し得る。5秒間の最悪価格という追加仮定は入れていない。

ラージの気配をミニ・マイクロの約定価格代理として使っている。実商品の気配、板数量による部分約定、注文待ち順は再現していない。

## 日中：E01 の入口と管理を残し、逆行と値幅収縮に対処する

### 継承する基本動作

1. **方向を決める。** 当場の確定1分足から EMA15・EMA60 を計算する。両市場で、売買方向に沿った EMA の差が0.15ATR超、EMA60の3本前からの変化が0.02ATR超となる準備条件を使う。元の短期確認では、公開済み板中値の30秒変化が同方向へ0.05ATR超であることも要求する。
2. **直ちに飛び付かず、追跡新規を待つ。** 買いなら準備後の安値から0.25初期ATRの反発、売りなら高値から同幅の反落を待つ。新規準備の期限は5分。発注判断時には、気配差が0.5初期ATR以下、現在値から約定側気配までの不利な差も0.5初期ATR以下を要求する。
3. **伸びたら部分利確と追尾を使う。** 元 E01 の初期ストップ0.75ATR、2ATRの部分利確、1.5ATRから幅3ATRの追尾、3ATR進行後は追尾幅を0.75ATRまで短縮する規則を継承する。保有上限は360分。
4. **順行後の悪化で減量する。** 元の通常影が1.5初期ATR進行した後、新しく公開された反対方向の価格反応で一度だけ半減する。悪化は2分の板中値変化が `max(0.25ATR, 2呼値)`、直近30秒も `max(0.10ATR, 1呼値)` 以上、反対方向に揃う条件。減量後は戻さない。

この入口・途中判断が使う板情報は主に**気配価格の変化**であり、板の厚さや補充量を直接使う手法ではない。元の条件列・注文通知を保存結果から引き継ぎ、今回の追加判断だけを分けている。

### 早く降りても、元の仮想保有が終わるまで待つ

E01 は実保有とは別に、通常ストップ1ATR・追尾開始1.5ATR・追尾幅3ATR・後半短縮なしの「通常影」を動かす。この仮想保有が次の新規準備時刻を決める。

実保有を早く返済しても、**通常影の終了と、その後5分の待機が済むまで新規準備を再開しない。** 実際に持っていない間も仮想判断だけを続ける仕様であり、早期損切りの直後から連続して入り直す手法ではない。今回の条件で入口を見送った場合も、この元の時計を前倒ししない。

### 第三巡に共通する損失枠の縮小

初期の金額リスク単位を「実際の初回枚数 × 初期ATR × 円倍率」とする。組全体の確定損益と残玉の気配評価損益を合算して監視する。

保有中の ATR が初期より小さくなれば、この組の損失枠を同比率で縮小する。ただし初期リスクの75%よりは狭めず、一度狭めた枠は広げない。式では、累積する縮小率が `min(それまでの縮小率, max(0.75, min(1, 現在ATR / 初期ATR)))`。元 E01 の返済通知も有効なので、こちらの追加損失枠に達する前に元の出口で返済する場合もある。

### D16〜D20 の違い

ここでいう「短期支持」は、**発注判断時**の両市場の30秒現在値変化を、それぞれの公開済みATRで割ったもの。両方が売買方向へ0.05ATR超なら強い支持、片方でも反対へ0.05ATR超なら明確な逆行とする。

| 条件 | 入口の追加判断 | 強い支持の初回枚数 TOPIX／日経 | それ以外の初回枚数 |
|---|---|---:|---:|
| D16 | 強い支持だけ採用 | 5／10枚 | 見送り |
| D17 | 明確な逆行だけ見送る | 5／10枚 | 5／10枚 |
| D18 | 追加の方向見送りなし | 5／10枚 | 2／4枚 |
| D19 | 明確な逆行を見送り、弱ければ減量 | 5／10枚 | 2／4枚 |
| D20 | 明確な逆行を見送り、弱ければ減量 | 5／10枚 | 3／6枚 |

D16・D17・D19・D20 は必要な観測が不明なら見送る。D18 は短期支持を確認できない場合も減量側に含める。縮小枚数での部分返済は、元の累計返済比率を整数枚数へ丸めて対応し、最終的には全量を返済する。保有後に支持が強くなっても増量しない。

## 夜間：固定した20分帯の突破を、両市場で確認する

第三巡 N23〜N30 はすべて同じ入口状態機械、`mode=2` を使う。下記の買い条件を上下反転したものが売り条件になる。

| 状態 | 買いの場合の処理 |
|---|---|
| 待機 | 米国開始後の準備時間、観測の鮮度、気配条件を確認する。 |
| 突破準備 | 当時既知の20分帯の上限を現在値が超え、相手市場の5分・20分変化がともに上向きなら準備する。自市場の20分効率は0.35以上を要求。 |
| 境界の固定 | 準備時の上限を突破線として固定する。初期値幅も固定し、後から動く20分高値へ差し替えない。 |
| 確認 | 固定線を大きく割らず60秒以上経過し、発注時は突破線から0.25初期値幅以上上にあり、両市場の30秒変化が上向き、両市場の120秒変化が各0.05ATR超上向きなら発注判断する。 |
| 準備取消 | 突破線の内側へ0.25初期値幅を超えて戻る、準備から30分を超える、休止・場末に入る場合。 |
| 保有 | 初期1値幅の損切りと、条件別の利益追尾を実行する。 |
| 構造の失敗 | 固定した突破線の内側へ0.25初期値幅を超えて戻り、相手市場の20分変化も反対になったら返済判断する。 |
| 再開 | 全返済から5分待ち、あらためて突破準備から始める。 |

20分帯は、20分を隔てた**21個の確定1分終値の最高・最低**。分足内の最高値・最安値ではない。効率は「20分の始終点の変化幅 ÷ その間の1分終値変化の絶対値合計」であり、一方向に進んだ割合を見る。

確認中は固定線の内側へ0.25初期値幅までの小戻りを許すため、「60秒間ずっと帯外にいる」という条件ではない。また、準備時に要求した相手の5分・20分支持は、第三巡の発注時には再確認していない。発注時に改めて確認するのは上表の30秒・120秒支持である。

準備・発注判断時の気配条件は、気配差がその時点の値幅の0.25倍以下、現在値と両側気配の最大乖離が0.5倍以下。入口確定後、実際の約定行で悪い値を見て注文を取り消すことはしない。

### 1R と利益追尾

夜間の価格単位を **`1R = max(準備時の公開ATR, ラージ4呼値)`** とする。下限は TOPIX 2pt、日経40円。準備から保有終了まで固定する。日中の「枚数を掛けた組全体の金額リスク」とは単位が異なる。

最大順行幅は、買玉なら買い気配、売玉なら売り気配で返済できる値を使って測る。追尾が始まったら「それまでの最大順行幅 − 追尾幅」を利益床にし、以後は床を下げない。

| 条件 | 追尾開始 | 追尾幅 | 判断時の約定側気配と固定突破線の距離上限 |
|---|---:|---:|---:|
| N23 | 1R | 1R | 制限なし |
| N24 | 1R | 0.75R | 制限なし |
| N25 | 1.25R | 1R | 制限なし |
| N26 | 1.5R | 1R | 0.75R |
| N27 | 1.5R | 1R | 1.5R |
| N28 | 1R | 1R | 1R |
| N29 | 1R | 0.75R | 1R |
| N30 | 1R | 1R | 0.75R |

比較元 N16 は「1.5Rから幅1R、入口距離制限なし」。N23〜N25 は、順行しても追尾が始まらないまま赤字になる経路への対策。距離制限は、既存取引の診断では主な損失原因と確認できなかったため、**反証を含む比較条件**としている。

N23 の「1R進んだら建値の床」は手数料前の意味。手数料と次原行の値飛びがあるため、黒字や建値返済を保証しない。夜間には部分利確も、一定分数での通常返済もなく、上の条件か場末で全量返済する。

### 第四巡・第五巡：準備した根拠を発注時にも確認する

第三巡までは、準備時の相手5分・20分支持が、その後に消えていても30秒・120秒支持で発注できた。この点を出口と分離して比較する。

- **第四巡 N31〜N33：** 発注時に、自市場・相手市場の両方で5分差・20分差が売買方向に正であることを追加要求する。実装は `entry_confirm=2`。
- **第五巡 N34〜N36：** 発注時に、準備時から要求していた**相手市場だけ**の5分差・20分差を再確認する。自市場の中期支持は追加要件にしない。実装は `entry_confirm=3`。

| 条件 | 対応する基準 | 発注時に追加確認する市場 | 追尾開始 | 追尾幅 |
|---|---|---|---:|---:|
| N31 | N16 | 自市場と相手 | 1.5R | 1R |
| N32 | N23 | 自市場と相手 | 1R | 1R |
| N33 | N24 | 自市場と相手 | 1R | 0.75R |
| N34 | N16 | 相手のみ | 1.5R | 1R |
| N35 | N23 | 相手のみ | 1R | 1R |
| N36 | N24 | 相手のみ | 1R | 0.75R |

いずれも両市場の30秒・120秒確認を残し、入口距離上限は設けない。初期損切り・構造失敗時の返済・枚数・手数料も対応する基準と同じ。

追加確認が不成立なら、その行の発注を見送り、準備状態を保つ。元の取消条件や30分期限までに支持が回復すれば、後で発注する。このため、既存取引を集計から取り除くだけの比較ではなく、新たな建値・後続取引も含めて再検証する。

## 時刻と、将来データを使わない扱い

- **米国開始時刻：** 保存入力の `ready.us_open` を使う。入力生成元はセッション日付のニューヨーク09:30を `America/New_York` で時刻変換するため、夏時間は日本22:30、冬時間は23:30になる。米国休場日の判定はこの計算に含まない。
- **夜間の取引帯：** 第三〜第五巡は米国開始後だけ取引する。開始前後15分は停止し、開始後22分までは準備しない。その後も突破準備から60秒確認する。20分履歴自体を開始時刻にリセットする処理ではなく、遅延公開した履歴が揃うまで待つ実装。
- **足の公開：** 元 E01 の確定1分足は足始時から120秒後、相手市場はさらに60秒遅らせる。今回の20分帯も、自市場は1分終端から60秒後、相手はさらに60秒後に公開する。公開前の足は利用しない。
- **ATR：** 既存入力を継承する。確定5分足の真の値幅を指数平滑（係数1/12、初期3本）し、ラージ2呼値以上とした値を、足始時から360秒後に公開する。更新中の5分足へ置き換えない。
- **30秒・120秒の比較：** 現在値の保存時計を使用する。相手市場は自市場時刻より厳密に過去の行だけを採り、鮮度15秒以内を要求する。共通の実受信時計を復元した結果ではない。
- **場末：** 日中15:35、夜間翌05:50を返済時刻にする。未約定新規は取り消し、正常気配で全量を返す。時刻の後にも原行があり、残玉ゼロになることを会計検査する。15:45・06:00の終値約定を仮定していない。

## 損益の数え方と検証範囲

手数料は新規・部分返済・最終返済の**注文ごと**に「枚数 × 片道料金」の1円未満を切り捨てる。ひとつの初回新規から全返済までを一組とし、部分利確を合算した組全体から全注文の手数料を引く。その値が正の組の合計が「利益」、負の組の絶対額合計が「損失」、差が「収支」。部分利確だけを勝ちとして数えない。基準 GU_Q も同じ会計へ再集計している。

対象は保存済み43場（日中22・夜間21）。日中と夜間は別々に比較し、上昇・下落区分や前後半区分は**結果の採点だけ**に使う。セッション終値を入口や手法切替に使わない。すでに参照済みの期間を繰り返し改善しているため、前後半比較も完全な未見データ検証とは呼ばない。
