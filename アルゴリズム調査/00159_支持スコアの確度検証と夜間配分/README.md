# 支持スコアの検証と夜間用の配分

**支持が強ければ初回から多く建てる方針は妥当な検討対象です。ただし、今の支持スコアを「勝ちやすさ」とみなす根拠は不十分でした。夜間は16条件を26場で比較し、安定性では基準のP05＋D07を上回る案は確認できませんでした。**

最初に見る資料：[支持スコアと昼夜の全セッション損益.xlsx](支持スコアと昼夜の全セッション損益.xlsx)。読み順は「比較」→必要な手法のシート→[支持スコアの検証](支持スコアの検証.md)。具体的な損失原因と反証は[検証記録](検証記録.md)へ分けました。

## 初回から多く建ててよいか

初回少量固定を新たな必須条件にはしません。今回調べたのは、**枚数を増やす根拠に今のスコアを使えるか**です。

- 日中：支持0.25〜0.50では12勝7敗、0.50〜0.75では8勝5敗、0.75以上は1勝1敗。強いほど勝ちやすいという順序は確認できません。
- 夜間後半：支持0.25〜0.50は9勝1敗ですが、0.50〜0.75は2勝3敗。件数が少なく、範囲選別にも不確実性があります。
- 過去の完了場だけで学習して次の場を予測しても、支持スコアを追加しただけでは、勝率や利益幅の予測誤差は改善しませんでした。

これらは初回玉の全返済が黒字になった割合です。追加玉込みの親収支や、一度だけ順行した割合ではありません。利益幅・逆行幅も別に検証しています。

## 夜間に作った手法

いずれも、**米国開始前はP05、開始前後15分は返済・静観、開始15分後から新しい状態のD07**を使います。米国時計は夏時間に追従します。

|手法|変更の内容|
|---|---|
|N00：基準|元の数量配分。米国前は利益玉の短い追尾、米国後はD07の入口・追加・出口|
|N04：支持比例|米国後の初回量を支持に比例。支持を計算できない時は最低量|
|R01：超過分40pt保護|支持が未知なら元の数量を使用。元の数量を超えた分だけ、40pt順行後に40pt戻りで返済|
|R02：超過分80pt保護|R01の保護開始を80ptへ遅らせる。戻りは40pt|

支持比例の初回希望量は `切捨て(10＋90×支持スコア)` micro、片方向上限100microです。例えば支持0.50なら初回55microを希望します。既存保有・予約で余裕がなければ減ります。支持は方向と短期勢いの合成値で、0.50を勝率50%とは扱いません。

## 夜間26場の比較

日経mini10枚相当をmicro100枚へ細分化。手数料0、判断後の次の正常ラージ気配で買Ask・売Bidを使った研究値です。実mini10枚で端数量を丸めた再生や、実約定の保証ではありません。

|手法|累計収支|赤字場|赤字場の平均損失|最大赤字場|場内の最悪損益|大勝ち3場除外後|
|---|---:|---:|---:|---:|---:|---:|

|R02|+1,614,200円|8/26|34,275円|61,400円|−128,600円|+770,400円|

**安定性を優先するなら現段階はN00を維持。R02は増益を狙う研究候補です。** R02は大勝ち3場を除いても増益ですが、負け1場の深さと途中赤字は悪化しました。R01も損失を一律に改善したわけではありません。全案で無取引場は0でした。

上昇14夜・下落10夜の合計はN00/R01/R02とも黒字。ただし横ばい2夜は全て赤字で、どの相場でも安定したとは言えません。追加完了版10月26日ナイトはN00−36,000円、R01−29,400円、R02−46,500円でした。

全て既知データを使う開発比較です。旧日中26場のS01/J02は保存結果を掲載し、10月27日追加完了版は返済配賦の版差を明示して別シートにしました。アプリ・運用設定は変更していません。
