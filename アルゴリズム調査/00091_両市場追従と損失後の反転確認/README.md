毎セッション安定して損小利大を達成する解には未達。38条件中、両銘柄で金額利益80%を満たす条件は0でした。

前16で選んだ参考 P0_R1_S は、両銘柄とも黒字17／取引29場。日経の最大赤字は約7.3万円→5.5万円へ減りましたが、TOPIXは約19.0万円→21.0万円へ増えました。

両市場の5分方向が一致した時に入り、損切り後の逆方向新規だけを制限する手法です。価格観測を増やす主の改修は両赤字。両銘柄で一貫した損失抑制を確認できていません。

38条件を切り替え、TOPIXミニ片方向10枚・日経マイクロ片方向20枚以内の全31場の利益・損失・収支と決済枚数を確認できます。詳しい前後・昼夜・売買別の内訳は折り畳みにあります。

最大総収益より、赤字場数・平均赤字・最大赤字を重視しています。無取引を勝ちに含めず、少枚数による円リスク縮小と手法の優位を分けます。目標は両銘柄の金額利益80%・損失20%と安定性です。

全31場は既知です。価格の観測資格、候補の発火経路、損失後の反転確認を分けて検証しました。出口は旧の始値0.4%追尾・30分期限を保持しています。ラージ板の次有効気配を代理に全量仮想約定し、両側手数料と全玉清算を含みます。追加5秒悪化なし。実ミニ／マイクロ板、真受信時計、全量約定、未知場の安定性は未証明です。
