# 00053 価格が動く理由と板データの再点検

最初に [価格が動く理由と板データ.html](価格が動く理由と板データ.html) を開いてください。短い原理説明、数値例、保存データで観測できる範囲をまとめています。

今回は価格形成と測定の再点検です。新しい価格イベント手法は保留しており、新手法・新損益はまだありません。既存手法の診断は、新しい売買成績とは区別しています。現在セッションのAPIは取得していません。

読む順序:

1. [主HTML](価格が動く理由と板データ.html)：買いと売りが同じ枚数でも価格が変わる理由。
2. [根本説明と観測対応](../../work/wave_v56/theory/価格が動く理由と観測対応.md)：直接観測・推定・不明、既存抽出列の対応と一次資料。
3. [板の観測診断](../../work/wave_v56/diagnosis/板の観測可能性.json)：元件数、原本例、観測タイミングの制約。
4. [入口・途中・出口の診断](../../work/wave_v56/diagnosis/入口途中出口の診断.json)：前回4手法を、返済後の値動きまで分けて記述した資料。未来値は説明専用です。
5. [原理と識別の監査](../../work/wave_v56/review/価格が動く仕組みと識別の監査.md)。
6. [表示範囲補正の全数監査](../../work/wave_v56/measurement/表示範囲補正とOFIの全数監査.json)、[売買代金の独立監査](../../work/wave_v56/review/代金監査の結論.md)。

特に、旧数量差分は前後の共通表示価格に限定しており、最良板の消失量を数えていませんでした。今回、その消失を補い、観測範囲外へ出ただけの数量は不明に分離して46原本を再集計しました。測定の補完は、利益や将来予測の改善を示した結果ではありません。

再生成: プロジェクトルートで `python work/wave_v56/build_report.py`。売買代金の追加監査は `work/wave_v56/review/レポート追記.json` があれば反映されます。生成後のSHAは [生成記録.json](生成記録.json) に保存します。
