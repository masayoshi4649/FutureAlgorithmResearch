# 移動平均の傾きと比例枚数：検証条件

成績は[手法別xlsx](移動平均の傾きと比例枚数の全セッション損益.xlsx)、結論は[README](README.md)。本資料は計算条件と再現資料を示す。

## 何を試したか

「上向きが緩ければ少量、急なら多く買う。下向きなら同じ仕組みで売る」を、E01・D07・P05とは独立した手法として検証した。保有時間を何分と決めず、価格・傾きの出口が成立したら返済し、全返済から10秒後には再参加できる。

チャートの見かけの角度を使わず、正常なラージ売買気配の中値を時間で重み付けした移動平均を使用する。

`傾き = 10,000 × (現在MA / 過去MA − 1) × 60 / 比較秒数`〔bp/分〕

|移動平均の長さ|比較する過去|初回比例のT/Z/D|途中増減のT/Z/D|
|---|---:|---|---|
|1分|30秒前|M01 / M02 / M03|M04 / M05 / M06|
|3分|30秒前|M07 / M08 / M09|M10 / M11 / M12|
|5分|60秒前|M13 / M14 / M15|M16 / M17 / M18|
|10分|60秒前|M19 / M20 / M21|M22 / M23 / M24|

傾きの絶対値0.25bp/分で参加を始め、2.5bp/分で上限10枚となる。小数は切り捨てる。例えば0.25なら1枚、1なら4枚、2.5以上なら10枚。価格65,000なら、それぞれ約1.6・6.5・16.3pt/分に相当する。これは第一巡で固定した比較設定であり、最適値と確認した数値ではない。

初回比例は最初の数量を保持する。途中増減は、直前の約定から10秒以上経過していれば、その時点の保有方向の傾きへ枚数を合わせる。弱化時は最低1枚へ縮小し、全返済は下記の出口に任せる。角度不明時は追加・縮小を停止する。

F01・F10はM09と同じ入口・出口で、固定1枚・10枚とした対照。M09/F01/F10は売買時刻・方向・価格・理由を一致確認する。別の期間や出口の成績差を、そのまま数量比例の効果とは呼ばない。

## 出口

価格幅は当場の最初の正常中値に対する比率で固定し、追加しても基準をずらさない。初回の実約定建値から12bp逆行した場合は、全条件で残玉を返済する。

- **T**：6bp順行したら追尾を開始し、最高利益から3bp戻れば全返済。
- **Z**：Tに加え、保有方向の傾きが0以下になれば全返済。
- **D**：Zに加え、傾きが入口時の2倍以上になった後、最高の傾きの半分以下に弱まれば全返済。

追加によって親の初回建値・停止線・最高順行幅・最高傾きを再設定しない。数量縮小だけを古い玉から返済する。売買気配の飛びによって、利益トレーリングの判断・約定が赤字になることも会計へ残す。日中15:35・夜間05:50から新規停止・全返済し、次の正常気配で清算する。今回は米国寄付前後の特別停止を加えていない。

## 原因を見て修正した第二巡

初巡は微小な傾きでの出入りと、過去の傾きが残る方向への再参加・追加が問題となった。その後に固定した8条件は以下。元の26条件を上書きせず、同じ51場を別の売買状態で再生した。

|条件|3分MA・D出口|10分MA・T出口|
|---|---|---|
|同方向の傾きが一度弱まるまで再参加しない|R01|R05|
|さらに現在価格と短期の傾きも同方向の時だけ入る|R02|R06|
|さらに保有中も元の比例式で増減|R03|R07|
|追加は初回基準の含み益と価格進行を確認、増減は2枚差以上|R04|R08|

全返済後、同方向の傾きが0.125bp/分以下へ一度落ち、再び0.25以上になることを再参加条件とした。価格確認は「現在中値が基準MAより予定方向へ先にあり、1分MAの30秒差も同方向」。追加の進行確認は、返済側気配が直前の新規・追加実約定値から現在の売買気配差以上進むこと。合算の全玉含み益を保証する条件ではない。R04/R08は複数の制限を同時に加えたため、それぞれ単独の効果とは解釈しない。

入口の閾値・比例式・価格出口幅は初巡と同じ。詳細は[第二巡固定仕様](../../work/ma153/round2/spec153r2.md)に記載した。

## 資料と会計

2026年9月21日〜10月26日デイの51完了場（デイ26・ナイト25）を、日経mini・TOPIXmini各上限10枚で比較。312資料・約23.7GBの内容指紋を固定し、再生前にも全文照合した。現在APIは取得していない。既取得の10月26日ナイト21:13:52未満は、末尾清算をせず別シートに掲載し、51場の集計には含めない。

手数料0。判断行での中値約定はせず、**判断後の次の正常ラージ気配で買いはask、売りはbid**とする。気配差は収支に含まれる。miniの実注文遅延、板を食う影響、実約定価格は再現していない。

xlsxの「利益」「損失」は返済ごとのFIFO配賦の正負合計。「親利益」「親損失」は初回から全返済までを合算した親取引の正負で、分割返済の見かけの勝率と区別する。両者の純収支は一致する。未返済含み・最大時価下落・保有時間・追加回数も保存した。

上昇／下落の区分は、当場の資格済み最初Lastと、終了直前6分以内の最終Last代理を比較する。正式終値とは呼ばず、売買判断にも渡さない。米国前後の分析は返済が起きた時刻による確定損益の帰属であり、途中の含み損益を含む独立運転の成績ではない。

## 誤解を避けるために確認した点

1. 未来の板を書き換えても、それ以前のMA・売買が変わらない。
2. 現在板を過去の時間へ埋め戻さない。同時計の更新の時間重みは0。
3. 120秒を超す無観測区間と異常BBOを未知扱いし、含む窓では新規しない。
4. 窓と比較時点の履歴が揃う前には入らない。
5. 上昇の減速と下向きの傾きを取り違えない。
6. 追加で初回基準の損切り線を緩めない。
7. 部分返済・追加のたびに追尾の最高利益を消さない。
8. 注文判断の次の板で約定し、悪化・赤字を隠さない。
9. 保有と新規予約を合わせて10枚以下とする。
10. 未返済のまま反対方向を新規せず、場末に残玉を持ち越さない。
11. F01/F10/M09の数量以外の経路と、固定10枚の金額10倍を照合する。
12. 途中データの末尾へ架空の返済を足さない。
13. 同じ場を並列処理しても、場内の順序と結果が変わらない。
14. 利益の総額だけでなく、昼夜・上昇下落・無取引・負け場の深さを調べる。
15. 大きい傾きの群の1枚あたり成績と、追加玉の損失を分けて調べる。

初巡は人工29試験、第二巡は既存試験も含め39試験、集計器も別の人工試験を実施した。人工試験通過は市場での収益性を証明しない。全51場は既知の開発資料であり、損失を見て修正した第二巡や結果上位を選んだ成績を未見検証とは扱わない。

保存板には独立した受信時刻がないため、時間加重はCurrentPriceTimeの時計に基づく近似。同時計の複数板の時間重みは0とし、次の時計まで最後の正常板を最長120秒保持する。原行の未来参照はしないが、実際に各気配が表示されていた秒数を厳密に復元したものではない。
