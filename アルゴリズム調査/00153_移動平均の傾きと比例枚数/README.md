# 移動平均の傾きと比例枚数

**「緩やかなら1枚、急なら10枚」は機械的に実行できる。ただし、今回試した34条件では単独の売買手法として有望とは言えなかった。** 1・3・5・10分平均、途中の追加・縮小、トレーリング・角度出口を、両銘柄の51場で比較した。

最初に[全セッションの損益xlsx](移動平均の傾きと比例枚数の全セッション損益.xlsx)。銘柄・手法別シートに利益／損失／収支／累計を掲載している。詳しく見る場合は[損失の具体例](損失の具体例.md)、[計算条件](検証記録.md)の順。

## 結果

日経mini・TOPIXmini各上限10枚、手数料0。ラージ原板の売買気配を使った約定模型で、mini実板の実測ではない。

|手法|簡単な説明|日経の51場収支|日経の赤字場|TOPIXの51場収支|TOPIXの赤字場|
|---|---|---:|---:|---:|---:|
|M09|3分平均の傾きで初回1〜10枚。追尾・傾き失速で返済|−90,326,000円|51/51|−28,434,500円|51/51|
|M12|M09に、保有中の傾きに合わせた追加・縮小|−144,646,000円|51/51|−54,303,500円|51/51|
|R06|10分平均。冷却後だけ再参加し、現在価格・短期方向も確認|−4,688,000円|44/51|−1,680,500円|39/51|

全34条件が両銘柄で累計赤字。R06は赤字額が最小だったが、取引と枚数を減らした影響が大きい。元の10分平均M19に対して利益／損失比は日経0.574→0.548、TOPIX0.625→0.613で、収益性が改善したとは言えない。無取引は全条件0場。

R06もデイ／ナイトはそれぞれ、日経−2,244,000／−2,444,000円、TOPIX−811,500／−869,000円。上昇場・下落場のどちらも合計赤字であり、特定の方向や昼夜へ限れば採用できる結果ではない。

## 何が分かったか

**枚数の比例配分だけなら、改善する部分はあった。** 同一売買経路の固定数量とM09を比べると、利益／損失比は日経0.374→0.421、TOPIX0.340→0.392。ただし1未満のまま。大きい傾きの群ほど黒字取引の割合は上がったが、固定1枚で測った全5傾き区間の平均収支は赤字だった。

**平均線は、反転後にも古い傾きを残す。** 10月20日09:28、日経を2枚から10枚へ追加した後、追加8枚だけで8万円を失った。返済時も3分平均の傾きは上向きだった。全場ではM12の追加玉だけで日経−56,561,000円、TOPIX−27,178,000円。縮小による改善を上回った。

**頻繁な出入りが気配差を積み上げた。** 固定1枚F01の日経は1場平均約244回、平均保有約113秒。−19,467,000円の内訳は、中値変化分−858,000円、入口・出口の気配差負担18,609,000円。手数料を0にするだけでは解決しない。この気配差はラージ板による模型値である。

再参加を新しい冷却後に限り、追加を初回基準の含み益と価格進行で制限した第二巡8条件でも黒字化しなかった。消えた勝ちも確認した。例えば10月8日14:50の追加利益10.8万円が同じ時刻では消え、該当親の利益は17.9万→16.6万円へ減った。[追加制限の両面](../../work/ma153/round2/addition_comparison153r2.md)を参照。

**現時点では、傾きだけを「大きく張ってよい確度」として使わない。** 数量を増やす前に、その入口と出口が1枚でも十分な値幅を残す必要がある。今回の反証はこの定義・期間・約定模型に対するもので、移動平均を使う全手法の否定ではない。

今回のデータは既知の開発資料。途中ナイトは別シートに分離した。現在API取得・実注文・P05/D07のアプリ設定変更は行っていない。
