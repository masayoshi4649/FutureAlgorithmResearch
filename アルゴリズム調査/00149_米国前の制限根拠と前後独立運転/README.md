# 米国前の制限と、前後を分ける運転

**米国前を一律に稼ぎにくい時間とは断定できない。ただし、現D07をそのまま前倒しする案は悪化した。提案の三分割も試したが、今回の最良は現D07の維持だった。**

最初に見るファイルは [全25夜の利益・損失・収支と累計（xlsx）](米国前の制限と前後独立運転の損益.xlsx)。比較 → 日経_各ID の順。日中は今回変更・再生していない。

日経mini・片方向上限10枚、手数料0円。2026/9/21〜10/23の保存25夜を、現アプリと同じ原板処理で比較した。金額は円。

## 三分割から分かったこと

1. **前半と後半の売買状態を分ける意味はある。** 前半も動かすC05の後半収支88.7万円は、建玉を閉じ売買状態・利益予算を初期化するS02で114.3万円へ回復した。ただし、この差は返済・新規状態をまとめた効果で、予算だけの単独効果ではない。前半−43.4万円は消さず計上した。
2. **指標までゼロにする根拠は得られなかった。** 同じ開始時計でS02→S03は後半114.3万→42.4万円。20・40分の判断材料を作り直すため、参加時刻・入口・停止幅が変わる。ただし保持が有利13夜、不利11夜、同じ1夜。改善上位3夜を除く差は−3.8万円なので、指標保持が常に良いという法則でもない。
3. **前半の利益源が未解決。** C05の前半は9黒字・16赤字。10/16は17:23買い→18:01損切り−5.5万円、19:01売り→19:17損切り−4.5万円。最近の方向へ参加しても、その後の戻りに負けていた。後半を分離するだけでは、この損失を直せない。

S02/S04の後半は25夜すべて約定列が一致。S04は現D07と赤字9夜・最大赤字5.3万円も同じで、累計が1.2万円少ない。分割運転への大きな不利益は見えないが、利益改善も確認できていない。現在の標準ルール・実機設定は変更していない。

## 米国前が厳しい理由

旧手法で米国後に限定すると損失が減った経緯があり、その制限をD07も引き継いでいた。今回、同じ25夜を同じ長さで測ると平均値幅は前581pt・後772pt、気配差中央値は前後10pt。『前は動かない／前だけ気配差が大きい』という説明は支持されなかった。詳細は [市場の性質と入口の損失](米国前が難しいと言えるか.md)。

- 25夜は既知の開発資料。10/26も指摘済みの三波を含み、未見検証ではない。同夜は21:13:52未満の保存分だけを別掲載し、強制精算せず含み損益を分けた。現APIの再取得・実注文は0。
