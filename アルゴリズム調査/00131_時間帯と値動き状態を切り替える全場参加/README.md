## 簡単な手法

- **日中T06：** 両市場の方向を確認して追従する従来改修を維持。両市場が継続して逆行したら撤退する。12:30まで一度も入っていなければ、二市場の始値からの方向を優先して一度だけ補う。
- **夜間TOPIX T04：** 米国開始後、二市場が確認する価格帯突破を狙う。ロンドン16:30まで未参加なら、二市場の直近20分・5分方向で一度だけ補う。
- **夜間日経U06：** 価格帯突破後の押し戻りと再進行を待つ。米国開始30分後まで未参加なら、二市場の始値からの方向を優先して一度だけ補う。追加分は早めに利益を保護し、初期損切り幅が広いときだけ枚数を減らす。

旧担当はTOPIX5枚・日経10枚。追加担当も最大5枚・10枚で、合算の片方向上限は10枚・20枚。後から旧担当が入っても、先に出した追加注文を取り消しません。日経U06の追加枚数は当時の初期停止幅Rで `floor(10×120円÷R)` を計算し、1〜10枚の範囲に収めます。過去20分帯半幅・当時ATR・8呼値の最大値をRとします。数量は発注判断時に固定します。

追加分の初期停止は1R。追尾の開始／幅は日中T06が1R／0.5R、夜間TOPIX T04が1.25R／0.75R、夜間日経U06が0.75R／0.5R。旧担当の出口は変更しません。全建玉を場内返済します。最低1枚、気配の飛び、手数料があるため、枚数算式は損失上限を保証するものではありません。

NY・Londonの夏時間は地域別に処理。対象期間では米国開始30分後は23:00、London16:30は翌00:30です。取引日ごとの損益や事後の上昇・下落で手法を選び直すことはしません。

日経夜間は固定10枚のT05に対し、追加20取引中4取引だけ減枚。勝ち2取引の利益4,490円を削る一方、負け2取引の損失28,542円を減らしました。合算の赤字6場・損失中央値8,720円は不変、平均赤字11,663→8,841円、最大赤字28,220→16,440円。**方向予測が改善した結果ではなく、同じ売買時刻の損失額を調整した結果**です。

より強く減枚するU05は夜間の平均赤字6,341円・中央値5,644円で、損失の軽さなら対案になります。赤字は7場ですが、増えた1場は−396円の小赤字。U06は大勝ち保持とのバランスで選び、U05を赤字数だけで否定していません。

TOPIXは全体でも平均赤字が平均黒字より大きい状態です。上昇22場だけから上位3黒字を除くと−72,386円。日経も夜間上昇10場では同じ除外後が−31,268円です。夜間の時系列後半11場では除外後TOPIX−60,024円・日経−17,148円。**全43場の除外後黒字を、どの小区分でも同じ強さがあると読み替えません。**

## 何を直したか

四巡36条件を比較しました。最初の「時計・方向効率で追随と回帰を繰り返す」12条件は両銘柄とも赤字。低い方向効率を、次も反発する根拠にしたことや、入り直しが増える問題がありました。旧有望核を残して未参加の場合に一回だけ補う形へ修正。次に利益保護待ちで勝ちを返す取引を追い、日経夜間の追加分を−43,400円から+26,600円へ改善。最後に固定枚数で広い停止幅を負う問題を減枚で修正しました。
