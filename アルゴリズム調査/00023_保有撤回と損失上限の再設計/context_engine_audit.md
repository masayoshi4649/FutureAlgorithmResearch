# 第4反復エンジンの独立監査

入口と保有方向の2入力を、成績選別なしで検査した。

- 保有判定4箇所以外のsimulate処理は旧エンジンと同一。context=entryの旧互換228比較が完全一致。
- prefix 32比較、未来の2方向/価格/ATR改変32比較が一致。
- 注文から独立再構築した会計を25,527,076行で照合。上下反射10ケースが一致。
- 96入口は24中期方向へ対応し、2496配列比較が一致。
- contextだけでは通常新規しない。entry中立でもcontextが維持されれば中立撤回しない。未約定取消と連敗解除はentryに従う。
- 奇数枚の部分利確後も元建値と残枚数を保持し、組全体の損益で連敗を数える。含み損予算停止後は価格反発でも再開しない。

- 監査通過は収益性の保証ではない。
- context反転の補充新規は保有管理の例外。今回の管理候補では反転を使わない。
- セッション損失予算は次行執行のため価格飛躍で超過し得る。
- CurrentPriceTimeは受信時刻ではない。
