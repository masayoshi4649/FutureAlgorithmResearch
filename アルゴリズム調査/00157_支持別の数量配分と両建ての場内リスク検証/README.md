# 00157 支持別の数量配分と両建ての場内リスク検証

**今回の数量調整で、元S01より安定したと採用できる案は確認できませんでした。** 順行追加O01は収益を拡大する候補として残せますが、途中の赤字も深くなりました。逆玉カバーと回復後の追加を足しても、この問題は改善しませんでした。

最初に見る資料：[支持別配分と両建ての全日中損益.xlsx](支持別配分と両建ての全日中損益.xlsx)。比較シート→気になる手法のシートの順で見てください。全73手法の各場利益・損失・収支・累計と、場内最悪収支・最大下落を正式テーブルで掲載しています。条件と具体的な失敗は[検証記録](検証記録.md)です。

日経mini10枚相当＝micro100枚相当／片方向。手数料0、ラージ板だけで判断し、次正常気配で約定する模型です。以下は**完了26デイ**。10月27日15:20未満の途中場は別欄です。

|手法|26場収支|赤字場|場内最悪収支|最大下落|
|---|---:|---:|---:|---:|
|C00：元S01|+1,935,000円|8|−203,000円|294,000円|

場内最悪は確定収支＋残玉全量の返済側気配による含み損益の最低値。最大下落は、その場で先に付けた最高時価からの落差です。表の5案に無取引場はありません。

- **初回量**：最低5/10/20micro＋支持量、線形・二乗、固定量を比較。支持の強さと後の損益の関係は弱く、「確信度」として増枚する裏付けは不足しています。
- **追加・ナンピン**：順行20/40/80pt、逆行20/40/60pt後の20pt回復、追加累計25/50microなどを比較。利益が増える案でも、場内赤字・下落が大きくなりました。
- **カバー・抑制**：元玉の旧出口を維持した逆玉だけの利確も比較。赤字後の減枚は最悪損失を浅くしましたが、赤字場数や大勝ち依存が悪化しました。

上限が同じでも実使用量は異なります。O01の場全体の時間平均総保有は30.49micro、J02は14.08microです。増枚による利益増を予測精度の向上とは呼びません。

O01は上位3黒字場を除いても+1,188,700円で、大勝ち3場だけの黒字ではありません。一方、平均赤字は元S01の53,500円から110,890円へ増えました。収益拡大と、求める損失軽減は分けて判断します。

既知期間での開発比較です。夜間の有効性・実mini/micro板での約定性能は未検証。今回、実アプリと稼働設定は変更していません。次の改善点は単なる増枚より、追加する場面を選ぶ判断の検証です。
