# 日経の100円順行と50円逆行の先着

**条件を満たした入口はあります。ただし、現在の主要手法の初回入口全体では30.3%でした。高確率の入口を確認したという結果ではありません。**

最初に見る資料はこのページ。全件の時刻・建値・先着価格は[計測の全件](../../work/entry160/先着の全件160.json)、担当別・支持別は[集計](../../work/entry160/先着の集計160.json)、定義は[事前計画](../../work/entry160/計測計画.md)を参照してください。今回は入口の確率だけを測定し、変更後の売買損益は作っていません。

## 今回の条件

買いなら建値から**100円上がる前に50円下がらない**。売りは上下対称です。50円ちょうどの逆行も失敗に含めます。新規の価格を基準とする固定幅で、高値から50円戻るトレーリングではありません。

時間で区切らず、元の利確や米国前後の切替後も、同じセッションの保存終端まで原板の発生順に追いました。目標100円に先に達した後の逆行は、この先着判定を変えません。

主計測は買Ask・売Bidで新規し、買玉はBid・売玉はAskで返済できる値幅です。手数料は0ですが売買気配差は含みます。右列は気配差を外し、新規時のLastからその後のLast変化だけを見た補助値です。

日中の支持0.25〜0.50は8/21＝38.1%、0.50〜0.75は6/14＝42.9%、0.75以上は0/2。夜後半は同じ順に6/12＝50.0%、2/6＝33.3%、1/1です。小標本の100%を高確度と判断できず、支持が強いほど先着率が上がるという単純な関係も確認できません。

## 結果の限界

- これは既存のS01・P05・D07/J02型の初回入口を測った結果です。過去に調べた全手法の最高値や、今後作れる全ての入口の限界ではありません。
- 従来の決済勝率・最大順行幅から推定せず、100円と50円の最初の到達原行を直接比較しました。同秒でも原行順を保持しています。

- 全て既知データです。入口をこの結果から選び直した未見検証はしていません。100円利確・50円損切りへ出口を変更した場合、その後の再エントリー系列まで同じになるとは限りません。
- 原資料・既存結果・アプリ・運用設定は変更していません。原板の内容指紋、初回価格、次正常気配の約定行を照合しています。
