# 格子とNTの先頭9セッション再検証

対象は9月21日デイから9月25日デイまでの9セッション。前回の格子54条件・NT36条件を変更せず再生した。9月25日ナイトはこの資料の作成時点で未評価である。銘柄・玉数の違う円収支を横断順位には使っていない。

## 1. 逆指値格子と全玉管理

NK225の格子内では、前回と同じ `G16_A10` が旧選択規則を満たした。開始20分以降の中心から上下へ1ATR刻みで逆指値を置き、個別の損切り・トレーリングに加え、全玉合算の損失5段、利益4段到達後1段の追跡、個別保有90分上限を使う。

| 評価 | 結果 |
|---|---:|
| 完了サイクル | 22組、13勝9敗 |
| 平均利益／平均損失額 | 323,846円／274,444円 |
| 平均勝敗比／PF | 1.180／1.704 |
| 9区間収支 | ＋1,740,000円 |
| 黒字セッション | 6/9 |
| 最良セッションを除いた収支 | ＋910,000円 |
| 最悪サイクル | −660,000円 |
| 最大のセッション内・含み込み下落 | 1,270,000円 |

9月24日ナイトは−660,000円、9月25日デイは＋360,000円。過去7区間の＋2,040,000円から9区間の＋1,740,000円へ減った。平均勝敗比は1をわずかに上回るが、各敗戦が十分小さいとまでは言えない。最良サイクル550,000円より最悪サイクル660,000円の絶対額が大きいことにも留意する。

## 2. TOPIXのかご損切り付き指値格子

TOPIXの格子内では `G05_A05` が旧選択規則を満たした。幅0.5ATRの上下指値格子に、全玉合算で5段損失となった際の全返済を加えた条件である。

24組6勝18敗、平均利益489,167円／平均損失131,944円、平均勝敗比3.707、PF1.236、9区間合計＋560,000円、黒字5/9。勝率25%と低くても平均勝敗比によって合計は黒字になった。

ただし、最良セッションを除くと−305,000円、最良サイクルを除くと−480,000円になる。旧選択規則で用いるATR・設定枚数換算の最良セッション除外収支は＋0.008249とわずかに正なため形式上は通過するが、円損益で安定性が確立したとは解釈できない。最大セッション内下落は830,000円である。

9月24日ナイト＋140,000円、9月25日デイ＋325,000円の追加によって上位へ出てきた候補である。この2区間で条件を選び、その2区間を未見の証明に使うことはしない。

## 3. 手動例に近い利益玉のみの5ポイント格子

TOPIX `G01_T10` は9組6勝3敗、平均利益151,667円／平均損失475,000円、平均勝敗比0.319、PF0.639、合計−515,000円。追加2区間は＋100,000円と＋20,000円で改善したが、残した負け組の損失額を覆せていない。

同水準の指値と逆指値を併設する `G15_T10` のTOPIXは、平均勝敗比0.491、PF0.614、合計−270,000円。今回の固定した利確・損切り定義では、方向を両方に展開するだけで安定した損小利大にはならなかった。

これらは機械的な代替定義の評価であり、手動の裁量利確全体を再現した結果ではない。いずれもセッション終了までに全返済し、場またぎによる回復待ちを含めていない。

## 4. NT相対価格の持続と整数枚ヘッジ

実行可能なNT条件の旧基準選択は、引き続き `NT_ratio_mom_Z1_S1`。15分の対数NT比変化を過去の変動で標準化し、絶対値1以上の方向へ追随する。総20枚以内で両銘柄の相対元本差を最小にする整数組合せを使う。

50組25勝25敗、平均利益369,200円／平均損失288,800円、平均勝敗比・PFとも1.278、9区間合計＋2,010,000円、黒字5/9。入口前に固定する予定リスクR換算では平均利益1.305R／平均損失0.932R、平均勝敗比・PFとも1.400である。

最大セッション内下落2,700,000円、最悪サイクル−900,000円であり、相対取引でも小さな振れだけになるわけではない。完了サイクルの累積損益による最大下落は3,430,000円で、単一セッション内の指標とは対象期間が異なる。

| 追加区間 | 合計収支 | NT相対変動要因 | 共通方向に残る元本差の要因 |
|---|---:|---:|---:|
| 9月24日ナイト | −1,270,000円 | −1,262,934円 | −7,066円 |
| 9月25日デイ | ＋1,090,000円 | ＋1,089,992円 | ＋8円 |

9区間全体の相対要因は＋1,976,237円、元本差要因は＋33,763円だった。今回の整数組合せでは、少なくともこの2区間の大きな勝敗は端数より相対方向そのものの成否に支配されている。端数を減らすことと方向予測を当てることは別である。

NT全36条件中で得点が高いmini相当や連続枚数の条件は、価格代理・実行不能枚数を含む診断であるため、実行可能な採用から除外した。

## 5. 再現性・会計確認

旧7区間は格子756セルの全脚214,324値と集計22,680値、NT252セルの全サイクル103,796値が保存済み旧結果と一致した。

追加2区間では格子16代表セル・2,232,076原本行の全玉会計を別式で照合し、32件の未来打切りで過去の確定脚が変わらないことを確認した。NTは全1,784脚・892組の原本価格、整数数量、損益分解を確認し、8代表セル・2,234,797原本/時計行の独立会計と16件の未来打切りが一致した。

9区間の全格子・NT条件とも打切り時の未完了サイクルはゼロ。API取得ゼロ、旧ソース・条件・原本の変更ゼロ。各監査の件数とハッシュは `格子とNT_再検証監査.json` と `格子とNT_追加区間会計監査.json` に保存している。
