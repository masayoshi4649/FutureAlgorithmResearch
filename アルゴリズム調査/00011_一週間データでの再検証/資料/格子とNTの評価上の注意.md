# 格子・NTの今回の再検証

今回の目的は、前回の格子54条件・NT36条件を変更せず、一週間に延びた保存データへ適用して、同じ銘柄・同じ売買単位で平均利益と平均損失がどう変わるかを見ることである。最終の9月25日ナイトは採用条件を固定するまで計算しない。現在APIは使わない。

## 1. 格子では利確した玉だけを勝ちに数えない

中心価格を設定してから全返済・中心再設定・新規停止後の全返済・セッション終了までを一つの売買サイクルにする。その間の利益玉の利確と再配置は同じ組へ含める。途中で保有がゼロでも、同じ中心で再配置を続ける組は打切り時点では未完了とする。未完了組の確定利益を、独立した勝ち組として平均利益やPFへ加えない。

全建玉の含み損益を含む収支と最大下落を別に記録する。CSVの `profit_yen` と `loss_yen` は脚ごとの返済額であり、損小利大の主評価は `cycle_gross_profit`、`cycle_gross_loss`、`cycle_payoff_ratio`、`cycle_profit_factor` である。サイクル平均勝額が小さく平均負額が大きい場合、脚の勝率だけが高くても目的を達成していない。

手動の「反発・反落時に裁量で利益玉を利確」は一意に再現できないため、固定幅利確・全玉合算の追跡・時間上限など、前回定義した機械条件で代替している。裁量手法全体の有効性を否定したり再現したりした結果とは扱わない。

TOPIXの10呼値幅は5ポイント、NK225の10呼値幅は100ポイントである。上下格子は買い5枠・売り5枠、片側格子は10枠、指値と逆指値の併設は8枠であり、無制限の追加玉は許していない。原則の場内返済を守り、手動例の場またぎは再現しない。

## 2. 格子の損切りと追跡は別の役割を持つ

各玉の損切りは一つの入口の失敗を打ち切り、かご全体の損切りは複数玉を合わせた失敗を打ち切る。合算追跡は途中利確を含む全玉損益の最大値から一定額減ったときに退出する。これらの有効性は「同じ入口でも大損を減らせたか」と「利益を削りすぎないか」を分けて評価する。

停止条件を付ければ常に収益性が上がるわけではない。損失を小さくした一方で、その後の回復を取れなくなることもある。旧条件のまま、追加セッションでも平均負額・最悪サイクル・含み込み最大下落が改善したかを見る。

今回の指定価格約定では価格条件を飛び越えた場合も指定値で約定する。条件の更新は次の原本行から有効とし、同じ水準の再配置は一度不成立側へ戻ってからの再到達を必要とする。すでに成立している水準へ無限に置き直して架空の利益を繰り返すことはない。

## 3. NTは相対変動と残った方向リスクを分ける

NK側の入口想定元本をA、TOPIX側をB、各入口後収益率をrNとrT、NK側の方向をdとする。実際の2脚損益は次の2項に厳密に分かれる。

`d×(A+B)/2×(rN−rT) ＋ d×(A−B)×(rN+rT)/2`

前項は相対変動、後項は共通方向に残った元本差の影響である。後項には整数丸め以外に注文判断から両脚約定までの価格変化も含む。過去βで数量を決めた条件はβ対応の分解も併記し、βが1ではないため意図的に残した方向と丸め誤差を混同しない。

整数等金額の組合せは最大20枚以内で相対元本差を小さくする。少数枚の組合せより残差率が小さくても、総元本が大きくなる場合がある。円収支の増加を精度向上と読み替えない。NT内部でも予定リスク1R換算のPF・平均勝敗比を併記する。1Rは入口前の共分散に基づく予定幅であり、証拠金収益率でも損失保証額でもない。

mini相当2方式はラージの価格へmini倍率を適用した感度分析で、実miniの板を検証していない。連続枚数方式も実行不能な比較用であり、これらを発注候補の選択へ混ぜない。

NTの合算逆指値には単独銘柄のような唯一の指定価格がないため、条件判定後の各銘柄の次の原本価格で個別返済する。合算の到達額を架空の同時約定価格へ割り振らない。したがって1R損切り指示でも実現損失は1Rを超える場合がある。

## 4. 週の利益だけでは安定性を判断しない

損小利大は平均利益÷平均損失が1を超えるだけでは不十分で、勝ち頻度を含むPF、セッション別収支、最良セッションを除いた収支、全原本行の含み込み最大下落を合わせて見る。同銘柄間でも玉数と保有時間が違うため、平均勝敗比・PFに加えてATRと設定上限枚数による補助値を表示する。この補助値を実損切りのRと呼ばない。

一週間の10セッションは取引が多数あっても10個の独立した相場環境とは限らない。同じトレンド内の売買は相関し、11,253条件から良い条件を拾う行為にも選択の偏りがある。最終夜が良かっただけで「有意な規則を確立した」とはしない。逆に、今回の有限な格子・NT条件が悪かっただけで、全てのアルゴリズムが不可能とも判断しない。

今回の先頭9セッションは再選択用、最終夜は固定後の照合用として明記する。旧候補をそのまま延長した結果と、先頭9区間で選び直した候補の結果を分ける。既に閲覧された期間を未見の検証期間と呼ばない。
