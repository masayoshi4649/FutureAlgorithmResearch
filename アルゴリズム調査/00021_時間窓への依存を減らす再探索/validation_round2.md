# 第２反復の敵対検査

最初に `反証規則の固定.json` を読む。新しい成績を見る前に数値基準を固定する。`反証実装の固定.json` は実行開始前にコードと入力の指紋を確定する。

時計窓・相手遅延の4条件、経過確認の2条件、入口幅の2条件、管理stop/trail/lock/timeoutの8条件を混ぜず判定する。時計4条件なら3条件以上が両銘柄黒字かつPF1.2以上。各カテゴリは各銘柄の中央値が元収支の半分以上、最悪値が元収支のマイナス25%以上を要求する。遅延1/5/15秒と観測価格約定は全条件で両銘柄黒字・PF1.2以上を要求する。

構造上使用しない値（成行入口幅、0の利益保護/時間上限、確認0、単独F32の相手遅延）は分母から除外する。有効な変形でも今回の方向列が偶然同じなら、その件数・比率と台帳一致を表示する。時計小区分や個別管理変数の結果も分けて残し、平均値の裏で壊れる条件を隠さない。

探索上位30の異なる台帳と各信号思想の首位を最大75件まで検査し、合格から異なる信号思想・管理思想の組を最大10件、固定64seed×2の無予測対照へ進める。乱数の都合の良いseedを採らず正式な有意確率を主張しない。これらは全て既知期間に対する反証であり、未知期間の検証とは呼ばない。

費用0・指定価格約定を主条件として維持する。観測価格約定は費用とは別の補足耐性検査である。全玉合算、片方向保有限度、次観測以降の執行、場内返済を各再生で検算する。

実行順序:

1. `python work/wave_v26/validation_round2.py --rules-only`：結果を読まず数値規則だけ固定。
2. 信号コードと探索仕様が完成後、`python work/wave_v26/validation_round2.py --prepare`：実装指紋固定と合成検算。
3. 全探索終了後、`python work/wave_v26/validation_round2.py --workers 10`：固定候補へ一次反証。
4. `python work/wave_v26/validation_round2.py --workers 4 --random`：通過した思想へ64seed×2対照。

主結果は `一次反証の結果.json`、詳細は `adversarial/`、乱数要約は `無関係対照の要約.json`、全seedは `randomized/`。同じ反証実装指紋の結果だけを再開利用できる。
