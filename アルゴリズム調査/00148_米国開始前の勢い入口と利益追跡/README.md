# 米国開始前の変更と時間帯ごとの手法切替

**時間帯ごとに手法を選べるアプリへ改修した。一方、今回の勢い入口24条件は過去25夜で改善せず、標準D07には採用しない。**

最初にこのREADME、次に[全25夜の損益表](米国開始前の変更と全夜間損益.xlsx)を参照。必要なら[具体的な損失時刻と板](損失原因/損失原因.md)、[検証条件と反証](検証条件と反証.md)へ進む。

日経mini・片方向上限10枚、手数料0円。売買気配差と判断後の次正常ラージ気配での約定を計上。2026年9月21日〜10月23日の保存25夜で比較した。

| 手法 | 米国前の収支 | 夜間全体の収支 | 夜間赤字場 | 最大赤字場 |
| --- | ---: | ---: | ---: | ---: |
| D07 | +81,000円 | +1,635,000円 | 8/25 | 53,000円 |
| P01 | -1,800,000円 | -246,000円 | 18/25 | 210,000円 |
| P06 | -220,000円 | +1,334,000円 | 12/25 | 147,000円 |

- **P01**：短期と中期の勢いが同方向なら5枚。順行後5枚追加。赤字の方向反証で損切り、100pt順行後は80ptトレール。
- **P06**：入口確認を15→30秒へ延長。新候補では損失が最小だが、米国前9/25場が無取引となり、D07全体より赤字場も増えた。
- **Q01**：価格更新が5秒空くだけで方向確認を消さないよう修正。参加は増えたが、損失も増えた。
- **Q06**：Q01に「40pt押し戻り後、30pt再反発」を加えて入口を改善。損失は縮小したが黒字化せず。

**主な原因は、既に進んだ方向への追随が反転を受けること。** P01の最悪3夜では損失16玉中13玉が最大順行40pt未満だった。利確幅だけでは救えない。一方、10月22日の+70/+90ptから損切りした玉には保護開始の遅さもあった。

今夜10月26日21:13までなら、Q06は確定+170,000円・含み−20,000円。しかし過去25夜の米国前は−3,590,000円。この途中場だけを見て採用すると判断を誤る。途中結果はxlsxの別シートに置き、25夜の合計から除外した。

## アプリ

商品の⚙から「時間帯を追加」し、開始・終了・手法を指定する。日本時間と「米国開始の前後」を選べ、昼夜の中をさらに分割できる。設定できるのはOFF時だけ。

境界では当運転の未約定を取消・照合し、所有玉を返済してから次手法を新規状態で始める。手動玉・前起動の玉は対象外。空白時間は静観。旧設定のままなら従来の動作を維持する。
