## 板をどう読むか

外部の相場変化に追随するなら、国内参加者は注文価格も置き直すはずです。**厚い・薄いだけでなく、買い気配と売り気配が揃って移動し、その価格帯を維持できるか**を見ました。同じ価格の数量回復を併せて読み、反対方向の価格帯が成立した時は既存の入口を疑います。表示数量だけでは、実際の約定消費・取消・隠れた補充は識別できません。

03では、元の入口と反対の価格帯維持・同価格の数量回復が既知なら待機します。価格時計で30秒以内に元方向の新しい価格帯維持が成立した場合だけ参加し、成立しなければその入口を取り消します。常に30秒待つ条件ではありません。
