# 売買をどう捉え、何を反証するか

約定は買い手と売り手が同時に成立する交換です。約定した買い数量と売り数量は等しく、「買いが多いから上がる」をそのまま数量差とすることはできません。価格の移動は、今すぐ執行する側がどの価格まで受け入れ、待つ側がどこにどれだけ流動性を残すかという関係として検証します。

相場で確認できるのは参加者の内心ではなく、提示価格、数量、その変化、成立価格、出来高です。同じ補充でも情報を持つ受け手、機械的な執行、在庫調整など複数の説明があり得ます。仮説を観測事実と同一視せず、逆の解釈・無効になる状況も併記します。

## 哲学的な出発点

**同じ価格で買う人と売る人がいるのは、目的・期限・情報・在庫・許容損失が違うからです。** 上がると考える買い手だけでなく、既存の売りを閉じる人、現物リスクを調整する人、期限までに執行する必要のある人もいます。売りも同様です。短期の方向予測に全員が参加しているという前提は置きません。

価格は参加者全員の信念の平均を直接表示するものではありません。現在の提示注文に対し、実際に交換が成立した位置です。したがって今回の対象は「真の価値を当てること」よりも、「今後の執行圧力とそれを受ける流動性の変化を、この観測範囲で先に識別できるか」です。同じ売りでも、補充される買い板へ向かう場合と、買い板が撤退する場合を分けます。

表示されていない注文が後から現れるので、現在見える板だけを固定した全需給とは扱いません。[潜在流動性の研究](https://arxiv.org/abs/1808.09677)は、この観点を考える参考です。今回のデータで潜在注文量そのものを推定したわけではありません。

注文手法には損益分布を変える働きがありますが、単独で期待利益を作れるかは別の命題です。たとえば「各次時点の価格差の条件付き期待値がゼロ」「保有数量はその前に決める」「数量に上限」「固定した場内期限で全返済」という理想化では、期待損益 `E[Σ 保有数量 × 次の価格差]` はゼロです。この仮定を市場が満たすかを検証するのであり、先にコイントスだと決めません。

同価格で同枚数の買いと売りを同時に持つと、その時点以後の価格変化に対する損益は相殺します。片側利確後の利益は、残った純保有の方向と次の価格経路に依存します。利益玉だけを数えず、全玉の時価を追跡する理由です。今回はこの会計を原本行ごとに独立再構成して確認しました。

アルゴリズムの利用者が多いという事実だけでは、この保存データ・時間軸・場内完結・約定仮定で自分に利用可能な利益があることまでは証明できません。一方、それを理由に探索を打ち切ることもしません。観測、行動、反証の三つが揃った仮説を実装して比較します。

## 選択まで含めて一つの機械にする

「今日は順張り、明日は逆張り」という事後の説明を取引アルゴリズムとは扱いません。追加した選択器は、①当時までの相場状態で方向手法を選ぶ、②完了済みセッションの実績で次の手法を選ぶ、の二系統です。選択確認回数や最低継続時間も数値化します。

選択された方向列を、単一の注文管理器へ渡して原本の先頭から再生します。保有・休止・連敗・損失予算を引き継ぎ、切替時に過去の損失玉を消しません。保持、判断撤回による返済、反転を別々に一体評価します。選択後の他手法の過去利益だけを足す方法は使いません。

## 検証する市場原理

| 原理・動機の仮説 | 保存データで測るもの | 成立を疑う条件・反証 |
|---|---|---|
| 急いで売りたい参加者が買い板を使い切ると、成立可能な価格が下がる | 推定売り流入、買い板減少・後退、価格応答、両銘柄での同時性 | 流入しても補充され、価格が下がらない |
| 大口は一度で処理できず分割し、同方向の執行が続く | 推定約定符号の持続、注文フロー、短期と中期の一致 | 流れが続いても価格効果が消失する、次期間で関係が逆転する |
| 同価格で受け続ける参加者が圧力を吸収する | 数量減少後30秒以内の同価格補充、フローに対する小さい価格反応 | 補充が途切れ、その価格帯を抜ける |
| 待っている流動性が撤退すると小さい売買でも価格が動く | 距離重み付きの板変化、推定売買量当たり価格変化、近い板と遠い板の差 | 板が素早く戻り価格も戻る |
| 情報による価格の見直しは、一時的な需給ショックより持続しやすい | 急変後の持続方向、流動性回復、両銘柄の確認、時間を変えた応答 | 数分で元の帯に戻る、両銘柄が一致しない |
| 在庫を抱えた側や損失が膨らんだ側の返済が次の流れを作る | 累積推定売買と価格反応の食い違い、その後の反転 | 新規・返済の別を識別できず、代理指標が将来に結びつかない |
| 共通因子の売買ならNKとTOPIXの流れが同期する | 銘柄ごとに尺度を正規化したOFI・補充・価格方向、60秒遅延の相手情報 | 片方が吸収する、業種構成差による単独変動、先行関係の反転 |
| 方向のある価格変化が自己継続する場合がある | 複数速度の順張り、過去高安更新、効率比、開場レンジ | 往復相場・ブレイク失敗で損失が累積する |
| 価格帯内の需給修復では平均回帰が働く場合がある | 低効率比、VWAP偏差、ブレイク失敗、流動性回復 | 片方向相場で反発買い／戻り売りが連敗する |
| 予測が弱くても損失制限・利益伸長に効果があり得る | 同一信号と異なる注文管理、同じ注文管理とランダム方向の対照 | 選択した一部乱数だけで良い、損失玉を未決済で隠している |

「買ったら後に売る」という説明は、同じセッション中の売り圧力を保存板だけから確定させる根拠にはしません。新規・返済、所有者、注文ID、隠れた注文は識別できません。ここでいう蓄積は推定フローの履歴であり、物理的な保存エネルギーではありません。

## 方法と目的の切り分け

検証の順は、観測量の因果的生成、将来の値動きとの関係、機械的な新規・返済、損失の連続時の挙動です。後から見た「今日は下落日」というラベルを入口に使いません。上昇と下落は対称条件で扱い、中立・不一致・判断撤回を明示します。

全13セッションは既読なので、全期間の最良値を未知データの実績とは呼びません。最初６セッションから過去だけで選ぶ逐次検証、最大勝ちを除いた成績、独立した管理単体の合成下落ストレスを区別します。全条件の結果を残し、何もしない候補を最優秀にしません。

## 調査した一次資料と今回の独自化

- [Huang・Lehalle・Rosenbaum：Queue-reactive model](https://arxiv.org/abs/1312.0563)。板の状態に応じた注文到着という観点から、近い板・遠い板の変化を分ける仮説を追加します。
- [Bechler・Ludkovski：Order Flows and Limit Order Book Resiliency](https://arxiv.org/abs/1708.02715)。追加・除去と板形状の観点を、距離重み、補充、価格応答の組合せへ具体化します。
- [Xuほか：Limit-order book resiliency](https://arxiv.org/abs/1602.00731)。衝撃後に板が回復する場合と回復しない場合を別の候補にします。
- [Tóthほか：Why is order flow so persistent?](https://www.cfm.com/why-is-order-flow-so-persistent/)。分割執行を示唆する持続性を、注文者の同定を伴わない代理特徴として測ります。

これらの研究は別市場・別期間を含み、今回のOSEデータで利益が出る証明には使いません。今回の閾値や組合せは独自の検証仕様であり、論文の完全再現ではありません。
