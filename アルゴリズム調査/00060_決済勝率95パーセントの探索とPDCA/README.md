95%以上はTOPIXの同じ入口の1勝/1取引だけでした。負けの大きさが未観測で、3つの継続運用成功候補とはしていません。3候補は未達の比較対象です。

金額は費用後の全決済組を正負へ分けた利益・損失です。枚数はその組の決済枚数。手数料を再度引かないでください。全場内返済、初回TOPIXmini5枚/NKmicro10枚、追加なし、片方向上限10枚/20枚以内です。
