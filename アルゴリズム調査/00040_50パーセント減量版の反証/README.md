# 50パーセント減量版の反証

最初に [短い比較と結論](50パーセント減量版の反証.html) を見てください。

読む順序は次のとおりです。

1. [比較と結論](50パーセント減量版の反証.html)：50%版と元方式の損益、今回の反証結果。
2. [全条件の損益](全条件の損益.html)：153条件から選び、各セッション・各週・全期間の利益／損失／収支を金額・決済枚数で確認。
3. [5分足と売買](５分足と売買.html)：A0・C01・25%版・50%版の4方式×26場銘柄、104図。

主案は `G150_F50_N1__V000`。元H019で方向を決めて入り、初回価格から有利な方向へ1.5初期ATR進んだ後、新しい逆行判定で現存枠の50%を最大1回減らします。端数を切り捨て、最低1枠は残します。新しい回復判定が出れば、生存している元の枠だけを復元します。初期損切り・部分利確・トレーリング・360分期限・場内返済は維持します。

1.5ATRは価格の距離であり、利益金額の倍率ではありません。到達後に価格が戻っていても減量の許可は残ります。到達行で同時に減量せず、到達後の新しい判断だけを受け付けます。初回の判定に未来の値動きを使いません。

TOPIXミニは初回5枚・片方向上限10枚、NK225マイクロは初回10枚・片方向上限20枚。費用0・指定価格約定の仮定です。大型先物の観測価格を小型商品の倍率へ換算しています。勝ち／負け枚数は返済した累計枚数であり、同時保有枚数や注文件数ではありません。

対象は保存済み13セッション。後半7セッションも既知資料で、未見データではありません。中央50%版は前回の探索で成績を見て選んだ候補です。既知11条件は経済条件を変えず引き継ぎ、今回新しく142条件を反証しました。中央の既知利益を、新しい独立検証による利益と重複して数えません。現在APIの追加取得・保存ライブの再利用はともに0です。
