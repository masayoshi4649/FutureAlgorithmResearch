# 支持境界と利益追尾による毎場の損失抑制

最初に[短い説明と全セッション損益](支持境界と利益追尾の説明と全セッション損益.html)を見てください。最大収益より、赤字頻度・損失規模・大勝ちへの依存を優先した121条件の比較です。

読む順序は、HTMLの結論と比較表 → 各手法を開いた全セッション損益 → [公開会計](公開会計.json)です。

単一手法は各商品1枚。二手法の配分はTOPIXミニ合計10枚、日経マイクロ合計20枚。利益・損失は手数料後、相殺前の取引別集計です。無取引を勝ちに含めません。
