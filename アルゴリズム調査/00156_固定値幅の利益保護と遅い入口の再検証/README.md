# 00156 利益保護・入口・再参加の見直し

最初に見る資料は [全44手法のセッション損益（Excel）](利益保護と再参加と入口見直しの全日中損益.xlsx) です。比較シートの後に、手法ごとの全26完了日中を掲載しました。10月27日途中は別シートです。

**小さい利益を守る効果は確認できましたが、今回の改修をS01に代わる改善版として採用する結果にはなりませんでした。**

|方式|26場収支|赤字場|途中の最悪収支|当場の最高収支からの最大下落|
|---|---:|---:|---:|---:|
|比較元S01|+1,935,000円|8|−203,000円|294,000円|
|完成2分の順行を確認して入るE01|+1,343,000円|8|−133,000円|218,000円|
|利益発生後20pt追尾F05|−366,000円|14|−104,000円|106,000円|
|F05＋20pt回復で再参加R01|−3,203,000円|24|−462,000円|468,000円|
|R01＋再参加玉に20pt逆行制限L01|−1,216,000円|25|−141,000円|143,000円|

E01などはこの調査内の比較IDです。以前の取引手法E01とは別です。途中収支は、確定損益と全残玉の返済側気配による含み損益の合計です。

原因は三つでした。①15:00の新規前に検出できた停滞を入口へ使っていなかった。②早い全利確では大きな順行利益も消えた。③再参加を増やすと、気配差と一度も順行しない追加取引の損失が増えた。再参加玉だけ狭く損切りしても全体黒字には届きませんでした。

S01も全指標で最良ではありません。入口E01は収支を59.2万円減らす代わりに場内リスクを下げました。**初回5枚などの数量は比較元のままであり、数量配分を最適化した結果ではありません。** 最新指定の初回量・追加・抑制・ナンピン・両建ては次の研究で分離して扱います。

読む順序は、上のExcel → [実運用で起きたこと](実運用で起きたこと.md) → [条件と検証記録](検証記録.md)です。条件別の具体売買、43項目の独立反証、再会計の根拠は検証記録から参照できます。

日経mini片方向10枚・手数料0・ラージ板の次正常気配による研究比較です。全44手法は既知期間での開発比較で、実mini約定や将来の成績を保証しません。アプリ・稼働設定は変更していません。
