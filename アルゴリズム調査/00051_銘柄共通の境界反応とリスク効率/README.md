## 固定したこと

利益の順位で銘柄別の手法を選ばず、同じ境界反応から方向を選ぶ主案S3_Tを先に固定しました。F/R/Sは定着追従だけ／突破失敗だけ／両者の状態選択、0/1/2/3は価格だけ／指値供給確認／出来高確認／両確認、末尾T/Fは追跡／2R固定利確です。3政策×4確認の12条件と、S0_F/S3_Fを合わせて14条件です。

最初に固定した数値で全23場を照合し、成績を見て再調整していません。主案が不合格でも対照の最良結果へ差し替えていません。板の確認と出来高の確認を分け、管理は固定反証線・単純追跡・30分期限に絞りました。

新規はTOPIXミニ5枚、NK225マイクロ10枚。追加建てなし、片方向上限10枚／20枚以内。原本ラージ価格の判断後次有効行で仮想約定し、費用0、全玉を場内で返済します。全14条件・644口座を照合。現在API取得0です。

## 再現

Python、numpy、pandas、numbaを使用します。プロジェクトルートから:

```text
python -X utf8 work/wave_v54/features.py
python -X utf8 work/wave_v54/backtest.py
python -X utf8 work/wave_v54/analyze.py
python -X utf8 work/wave_v54/build_report.py
```

元の公開足は作業00050の監査済み特徴、生板の集計は作業00049の監査済み原始量を利用します。`backtest.py` は [売買仕様固定.json](../../work/wave_v54/売買仕様固定.json) のコードハッシュと一致する場合だけ再実行します。既存23場を再現するコードで、新セッション追加は入力一覧と監査を拡張して別作業で評価します。
