# 論理と検証結果

前回の「TOPIXはT05、日経はT12」は、実績からの候補選抜でした。今回は、銘柄名で分けずに利益を狙う理由と、その理由が否定される条件を先に置きました。

## 利益源として必要なもの

効率は、初めに引き受けたリスクに対する全玉の収益です。小さい損切り幅を置くだけでは、その損切りに当たりやすくなるため優位性になりません。+2R／−1Rで正確に完結する特殊な取引なら期待値は `3×勝率−1` R。目標が2倍でも、勝率が1/3以下なら正になりません。期限返済や約定のずれを含む実際の試験は、全取引の実現R平均で比較します。

板の注文変化がその区間の価格変化と関連するという研究はありますが、同時点の説明力から、その後も同方向に動くとは導けません。[Contほか](https://arxiv.org/abs/1011.6402)

T05には「VWAP回復後も値直しが続く」、T12には「一時的な執行偏りが後で戻る」、T08には「帯内復帰後に平均へ戻る」という未確定の仮定があります。どれも指標名だけで両市場共通の利益を論理的に導けるものではありません。

## 共通主案の考え方

既知の高安線を越えた後、外側で価格を保つか、内側へ戻るかを観測します。定着なら追従、突破失敗なら回帰を狙う。反証線の近くで入り、外れた場合を小さくし、続いた場合を伸ばす。同じ支持抵抗でも反転・加速の両方が生じ得るという発想には注文機構の研究上の根拠があります。ただし為替の研究であり、この先物での利益を証明するものではありません。[Osler](https://www.newyorkfed.org/research/staff_reports/sr125.html)

| 段階 | 今回の機械化 |
|---|---|
| 入口 | 現在足を除く20分高安を、終値が0.1ATR超えたら線・ATR・中点を固定。開始足を含む2本連続が線外なら追従、後続足が線内へ0.1ATR戻れば逆方向。10分以内の最初の確認だけを使う |
| 参加位置 | 判断時の反証線まで2呼値以上・0.75ATR以下。回帰側は、固定レンジ中点まで少なくとも損切り幅の2倍を必要とする。追従先に同じ余地が保証されているとは扱わない |
| 確認 | 同価格の指値供給の純変化を近接板厚で割り、入口方向への変化が当場過去の通常規模以上。出来高も当場過去中央値以上。尺度は事件開始時に固定。両者を分けた対照も実施 |
| 途中・出口 | 固定した反証線で損切り。1R進んだ後は1R幅で追跡。30分又は場内期限で返済。部分返済・増玉・複雑なモード切替は追加しない |

価格・数量の単位差はATR、呼値、板厚、当場の過去中央値で調整します。銘柄名を交換しても判断は不変でした。しかし、この正規化は継続性・回帰性・ジャンプの違いまで消しません。同じ規則を適用できることと、両方で期待収益が正であることは別の検証です。

## なぜ論理だけでは足りなかったか

板・出来高も通った定着候補は、待つ間に平均0.20ATR／0.25ATR進んでいました。一方、確認後15分の中値変化は候補方向を正として−0.15ATR／−0.13ATRでした。見えた強さは主に確認前までの動きで、その後に継続する根拠が不足しています。未来のこの数値は結果分析だけに用い、入口へ戻していません。

回帰側は、近い反証線と2Rの余地を同時に満たす候補が元からTOPIX17件・日経12件と少なく、主案の両確認後は4件・7件でした。ここは安定した法則を判断できる件数ではありません。途中で反証線に当たって返済していても後で回復する例があるため、15分後の平均変化だけを取引利益と読み替えていません。

主案の全入口から固定30分の価格経路を調べると、利益2R先着／損失1R先着は12／30組、12／26組。未到達は3／1組でした。「利益目標を遠く置いたから、期待値が上がった」とは言えません。トレールの実収益とは別の経路対照です。

## 結論

今回、共通化できたのは尺度と状態の判定手順、リスク管理です。両銘柄で共通する正の収益性は確認できていません。したがって、以前の銘柄別の好成績を理由にT05やT12を共通の本命とは扱いません。

理論上の焦点は、価格の変化が一時的な注文偏りの消化か、継続する値直しかを、**まだ利益余地が残る時点**で識別できるかです。今回の「2本の定着＋現在足の供給と出来高」はその識別器として不十分でした。確認を増やすことと、未来の情報が増えることは同じではありません。

未検証なのは、定着の待ち時間・近接条件・回帰余地の各条件を単独で外す比較、複数場の履歴、相手市場の追加、未知セッションの再現性です。今回の14条件は方向政策・供給・活動・出口の部品対照で、これら全てを試したわけではありません。

全644口座の円・実効R・計画R、数量、場末保有0と、未来を切断／変更した際の過去判断不変を独立確認済みです。保存履歴は既読23場なので、成績を固定後に照合しても未知データの試験にはなりません。
