# 一般的な分析と、板確認・損益管理

最初に見るファイルは **[一般的な分析と損益管理の検証.html](一般的な分析と損益管理の検証.html)** です。銘柄と手法を選ぶと、入口・途中・出口、各場・各週の金額と枚数、5分足の売買位置が変わります。

読む順序:

1. HTML冒頭の結論と、同じ入口の4層比較。
2. [短い検証結果](検証結果.md)：残った候補、管理が効いた／効かなかった理由。
3. 必要な場合だけ [12入口の規則](../../work/wave_v53/theory/入口12条件の原理.md)、[管理と自動選択](../../work/wave_v53/theory/4層比較と自動選択.md)、[一次資料とデータの限界](../../work/wave_v53/theory/一次資料とデータの限界.md)。

集計用: [セッション別損益.csv](セッション別損益.csv) · [週別損益.csv](週別損益.csv) · [4層比較.csv](4層比較.csv)。注文・判断の全件は [work/wave_v53](../../work/wave_v53/) の `台帳/`・`判断/`・`30分/` にあります。

## 比較の範囲

- 保存済みの2026/09/21〜10/06、23セッション・46原本。現在API取得0。全条件で当該セッションのみを参照。
- 支持抵抗、突破と戻り、当場近似VWAP、EMA、RSI、帯内復帰、確定高安、同価格の板回復、執行偏りの12入口。
- A基本保護・B管理追加・C板と相手の確認・D確認と管理を併用、計48条件。状況による固定選択AUTO_A/Dを加え50条件。
- 新規はTOPIXミニ5枚・NK225マイクロ10枚、追加なし。片方向上限10枚・20枚以内。高度管理は一度だけ2枚／5枚返済可能。上限まで常時保有する設定ではありません。
- 条件成立後の次有効原本行の最終価格で約定、費用0。原本はラージの価格と板。全玉を場内返済。
- 全履歴は既読で、未知データの成績ではありません。数値は新成績を見る前に固定。今回の成績に基づく候補選抜は探索段階です。

## 再現

プロジェクトルートから実行します。Python、numpy、pandas、numbaが必要です。入力キャッシュは00049以前の監査済み原本抽出を使用します。

```text
python -X utf8 work/wave_v53/features.py
python -X utf8 work/wave_v53/backtest.py
python -X utf8 work/wave_v53/analyze.py
python -X utf8 work/wave_v53/build_report.py
```

`backtest.py` は [売買仕様固定.json](../../work/wave_v53/売買仕様固定.json) のコードハッシュを照合し、無記録の規則変更を拒否します。既存の46原本を対象とした再現用です。新セッション追加には入力一覧の拡張と、その時点での別作業としての固定評価が必要です。

[特徴監査](../../work/wave_v53/特徴監査.json)・[信号監査](../../work/wave_v53/信号監査.json)・[独立監査](../../work/wave_v53/review/) に、未来切断・原本行順・分割会計・場末保有0の確認を保存しました。
