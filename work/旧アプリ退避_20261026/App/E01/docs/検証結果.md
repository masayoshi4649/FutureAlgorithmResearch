## 再実行

`App/E01` で次を実行します。固定の期待値は同梱しており、テストにもPythonや実口座接続は不要です。

```text
go test -count=1 ./...
go vet ./...
go run . -check
go run . -dryrun -duration 180s -log-dir log/check -state-dir state/check
```

最後のコマンドだけは実controllerへ読み取り接続します。記録対象を分けたい場合は保存先を変えてください。
