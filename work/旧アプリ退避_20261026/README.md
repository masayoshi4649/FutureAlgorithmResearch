# 旧アプリの退避

旧E01とSessionTraderの商品別単品配布10フォルダを、App・distの外へ移動した。削除の一括処理は自動承認レビューが拒否したため、復元可能な移動へ変更した。新しい配布はSessionTrader Web版だけを生成する。

元の配置は`移動計画.json`、設定・ログ・状態48ファイルの移動前後のSHA256照合結果は`監査ファイル指紋.json`に保存した。ソース直下の旧単品conf6ファイルは`SessionTrader旧単品ソース設定`へ別途退避し、新しいWeb用confへ置き換えた。旧アプリのソースや実行ファイルもこの領域に残してある。

現在使う実行ファイルと設定は`App/SessionTrader/dist/{OS}/Web/`。ここにある旧実行ファイルを同時に起動しない。
