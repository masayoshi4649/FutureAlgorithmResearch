# 支持と初回数量の根拠を測る計画

**強い支持で初回を大きくする方向は維持し、その支持に勝率・期待値幅の差があるかを検証する。** 00157の全155初回親を採否にかかわらず使い、数量変更後の損益ではなく、変更前S01の同じ初回玉へ結び付ける。

## 保存資料の再利用

- `work/allocation_157/round2/支持と元S01損益の関係1572.json`：26日中・155初回親。当時のM/T/Opp、自己5/15/120/300、相手120、OFI、既知フラグ、端点時計がある。自己価格既知137、未知18。
- `work/s01_156/audit/cases/{session}/S01.json`：元初回玉の枚数・建値・全返済、1枚当たり最大順行/逆行、その時刻がある。Source親と初回判断原行を照合する。
- 夜間の初回支持は保存されていない。日中で得た関係を夜へ一般化せず、別登録で特徴を採る必要がある。

指紋と利用可能項目は[入力目録](保存入力と可用項目159.json)、全定義は[固定計画JSON](分析計画159.json)へ保存した。今回の処理は保存結果の識別・校正分析であり、新しい売買判断や約定を生成しない。

## 何を測るか

主評価は初回新規IDの全返済損益÷初回枚数÷倍率による単位pt、勝ち・負け・0、同IDが残る間のMFE/MAE。親全体の初回枚数当たり/全新規枚数当たりptは副評価とする。後続追加を含む親の高利益を、初回方向の予測力と同一視しない。

MFEは途中の最大幅であり、部分返済後に付いた値を初期全量の実現可能利益へ直さない。MFE/MAEだけから利確・損切りの先着確率を作らない。

支持帯は前回と同じ `[0, .1, .25, .5, .75, 1]` の5帯に固定し、未知は別群。全体・担当・売買方向・前13日/後13日を比較する。件数の少ない帯も消さず、26場丸ごとの5,000回bootstrapで区間を表示する。最もよかった帯だけを新閾値に選ばない。

## 時系列校正と追加特徴

過去8完了場で学習し、次の1場だけを予測する。以後、先行完了場だけで更新して18日中を順次評価。同日の先行親の最終損益も学習へ入れない。

| モデル | 当時知る入力 |
| --- | --- |
| P0 | 担当のみ |
| P1 | P0＋元の支持M×T |
| P2 | P0＋中期Mと短期Tを別々に使用 |
| P3 | P2＋短期の変速＋120秒と15秒が同時に予定方向へ進んでいるか |

P1〜P3は成分の欠測フラグを追加し、未知を弱支持0として扱わない。確率はロジスティック回帰、期待ptはridge、正則化10を固定。標準化・欠測補完・学習は先行データだけ。Brier/log lossと期待値幅誤差を別々に測り、勝率だけ高い大損型を増枚根拠にしない。

26場は既に開発で見た資料なので、これは時系列の疑似外部評価。10/27Dayは15:20まで、10/26Nightも21:13まで既知。完了資料が使用可能なら「既知途中場の完了版確認」として別分離し、既存26場へ混ぜない。新しい1場全体が完全未見であるとは呼ばない。

App・原データ・既存研究成果を変更しない。夜間や新しい売買条件の再生は、新たな計画登録とrootの実行指示を待つ。
