# 元公開と継続窓の第一段診断

この段階では新売買を作りません。既TradeGate33とTradeExit33を厳密に結び、元公開の資格と、その後の現在窓の資格を測ります。sourceと人工は完成、最終小目録三つも各一読して束縛しました。cache本文解析・金融・原板・NPZ・実台帳・APIは0です。本文診断の実行は根が独立監査と計画を確認した後の一回だけです。

## 最小入力

| 素材 | 必要列 | 用途 |
| --- | --- | --- |
| TradeGate33 | recordのLast/seq/PriceTime/start/end/limit/tick、同原行quotesのbid/ask/資格/seq/時計 | 当時価格・新規期間・静観との対応、自己/相手の現在価格票 |
| 同素材 | 10列feed、quiet/quiet_force、mapping、公開trade_features10/30/60 | 現在paper CID/方向/残量/公開ATR、元公開の既signed出来高代理、原行対応 |
| TradeExit33 | 同record/quotes、全normalの10/30/60票known/reason/up/down/unsigned balance、候補原row/seq/時計・基準原row・窓始原row | 元公開票のexact照合と、公開後の現在出来高代理 |

同じnormal row番号だけでは結びません。record/quotesの型・shape・欠測位置・値を一致させ、候補raw rowをmappingへ、原seq/PriceTimeをrecordへ一致させます。元公開全行では三窓のknown/reason/debug票/countと、紙上sideを一度だけ掛けたbalanceを照合します。既知0票はPUBのNoneと全normalのNaN、未知はdebug票と採用票を分けます。

TradeExitの最終目録と非有限時計系譜の同値補完を束縛しました。archiveの初版目録で代用していません。`reference_raw_seq`、基準の価格時計、最後に実方向票が発生したseqは全normal票にありません。原seq＝raw rowと推定してfreshな根拠を作りません。

## 固定した診断資格

現在出来高代理はW60、known・2票以上・方向signed balanceがTOP .5/NK .25以上です。公開時のsigned値を後へ持ち越さず、その行のunsigned値を当時paper方向へ一度向けます。

現在価格票は正常Lastの非零隣接更新です。W60、自己/相手ともknown・各2票以上・当時方向balance .25以上を測ります。自己は当行原seqまで、相手は当行PriceTimeよりstrict過去の最後の正常行です。相手の窓終点は選択されたpeer時刻、ageは自己現在時刻との差で60秒以下です。価格票は出来高方向票とは別です。

静観、`[record.start+300, record.limit−300)`、正常Last/BBO、紙上公開価格/ATR、公開spread＋注文別往復floor料の余裕を別flagへ分けます。111の暫定PUB理由は予定静観/期限→同行paper撤回→新規期間→正常価格/ATR→出来高資格→公開費用の順で、**実busy・予約・場停止を測っていない判定**と明記します。最初のreasonを唯一の拒否原因にしません。

## 二つの母集団

- 紙上CIDごとの当時方向区間では、元公開と後の窓資格を比較します。開始/最終観測の原seq/代理時計、方向年齢、normal観測数、PriceTime値数、連続適格normal区間を保存します。
- 紙上zero中も含む全normalではBUY/SELL両方向を別集計します。現在出来高/価格/両方の資格、正常・静観・新規期間との交差を数えます。paper ATR・実busy・実FAKはこの母集団に推定しません。

各観測より前の累積適格観測数は接頭で数えます。実入口前の正確な観測数や、FAK失効後の実状態との交差は実台帳を読まないため未測です。normal観測数、同時計更新、連続適格区間は独立した参加機会・取引勝率・未来正答率ではありません。
