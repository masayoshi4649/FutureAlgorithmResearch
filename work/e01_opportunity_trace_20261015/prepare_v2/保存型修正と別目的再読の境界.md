# JSON保存型だけの修正

初版はTradeGate33・TradeExit33を各一読し、全33場の厳密join・PUB照合・現在窓計算まで完了しました。しかし最後のJSON保存で `completed_paper_direction` のNumPy boolが直列化できず、結果は保存されませんでした。初版FalseのSHAは `c84415f12858d5eaf5d33f383b9f62511c6591f45f0768ebd7f5e631f3e55113` です。初版を成功へ上書きせず、元23source・計画・人工・fixed・guard・Falseを指紋付きで保全しています。

この兄弟領域では、保存項目の `completed_paper_direction` をPython boolに、元公開のcount/balanceをNone又はPython int/floatに写しました。票の窓・符号・資格・判定順・観測計算・売買ルールは変更していません。非有限値を0や有限値へ救済していません。

人工513検査はterminal 0です。合成 `analysis.analyze` の全出力を `json.dumps(..., allow_nan=False)` とその復元へ通し、元公開dictのknown/count/balanceなどをnp.bool_/np.int64/np.float64へ替えた素材も検査しました。既知零票・未知票も含みます。

修正版fixedは、初版で束縛済みの最終TradeExit目録・有限時計修正補完・全33組のcache path/SHAを完全不変で継承しています。cache66はstatだけで同サイズを確認し、元小目録三つの内容追加読取は0です。この修正作業でcache本文の再読・金融・原NPZ・実台帳・APIは行っていません。

初版の計算結果が未保存のため、新目的は「保存不具合修正後の非金融診断を一回だけ保存する」です。独立監査と根の授権後、根がTradeGate33＋TradeExit33を各一読します。これは新売買・新効能の追加証拠ではありません。初版66読の履歴と、修正版での別目的66読を結果に分けます。

根がこの領域をcwdとして実行するコマンドは次です。準備担当は未実行です。

```powershell
python -B -X utf8 run.py --run --root-input-review-complete
```

旧prepareと111金融源は不変です。失敗時はFalseと読取計数を保存し、自動再開始しません。実busy/FAK失効/場停止のexact状態は従来どおり未測です。全normalの両方向資格と、紙上方向条件付き区間を独立した取引機会・勝率へ読み替えません。
