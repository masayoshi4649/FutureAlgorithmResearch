# 指標の必要履歴と参加者行動の検証仮説

取得日：2026-10-15（日本時間）。公式説明の確認と既存資料の仕分けだけ。金融・大型入力・台帳・現在APIの読取、公開・共通知見の編集は0。

指標は過去観測の要約であり、注文を出す主体ではない。**注目水準で注文が変わる、含み損の側が撤退する、利益の側が利確する**という行動仮説を、その後に観測される活動と価格応答で確かめる。公式の一般的な使い方は、この先物での参加者利用率や成功確率の証拠ではない。[マネックスの分類](https://info.monex.co.jp/technical-analysis/indicators/)と[三菱UFJ eスマート証券の分類](https://kabu.com/investment/guide/technical/01.html)を確認した。

## 数式と履歴の境界

`C,H,L,V`は当時すでに確定した足の終値・高値・安値・出来高。`n`は確定足の本数。未確定足を混ぜる場合は別定義で固定する。公式の「日」を短い足の「本」に替えるのは計算可能性の話で、参加者が同じ注文を出す証拠ではない。

数式は必要観測を確認するための整理で、公式ツールの完全複製ではない。特にDX/ADXはここでは0〜100表記。公式説明間にも平滑化・σ分母・初期値の省略や流儀差があるため、実測のsource契約を別に固定する。

| 部品 | 数式・必要観測 | 当該セッションのみで使う境界 |
|---|---|---|
| SMA・GC/DC | `SMA_n=ΣC/n`。短長差の符号変化が交差 | 長期n本の確定まで未知。傾き・交差にはさらに前回値が必要。[MA](https://info.monex.co.jp/technical-analysis/indicators/001.html) |
| EMA・MACD | `EMA_t=(1−α)EMA_(t−1)+αC_t`、通常`α=2/(n+1)`。`MACD=EMA_短−EMA_長`、シグナルはMACDのEMA | 当場種を決めれば計算可能だが、前場から連続したEMAとは別。12/26/9でSMA種なら形式上34本から。初期値の残りは`(1−α)^m`で、EMA26の種から約60本で1%未満になるという算術にすぎない。MACD全体の成熟保証ではない。[MACD](https://info.monex.co.jp/technical-analysis/indicators/002.html)、[EMA再帰式](https://kabu.com/investment/guide/technical/13.html) |
| BB | 中心`SMA_n`、上下`SMA_n±kσ_n` | n本必要。σの分母nかn−1、終値か別価格かを測定前に固定。帯外が次に帯内へ戻る確率を95%と読まない。[BB](https://info.monex.co.jp/technical-analysis/indicators/003.html) |
| RSI | `U=max(ΔC,0),D=max(−ΔC,0)`、`100×平均U/(平均U+平均D)` | n個の差にn+1終値。単純平均かWilder平滑かを固定。両平均0は未知。高RSIは買いの余力消失そのものではなく、過去上昇の割合。[RSI](https://info.monex.co.jp/technical-analysis/indicators/005.html) |
| DMI・ADX | `u=H_t−H_(t−1),d=L_(t−1)−L_t`、大きい正の側だけDM。`TR=max(H−L,abs(H−C前),abs(L−C前))`。`±DI=100ΣDM/ΣTR`、`DX=100abs(+DI−−DI)/(+DI+−DI)`、ADXはDXの平滑値 | HLCが必要。ローリング定義ならDIにn+1本、ADXに概ね2n本。Wilder版は初期化が残る。TRで正規化するので完全に値幅尺度なしの指標とは呼ばない。[DMI](https://info.monex.co.jp/technical-analysis/indicators/015.html) |
| 出来高MA | `ΣV/n`。累計出来高の差ならreset・時計資格を別確認 | n本の出来高が必要。出来高増は買いと売りの成立量であり方向を持たない。Last対直前気配の方向代理とは別。[出来高MA](https://info.monex.co.jp/technical-analysis/indicators/014.html) |
| 当場VWAP | 取引列があれば`Σp_i q_i/Σq_i`。公式は売買代金/出来高 | 当場の整合した代金・出来高が必要。先物は代金単位/契約倍率と両時計の対応を確認する。典型価格×足出来高、Last×公表増差は近似で、集約増差を最終約定価格へ全配賦しない。[VWAP](https://kabu.com/glossary/kabu0076.html) |
| 標準ピボット | 前日の`H,L,C`から`P=(H+L+C)/3`、下支持`2P−H,P−(H−L)`、上抵抗`2P−L,P+(H−L)` | **前日要**。当場の途中HLCへ置換すると変動水準を使う別指標。先物の前日/前セッション/営業日の区切りも先に固定。[ピボット](https://kabu.com/investment/guide/technical/16.html) |
| 当場の既知高安・始値 | 判定行より前の高安・場最初の観測価格 | 当場だけで可。ただし序盤は履歴不足。最後に決まった高安を当初から既知だった水準にしない。 |

日足SMA25/75は過去25/75営業日の終値が必要で、当場だけでは再現できない。5分足の25/75本は125/375分、15分足では375/1125分の観測を要する。「日足25/75は有名だから5分足25/75にも皆の注文が集中する」という結論は出せない。足の区切り、取引なし足、確定/公開遅延も固定する。

## 独立に確かめる三つの行動仮説

以下は公式からの直接結論ではなく、次段で測るための推論。複数指標をANDで足して成績を作らず、各仮説を対照に分ける。全て今回未測定で、確率・損益はまだない。

| 仮説 | 参加者の行動として予想すること | 支持と失敗をどう分けるか |
|---|---|---|
| 注目水準の突破で注文が増える | 過去に確定した高安・MA等を越えると、逆側の撤退と順側の追随が増える | 接触前に水準を固定。接触前後の既知出来高増差・代理票・両気配進行・表示数量応答を測る。ずらした偽水準/非接触の同程度変動対照より反応が増え、その後も同方向の気配進行があれば支持候補。増加しても進まない/直ちに水準へ戻るなら吸収や失敗候補。注文主体・逆指値発火は同定不能。 |
| 戻り局面で順側の支持が残る | 突破後の利確で一度戻っても、新しい順側注文が吸収し、逆側の損切りが再開する | 初突破では入らず、**当時観測した戻りと、その後の再進行**を別イベントにする。戻り中の反対活動に比べて価格が進まず、その後順活動と両市場進行が再開するか測る。戻りが長い/短いから成功とは決めず、水準破れ・反対活動に伴う逆気配進行が失敗。これは波中央を取る仮説だが、旧押し戻り参加の成功を仮定しない。 |
| 強い活動に価格が応じなくなる | 同方向の約定活動が残っていても、利確・新反対注文が供給を増やし、保有理由が崩れる | 一方向の代理票増加と価格進行量を別計測。進行失敗に反対側の気配進行/回復不能が加わるかを比較する。BB外/RSI極端だけで反対側へ張らない。活動低下だけで返済する対照、反対活動を伴う対照を分け、元回復勝ちも必ず数える。 |

MA/MACD/DMIは方向履歴の要約として同じ原因を重複計測しやすい。BB/RSIは乖離・過去上昇割合を測るが「過熱なので必ず反転」は導けない。出来高は参加の強さ、板変化は供給応答という別部品にする。VWAPは取引平均で、売買済み/返済済みを含む。**現存保有者の平均建値・損益・残建玉分布ではない。** 公式の平均購入価格という説明から実保有者の利確/損切り心理を直接復元しない。

この読取ではMACD/DMI/標準ピボットの独立した実績は確認していない。「過去に試していない」と断定せず、金融化前に旧試行台帳で重複照合する。旧説明の再読は新有効性の証拠ではない。

次段で先に測る価値があるのは、**当時既知の注目水準への接触が、非接触や偽水準に比べて活動と価格応答を変えるか**。指標名を増やすより先にこの差の母数を確かめる。波の頭・尻尾は目標にせず、入口後の費用を越える中央の継続を測り、同時に進行失敗と回復勝ちの反例を保存する。測定窓・水準・反応の定義・欠測処理・旧試行との相違は実観測前に固定する。
