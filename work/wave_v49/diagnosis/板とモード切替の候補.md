# 板とモード切替の候補

以下は実装前の候補案であり、利益が出ると確認した仕様ではない。既存の板指標を使えることを確認し、価格だけの比較対照と組み合わせるために整理した。

## 利用できる板データ

追加ナイトの `new_features_depth.pkl` は42列、TOPIX 6,870公開ブロック、NK 4,817公開ブロック。

|情報|列|意味と注意|
|---|---|---|
|最良気配と数量|bid / ask / bid_qty / ask_qty|公開行の気配。中値の反発は約定価格の保証ではない|
|厚みの偏り|imb1 / imb5 / imb10 / micro_bias|厚い板が価格を支え続ける保証はない|
|最良付近の変化|ofi_signed / ofi_abs|窓内の符号和÷絶対和で正規化。買い優勢は売り板取消でも発生する|
|気配移動|quote_up / quote_down / quote_move_ticks|価格更新の回数・幅を、単なる厚さの偏りと区別できる|
|追加・除去|added_bid / removed_bid / added_ask / removed_ask|約定と取消の区別はできない|
|推定売買|trade_pos / trade_neg / trade_unknown|売買方向の推定であり、注文主体や返済新規は識別しない|
|距離別の変化と圧力|dflow_near / dflow_far / pressure_near / pressure_far|現在最良価格からの距離を指数減衰。近傍はexp(−距離/2)、遠方はexp(−距離/8)|
|同価格の補充|refill_bid / refill_ask|直近30秒の同価格減少残高を埋めた追加数量。食われた証明・同一発注者の証明ではない|

公開行 `seq <= 現在原本seq` を必須とする。指標の対象ブロックは `source_last_seq < seq`。同秒でも行順を飛ばさない。対市場は既存仕様の追加60秒遅延を保つ比較版から始める。

今回のブロック遅延は中央値4秒、最大はTOPIX 128秒、NK 327秒。公開時刻が今でも、特徴の元時刻が数分前の可能性がある。`現在時刻−source_time_s` と `block_delay_seconds` の双方を見て鮮度上限（例30秒/60秒）を付ける。欠測・古い板は中立とし、古い補充を新しい支持として保持しない。

`dflow_near/far` は各ブロック内で既に正規化されている。複数ブロックの単純合計を生の注文量とは呼ばない。平均又は有効イベント数加重平均と明記し、OFIの符号和/絶対和の再集計と区別する。

## 案1：範囲内の反復と、範囲外の追従を切り替える

1. 公開済み1分足から、実時間20分/30分の純移動幅÷総移動幅（ER）と直前範囲を得る。ERが両市場とも低く、上端下端が大きく拡張していない状態を反復候補とする。
2. 例えばER<0.25が3回継続で反復、ER>0.45か同方向の範囲突破が2回継続で追従、それ以外は中立。境目で売買方式を毎秒往復させない。閾値は探索前に有限集合へ固定する。
3. 反復では過去範囲の外縁に来ただけでは入らず、直近安値から0.2ATR反発・又は高値から0.2ATR反落を待つ。最新30〜60秒OFIが反発方向に転じた場合だけエントリーする板版と、価格だけ版を比較する。
4. 中央又は反対端を目標にし、初期損切りと狭いトレーリングを併設。真の突破を検出したら逆張りを止める。返済と同時に反対建玉を作る版は、反対側の新しい根拠を要求する版と分ける。

**反例**：下降の途中の横ばいでもERが落ちる。反復で何度か勝った後の突破1回で全部失うおそれがある。反復モードの総損失・連敗・突破時損失を一緒に評価し、勝率だけで採らない。両市場が同じ速さで動くとは限らず、双方低ER条件が良い機会も消す。

## 案2：板が吸収したことを価格反発で確かめる

1. 窓内の推定売りが優勢なのに、下落幅がその時点のATRに対して小さい状態を候補とする。加えて同価格の買い補充が売り補充より多いことを確認する。買いを吸収する売り側は対称。
2. 補充だけでは買わず、その後の価格反発と近傍dflowの上転換を待って入る。準備した吸収地点を0.25〜0.5ATR割れたら損切り。相手市場が強い下落を続ける場合は買い候補を止める。
3. 範囲内の反復モードだけで実行する版と、主方向転換の初動にも許可する版を区別する。吸収候補の有効期限を短くし、古い候補を保持しない。

補充比は `refill_bid/(refill_bid+refill_ask)` のように比較する方法が単純。`refill_bid/removed_bid` は窓開始前の減少を窓内補充が埋めることがあり、1を超え得るため「売られた分の補充率」と誤記しない。

**反例**：補充注文が結局すべて突破される、気配の取消がOFI転換に見える、数量が極小の静かな市場で比率だけ大きくなる。最低有効更新数・売買量又は絶対変化量・鮮度が必要。「プロの買いを見抜いた」とは説明できない。

## 案3：伸びなくなったら、時間と板の両方で出口を狭める

1. 新規は既存の追従条件を使う。入口まで全て変更せず、出口の追加効果をまず単独比較する。
2. 初期ATR・最大順行幅・最後に高値/安値を更新した時刻をその都度保持する。
3. 10分/20分新値更新がない場合、トレーリング幅を段階的に縮小する時間だけ版を作る。板の30〜120秒OFIが弱まり、近傍圧力も反対へ傾いた場合だけ縮小する板併用版と比較する。
4. 損失上限は維持し、追跡水準を緩めない。含み益が十分ない段階まで無理に建値へ引き上げる版と、利益領域だけで適用する版を分ける。返済後の反転は新しい逆方向候補が成立した場合に限る仕様も併設する。

**反例**：大きな波の途中の休憩で下ろされる。休憩明けに再び入り直して損切り回数が増える可能性もある。狭い出口の単独成績を組み合わせるだけでなく、再エントリー時計も含む単一口座を再生する。

## 評価を分ける

- 「追従だけ」「反復だけ」「自動切替」を同じ口座制限で比較する。
- 板なし対照と板ありを比較し、板の追加で改善したか判定する。
- 4候補の元の出口との比較、各場の損益、1枚当たり平均勝ち/負け、最大下落、最大連敗を確認する。
- 状況の分類は当時公開済みの数値から行う。後から「この日はレンジだった」とラベルを付けて方式を選ばない。
- 最新ナイトだけで改善案を選んだ結果と、過去全場へ同一仕様を適用した結果を混同しない。
