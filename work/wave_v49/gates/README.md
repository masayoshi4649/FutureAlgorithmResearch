# 入口を見送る12条件の再検証

最初に見る資料は `見送り条件の比較.json`。候補1・候補2それぞれについて、基準と12条件を旧15セッション／問題の09月30日ナイト／全16セッションで分けている。

読む順序は、比較JSON → `条件の事前固定.json` → `新規見送り信号の因果監査.json` → `新規約定直前の許可監査.json`。個々のセッションは `sessions`、注文と取引組は `ledgers`、独立会計器と経済因果検査は `audits` に保存した。

初回枚数はTOPIXミニ5枚・NK225マイクロ10枚、片方向上限は10枚・20枚。手数料・滑りはゼロ、指定価格で約定する前提。途中・出口・枚数は既存の各候補から変更していない。

確定1分足は開始時刻から120秒後に公開、相手銘柄はさらに60秒遅延する。5／15／30分は実時間の窓であり、足の行数差ではない。EMAの3本傾きは既存の定義を維持する。G11は「片方でも最新EMA60傾きが入口と逆なら見送る」という意味。欠測時は見送る。

見送りは新規方向を0にする操作として実装した。既発注注文の約定判定が先に行われ、観測した行の取消は次行から有効。約定した行の情報を使って過去の注文を取り消さない。準備・取消・新しいエントリー時刻・仮想基準の終了時計・待機時間まで全て再生するため、元の負け取引だけを消した結果ではない。見送り条件を加えても新しい注文時刻が変わるので、総取引数が増える場合もある。

差額分解は、初回の原本行・方向・価格・枚数が一致する取引組で対応させる。消えた元の負けの損失だけでなく、消えた元の勝ちの利益、別時刻の新しい取引の損益も示す。全く取引しないことを有望とは評価しない。

今回の問題セッションを見た後に設計した再探索であり、完全な未見検証とは呼ばない。候補3・4への12条件の適用は未実施。
