# 00156 第1巡：利益回収後の空白と、入口拒否の逆例

根拠は全 27 場の保存済み通知・約定・snapshot だけである。原板の追加再生、条件変更、App 改修は行っていない。全会計は `report156.json`、具体抽出は [具体診断156.json](具体診断156.json)、再抽出手順は [diagnose156.py](diagnose156.py) に保存した。以下の金額は日経 mini・手数料 0。

## 固定幅で利益を削った主因は、全量回収後に同じ波へ戻らないこと

F05 は含みが正になったら全玉に 20pt 幅と建値床を付ける。次の例では床は働いている。しかし実玉がなくなっても元の仮想源は従来どおり波を保有し、初回新規通知を再発行しない。

|場・担当|実新規|F05の全返済|F05の親収支|S01の同じ親|差|
|---|---|---|---:|---:|---:|
|10/22 core|10:04:55 売5 @64,390|10:05:40 買5 @64,370|+10,000円|+361,000円|−351,000円|
|10/15 core|09:53:31 売5 @65,380|09:54:35 買5 @65,370|+5,000円|+282,000円|−277,000円|
|10/01 core|10:25:50 買5 @68,130|10:26:21 売5 @68,130|0円|+240,000円|−240,000円|

各 F05 の保護返済直後の保存診断は **実玉 0、元 core 仮想源 10**。仮想 10 は旧 source 内部の基準数量であり、実口座で 10 枚や上限超過の意味ではない。この 3 例には、その後の core 新規も、同じ親への再参加もない。

10/22 の S01 は 11:22:16 に2枚 @64,090（+60,000円）、13:59:29 に2枚 @63,510（+176,000円）、15:35:00 に1枚 @63,140（+125,000円）を返済した。F05 の source は改造・停止されておらず、実玉だけを早期終了した。そのため「利益回収と再参加を繰り返しても無効」とは今回から言えない。

10/22 の証跡は F05 新規判断/約定 35305/35306、保護返済 35646/35647。10/15 は33740/33741、34225/34226。10/01 は42454/42455、42647/42648。いずれも `results_go/{日付}_Day_S01.json` の該当条件。source がゼロになった正確な秒は疎な snapshot だけでは断定しない。

## 一部では元の追加が来て、別の損失を作る

すべてが再参加不能ではない。10/23 F05 の episode 親8は15:24:25に売玉2枚を @62,860 で建値返済した後、15:29:43 に元 source の「利益保護後の追加」通知で売1 @62,760。その玉は一度も利益にならず、15:30:00 に @62,870 で返済し **−11,000円**だった（新規187390/187391、返済187580/187581）。

この損失は起動したトレールが利益を取り逃した例ではない。元の追加通知は仮想親の進行に合わせて出るため、実口座が一度全量降りたことに合わせた新しい入口判断ではなかった。第2巡では元 source の初回通知を待たない再参加を別に検証し、この経路と区別する。

## 直前失速だけで入口を消すと、勝ちも失う

元出口のまま入口だけを変えた E07 は、完了26場の拒否した元 core 親12件で、元の勝ち **+611,000円**、元の負け **−325,000円**を消した。差は **−286,000円**。全体会計とも一致する。未知・足不足による拒否も含むため、この12件全てを失速と呼ばない。

特に10/22 10:04:55の売りは、売り方向にその前3分が+110pt、直近2分が−40ptで E3 に該当した。しかしその後の S01 親は +361,000円になった。9/28 10:09:19の親も、その前3分+120pt・直近2分−110ptで拒否されるが元は+106,000円。短期の押し戻りが再加速前の休みの場合を含む。

E1 は10/01 10:25:50の買いを直近2分−70ptのため拒否し、元親+240,000円を失う。10/27 15:00だけに効いたように見える拒否条件を、そのまま全日に採用する根拠にはならない。

## 原因へ対応する次の検証

- 利益保護で全量返済した後、元 source が同親・同方向を維持している間だけ、新たに観測した高安から追尾再新規を準備する。旧最高値や旧床は再利用しない。
- 元 source の新規・追加・返済と予約を優先し、同じ数量枠を二重に使わない。元 source の終了や反転では再参加を止める。
- 初回の大きなリスク、回収の幅、再参加による往復損を分けて採点する。第一巡で利益だった玉の赤字返済が抑えられても、未順行の損失と小勝ち化だけで全体が赤字になる場合がある。

以上は第2巡の仮説であり、再参加を加えれば黒字になるという結論ではない。
