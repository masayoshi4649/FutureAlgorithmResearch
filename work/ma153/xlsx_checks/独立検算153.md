# 00153 最終Excelの独立検算

結果：数値・数式・表定義に不一致はなく、全70シートの描画に報告を妨げる欠けや崩れは見つからなかった。Excelは読み取りのみで、保存・再出力・編集を行っていない。

対象は公開フォルダの `移動平均の傾きと比例枚数の全セッション損益.xlsx`。元会計は `work/ma153/report153_combined.json`。Spreadsheetsスキルの読み取り専用監査に従い、openpyxlで保存計算値と数式を別々に読み、ZIP内のExcel正式テーブル定義も確認した。

| 確認対象 | 結果 |
| --- | --- |
| シート名・順序 | 比較1＋銘柄/手法68＋途中1、合計70で一致 |
| 完了場明細 | 68手法×51場＝3,468行、一意な場名・区分・全数値を照合 |
| 各場のC利益/D損失/E収支/F累計 | 全件一致。収支は利益−損失、累計は時系列積算 |
| 各手法57行目 | 合計・平均・最大と全数式を独立集計して一致 |
| 比較表 | 68行。利益/損失/収支・比率・黒字/赤字/無取引・赤字深さ・上位3黒字除外・昼夜収支・初回件数が一致 |
| 取得済み途中場 | 68行。実現と含みを分けた会計が一致。完了51場への混入なし |
| 保存数式 | 8,772本を全件照合、キャッシュ欠落・エラー値・参照エラーなし |
| 正式テーブル | 全70シートに1つずつ。表範囲・列見出し・autoFilter・シートからの関連付けが一致 |
| 見出し固定 | 全70シートでA6、5行目までを固定 |
| 照合総数 | 数値・文字・数式・構造61,310件、不一致0 |

視覚確認では、手法68シートの全画像を12枚のコンタクトシートで目視した。比較表と途中表は元画像を全範囲で確認し、日経M09の元画像でも文字と数値の大きさを確認した。見出し、数値桁、最終行、赤字表示、説明の折返しが読み取れ、`####`、空白シート、数字の切れ、行の重なりは見当たらなかった。表のフィルター矢印は描画の見え方ではなく、保存済み正式テーブルのautoFilter定義で存在を確認した。

監査前後のExcel SHA256は一致した。

`944193e8697ab44fc7a1769166a2d597d8c50af131f5dd119bdbe60db6a42987`

Excelネイティブアプリでの再計算・並べ替え操作は今回実施していない。保存数式の全参照と保存計算値を元会計へ照合した検査であり、Excelアプリ上の操作試験と同一視しない。金融再生は行っていない。

詳細な検査記録は [独立検算153.json](独立検算153.json)、再実行できる読取り専用検査は [independent153.py](independent153.py)。監査用コンタクトシートは `監査一覧_01.png` から `監査一覧_12.png`。
