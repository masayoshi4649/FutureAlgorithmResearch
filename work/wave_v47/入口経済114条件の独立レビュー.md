# 入口114条件の独立確認

重大な矛盾は見つからなかった。初期化26入口×3管理＝78条件、EMA暖機12入口×3管理＝36条件が、旧13セッション×2銘柄について全部保存されている。追加9/29ナイト、その損益、追加を含む複合口座資料は読んでいない。

| 確認 | 結果 |
|---|---|
| 保存条件・口座の完備 | 114条件、2,964口座。欠落・重複なし |
| 返済脚の独立会計 | 31,692脚について、方向×（返済値－建値）×返済枚数×銘柄倍率が保存損益と一致 |
| 注文からの別計算 | 51,455注文の売り受取－買い支払が純損益と一致。新規と返済の延べ枚数一致、場末残玉0、片方向上限TOPIX10枚・NK20枚以内 |
| 中央H019の旧同値 | 3管理×26＝78口座。旧台帳の共通保存列全部・実15配列指紋・期間集計が一致 |
| 期間集計と集中 | 456期間銘柄セルの利益・損失・純損益・勝敗枚数・一枚勝敗比・上位利益2元組除外・採否が一致 |
| 対応差と感度 | 初期化2,340組、暖機936組のセッション差一致。主窓3点の36領域は短期窓を固定し、相手遅延48/72秒を混在させていない |
| HTMLへの入口集計 | 新ナイトを読まない純粋関数だけ抽出。全114条件の684週・全期間行を独立会計値と照合し一致 |
| 先行価格診断との分離 | `financial_report.py` の入口部分は `entry_sessions` の口座損益だけを読む。先行5/15/30/60分の値動きを口座利益へ加算していない |

`replay_parts.py` は入口方向列だけを差し替え、A0/C01/F50の管理器を固定する。主窓倍率はEMA短長・傾き本数、短期倍率は中値の参照秒数に別々に接続されている。ただし短期確認を無くす比較には信号保持時間の差も含まれるため、短期価格情報だけの純粋な寄与とは呼べない。

元A0初回の先行価格診断は、実初回に選ばれた時刻から先の値動きである。将来価格を入口へ渡しておらず、診断の正方向割合を返済勝率や将来利益の保証と扱っていない。指値モデル、実初回の選択条件、期限、時間帯による差は別途診断に残されている。

今回の独立検算は保存脚・注文・元組を用いた会計確認であり、DDの全原本行再生を重複実行したものではない。中央の旧共通列照合では、旧台帳にだけ存在する影・ゲート指紋とゲート武装記録の3補助列を対象外とし、実経済15配列の指紋は全て照合した。

証拠は [入口経済114条件の独立監査.json](入口経済114条件の独立監査.json)、再実行コードは [audit_entry_economics_independent.py](audit_entry_economics_independent.py)。元コード・経済結果は変更していない。
