# 同じ初回建玉で出口を比較する契約

13方式は [exit_design.py](exit_design.py) の固定一覧。数量調整・復元を加えず、元A0の同じ初回5枚／10枚、同価格・初期ATR・Rから始める。期間は旧13場のみ。新ナイトは扱わない。

`engine_exit_campaign.run(ready, entry, spec, observed_fill=False, detail=True, require_complete=True)`。

- `ready`：原本行に対応する時刻・価格・seq、呼値、安全返済判断時刻・終場。ATRの将来更新は使用しない。
- `entry`：`row, decision_row, side, qty, price, initial_atr, initial_risk, campaign`。元注文の成立を外で照合済みの初回。**元の終了行・未来の損益は含めない。**
- `spec`：13条件の一つ。元R、初回時刻を部分利確でリセットしない。
- 返り値：`orders/trades/cycles/curve/plans` と完済状態。既存の注文8列・返済11列・曲線8列を踏襲し、元脚番号だけ独立実験内0とする。

初回約定行の価格は初期の追跡極値更新に利用できるが、返済は必ず後続の有効原本行。次行に同秒を許し、前の行へ遡及しない。保有中に新設した線が既に通過済みなら、次の観測価格で返済する。元の期限・場末市場予約と価格注文が競合した場合は旧実装の市場予約優先を維持。価格注文同士は前観測からの到達距離を使い、同距離なら初期stop、trail、部分利確、全利確の順。区間内の未観測経路を創作しない。

追加の実R予約は元注文より後に執行し、元部分利確で消さない。主は伝達0秒・次行、別モデル `observed_fill=True` は出口側の約定を現在観測価格へ変更する。初回は共通の固定価格を保つため、これは全入口も変更する既往の観測約定試験とは異なる。

元方式より遅く退出する条件も、自己の出口が成立するか場末まで価格を追う。元の終了価格で都合よく清算しない。場内の返済行が欠けて残玉があれば完結検査は失敗とし、途中切断監査では残玉を時価表示したまま返す。

同じ口座から得た元初回をそれぞれ独立に再現するため、変更後の組が時間的に重なる場合がある。**13方式の診断収支をそのまま実運用口座の利益とは呼ばず、診断曲線を足して口座DDを作らない。** 元組内DD、重複数、同時に必要となる枚数は別記する。除外すれば有利になる損失組も含め、共通初回集合を固定する。元出口を再現するE00は元台帳と全返済時刻・方向・価格・数量・理由・損益が一致することを先に要求する。

初期stop／2A部分利確／追跡／期限の必要性と、幅や短縮による交換を計測する。勝率だけ、最高利益の返却だけ、週収支だけで出口を選ばない。全元組・各場・前6/後7・全13について利益損失、枚数、基準からの対応差と最大差の集中を分ける。候補採用や数量調整との統合はこの診断だけで行わない。
