# 同じ初回から数量調整と出口を統合する

対象は既知13セッション・26入力。9月29日ナイトはこの比較に使わない。数量4方式と出口3方式の12組合せを先に固定した。

| 部分 | 固定した機械規則 |
|---|---|
| 新規時計 | H019を受け取る元A0を仮想口座で独立運転し、新しい未約定注文を準備した原本行だけ実側の新規準備を許す。約定後の途中参加はしない。 |
| 初回 | 元の次行約定・初回価格・枚数・初期ATR・初期予算を維持。早期返済しても元A0の次の準備まで待つ。元の5分休止も維持する。 |
| E00 | 順行1.5ATRから幅3ATRで追跡する元の出口。 |
| E10 | E00と同じ開始後、順行3ATRへ到達した行で追跡幅を1.5ATRへ短縮し、次の原本行から有効にする。 |
| E11 | E10の短縮後幅を0.75ATRにする。 |
| 共通の返済 | 初期組予算1ATR、2ATRで元枠の半分を利確、360分期限、場末返済を維持。既設追跡線は緩めない。 |
| A0 | 途中数量調整なし。 |
| C01 | 元B00の新しい逆方向根拠で生存枠を25%減量し、新しい正方向根拠で一度復元する。 |
| F50 | 元A0の価格が初期ATRの1.5倍順行した後、その到達より新しいB00で50%減量し、新しい正方向根拠で一度復元する。 |
| F50_NONE | F50と同じ減量を行い、復元しない。 |

3ATR・1.5ATRという距離は組全体の円利益ではなく、初回価格からの最大価格順行である。元A0の独立運転から短縮影を作り、その前行までに公開された返済条件を実枠へ並行配置する。未来の終了行を後から実口座へ移す実装ではない。減量許可の1.5ATR判定は、短縮後の影ではなく元A0に固定した。

元の価格返済・部分利確を調整注文より優先し、部分利確で失効した枠は復元しない。実現と含みの組損益が−R以下になった場合の実予算返済も残す。これは次行で退出を始める予算であり、ギャップ時の損失額を保証しない。

実装は旧影注文器に既にある短縮パラメータと新規準備許可を使う。数量注文器は参照する影のimportとキャッシュの依存指紋だけを変更した新コピーで、数量計算本文は旧修正版と同じである。原本・過去コードは変更していない。

人工では全48入力の独立会計、接頭部・未来変更・上下反射を検査した。旧26入力の本検査では、E00の全15配列旧一致、無調整E00/E10/E11の306組と既存の独立出口比較の一致、全312入力の会計・因果を要求する。早期返済による再新規増を収益改善へ混ぜない比較である。
