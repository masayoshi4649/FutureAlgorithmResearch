# 入口の証拠棚卸し

**結論：H019は機械的に実行でき、既知13セッションでは利益と損小利大を残した。ただし「入口の各材料がそれぞれ必要」「時間幅を多少変えても安定」という結論は出ていない。** とくに、開始直後の暖機と時間幅の内訳は、収益とは別に確認できる構造上の課題である。

この資料は既存成果とコードだけの棚卸し。追加された9/29ナイト、保存ライブ、新しい損益は読んでいない。原則の対象期間は9/21デイ～9/29デイの既知13セッション・両銘柄26入力。数万条件を独立した数万相場とは数えない。

## 未検証を埋める順番

1. **現入口の一因子分解を先に行う。** 主方向窓だけ0.8/1/1.2、短期価格窓だけ0.8/1/1.2、相手確認あり／なし、短期確認あり／なし。中央と旧一括±20%も同じ実装で再現する。暖機・閾値・発注・途中管理・出口は固定し、どの変更が実際に方向列・約定を変えたかも記録する。現入口からの除去効果は相互作用を持つので、4つの値を足して予測力100%へ分解しない。
2. **入口の先行性と注文後の儲けを分ける。** 発火時点から事前固定した複数期間の先行価格変化を、逆行・順行・機会数と併記する。将来価格は評価にだけ使う。重なる発火を独立標本と数えず、セッション別に示す。この診断の方向性が良くても追跡入口／出口の収益を保証しない。
3. **約定時機を別比較する。** 同じ方向・公開時点を起点に、次観測新規、固定逆指値、0.25ATR追跡を同じ初期ATR・期限で比べる。各々の実約定が変わるので、準備した全機会を残し、成立しなかった分を都合よく消さない。旧0.20/0.30近傍済みと区別する。
4. **暖機履歴を別条件とする。** 前セッションの確定足を持ち越す案は、指標履歴のみ継続し建玉は必ず場内返済。休場ギャップの扱い、ATRの初回TR、最初の履歴不足を先に決める。序盤を取れるようになることと増益は別に評価する。
5. **新しい時計はその後。** v46価格距離時計は人工検査済みの試作で、実相場の新売買・新損益は未検証。価格距離平均と原本物理時間平均の双方を同じ観測頻度・品質・相手処理で比較しないと、時計変更と単なる高速化が混ざる。[現段階](../wave_v46/README.md)。

入口だけでも現時点で高確度なのは「完全に機械化できる」「数量なしの既存候補が既知相場で成立する」「現H019は序盤約1時間に構造的な空白がある」「一括時間幅変更でTOPIXの利益集中が再現し、3窓合議は解消しなかった」。相手・短期・追跡新規を全て必要とすることや、どれが入口の弱さの原因かは、ここからの部品検査の問いである。

[component_signals.py](component_signals.py) は旧H019を組み替える26仕様。主方向3窓×相手有無2×短期状態4（なし1状態・あり3窓）の24仕様に、中央の相手48／72秒を加えた。不使用変数の重複は除いた。主方向0.8はEMA12/48・傾き2本、1.2はEMA18/72・傾き4本であり、EMAだけを変更する検査ではない。

中央H019、相手／短期の除去3方式H016/17/18、旧一括±20%の計6仕様×26入力＝156方向列が旧保存列と完全一致。全26仕様×26入力＝676方向列について、途中切断・未来変更・上下反射・同秒原本群途中の切断を各676件確認した。[因果監査](component_signal_audit.json)、[固定仕様と指紋](component_signals_fixed.json)、[保存入口列](component_entries/)。新ナイトと新損益を読まず、売買は再生していない。これは**信号実装の検証完了**であり、26方式の経済採否ではない。

短期確認なしは旧H016/17どおり主方向を直接渡し、短期TTL120秒も存在しない。したがって「短期確認を除く」対照には、価格確認の除去と発火・保持時間の変化が含まれる。これを短期価格の符号だけの予測価値と呼ばない。必要なら同じ発火機会・TTLを残して短期符号だけ無作為化する追加対照を別固定する。

先行価格診断は[別紙の結論](forward/先行価格診断の結論.md)で実行済み。全26仕様の発火を厳密な次行価格から5／15／30／60分後まで評価し、同じ発火集合・欠測件数・最大順行／逆行・セッション等重みを開示した。口座の新規準備や損益はまだこの診断には接続せず、不成立注文の明細は注文側の比較で扱う。中央の先行価格差は小さく、「発火だけで強く持続を予測する」との説明は不十分だった。符号乱数の新しい追加対照は今回の価格診断には含めていない。

前場の確定足でEMAだけを暖機する12方式も、[信号仕様と確認](EMA暖機の仕様と確認.md)まで実行済み。初日以外の中央24入力で序盤の空白は埋まったが、9/23デイの最初は両銘柄とも買いであり、早く発火することと方向・利益の改善は同じではない。上記の未検証一覧に挙げた暖機方式は、現在**信号の因果検査済み・経済採否は別途**という段階である。
