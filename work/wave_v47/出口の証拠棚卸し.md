# 出口の証拠棚卸し

**現出口は「機械実行・会計と、同じ既知期間での局所的な耐性を確認した比較基準」である。「出口単独で優秀」「3ATR・半分利確・360分が最適」とまでは確認していない。** 早期返済を追加すると悪化した例は多いが、それだけで元出口の各部品が必要だとは証明できない。

本資料は旧保存結果の読取整理のみ。追加の **2026-09-29ナイト、新損益、現在保存物を読まず、再生・API取得も行っていない**。以下の「13場」は9/21デイ～9/29デイ、「後7」は9/24デイ以降の既知部分集合。反復回数や条件数は独立した標本数ではない。円は銘柄内だけで比較し、通常はTOPIXミニ／NKマイクロ換算。

## 現A0・C01・F50で何が返済を決めるか

ここでは方式名のA0と区別するため、準備時に固定するATRを **A** と記す。初回枚数qはTOPIX5／NK10、初回価格はE、初期組予算は **R＝q×A×円倍率**。Aは未来足ではなく、確定5分足TRの指数平滑（α=1/12、最低3本、最低2呼値）、足開始から360秒後に公開した値。

| 部品 | 現在の機械条件 | 注意 |
|---|---|---|
| 初期損切り | 組損益の床を−Rに置く価格注文。初回はおおむねEから逆行1A、呼値へ丸める。 | 「必ずR以内」の保証ではない。部分利確後もRを残枚数に比例して減らさず、実効線には既存追跡も作用する。 |
| トレーリング | 価格の最大順行が1.5Aへ達した後、買いは最高価格−3A、売りは最安価格＋3A。既設線は緩めない。 | 保有中ATRへ更新しない。1.5Aは価格距離であり、組利益1.5Rではない。 |
| 元の部分利確 | 初回Eから2A順行で、元qの半分切捨ての枠を一度だけ返済・退役。 | TOPIXは2/5枚、NKは5/10枚。減量で空いた枠も退役し、その後復元できない。 |
| 時間・場末 | 初回約定から360分、又はデイ15:35／ナイト05:50に全返済を判断。 | その後の有効行へ発注する。場末は15:45／06:00より前に完了、場またぎなし。減量・復元で期限をリセットしない。 |
| 実口座の追加R退出 | 組開始後の実現＋含み損益が−R以下なら全返済予約。 | 元A0の返済が優先。次行価格・伝達待ち・部分利確優先でR超過があり得る。 |
| 方向撤回・実反転 | 現3方式では、方向中立／反対だけでの全返済や即時ドテンを使わない。 | C01/F50の一部減量は、この「全返済・ドテン」と別機構。 |
| 執行 | 原本行順で判断→後続有効行。線の更新も先読みしない。主条件は費用0・指定値約定。 | 補足では全約定を観測価格、注文伝達を1/5/15秒へ変更。伝達遅延は入力信号遅延と別。 |

元A0は独立した仮想運転から**その時点までの有効注文計画**を実側へ渡す。完成後の返済行をコピーしない。C01/F50も初回の影の準備・約定を共有し、実側だけ早く空になっても勝手に再入場しない。

- **A0**：上表の元注文をそのまま保有。
- **C01**：新しいB00逆行で生存枠の25%を最大1回減量し、新しい正方向情報で元の生存枠を復元。B00は気配価格の長短変化であり、板数量補充の指標ではない。
- **F50（G150_F50_N1）**：影の価格が1.5A順行した後の新しいB00だけで50%減量。許可は価格が戻っても残る。復元、R、元利確枠、期限は維持。

したがってC01/F50の成績差は、**途中の数量・建値・実現損益と追加R退出**の差を含む。3A追跡そのものの優劣ではない。正本は[元の管理固定](../wave_v38/探索条件の固定.json)、[現影注文器](../wave_v38/engine_shadow_plan.py)、[修正版実注文器](../wave_v41/engine_partial_restore_corrected.py)、[執行契約](../wave_v38/エンジンの実装契約.md)、[枠と優先順位](../wave_v37/数量調整エンジンの契約.md)。

## 次に必要な最小対照案（未実施）

まず途中減量・復元を外したA0で、入口を結果前に固定する。既に行ったstop／trail／期限±20%の繰返し探索より、**部品が必要か**を調べる次の4方式を優先する。

| 対照 | 固定するもの | 新しく答える問い |
|---|---|---|
| E0：現A0 | 初回5/10枚、1A組予算、1.5A始動・3A追跡、2A部分利確、360分・場末 | 比較原点 |
| E1：元2A部分利確だけなし | 同じ初回数量・R、追跡と時間 | 早い確定益と残数量の減少は、損小利大へ本当に必要か。1枚化や初回半減で代用しない。 |
| E2：追跡だけなし | 元価格損切り、2A部分利確、360分・場末 | 長い波の保持より、最高値から3Aの切上げが改善しているか。損切りまで外さない。 |
| E3：360分期限だけなし | 元価格損切り・部分利確・追跡、場末返済必須 | 通常の時間終了が、無益な保有を切るのか、利益波を切るのか。 |

二段階に分ける。第一段階は因果的に動く固定影の初回を起点に、**各元組を独立に対応比較**する。終了が遅い対照の組が重なっても、これは仮想診断であり口座収支・必要枚数の実績と呼ばない。第二段階だけ一つの口座へ接続し、保有中の次機会は見送り、上限・休止・場末を守る。共通初回の返済差と、見送り／再新規の差を別記する。

全組を対象に、利益／損失／収支、勝敗決済枚数、1枚平均勝敗比と元組勝敗比、含み込みDD、R超過、始動前／後の損失を確認する。利益返却は勝ち組だけ抜かず、最高益の合計を実現可能利益と誤記しない。出口の汎用性は、入口側で独立に固定した別系統へ同じ4方式を移して確認するまで未確認とする。

その後にC01/F50を統合するなら、F50の追加実R退出ON/OFFを一組だけ加え、出口部品の差と数量管理・予算の差を分離する。これは旧v38のC01で実施済みの比較を**到達ゲート付き50%へ拡張する未検証対照**であり、旧試験を新発見と数えない。現時点で設定変更や採用判断は行わない。
