# 出口短縮と数量調整の独立レビュー

旧13セッションと別管理の新ナイトを混ぜず、まず人工経路だけで確認した。A0・C01・1.5ATR到達後50%減量復元・同復元なしの4方式に、固定3ATR追跡／3ATR順行後1.5ATR追跡／同0.75ATR追跡を対応させる。今回の範囲は指定価格約定・伝達0秒であり、正の伝達遅延や観測価格約定への一般化はしない。

| 確認箇所 | 独立確認の方法 | 結果 |
|---|---|---|
| 初回新規と新規準備 | 通常A0を独立生成し、通常A0・短縮影・実口座の注文、準備、初回ATR・元予算を照合 | 人工全48入力一致 |
| 減量ゲート | 短縮影ではなく通常A0の価格順行から1.5ATR到達を再生成 | 入力と公開元を一致確認 |
| 公開と執行 | 入力と過去注文会計から価格線37列を別式再構築し、前行までの有効計画・全注文成立／不成立を照合 | 全48入力一致 |
| 途中数量と優先順位 | 旧枠監査57個のassertを維持し、枠退役、減量復元、予算保持、旧価格注文優先を照合 | 全48入力一致 |
| 時間順 | 3接頭部、未来価格・ATR・方向変更、同秒、上下反射 | 接頭部144・未来144・反射48一致 |
| E00互換 | 旧v41数量注文器と全15配列比較 | 人工16入力一致 |
| 破損拒否 | 追跡線、成熟線、準備許可、通常影、注文数量、部分枠、予算状態を個別改変 | 7例すべて拒否 |

独立影監査は旧版の`publication`と`audit`だけへ、短縮幅の式・通常影の準備許可・通常影の旧監査を追加した。逆置換で元本文と完全一致し、その他の関数はAST同一。枠監査は参照する影監査のimport一箇所だけ変更し、会計・全期間統計の接続関数も旧版とAST同一である。固定3ATRの旧監査をそのまま短縮影に当てて形式的に合格させる処理はない。

人工では減量と復元が実際に発生しており、無取引だけを確認したものではない。ただし人工合格は実相場の経済成績を示さない。次段階の旧26入力×12条件では、全会計・公開計画・枠の検査に加え、E00の旧保存指紋、無調整E10/E11と初回固定の出口診断との一致を別途結ぶ。新しい夜間データは参照しない。
