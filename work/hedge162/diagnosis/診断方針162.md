# 00162 選択後の具体売買診断

凍結した26条件・入口・数量・選択順位を変更しない。前40場と後13場の完了証跡、結果指紋、選択凍結指紋を確認し、rootの全完了通知を受けた後だけ保存結果を読む。売買の再生・最適化は行わない。

- 対象は前40場で選択された最大3案。比較基準はカバーなしのN00を主、50円損切りのS00を補助とする。前40場と後13場を分け、全53場の記述も別枠に置く。

場末代理は時計endで最後の正常板を使った模型であり、通常の次板約定・実際の引け約定と区別する。価格時計の同秒約定を実通信遅延0秒と解釈しない。後13場も既知の資料であり、完全未見とは呼ばない。
