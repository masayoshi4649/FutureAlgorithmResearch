# 00161 原板特徴と先着ラベルの分離仕様

正本は `../inputs161.json`。53場の原板だけを使い、旧手法の入口・売買状態・分足を入力しない。train 30場、validation 10場、test 13場の割当を変更しない。すべて過去研究で参照された期間であり、完全未見の市場期間とは呼ばない。

## 原行と判断時点

- `CurrentPriceTime` を価格時計の代理として使う。受信時計ではなく、二市場の実受信順を復元できない。
- 全JSONLを読み内容SHAを確認。場開始以上、場終了以下、cutoff未満を採用する。時計欠測・時計巻戻り・有限正値でないLastは除外する。不正BBOは採用原行の添字へ残す。物理行は1始まり、採用添字は0始まり。
- 正常BBOは有限な `0 < bid < ask`。数量は価格正常性と別に判定する。
- 自市場の観測点は、価格時計が変わるたびに最初に現れた正常板。初行が不正ならその時計の最初の正常行を使う。同時計の最後の板を後から選ばない。特徴はその物理prefixまで。
- TOPIXも同時計の最初正常板を代表とする。全行不正の時計は最初不正板を代表に残す。相手の現在点は自市場時計より厳密に過去、遅れ15秒以内の最新代表。最新が不正なら未知へ戻し、古い正常代表を現在点として延長しない。これでも実受信順の完全な同期保証はできない。

## 当時の特徴

列名・配列型は `schema161.json` に固定する。欠測はNaN、非有限値もNaN。

- 中値変化は目標窓5/15/30/60/120/300秒。過去端は `t−窓` 以下の最後正常板、目標端からの遅れは15秒以内。変化量は実際の両端差で、速度は実経過秒で割る。したがって `ret5_pt` は厳密な5秒差とは限らず、最大20秒の観測端点差となる。実経過と端点遅れを併記する。途中の不正板だけで両端差を捨てず、不正行数を別保存する。
- 速度差は5対15、15対60、30対120、60対300秒。前5秒窓は `t−5` と `t−10` の正常過去端間。5秒差同士の加速も実経過速度で比較する。
- 高安とrangeは30/60/120/300秒の正常中値、現在原行を除外。直前60秒rangeは `[t−120,t−60)`。位置は `(現在−安値)/幅` で突破時は0〜1の外へ出る。効率は両端の絶対差÷採用正常中値の観測経路長。観測間の連続経路が既知という意味ではない。
- 最良OFIは隣接原行の正常板と有限正数量から、価格の上下を考慮した買側数量増減−売側数量増減を、両行の買売数量合計で割る。間隔15秒超又はどちらか不正なら遷移未知。5/15/30/60秒の既知遷移平均は2遷移以上かつ過去端準備済みで有効。平均・既知件数・全行に対する割合を保存する。窓内の不正遷移だけで他の観測を捨てない。
- 同値段での数量増加/減少を、それぞれ表示回復/消耗の代理とする。注文ID・取消し・取引方向がないため、本当の補充・吸収・約定を断定しない。
- 板不均衡は最良、5段、10段、距離重み付き10段。距離重みは `1/(1+最良からの距離/tick)`、NK225のtick=10、TOPIX=0.5。micropriceの中値差は `spread×最良不均衡/2`。表示板の代理量であり、成行約定可能性を保証しない。
- VWAP固有の時計がないため、前場混入を排除できない公開VWAPや出来高から新しいVWAPを作らない。代わりに、正常中値を原行間で最大15秒だけ保持した60/300秒TWAPと既知時間率を保存する。同時計の時間重みは0。不正板以後は新正常板まで保持しない。
- 相手5/15/60秒は相手代表内の両端bp変化と実経過速度。現在相手の鮮度は別列。自己の価格だけを使う候補は、この相手同期の限界に依存しない。
- 時刻は当場の開始から/終了まで/米国開始まで。Day=0、夜の米国前=1、開始以降=2。米国付近の静観や旧アルゴの準備時間を追加しない。

## 先着ラベル

判断原行より大きい添字の次正常NK225板を入口とする。同じ価格時計の後続原行も次行に含む。次正常が場末まで存在しなければ未約定として残す。

主定義は買いask建値から返済bid、売りbid建値から返済ask。入口原行を含め、その場の最終正常板までを追い、順行100円以上と逆行50円以上の最小原行をそれぞれ保存する。最初に成立した側がラベル。補助Last定義は同じentry原行のLast建値から最終採用Lastまで。同じ点で正負の障壁は同時成立しない。

未来全走査を各点で繰り返さず、範囲最大/最小木から各障壁の最小原行を厳密に検索する。これは事後ラベル計算であり、候補条件から参照しない。

statusは成功1、逆行先着−1、両方未到達0、次正常なし−2。未到達/未約定を成功率の分母から都合よく落とさない。未到達のresolution indexは−1、timeは価格定義の末尾時計とする。方向列は買い・売りの順。

品質には判断→entryの時計差、不正板を飛ばした数、米国区分跨ぎ、entry→決着又は末尾の不正BBO数、隣接価格時計15秒超/60秒超の空白、同経路の米国跨ぎを保存する。欠測中の障壁順序は分からず、観測された最小原行の先着である。これらは未来側診断で、特徴や候補の選択条件へ後付けしない。成功例だけ品質で選別しない。

## ファイルと実行制限

- 特徴: `cache/features/{split}/{session}.npz`。ラベル: `cache/labels/{split}/{session}.npz`。両者は同じdecision index/時計の順序で結合し、全行一致を検査する。
- `extract161.py --stage features|labels --split train|validation|test` の一段階だけ実行する。既存NPZを上書きしない。登録成功の両フラグ、段階許可、入力と選択仕様のSHAが一致した場合のみ実資料を読む。
- testの特徴/ラベルは双方とも `--freeze selection_frozen161.json` 必須。`test_opened:false`、選択/モデル、入力/選択仕様/正規化内容/許可されたファイルSHAを照合する。候補凍結前のtest抽出を禁止し、抽出証跡へfreeze指紋を保存する。
- 実資料の抽出はrootの正式登録後に限定。人工検査では線形・同時計・欠測・不正板・鏡像・板飛び・先着木の素朴探索同値・testゲートを確認した。特徴抽出に金融再生や候補成績の集計は含めない。
