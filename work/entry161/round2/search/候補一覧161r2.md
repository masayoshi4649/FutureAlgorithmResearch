# 第二巡：板指標の尺度を合わせた24入口

第一巡では、平均化されたOFI・補充代理に対して0.1・0.2という閾値が大きすぎた。日中trainのOFI15の99百分位は0.046、買補充の99百分位は0.089だった。板の条件がほぼ成立せず、板の有効性を否定できる試験になっていない。この尺度だけを直す第二巡として分離し、第一巡の結果・選択・コードは変更しない。

**後半13場は既に第一巡の成績が確認された資料。第二巡の追加確認であり、未見検証や再認証とは呼ばない。** 閾値は30train場の特徴だけ、選択は同じ30train/10validationで固定する。ラベル・validation・後半は閾値母数にしない。

## 8構造×3分位

買いについて記載し、売りは符号と板側を反転する。各系列の01/02/03が50/75/90分位。全て、入口条件の新たな真への遷移、判断間隔60秒、一予測未決中の再参加禁止を維持する。

|ID系列|条件|分けて確かめること|
|---|---|---|
|BF：OFI単独|OFI15が正で絶対OFI分位以上|表示注文増減だけの情報量|
|BD：距離板単独|距離加重板偏りが正で絶対偏り分位以上|厚みだけの情報量|
|BR：優勢補充単独|買補充が買補充分位以上、かつ売補充より大きい|同価格の数量回復だけの情報量|
|BA：OFI＋価格受容|BFに、15秒と5秒の価格変化がともに非負|数量だけの条件に価格の一致が必要か|
|BP：補充＋価格受容|BRに、15秒変化≧−10円、5秒変化≧0|補充を受けても価格が崩れないことの価値|
|BC：OFI＋距離板|BFとBDの両方|注文増減と表示数量の一致の価値|
|BS：逆OFI＋反発|OFI15≦負の分位、15秒変化≧−10円、5秒変化≧10円|逆向きの圧力でも価格が下がらない代理|
|BU：吸収代理の二経路|「逆OFI又はBR」のいずれかに、15秒変化≧−10円、5秒変化≧10円|逆OFIと同側補充を同時必須にしない比較|

補充代理は同じ最良価格で表示数量が増えたことを示す。真の約定消費・同一参加者の再補充・建玉の主体は識別していない。

## 変更しない境界

- 新規は判断後の次正常ラージBid/Ask、買売対称。実新規原行の清算気配から、100円順行と50円逆行の接触先着。終端までの未決は成功にしない。
- 必要特徴が欠測した比較はfalse。ただしOFIだけの候補に、使わない補充・板偏りの既知を要求しない。
- 候補×phaseごとに一予測未決、条件edgeは未決中も更新。決着原行より後、かつ前の**判断時刻から60秒以上**で再参加を許す。約定時刻から60秒ではない。
- 前半の予測が後半へ残る場合も採点を継続する。各phaseの率だけを報告し、選択3条件を単一非重複戦略へ合算しない。
- train40事象/8場/買売各5/最多1場30%以下、validation15事象/3場/買売各2/最多1場50%以下。
- 適格な候補のうち、validationの保守下限を最大にする1条件/phase、最大3条件。学習モデルの再当てはめ・混在はしない。適格なしを無理に埋めない。
- 第一巡の`engine161.py`を指紋固定した依存として使う。別プロセス内だけ候補関数とモデル無しを接続し、元ファイルを変更しない。
- CLIと保存名は第一巡互換。`locked_test161.json`というファイル名であっても、全出力に「第二巡・既知後半の追加開発」を必須で記録する。

仕様は `spec161.json`、候補は `candidates161.json`、実行器は `engine161r2.py`。新しい登録受領がない限りラベルの再評価を開始しない。
