# 機械化の注意と一次資料

## 先に決める曖昧さ

| 論点 | 今回の扱い・確認事項 |
|---|---|
| 「始値」は何か | APIのOpeningPriceなどが前ナイト由来の場合があるため、当場最初の有効最終価格Oを固定する。厳密な取引所の寄付き価格とは限らない |
| 線外にいるか、新たに越えたか | P01・P02・P05は初回準備時の例外を除き交差イベント。状態が続く間の毎分発注ではない |
| 準備完了時に既に線外だった場合 | P01・P02・P05だけ、最初の判断時点に既存の状態から一度候補を許す。初回フラグは発注成功とは独立に消費する |
| 再エントリー | 返済後60秒休止。同じ状態が続くだけなら交差型の入口は出さず、一度反対側又は内側へ戻った後の新しい交差が必要 |
| 帯の内側とは | 下側帯≤終値≤上側帯。前足の片側帯外から反対側帯外へ飛んだものは帯内復帰ではない |
| 帯と価格の時点 | 前足は前足の帯、現足は現足までの20分帯と比較。現足の帯を過去へ適用しない |
| 現足で帯を作ってよいか | 確定足が公開された後にその終値を含む帯を計算するなら因果的。約定も公開後とし、確定前の価格へ遡って入らない |
| 過去20分高安 | 現在足を除く。現在足自身の高値を抵抗として同じ足で突破した扱いにしない |
| EMAの初期値 | 初終値から開始するか、最初の各期間の平均から開始するかを固定。どちらも未来参照ではないが、最初の信号時刻が変わる |
| 幅比較の準備期間 | 標準偏差幅が使えるまで、他の幅にも同じ準備条件を適用するのが比較として明瞭。P04は現足を除く20本が必要なので最短21本目。最終の共通開始条件は固定仕様を参照 |
| ATRが間接的に残る経路 | 旧実装のcan_tradeなどがATR準備を条件としている可能性がある。新規可否を足数・連続性・鮮度などだけで作り直す |
| 固定トレールの開始 | 約定直後から常時追跡。1幅順行してから開始する別方式へ結果を見て変更しない |

1分OHLCの中の高安の順番は推定しません。入口は公開済みの終値、決済はその後の原本の価格順に処理します。注文を出した次の価格が不利でも、その値を見て過去の発注を取り消しません。

## 計算上の最低限

20分の平均を `m_t`、母標準偏差を `σ_t` としたとき、上帯は `m_t+2σ_t`、下帯は `m_t−2σ_t` です。母標準偏差か不偏標準偏差かは明示し、同じ名称で計算を混ぜません。今回提案は従来のSMA20と母標準偏差です。

EMAの更新係数は期間nに対し `2/(n+1)`。欠けた分を直前価格で埋めて、20分や8/21分が揃ったことにはしません。初期化と欠落時の更新方法は固定します。

実装監査では、旧ATR列を削除又は極端な値へ変更しても入口・枚数・返済が同じであることを確認します。旧台帳のATRやATR換算の順行幅という名称を、新しい固定幅Wの値に流用しません。

## 一次資料

| 一次資料 | 確認した事実 | 今回への意味 |
|---|---|---|
| [John Bollinger本人の使用規則](https://www.bollingerbands.com/bollinger-band-rules) | 帯への接触だけは売買信号ではない。強いトレンドでは帯に沿って進む。20期間・2標準偏差は既定値であり、確率分布の保証ではない | 帯外の順張りと、帯内復帰の逆張りを別の仮説として比較する。2σだから95%戻るとは説明しない |
| [TA-Lib公式のBBANDS定義](https://ta-lib.org/functions/bbands.html) | 移動平均の上下へ標準偏差の倍数を加減する計算 | ATRを除いても標準偏差による変動尺度は使っていることを明示する |
| [TA-Lib公式のEMA定義](https://ta-lib.org/functions/ema.html) | 最近の価格を強く重み付けする再帰式。公式実装説明の初期値は最初の期間の単純平均 | EMA8/21という名前だけで初期化まで同じと思わない。今回が初終値開始なら、その違いを記録する |
| [CME公式の支持・抵抗解説](https://www.cmegroup.com/education/courses/technical-analysis/support-and-resistance) | 過去高安や移動平均を水準の候補として使う。支持抵抗は正確な一点で必ず機能するものではない | 過去高安抜けを機械条件にできるが、その水準で必ず反転・継続するとは主張しない |

公式定義は、今回の日本の先物での利益を証明するものではありません。手法を再現可能な形へ落とし込むための資料として使います。新しい損益を確認した後で期間や開始方法を選び直さず、外れた場合も同じ条件の結果として報告します。
