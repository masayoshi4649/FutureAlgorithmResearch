# 単純化の狙いと20条件

最初に読む資料です。計算と再エントリーの注意は「機械化の注意と一次資料.md」を参照してください。新しい損益を見る前に作成し、親作業から共有された20条件に合わせています。境界値・準備時刻・例外処理の最終定義は、実装と固定仕様を正とします。

**今回は、入口を五つの単純な価格条件にし、決済を固定幅トレールへ揃えます。ATRを入口・新規可否・途中判断・出口・尺度のどこにも使いません。**

## 何を減らすか

| 減らすもの | 理由 |
|---|---|
| 板と相手銘柄の確認 | 確認待ちで値幅を使い切ることと、候補を捨てる影響を一旦なくす |
| 定着・反復などの状態選択 | 選択アルゴリズムの失敗と、入口自体の成否を分けやすくする |
| 時間・相場状況によるトレール幅の変更 | 同じ入口に対する幅の効果を直接比べる |
| 追加玉・分割返済・連敗休止 | 枚数や次の機会の変化による説明の複雑さを減らす |
| 指標期間の事後探索 | 結果に合う20分や8/21を後から選んだことにしない |

単純にしたことで計算・再現・失敗原因の切り分けは容易になります。条件数を減らしただけで未来の方向が分かるようになるわけではありません。

## 五つの入口

判断は公開済み確定1分足を使います。売りは買いの大小・方向を反転します。全条件は両銘柄に同じ定義を適用します。

| ID | 入口 | 期待する性質 | 主な反例 |
|---|---|---|---|
| P01 当場基準価格からの固定割合突破 | 当場最初の有効最終価格Oに対し、終値がO×1.001を新たに上抜けば買い、O×0.999を下抜けば売り | 当場の基準から離れた方向への進行が続く | 開始時の価格が一時的な高値・安値、固定線付近の往復、一方向に動いた後の遅い参入 |
| P02 ボリンジャーバンドの外へ | 20分平均±2標準偏差に対し、上側の外へ新たに終われば買い、下側の外なら売り | 直近の価格分布の外への動きが続く | 帯外が進行の終盤、薄い注文による瞬間的な突出 |
| P03 ボリンジャーバンドの内へ | 前足が下側の外、現足が上下帯の内側へ戻れば買い。上側からなら売り | 逸脱が縮小し、その後も平均方向へ戻る | 強いトレンドの小休止、価格の戻りでなく帯の移動による復帰 |
| P04 直前20分の高安突破 | 現在足を除く過去20分高値より上で終われば買い、安値より下なら売り | 直近の取引範囲を越えた値直しが続く | 過去の高安に意味がない、古い極値が窓から抜けたため線が移動しただけ |
| P05 EMA8/21の交差 | 8分EMAが21分EMAを下から上へ交差すれば買い、上から下なら売り | 最近の価格が、少し長い平均を上回る方向へ続く | 平均の遅れ、往復相場の連続した小損切り |

P01・P02・P05は、最初に準備できた時点で既に条件の側にいる場合に限り、その方向を一度候補にします。その後は新しい交差を待ちます。初回候補を保有・休止などで使えなくても、後から同じ状態を「初回」として再利用しません。

P03は上側の外から一度に下側の外へ移った場合など、終値が帯内にないものを復帰と数えません。P04は20分窓が動くため、連続する新高値・新安値も新しい突破候補になり得ます。同じ固定線を再交差するP01とは機会の発生方法が異なります。

## 四つの出口幅

各入口に、以下の4幅を共通して適用します。5入口×4幅＝20条件です。入口P01の割合0.10%は出口幅と連動させません。

| 幅 | 計算 | 含まれる仮定 |
|---|---|---|
| Oの0.05% | 当場最初の有効最終価格×0.0005 | 浅い戻りで早く降りる |
| Oの0.10% | 同×0.001 | その中間 |
| Oの0.20% | 同×0.002 | 深い戻りを許し、長い波を残す |
| 判断時の標準偏差1倍 | 直近20分終値の標準偏差 | 当時の価格の散らばりに幅を合わせる |

幅Wは2呼値以上とし、呼値単位へ切り上げます。入口判断時に固定し、保有後の標準偏差や価格から引き直しません。

約定直後から、買いは約定後の最高値−W、売りは最安値＋Wを追跡します。初期ストップも入口からWです。別の「トレール開始まで何R待つか」は設けません。線は有利な側にだけ移動し、緩めません。時間による保有上限は設けず、必ずセッション内で全返済します。返済後は60秒休止し、その間の信号は後から復活させません。

TOPIXミニ5枚、NK225マイクロ10枚で新規し、追加しません。価格はラージの観測を使い、判断後の次の有効原本行で約定させます。費用は0とします。

## ATRなしでも、変動の尺度は残る

ボリンジャーバンドと標準偏差幅は、終値の散らばりを使います。**ATR不使用は、変動を測る指標を一切使わないという意味ではありません。** また、価格水準の標準偏差はリターンの標準偏差と同じではなく、一方向に進むだけでも大きくなります。

固定割合は価格水準の単位差を縮めますが、当日の活発さには適応しません。静かな場では広すぎ、荒い場では狭すぎる可能性があります。高安線も将来の支持・抵抗を保証せず、窓から古い足が落ちることで移動します。

最も儲かった指標期間や幅を追加で探し直さず、同じ入口の4幅すべてを残します。狭い幅で損失が小さくなっても、勝ちをそれ以上に捨てれば改善とは言えません。金額・枚数・取引数・平均勝ち/負けと、幅W当たりの成果を合わせて評価します。
