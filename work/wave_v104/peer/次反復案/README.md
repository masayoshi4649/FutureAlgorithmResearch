# 次の入口改善候補

最初に読む資料は [105_入口品質の3候補_未検証.json](105_入口品質の3候補_未検証.json) です。既存104のsourceと入力は変更していません。

主手法の損失は、TOPIX111件中110件、NK22542件全部が利益トレール発動前です。主要な問題は、両市場が同方向に進んだことだけでは、狭い停止幅へ戻る前の順行を保証できないことです。

次の3候補を提案します。まだ成績は調べていません。

1. **進行効率と逆行余裕**：端点だけでなく途中の往復を測り、最近の揺れより停止余裕が小さければ見送る。
2. **価格受容を待つ**：自己の固定支持帯を、別時計の観測でも維持したら入る。崩れた場合や進み過ぎた価格では入らない。
3. **活動に対する価格反応**：方向代理出来高が多いのに気配が進まない状態が続けば、相手側に受け止められている可能性を理由に見送る。

旧版の利益取引にも、一度支持線を割ったものがあります。これらの条件で大勝ちや活動を失う可能性も、独立した対照として確かめる必要があります。無取引を勝ちに数えず、同じ日々の安定性基準で判断します。
