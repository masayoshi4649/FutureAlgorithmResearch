# 二市場共同判定の独立監査

最初に [全336条件と固定遅延42条件の会計選定独立監査.json](全336条件と固定遅延42条件の会計選定独立監査.json) を読んでください。続いて、未来参照・同期の検査、相手確認の補助診断の順に確認できます。監査の合格は会計と実装の一致を意味し、安定した将来利益の証明ではありません。

## 読む順序

1. [全条件の会計と前半選定](全336条件と固定遅延42条件の会計選定独立監査.json)：主336条件と固定遅延42条件、21,924口座、61,373決済、122,746注文を独立計算しました。全損失明細・双方の手数料・全行清算曲線を含め、前16場だけの代表選定が一致しました。
2. [実経路の片側未来切断](二市場実経路の片側未来切断と注文監査.json)：10設定・3場・480比較で、一市場だけの未来改変や同時計途中の切断が過去の判断と注文を変えないことを確認しました。途中に未返済玉がある20経路でも、配列終端による架空返済を行いません。
3. [主鮮度30秒の同期](二市場同期fresh30と片側未来改変の独立監査.json)、[人工経路](二市場モデルの人工状態と片側未来の独立監査.json)：同時計先頭、厳密な過去参照、片市場停止、欠測、矛盾、空入力、銘柄入替を検査しました。
4. [鮮度選択の入力十分性](鮮度選択の入力十分性独立監査.json)：損益前に用いた鮮度10・30・60秒の348集計と12全体集計を独立確認しました。主条件は鮮度30秒です。
5. [同じ新規機会の相手確認](同じ新規機会の過去確認分類と金額の独立監査.json)：S1の実新規142件を、その時点の相手方向確認あり・なしに分類し、前16・後13・全29場の二群会計18集計を確認しました。元の新規と出口を固定した補助診断であり、除外後の再入場を再生した成績ではありません。

全共同状態・新規発火・原本行への写像は、[遅延5秒](全共同状態と新規pulseの独立監査_delay5.json) を主に、[1秒](全共同状態と新規pulseの独立監査_delay1.json)、[15秒](全共同状態と新規pulseの独立監査_delay15.json)、[60秒](全共同状態と新規pulseの独立監査_delay60.json) でも全系列を照合しています。各遅延で3,248口座・7,454,720状態点が一致しました。旧鮮度10秒の同期監査は初期設計の記録として保持しています。

## 検査の範囲と限界

- 保存29場を前16・後13に分けた検査です。いずれも既知データであり、真の未見期間ではありません。後半や遅延感度から代表を選び直していません。
- 同期は最終約定時刻の代理時計上で、判断格子より遅延分だけ前の値を参照します。共通受信時計がないため、実際の両市場の受信順まで証明していません。
- 買いは売り気配、売りは買い気配に、判断後の次の有効原本行で約定します。TOPIXmini最大10枚、NK225micro最大20枚、両側の立会手数料を注文単位で切り捨てて課金しました。商品別の円収支を合算して優劣判定していません。
- 予定撤収時刻の超過返済は90件、最大124秒です。判断から次有効気配までの最大遅れは24秒でした。全返済は保存監視終端より前で、予定時刻の返済保証は行いません。
- 原本の新規取得・現在API取得・実注文は各0です。元データ、凍結モデル、研究結果、過去成果は変更していません。
