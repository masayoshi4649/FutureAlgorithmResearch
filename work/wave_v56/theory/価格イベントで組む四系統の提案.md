# 価格イベントで組む四系統の提案

**保留:** 2026-10-07の追加指示に従い、価格が上昇・下落する原理の分析を先に行う。本提案の新アルゴリズムは採用・実装しておらず、新損益も計算していない。

新しい損益を見る前の設計案。採用する具体値と処理順は親実装の固定仕様を正とする。本書の閾値は最適値という主張ではなく、機構の違いを比較するための提案である。ATRは使わない。

## 利益を期待する理由と、期待してはいけない理由

狙いは、大きな方向が続く場面で一時的な逆行を待ち、再開した方向に参加すること。成立には「大きな方向を条件にした、参加後の値動き」が無条件より有利でなければならない。流れが上向きだった事実や安い位置で買った事実だけでは足りない。

往復型は、最近の往復範囲が次の往復にも残り、端を越えて逃げる場面の損失を中央への回復益で補える場合に利益を生む。直近で往復したことは、次も往復する証拠ではない。自動選択も独立の仮説として検証する。

価格イベントで時間を刻む利点は、値が動かない原本行を大量に数えず、動いた場面を同じ値幅で比較できること。欠けた経路や受信時刻を復元する機能、利益を生む仕組みではない。

## 共通の観測・会計

- 原本を保存順で一行ずつ読む。同じ最終約定時刻でも原本行順を保つ。現在有効な最良売買気配の中値を信号価格とし、次の有効原本行の最終価格で約定する。両価格の差を入口の予測力と取り違えない。
- 小幅δは当場最初の有効最終価格の0.05%を出発案とする。参照ラージの呼値で切り上げ、最低2呼値。大幅Dは4δ。両銘柄に同じ割合・倍率を使い、銘柄名で規則を分けない。
- セッション開始で全状態を初期化し、セッション内で全返済。固定枚数・追加なしで入口の価値を比較する。
- 価格イベント法では連続20分足を要求しない。これは保存データの空白を無条件に安全と認める意味ではない。前回と異なる準備条件の効果は別の対照で残す。
- 一原本行で複数の価格段を飛び越えても、途中の仮想価格で約定しない。その行の中に「逆行して再開した」という未観測の順序を作らない。

## 1. 時間で方向を決め、短い反転で入る

**入口:** 現在と30分前の最後に観測できた中値の差が4δ以上なら上向き、−4δ以下なら下向き。それ以外は中立。方向確認後、小幅δの方向変化が一度逆向きになり、後の原本行で再び大きな方向へ変わった時に入る。方向が変わる・中立になる場合は待機を破棄する。

**途中:** 大きな方向が変わったという事実を記録する。最初の比較では、それを返済にも使うかは統一管理との対照に分離し、入口の効果へ混ぜない。

**出口:** 全手法共通の固定幅保護を基本とする。長い流れを残す管理は別の事前固定対照にする。

**反例:** 30分の上昇がすでに終わり、最初の下落局面で小さな反発だけを買ってしまう。過去の方向判定が古いほど起きやすい。30分前の参照値が古い場合は参照年齢を記録する。空白を均等な足で埋めない。

## 2. 大小二つの値幅で方向を分ける

**観測:** 大小それぞれに方向変化を逐次計算する。上向き状態では最高値だけを更新し、その最高値から閾値だけ下がった現在行で下向きを確定する。下向きは逆。極値が付いた昔の時刻には戻さない。初期は中立とし、最初の閾値変化で方向を得る。

**入口:** 大幅Dの方向が確定してから、小幅δの方向が反対になった事実を記憶する。大幅方向が保たれ、後の原本行で小幅方向が再び同方向に変化した時に入る。大幅方向変更時には待機を消し、同じ行の小幅変化を新たな押し目・再開として再利用しない。

**途中:** 当初の大方向と小方向、待機中の最大逆行、再開確認までに戻った値幅を記録する。

**出口:** 共通固定幅保護。大幅方向の反転で返済する案は追加対照に限定する。

**反例:** 一方向に戻らず進む日は押し目がなく入れない。大幅D未満の往復が続く日は古い方向が残る。大小の尺度を分けても長い時間を保有するとは限らず、保有分数を実測する。

## 3. 価格階段の進行率で追従する

**観測:** 最後のイベント価格qから中値がδ以上離れた現在行を次イベントとし、qをその行で実際に観測した中値へ更新する。飛越時も一行一イベントとする。これは固定幅を最低移動量に使う粗視化であり、架空の一定幅足を複数作る方式ではない。

直近8変化について、進行率E＝端点の純移動の絶対値÷各変化の絶対値合計を計算する。分母0は判定不能。E≥0.5なら純移動側を追従候補とする。

**入口:** 方向確認後に1イベント逆向きへ動き、後のイベントで同方向へ戻り、進行率の方向も維持していれば入る。押しを待たず条件成立時に入る方式を対照にする。

**途中:** 進行率は現在までの変化だけで更新する。保有後のE悪化で返済するかは、入口の判断とは別に比較する。

**出口:** 共通固定幅保護。イベント数による保有上限は将来候補であり、今回自動追加しない。

**反例:** 大きな一回の飛越がEを上げ、継続した流れと誤判定する。イベント数、最大一変化の総移動に占める比率、同時刻比率を診断へ残す。8という窓を損益に合わせて変えない。

## 4. 往復の端から中央へ参加し、自動選択へ組み込む

**入口案:** 直近イベントの進行率E≤0.25なら往復候補とする。新しい待機を始める前の直近16イベントの高値・安値・中央を固定する。価格が上端へ達した後、その後の極値からδ下がれば売り、下端からδ上がれば買い。狙う中央が現在価格の先に残っていなければ入らない。固定範囲を後から広げて失敗を消さない。

**途中:** 中央への余地、外側への逆行、範囲外への逃避を記録する。

**出口:** 初回比較は共通固定幅保護。中央で全利確する管理も論理に合うが、追加するなら入口比較とは分けて仕様を固定する。

**自動選択:** E≥0.5では3の追従、E≤0.25では4の往復、それ以外は新規なし。モードの変化だけで過去の待機を別モードへ引き継がず、破棄して新しい事件を待つ。成立後の利益を見てモードを選ばない。

**反例:** 往復判定の直後に相場が抜ける。最近の高安は需給の壁そのものではない。全局面の同じ逆張りより、低進行率の絞り込みが損失を減らすかで判定する。

## 構造の違いを調べる12対照の候補

| 対照 | 目的 |
| --- | --- |
| 時間方向に即参加 | 方向判定自体の基準 |
| 時間方向＋小幅逆行・再開 | 押し目待ちを足す価値 |
| 小幅方向変化だけに参加 | 大きい方向が必要か |
| 大幅方向変化に即参加 | 大尺度方向の基準 |
| 大幅方向＋小幅逆行・再開 | 時間を使わない押し目待ち |
| 同じ小幅再開を大方向と反対側だけ採用 | 大方向の向きが有益かという反証 |
| 価格階段の高進行率に即参加 | 経路選別の基準 |
| 高進行率＋逆行・再開 | 経路選別と押し目待ち |
| 全局面の範囲端反転 | 往復の基準 |
| 低進行率だけの範囲端反転 | モード選択を足す価値 |
| 高進行率追従／低進行率往復の自動選択 | 選択込みの一つの手法 |
| 自動選択に旧連続20分の準備条件を追加 | 準備条件除去の影響 |

これはパラメータを連続的に振って上位だけ選ぶ計画ではない。入口・準備・管理を一度に変更した対照は、差額を一要素の因果効果と呼ばない。返済時刻が変われば次の入口集合も変わる。

## 共通管理と採否の考え方

入口の最初の比較には、2δの固定初期ストップと同幅の常時トレール、場内返済を共通化する案が扱いやすい。ただし2δ自体に優位性はない。長い流れ用には「初期損切りδ、順行2δから2δトレール」を別に固定すれば、損切りと利益保護を分ける意図を検証できる。採用範囲は実装前に決める。

損益に加え、待機開始数、参加数、方向消失・期限・場末などで参加しなかった数、待機値幅、参加後の順行/逆行、中央値保有分数、損失連続数を出す。成立した入口だけの成功率を「波の検知正答率」とは呼ばない。

大きな方向の条件を加えても参加後の値動きが改善しない、逆側対照と差がない、両市場のどちらかで損失が続く、大勝を除くと利益が消える、という結果なら該当仮説を支持しない。今回失敗したことから、すべての手法が存在しないとは結論しない。

## 実装前の監査点

現在の経過時間と完了した過去イベントだけを使い、未完了イベントの最終長さを使わない。大/小の更新順を固定する。同じ行で逆行→再開を二度作らない。入力の途中切断・未来改変で過去の信号が変わらないことを確認する。シグナル中値だけで同じ注文を再評価した説明用損益も残せると、最後値による往復成分を区別しやすい。
