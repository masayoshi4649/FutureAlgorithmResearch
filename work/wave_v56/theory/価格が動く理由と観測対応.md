# 売買が同数でも価格が動く理由

2026-10-07。価格形成を先に考えるという追加指示に従い、新しい価格イベント手法の構成は未採用・未実装・新損益未計算のまま保留した。

**結論:** 売りたい人と買いたい人がいるだけでは、価格は上にも下にも決まらない。取引したい数量に対して、**今の価格で待つ相手注文が残るか、誰が次の価格まで条件を譲るか**で、次に取引できる価格が変わる。「買いが多い」は、約定した買い枚数が売り枚数より多いという意味では使わない。

## 小さい例で考える

売り板が100円に10枚、101円に20枚ある。直ちに約定させたい買い15枚が到着し、他の注文変化がなければ、100円で10枚、101円で5枚が成立する。買いも売りも15枚だが、最後の価格は101円になる。売り買いの人数ではなく、受け入れる価格とその価格にある数量が違うためである。売気配に届く指値でも即時に約定できるので、「積極的な買い」は成行注文だけを意味しない。[JPXの取引方法](https://www.jpx.co.jp/derivatives/rules/trading-methods/)、[注文の種類](https://www.jpx.co.jp/derivatives/rules/order-types/index.html)

同じ100円の売りが消費されるたび補充されれば、買いが続いても100円に留まる。反対に、100円の売り注文が取り消され、他に同価格の売りがなければ、約定なしでも最良売気配は101円になる。このため必要なのは「積極的な買いの量」と「売り供給の残り方」の両方である。板は注文の追加・約定・取消で更新される。[CMEの板更新の説明](https://www.cmegroup.com/education/articles-and-reports/understanding-the-cme-liquidity-tool-methodology)

買気配99円・売気配100円が変わらず、最後の約定が99円から100円へ移っただけなら、最終価格は上昇しても提示価格は上昇していない。値動きを調べる時には、この往復と両気配の値直しを分ける。

## 上がる・下がる・動かない条件

下表は上昇側の例。下落側は売買を交換すれば同じ構造になる。板寄せは別の価格決定方式なので、ここではザラバを対象とする。

| 状況 | 現在の市場で何が起こるか | 続くとは限らない理由 |
| --- | --- | --- |
| 売り供給を消費する | 買いが売り提示へ約定し、その価格の供給がなくなると次の売り価格が高くなる | 一回の大口注文が終われば、後続の買いはないかもしれない |
| 売り供給が撤退する | 安い売り提示が消え、売気配が上がる。買い出来高は必須でない | すぐに新しい売りが入れば元へ戻る |
| 買い手が提示を上げる | より高い買い指値が最良買気配を切り上げる。約定せず中値が上がることもある | 単にスプレッドを詰めた一注文かもしれない |
| 両側が高値へ提示し直す | 買気配・売気配がともに上がる | 共通情報への一度の反応なら、その変化は既に終わっている |
| 買いを売り補充が受け止める | 出来高は増えるが中値は進まない | 買いが止まれば反落し得るが、補充が先に尽きれば上へ抜ける |
| 両側が譲らず待つ | 売りと買いの条件が合わず、約定しない | 新しい注文・取消・情報で均衡は変わる |

見えている板の厚さは静止画である。価格を動かす時には、消費、追加、撤退、次の価格までの距離が組み合わさる。厚い売り板でも消えることがあり、薄い売り板でも何度も補充される。注文イベントの研究も約定だけでなく指値追加・取消を扱っている。[Eislerほか](https://arxiv.org/abs/0904.0900)

指値で待つ側も新しい情報、在庫、他市場の値動きを見て提示を変更する。約定しに来る側だけが価格形成の主体ではない。例えば上がると考えた売り手が安い売りを取り消すだけでも、買い気配が変わらないまま売気配と中値は上がる。この段階と、買い気配も上がって新しい水準に取引が移る段階を区別する。

「焦り」はこの過程を生む理由の一例である。高い値段を受け入れる買いは、新情報、損切り、ヘッジ、裁定、定時執行でも起きる。板だけからその人の心理を確定しない。

## 保存データで分かること・推定・不明

| 原理 | 今回の記録で直接分かること | 既存の測定列と、その限界 |
| --- | --- | --- |
| 最後値と気配の変化 | 各保存行の最後値、最良買値・売値、中値、差額 | `last/mid/bid/ask`、`quote_ticks`、`both_up/down`。行間の未保存経路や真の価値は不明 |
| 積極的な買い・売り | 累積出来高が増えたこと、最後値が直前気配のどこか | `exec_buy/sell/unknown` は方向代理。出来高増分の全約定内訳を最後の一価格で分類しており、買い/売りの真の集計ではない |
| 数量の撤退・追加 | 同じ表示価格の数量が前後で減った/増えたこと | `noexec_*` は出来高が増えない行の純増減。取消メッセージそのものではない。出来高と板の更新順のずれがあり得る |
| 同価格の補充 | 同価格の数量が減った後、表示量が回復したこと | `refill_*` は30秒以内の対応回復量。同じ主体、同じ注文、約定を受けた補充、隠れた大口注文とは断定できない |
| 近い供給と遠い供給 | 表示10段の価格・数量と最良価格からの距離 | `supply_*_near/far` は距離加重した表示供給。10段外や未表示注文は不明 |
| 二市場の反応 | NK225とTOPIXが各自の記録で同じ側へ気配を変えたこと | 共通要因の可能性はあるが、独立した二票や一方が他方を動かした証拠ではない |

既存列は [wave_v52の抽出実装](../../wave_v52/measurement/extract.py) と対応する。時刻は最終約定時刻で、各板更新の受信時刻ではない。したがって「30秒で補充」の時計も代理値であり、空白を無取引と通信欠損に完全分離できない。

**既存測定の重要な取りこぼし:** 数量差分は前後とも表示される共通価格だけを数えている。最良売値が消えて次の価格へ上がった時、消えた価格の数量減はこの差分列に入らない。よって既存の数量減だけでは、最良板の枯渇・撤退を全部測れたとは言えない。気配の価格移動とは分けて再確認する必要がある。

補う場合も、10段の遠方へ外れた価格を数量0にしない。前の売り価格が現在の最良売値より安い側へ消えた場合など、現在の最良気配から「その価格に表示売りがない」と言える場合と、観測範囲外で分からない場合を分ける。

今回この区別を実装し、46原本を再点検した。旧最良板が後退して表示0になった数量の延べ合計は、TOPIXの買い339,414・売り319,580、NK225の買い331,852・売り325,619。遠方10段外の旧表示量は不明に分離した。同じ数量が繰り返し出入りする場合を含むため、これらを取消枚数・約定枚数・固有注文数とは呼ばない。[表示範囲補正の全数監査](../measurement/表示範囲補正とOFIの全数監査.json)

売買代金と出来高の増分から平均約定価格を作る数値整合性も確認した。旧最後値代理と平均値代理の分類差はTOPIX1.42%・NK0.81%であり、旧代理の全面否定とはならなかった。平均価格を使っても個別約定の順序と方向は復元できない。また同じ約定時刻のまま板が変わる行が多数あり、原本順を保つ必要がある。[代金監査の結論](../review/代金監査の結論.md)

## この理解から先に調べる問い

同価格の表示数量は、概念上 `数量変化＝追加−取消−約定消費` となる。snapshotでは右辺を一意に分解できない。それでも、**同程度の買い執行代理に対して、価格が進んだ場合と止まった場合で、供給の減少・回復・買気配の追随がどう違うか**は調べられる。売り側も対称に調べる。

次に、その状態が後の区間でも残るかを確かめる。「買いで上がった」という同時点の説明と、「今買えばさらに上がる」という予測は別である。OFIと価格変化の研究も、同区間の価格影響をそのまま将来予測の証拠へ読み替えない。[Contほか](https://arxiv.org/abs/1011.6402)

新規売買ルールや損益計算はこの機構分析の後に進める。現時点で分かったのは、何を条件として区別すべきかと、この記録で直接測れる範囲である。未来の上昇・下落を高確率で当てられるという結論はまだ出していない。
