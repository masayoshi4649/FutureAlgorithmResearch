# 作業 00053 の独立監査

新しい売買案は保留し、価格形成の原理と既存の測定を再点検した。新戦略・新しい損益は作成していない。

最初に [代金監査の結論](代金監査の結論.md) を読む。原理の線引きは [価格が動く仕組みと識別の監査](価格が動く仕組みと識別の監査.md) にまとめた。

資料の順序：

1. [売買代金と出来高の同期監査](売買代金と出来高の同期監査.json)：46 原本の全数点検。時刻・平均価格・旧代理との差。
2. [一枚更新と複数枚更新](一枚更新と複数枚更新の監査.json)：1 枚更新は平均と最後価格が全件一致。
3. [表示範囲と OFI の独立合成監査](表示範囲とOFIの独立合成監査.json)：既知の最良板消失と遠方表示外を分離する新観測関数の検査。
4. [原本比較母数の独立照合](原本比較母数の独立照合.json)：別実装同士で全 46 場の行数・連続比較数・正出来高差分件数が一致。
5. [HTML 表示](HTML表示の独立検査.json)：実 Chrome の広幅・狭幅・詳細、18 数値、4 監査文、10 ローカルリンクを照合し、暗色配色を目視。

価格イベントによる売買の事前案は [事前の敵対的論点](事前の敵対的論点.md) に未採用として残した。
