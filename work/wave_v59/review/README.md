# 00056 の独立監査

最初はこの README を読む。次に理論上の限界、実装と会計の証跡の順に参照する。監査対象の原本と旧成果は変更していない。

2. [特徴と入口の独立監査](特徴と入口の独立監査.json)：確定足264行の別計算、未来切断・改変16件、交差と品質19件、銘柄名4件、価格単位変更1,104件。
3. [独立合成監査](独立合成監査.json)：出口24経路、接頭辞・未来改変82件、同時計の原本順、箱逸脱、保有と休止境界。
4. [旧23場の全口座会計](dev_全口座の独立会計監査.json)：3,312口座、109,612注文、54,806返済組、中値・気配134,208区間、未来比較576件、期間集計576件。

再現スクリプトは [check_core.py](check_core.py)、[check_features_signals.py](check_features_signals.py)、[check_accounts.py](check_accounts.py)。売買規則そのものを変更した検査ではなく、独立した人工経路・現金と数量の計算・最初に出口条件へ達した原本行の照合を行っている。

今回の主自動切替 `A1_M1_5_20_X2` は、旧23場で追従取引が各銘柄1組だった。したがって自動切替一般の有効性まで否定・肯定できない。空白足を前値で補った指標にも限界が残る。会計と因果順の監査合格は、将来利益や統計的な有意性の証明ではない。

追加2場は親担当の適用前固定・実行通知後に同じ規則で評価した。結果を見た規則変更はない。独立監査は保存入力と結果だけを使い、原本を再読取していない。将来切断・改変は、判定が既知範囲だけに依存することの検査であり、新しい収益条件の探索ではない。

研究候補 `S2_M1_3_10_X1` の追加2場の中値収支は TOPIX +1,250円・NK225 +6,500円、同じ注文を売買気配で評価すると −115,000円・−48,000円であり、すべて独立会計と一致した。理想中値の小さな黒字と実行可能性を混同しない。
