# 旧ATR方式の金額比較

最初に `旧ATR54条件の金額比較.json` を参照してください。次に `旧ATR会計の照合.json` で注文・料金・全玉組の独立再会計を確認できます。

対象は00064（wave67）の観測値16結果と00065（wave68）の観測値38結果です。E01とR01は重複結果のため、ランキングでは54資料・52条件として扱います。すべて同じ既存28場で、初回TOPIXミニ5枚・日経マイクロ10枚です。10/09デイは含めていません。

主指標は料金後の勝ち組利益合計／負け組損失合計（金額PF）です。損失割合は負け組損失合計／勝ち組利益合計と明記しています。一組の平均利益／平均損失、決済明細勝率、枚数当たり利益／損失は別の指標です。

主結果はCurrentPriceで発動・約定を再計算した既存の観測価格運転です。気配による再運転ではありません。固定気配置換38条件は別枠の参考で、元の注文行・方向・数量を保ち、買ask・売bidへ価格だけを置き換えています。利確・損切り線や連敗休止などを価格変更後に再計算していないため、v70以後の次観測気配運転と同じ条件ではありません。

既知28場での後付け順位を再確認したもので、未見データでの採用順位ではありません。原本・過去成果の変更、新規再生、API取得、実注文はいずれも行っていません。
