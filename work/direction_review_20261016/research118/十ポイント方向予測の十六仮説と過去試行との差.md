# TOPIX判断後10ptの方向予測：16仮説の設計助言

2026-10-16。**第一候補は「複数尺度で一方向が続く」状態を土台に、出来高または供給応答という別の情報を確認する方法。MA多数決を独立した証拠の束とは扱わない。** 以下は実測前の仮説案で、成功確率・損益は未測定。実データ本文・金融・APIの読取、新たな測定・実装変更は0。

## 評価を先に揃える

- TOPIXは判断後の**順方向10pt**と、反対方向**2.5／5／10pt**の先着を同じ候補で採点する。逆行幅3本は別の問いであり、最良幅を事後に選んで共通成功としない。
- 公開mid起点と、事前に定義した直後の正常新規ask/bidから返済側気配・全量往復料で評価する起点を分離する。後者も実返済約定率ではない。次行で不利になった事象だけ未来を見て取消さない。
- 未到達・価格資格切断・場末・保存末尾・仮新規気配なしを別分母にする。全候補順先率、解決内率、解決率を並記。00117の大量cutはmask4＝両気配不正の合流分類で、細内訳や無作為打切を未証明のまま補完しない。
- 同じ条件が真の間は最初の一回だけ公開し、再公開には事前定義した条件解除を要する。同familyの主群は最大逆行10ptと順行10pt・両起点の終端まで共通非重複にする。頭・底から10pt取る評価ではなく、**その判断時点から**残り10ptあるかを問う。
- 同じ候補・同じ期間の常時買い／常時売りを対照にする。買売・昼夜・前後・各場・場単位の不確実性も併記し、一日の下落だけで売りが当たる効果を分ける。日経も参考評価する場合、TOPIX10ptを日経10円へ置換せず、別の固定幅契約が必要。
- 10ptは価格変化の物差しであり、全33場平均収支10万円の達成判定ではない。TOPIXmini10枚の新規→返済価格差がちょうど10ptでも粗利10万円、往復注文料836円控除で99,164円となる。mid起点からの10ptなら、さらに新規・返済の気配差を区別する。
- ゼロドリフト・連続経路・無期限・対称拡散という強い仮定の理論先着率は、順行10に対する逆行2.5／5／10で20／33.3／50%。**80%を一律の必要精度にする理由はない**が、これは実データの基準率・採算性・金融目標達成の証明ではない。

## 一つの価格列から多数MAを作る際の共通定義

当場の**確定1分足終値**を`C_t`、`MA_n(t)=ΣC/n`とする。検討用の期間案は`n={2,5,10,20,40}`の一組だけ。これは合理的な時間尺度の間引き案で、参加者がこの分足期間を使うことや最適性を示すものではない。完全な40本と差分用の前値が揃うまで未準備。空足を前値で埋めるかも別に固定する。EMA/SMA全種類×全期間ペアを総当たりしない。

同じMA群から`G_ij=MA_i−MA_j`、各傾き`S_n=MA_n(t)−MA_n(t−1)`、扇幅`W=max(MA)−min(MA)`を計算する。**MAは現在保有者の平均建値ではない。** MACD、MA傾き、価格モメンタムは同じ価格履歴の変換で、独立票として信頼度を掛け算できない。日足25/75が一般的でも、分足25/75の利用者・自己実現効果は別途未証明。[公式MA](https://info.monex.co.jp/technical-analysis/indicators/001.html)、[公式MACD](https://info.monex.co.jp/technical-analysis/indicators/002.html)

## 残す16family

表は各familyの**一つの主定義を固定するための設計材料**。窓・本数・閾値・公開条件・解除条件は本測定前にROOTが確定する。以下の定義を既に登録済みの条件や有効な手法とは呼ばない。同群内は強く関連し、16本の独立証拠でもない。

| ID・群 | 行動の仮説 | 当時値だけで作る機械的な根拠 | 反証・対照 |
|---|---|---|---|
| M1 多尺度MA整列 | 短い追随と長い方向が揃うと、注文の追随が持続する | MAの全短長順序と傾きの同方向性。長い尺度を途中で逆向きにしない | 長短が不一致の同程度の直近値動き。整列そのものが動いた後を表すだけなら10pt追加は弱い |
| M2 収束から拡散 | 様子見後、一方向への注文移動が始まる | 過去にWが縮小した後、Wと短長差が同方向へ拡大し始めた**現在**を公開 | 収束だけ・方向未確定、拡大だけ。収束を反転サインと決めない |
| M3 順方向の押し戻りと再取得 | 利確で戻っても、新しい支持で中央の継続に乗れる | 長いMAの向き維持→短い価格/MAの逆行→当時の再上抜け/再下抜け、を状態機械化 | 最初の整列だけ、戻り中、再取得後の再破れ。未来の局所底は使わない |
| M4 長い方向の転換確定 | 古い方向の支持が崩れ、逆側へ注文が移る | 旧MA順序が崩れ、長いMA傾きも逆向きへ変わった初回。M3の長期維持とは区別 | 単一GC/DCだけ、長期方向が維持された小反転 |
| P1 経路の直進効率 | 往復の少ない進行は残り方向が持続する | `ER_n=abs(C_t−C_(t−n))/Σabs(ΔC)`と符号を短中長で計算。分母0は未定義 | 同じ純変化でも往復が多い区間。ERは勢いの因果でなく経路の要約 |
| P2 新しい同方向更新の持続 | 一回の急変でなく、別更新の連続が方向を支持する | 非零の両BBO進行符号／連続長／同方向更新比を複数の過去窓で測る。反復Lastは新票0 | 同じ累計進行だが一回の飛びだけ。旧票を保有中に新支持として再利用しない |
| P3 逆行の浅さ・回復の非対称 | 反対の動きが短く、順側が早く回復する | 過去窓内の各逆方向区間の深さ・回復距離を、当時確定した区切りで比較 | 直近の純変化が同じでも戻りが深い区間。後から最大波を選ばない |
| V1 参加量の増勢を伴う進行 | 新しい参加が同方向の進行に加わる | 公表既知正差の短窓/長窓活動比と、同時点までの価格方向を別列で要求 | 価格だけ、活動だけ。出来高は買い量でも売り量でもなく双方の成立量 |
| V2 活動当たり価格応答の変化 | 活動増なのに進まない供給と、進み始めた局面を分ける | 同じ事前固定活動単位ごとの`方向付きΔmid/公表ΔV`を過去連続区間で比較。活動0・未知を除算しない | 活動一定の価格効率だけ、反対数量も維持された進行失敗。全ΔVをLastの価格へ配賦しない |
| V3 取引参照価格の再取得 | 直近で成立した価格帯を越え、従来の反対側撤退が続く | 整合した代金/出来高が使えるなら当場/直近VWAPを使用。なければ確定足典型価格×出来高の**proxy**として明記 | 同じ位置のMA再取得、価格だけ。VWAPは現存保有者の平均建値・在庫分布ではない |
| S1 最良両側OFIの持続 | 約定以外の取消・追加も含む表示需給移動が継続する | 最良価格移動を考慮したbid/ask数量差分のOFIを当時まで累計し、過去深さで正規化 | 単なる静的数量偏り、価格更新票。snapshot OFIであり全messageの真の注文内訳ではない |
| S2 固定価格供給の維持・枯れ | 反対価格の供給が活動を受けても残る場合と減る場合を分ける | 価格pを固定してQ0/最小Q/回復/正差活動を状態化し、当時の両BBO再進行で方向を確定 | 00114の初回活動だけ・Q0到達だけ。量維持から反転を自動推論しない |
| S3 価格距離別の供給移動 | 最良だけでなく近い価格域の表示供給が片側へ偏る | 固定anchorの`Σ_p exp(−距離/k)ΔQ(p)`を近/遠二帯で測る。前後の共通知識範囲だけ比較 | 静的十段和、段番号差分、毎row重みを動かした見かけの増減。十段外を0にしない |
| S4 支持価格の段階移動 | 一時反発でなく、支持の場所が順方向へ移る | 当時確定した両BBO/既知水準の突破→戻り中の固定価格数量→再進行。支持線を事後に後退させない | 価格だけの押し戻りM3/P3と、表示数量を追加した条件の対照。足形だけで損切り発動を認定しない |
| X1 二市場の中短期同調 | 一銘柄固有でなく共通要因による方向が継続する | 各市場を自分の当時値幅で正規化した多尺度リターン/MA方向の一致。円額・枚数を足さない | 単一市場、相手が逆/不明。同時計の相手未来行をas-ofへ混ぜない |
| X2 二市場の先行と追随開始 | 先に動いた市場の後、他方に実際の追随が始まる | 過去だけで固定した相手の変化→自己の両BBO同方向進行、未追随残差の縮小を公開。役割を日後付け選択しない | 既に両方動き終えた同調、相手が古いだけの見かけのlag。時計差を真の物理先行と断定しない |

まずM1／M2／P1／V2／S1／X1を主となる六仮説にし、残りは異なる反例を拾う対照として整理すると解釈しやすい。これは**論理上の測定優先順**で、利益順位ではない。合成するなら「価格履歴1群＋活動/数量/他市場の1群」までを事前固定し、同じMA群の三重ANDで高確度と称さない。単体より件数だけ消えたのか、同じ時刻・同じ向きの比較で残り10ptの条件付き分布が変わったのかを分ける。
