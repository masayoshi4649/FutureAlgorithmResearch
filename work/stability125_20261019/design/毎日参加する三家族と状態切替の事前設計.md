# 毎日参加する三家族と状態切替の事前設計

2026-10-19、日本時間。親調査の依頼に基づく設計資料。新しい金融結果・原板・現在APIは読まず、正式試行台帳も変更していない。0.5%の分母と「1日」の区分は確認中であり、本資料では勝手に決めない。

## 設計の中心

**両建てを貯める方法ではなく、純建玉の方向と量を、その時点の進行・戻り・破綻によって変える。** 上下どちらでも同じ数式を使う。含み損も全玉の清算時価へ含め、場内で終える。

最低1日1回の実参加は新しい制約であり、収益源ではない。機会がない日に1枚だけ出してすぐ戻す方式は採らない。通常の半容量を、通常のリスクと退出規則のまま期限までに入れる案を対照にする。この参加を「期限参加」として、条件を満たした「根拠参加」と分けて測る。

方向の優位がない場に参加を義務づけると費用負けが生じ得る。その負けを利確玉だけの成績、未決済含み損、極小枚数で隠さない。毎日参加と毎日利益は別の条件である。

## 事前固定する共通規則

- 比較数量は片方向TOPIXミニ10枚・日経マイクロ20枚。最初はその半分、追加しても上限まで。反対玉を同時に持たず、反転は旧玉の実返済確認後に新規する。
- 新規と返済双方に手数料を課金し、最初の次正常原行で買ask・売bidの価格模型を使う。指値を使う別条件では、通過だけを全量約定としない。価格時計と本当の受信時計の違いは残る。
- 保有時間による強制利確は置かない。事前の仮説撤回、利益追尾、場末返済のいずれかで終える。日中15:45・夜間06:00で持越しを終える。実引けがない場合の価格代理は正式に固定して別記する。
- 期限参加は、評価単位Uの最初の場の開始30分後までに根拠参加がなかった場合、最初の正常気配で通常半容量を建てる。Uが日中・夜間のどちらを含むかはユーザー回答後に確定する。
- 期限参加の方向は、まず現在値と場始値の符号、同値なら最後の確定1分足の符号、完全同値なら事前固定の買いとする。これは方向優位の発見ではなく、必須参加を明示した対照。買売入替の感度を別条件として測る。
- 期限まで正常BBOを取得できなければ参加未達・入力不明とする。欠測を埋めて実参加を捏造しない。反対売買を同時に入れて活動実績だけを作らない。
- 損失後は無制限に同じ入口へ戻らない。一つの仮説につき新しい根拠がなければ再参加せず、当日の事前損失予算を使い切ったら以後終了。ただし損失予算は約定価格の飛び越しを保証する損失上限ではない。

## 状態は当時の情報だけで切り替える

下記は純粋な事前案。閾値は文献で最適とされた数値ではなく、実装と比較を具体化するための固定案である。意味のない細かい売買を避けるため、波の最初と最後を全て取ることは求めない。

1. 各商品の当場内・確定済み1分LastをPとし、最新15本の値動きから `ER = |P_t−P_(t−15)| / Σ|ΔP|` を作る。分母0ならER=0。原行数や同値更新回数を分母へ入れない。15本未満は状態未知とする。
2. 値幅尺度は `w = max(観測呼値×8, 確定済み過去15分の|1分変化|の75%点×3)`。ATRは使わない。同じ段階の反復に使うwは、その段階を準備した時点で固定する。途中で拡大して損切りを先送りしない。
3. 進行方向は `d = sign(P_t−P_(t−15))`。NK225とTOPIXのdが一致し、双方ER≥0.40、双方の進行幅が各w以上なら「追従候補」へ移る。弱い相手不一致だけで即反転しない。
4. 双方ER≤0.20、双方が直前15分の高安帯の内側なら「往復候補」。ERがその間、相手が欠測、同時点が不明なら「中間・未知」。これを往復と決めつけない。
5. 追従から往復へはER≤0.20が確定足2本続いたときだけ移る。往復から追従へはER≥0.40、双方同方向、新たな高安帯突破が確定足2本続いたときだけ移る。0.20/0.40の幅を設け、一つの足ごとの切替連発を防ぐ。
6. 板を使う追加条件では、同じ価格を保った最良数量の増減と最良価格の移動を区別したOFI代理を使う。反対供給の変化と価格応答を確認する。数量低下を全て約定、数量増加を全て補充としない。単一の厚い板を強気・弱気の確率へ変換しない。

相手情報は当時までに公表されたものだけを使う。保存されていない二市場共通受信順を作らず、足公開契約に沿って利用可能な確定足だけを参照する。使える時計が不足する場合は相手票を未知として、単独版と区別する。相手の足を未来から補完しない。

## 家族A：進行を確認し、押し戻りを抜けて参加

**収益源の仮説：** 両市場に共通する持続注文がある場合、最初の上昇・下落を見送っても、短い押し戻りの後に残る進行を取れる。

- **入口：** 追従候補のdに対し、その時点の極値Xを記録する。0.25w以上の押し戻りを一度確認し、そこから0.25w再進行したら半容量を建てる。準備極値から逆に1w破れば準備を撤回する。
- **損失を認める：** 準備時点の押し戻り安値（売りは高値）を1呼値破ったら全返済を判断。約定後に損切り線を遠ざけない。再進行せず下抜けた場合は仮説失敗とする。
- **利益を伸ばす：** 約定から1w順行し、現在も双方追従なら残り半容量を一度だけ追加する。全玉の返済側BBOを使い、最高清算益から0.75w相当を戻したら返済。追加時点で既存の撤回線へ全玉を清算した予定損失が予算を超えるなら追加しない。
- **相手が弱まったとき：** 単なる不一致では追加だけ止める。自市場の準備水準破れ、又は双方が強い反対方向へ追従状態になったら全返済。反対条件が別に成立していれば、旧玉の返済確認後に反転する。
- **毎日参加：** 信号が来なければ共通の期限参加を使い、入口の押し戻りを確認していないことを別理由で記録する。期限参加は1wの初期撤回線と同じ追尾を持つ。根拠参加と同じ成功率へ混ぜない。

**負ける場：** 往復の一時的な整列を継続と誤認する場、再進行が最後の買い・売りだった場。追加は平均建値を悪化させるため、1w順行だけを成功扱いにしない。

## 家族B：帯の内側へ戻る部分を取り、帯の外へ定着したら認めて持ち替える

**収益源の仮説：** 注文が一時的に偏っただけなら元の価格帯へ戻り、情報で評価が変わったなら帯の外へ定着する。この二つの応答を当時の値動きで区別する。

- **入口：** 往復候補の時点で、直前15分の高値H・安値L・中心C=(H+L)/2を固定する。幅H−L≥2wが必要。下側L+0.25w以内で下落が止まり0.25w戻ったら半容量買い、上側は鏡像の売り。
- **損失を認める：** 買いならL−0.25w、売りならH+0.25wで全返済。負け方向へ追加しない。両側の不利な玉を残して中心復帰を待たない。
- **利益を取る：** 中心Cへ届けば半分を返済。残りは返済側BBOの最高益から0.5w戻りで返す。部分返済の整数丸めと一注文ごとの料金を固定する。利益が小さすぎて気配差と料を越えない場合は信号見送りと記録する。
- **追従へ切替：** 帯の外側へ0.5w以上抜け、両市場がその方向へ追従条件を満たしたら、旧回帰玉の返済を確認して突破方向に半容量を新規する。新しい撤回線は突破時の固定帯の縁。単に最初の損切りを食らっただけではドテンしない。
- **毎日参加：** 期限時点で往復候補なら中心より下は買い、上は売り。中間・未知なら共通期限方向を使う。期限参加も同じ通常半容量で行い、帯が未形成なら1wの初期撤回線と0.75w追尾を使う別理由を記録する。

**負ける場：** 情報による新しい価格への移動を一時的な偏りだと思い込む場。切替判定が遅れれば回帰で負け、早過ぎれば往復中に順張りで再び負ける。帯・中心・押し戻りを後から描き直して正解へ合わせない。

## 家族C：目標の純建玉を段階的に変え、反対注文を先に減玉へ使う

**収益源の仮説：** 最初から大きく当てるのでなく、進行と往復の根拠が変わるたびに純建玉の量を変える。反対方向を新たな在庫へ貯めず、まず古い方向の損益とリスクを減らす。

- **初回：** 正常な方向判断があれば半容量で参加し、なければ共通の期限参加。実際に建てた時点から通常の撤回・追尾を適用する。
- **追従状態の目標：** d方向へ上限M。順行0.5wごとにM/4ずつ増やし、追加ごとに全玉の予定撤回損失を同じ予算内へ収める。一気に上限まで増やさない。
- **往復状態の目標：** 固定中心Cに対し、`q* = clip(round(−M×(P−C)/(H−L)), −M/2, M/2)`。安い側では買い、高い側では売りを目標にする。現在のqからq*へ移る時は一度にM/4まで。反対側の玉があれば新規ではなく先に減玉する。
- **中間状態の目標：** 新規追加しない。弱い不一致で全返済を繰り返さず、既存の構造撤回線・最高清算益からの追尾を維持する。中間に入る前の方向と価格根拠を保存する。
- **損失を認める：** 撤回価格へ達した時に残玉を全返済し、反対目標があっても同時両建てで損失を覆い隠さない。反対方向の新規は旧方向の清算確認後。
- **過剰な回転を防ぐ：** 目標変更は少なくともM/4、かつ直前調整価格から0.5w以上動いた時だけ。気配差が広くなれば数量調整の便益より費用が高くなるため追加を止める。既存玉の損切りを止める理由にはしない。

**負ける場：** 相場が少し進むごとに増やした直後に戻り、少し戻るごとに減らした直後に再び進む場。滑らかに数量を動かすこと自体は優位を作らず、摩擦と平均建値の悪化を抑えられるかを問う。

## 板を足す場合の最小限の数式

最良買価格b・数量Qb、最良売価格a・数量Qaについて、隣接する採用原行の変化を次で定義する。

`e_n = 1[b_n≥b_(n−1)]Qb_n − 1[b_n≤b_(n−1)]Qb_(n−1) − 1[a_n≤a_(n−1)]Qa_n + 1[a_n≥a_(n−1)]Qa_(n−1)`

前60秒の `F = Σe / Σ(Qb+Qa)` を有効時刻・有限正数量で計算する。両先物でFが入口方向へ0.1以上なら板確認付きとして別条件にする。簿冊スナップショットは全注文イベントそのものではなく、取消・約定の区別もできないので「真の攻撃フロー」と呼ばない。時刻不足・数量欠測は未知でありゼロ圧力へ置換しない。

Contらは最良価格の注文フローと短期価格変化の関係を検証しているが、同時の価格説明から本研究の将来10pt予測や手数料後利益は導けない。[原論文：The Price Impact of Order Book Events](https://arxiv.org/abs/1011.6402)。

## 一次資料が支える範囲

- 流動性提供・短期回帰には理論的な収益源がある一方、情報を持つ相手への取引で負ける危険がある。[Drechsler・Moreira・Savov：Liquidity and Volatility](https://www.nber.org/papers/w27959)。Bはこの交換を検証する仮説であり、日経/TOPIXでの保証ではない。
- 回帰の強さ・速さはボラティリティと売買回転で異なり得る。[Dai・Medhat・Novy-Marx・Rizova：Reversals and the Returns to Liquidity Provision](https://www.nber.org/papers/w30917)。株式横断の結果を指数先物の秒・分単位へ直接移さない。
- 売買費用があるとき目標へ部分的に近付く理論がある。[Garleanu・Pedersen：Dynamic Trading with Predictable Returns and Transaction Costs](https://www.nber.org/papers/w15205)。Cの根拠は費用を抑える制御であり、予測信号が存在することを理論から自動的に得るものではない。
- 先物注文は価格・時間の優先で成立し、指値へ価格が到達しただけで自己注文の全量約定とはならない。[JPX：売買の方法](https://www.jpx.co.jp/english/derivatives/rules/trading-methods/index.html)。
- 追尾線や逆指値線は実約定価格の保証ではない。[SEC：Stop, Stop-Limit, and Trailing Stop Orders](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-15)。これは株式の教育資料であり、OSEでの注文機能・執行は本プロジェクトの注文仕様を別に採用する。

## 最初に測るべきもの

三家族を大量パラメータで順位付けする前に、次を同じ起点で分ける。

1. 根拠参加と期限参加のそれぞれで、判断後に費用を越える順行幅が残ったか、逆行撤回より先に到達したか。
2. 初回のみと追加ありで、同じ入口の清算益・最大逆行・最悪場がどう変わるか。
3. 往復固定・追従固定・当時状態切替を別対照とし、切替の遅れ、切替直後の往復損を具体時刻で残す。
4. 見送った利益、避けた損失、新規に作った損失、共通入口の出口変更を分解する。反対側を持たなかった改善と、方向判断が改善した効果を分ける。
5. 両商品を別判定し、全日・前半後半・買売・日中夜間・上位3黒字除外を示す。0.5%はユーザー確認後の固定分母で費用後netから計算し、現物指数の騰落率や利益割合と混同しない。

**この記録時点では三家族とも新規仕様の成績は未測定。** 最初の優先はAで、次はB、Cは同一方向へ玉を貯める制御の対照とする。理由は既知の両建てロックと無制限逆行追加を避け、失敗の価格を入口時点で明確にできるためであり、目標達成の証明ではない。
