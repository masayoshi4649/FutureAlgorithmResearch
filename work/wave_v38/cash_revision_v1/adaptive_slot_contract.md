# 枠・分岐・注文伝達の独立監査

`adaptive_slot_audit.audit` は売買エンジンを呼ばず、入力・注文・返済・枠イベントから別式で照合する。損益の優劣を判定するものではない。

```python
audit(ready, result, config, policy, bad, bad_source,
      good, good_source, good_valid, curves, *, state,
      budget_enabled=True, min_delay_seconds=0., observed_fill=False,
      branch_direction=None, branch_source=None, branch_valid=None,
      branch_mode="fixed", branch_choice=None, branch_seed=None)
```

- `curves` は注文・返済から別に再構成した `cash / long / short / realized / equity`。価格ポイント単位で渡す。
- 各 `source` は `ready` 配列の行番号。原本 `seq` とは異なる。公開根拠と約定根拠を混同しない。
- 入力は時刻順で有限正価格の有効観測列。欠落観測は時刻の間隔として扱う。価格NaNを含むエンジン人工検査は別資料であり、この口座監査の入力契約外。
- 共通D273専用。初回5/10枚、固定A0、初期R・始動・部分利確・追跡・360分・5分休止・注文寿命の独立式を使う。他の管理設定へ汎用化したと主張しない。

`adaptive_shadow_oracle.py` が、まず影注文と返済から全行現金・純数量・実現損益を作る。続いて価格・ATR・方向・過去約定から公開計画37列と新規準備7列を独立に生成する。生成に保存済み計画を使わず、保存計画は比較対象に限る。当行の約定から当行後の状態を作る一方、その約定自体は前行以前の計画から別途判定するため、当行約定を無条件に正しいと仮定しない。

成熟元は `source_row < row` かつ `time[source_row] <= time[row] - δ` を満たす最新行を二分探索する。組ID・方向を現在の約定認知状態と照合し、既に終えた部分利確を無効にする。全行の成立注文と不成立行を判定し、取消待ちの旧新規、絶対期限、成熟線の維持、価格／市場注文の優先順を確認する。元注文は実側へ二重の遅延を掛けない。

実側では全枠の生存・保有・復元資格、調整予約の存在／不在・保持・取消、元の部分利確との競合、追加R退出の持続、元終了以前の全返済を確認する。減量約定時の生入力から分岐を再計算し、固定モードでは分岐イベントがないことも照合する。時計復元は期限後に公開された新しい有効根拠を必要とし、肯定方向は要求しない。R無効でも元A0の返済は残る。

返り値の合格キーは `全枠会計一致 / 全予約と新根拠一致 / 元終了以前 / 同約定両建て全行一致 / 全予算予約一致 / 全分岐独立一致 / 全伝達遅延一致`。`影の独立公開と執行` の中に `影全会計一致 / 独立公開計画一致 / 独立準備一致 / 最新成熟計画一致 / 全行注文成立不成立一致` と件数を返す。円換算・期間集計・全出力列の指紋・因果性検査は別担当の会計／入力監査と結合する。

## 人工検査と保証範囲

主206条件×2銘柄×活動／無取引の824件、補助768件、記録破損13件拒否が通過した。さらに固定64乱数経路×2銘柄×4方式×上下反射の1,024再生で、複数組・取消・同時刻・観測欠落・価格飛びを含む同じ独立監査が通過した。実相場の新条件損益は計算していない。人工経路の成績や良いseedを選択に使わない。

約定の即時認知と組単位の原子的処理はモデルの前提である。新規約定後の初期返済線が成熟するまで空白が生じる場合があり、Rは金額損失を保証しない。正の遅延で追加R退出が有効なA0実玉は、価格回復後も予約を保持するため影と返済が異なる場合がある。影との恒等性を一般に要求するのは追加R退出無効または遅延0に限る。

実装固定は `adaptive_slot_fixed.json`、人工証跡は `adaptive_slot_selftest.json` と `adaptive_slot_random_selftest.json`。旧コード・原本・現在保存物は変更も使用もしていない。
