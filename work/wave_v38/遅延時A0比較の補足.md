# 遅延を加えたA0と追加R退出

条件設計の固定後、実相場の新損益を読む前の人工検査で確認した意味の補足です。974条件・入力・売買実装・主仮説は変更しません。

注文伝達に遅延があると、固定元A0の価格ストップが成熟する前に、実口座の損失がRへ達する場合があります。価格が回復しても、追加の実R返済予約は取り消されません。このため**数量調整なしのA0_R1でも、正の遅延では追加Rの記憶作用により影A0と異なる返済になり得ます**。

例：15秒遅延で、0秒に価格100で準備、15秒に101で新規、16秒に97へ下がってR到達、17秒に101へ回復、40秒に次の観測。実R1は16秒の返済予約を40秒に執行します。元影は成熟前のストップを過去へ遡らせず、後の価格条件または場末まで保有します。

全配列の影同値を要求するのは、追加RがないA0_R0、または既定の遅延0のA0_R1です。正の遅延を加えた数量調整の比較では、同じ遅延・追加R有効のA0_R1を対応対照とし、元影と同一とは呼びません。元組の初回新規・初期R・枠・期限を共有する条件は維持します。

R無効と正遅延の人工対を含めて機構を独立に検査します。これは不都合な実成績を除外する修正ではなく、成績前に見つかった不適切な同値検査を限定するものです。
