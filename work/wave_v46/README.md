# 次の入口探索の準備資料

この作業は未固定・未採否です。新しい売買再生や実損益の検証は行っておらず、00040の153条件へ含めません。

読む順序は [独立批判](価格距離時計の独立批判.md) → [未固定仕様](価格時計モジュールの未固定仕様.md) → [価格時計の試作](price_clock.py) → [人工検査](check_price_clock.json) です。最初の設計案は [前作業の草案](../wave_v45/次入口の設計案.md) にあり、その数値は確定条件ではありません。

価格の移動距離を直前までに公開済みのATRで割り、距離が進むほど平均線を更新する仮説です。同じ原本価格を使う通常の時間平均とも比較します。実データの全日平均速度を取引開始前へ遡って使う校正は行いません。

次に確定する事項は、平均と勾配の時計、暖機、距離幅、通常平均の比較速度、相手市場の確認、短期価格確認、注文器との接続、反証条件と採否です。L1／4は通常のEMA15／60相当より典型的に速いため、単なる高速化を時計の効果と混同しない比較が必要です。

[小数距離の境界反例](小数距離の境界反例.json) と [修正前の試作](price_clock_float_before_boundary.py.txt) を保存しています。現在の試作は呼値整合を確認し、整数呼値の差と初期価格からの偏差を使います。人工検査の通過は、実相場での利益や、入力と注文を接続した全体の検証通過を意味しません。
