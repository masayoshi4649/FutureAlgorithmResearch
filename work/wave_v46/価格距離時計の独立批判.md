# 価格距離時計の独立批判

新しい売買・損益・原本を読まず、[暫定設計](../wave_v45/次入口の設計案.md)と[既存の入力距離診断](../wave_v44/価格時計の入力診断.json)だけを確認した。まだ幅や採否を決める資料ではない。

`|Δp| / 直前公開ATR` でEMAの記憶を進めることは、「経過秒より、標準化した価格の移動量が情報の入替え速度をよく表す」という仮説である。上向きと下向きで距離は同じため、それ自体に次の方向を当てる性質はない。さらに持続的な順行と往復を区別しない。往復ノイズの増加時に反応を弱める効率比型の適応平均とは、作用が逆になり得る。

## L1／4は中期方向の置換とはまだ呼べない

既存診断の開始30〜330分、30分区間143個／銘柄に限定すると、ATR距離／分の中央値はTOPIX 0.537、NK225 0.455だった。一定速度と仮定した `L / 速度` は、L1で約1.86分／2.20分、L4で約7.45分／8.78分である。旧15／60 EMA相当の時定数は約7.5分／30分なので、平均的な速さも約3〜4倍違う。全夜間を含む集計と件数が異なるのは範囲の違いである。

これは記述上の概算で、実際のEMA参照年齢ではない。30分平均は同秒・短時間の往復集中を隠す。L1／4を数秒相当まで進める区間がどれほどあるか、今の集計だけでは分からない。逆に「全区間で超短期化して無意味」とも断定できない。同値価格行の多さは安心材料にならず、変化した少数行だけで距離が蓄積する。

例えばATRが10呼値で固定なら、1呼値の上げ下げ一往復で0.2ATR進む。純変位ゼロでも5往復で短平均の初期記憶は `exp(-1)`、20往復で長平均も同程度になる。最良気配間の跳ね返り等を含む価格往復は、方向情報なしで時計を進め得る。これは数量の更新自体を使うという意味でも、各変化を約定起因と識別できるという意味でもない。

結果前の入力診断では、過去から距離Lに達するまでの**実際の秒数**、同秒距離の割合、同じ区間の総移動距離と純変位、方向反転・発火・保持時間、暖機不足時間を示すとよい。全日速度で日中のLを校正したり、後続情報で暖機を補完したりしない。

## 最小の分離比較

中央 `(1,4)` に対し、同原本・同品質・同じ初期化を用いる物理EMAの速度を旧相当の **0.25／0.5／1倍の時定数**で固定する案が小さい。短長時定数は約1.9／7.5分、3.7／15分、7.5／30分になる。後から最良速度を選んで距離方式へ勝たせず、全て並べる。候補幅の確定は別途行う。

時計そのものの比較では、中央距離EMAもこの物理3速度も**180秒勾配**に揃え、同じ距離暖機・品質・相手公開・短期確認マスクを使う。距離勾配 `0.4L` は距離EMAの対応対照として分離する。両平均の時計と勾配窓を同時に変えた成績を平均時計だけの効果とは呼ばない。共通の距離暖機をかけた物理対照は因果的な機構比較用であり、独立の実用物理戦略ではない。中央物理の自前暖機を別に残せば、参加抑制だけの効果も見える。

## 退けられる反例

1. **往復でのみ反応が加速する。** 同じ低周波の単調経路へゼロ純変位の小往復を加えると、主方向や新規準備が大きく増え、物理の速い対照よりも不安定になる。距離が増えたことと情報が増えたことを同一視しない。
2. **高速化又は参加制限で説明できる。** 同原本の速い物理EMAや、同じ暖機・勾配・参加マスクの対照が同程度の改善を示すなら、距離時計の固有価値は未確認。暖機切替や勾配変更による差を時計の成功へ足さない。
3. **跳躍・停滞で方向を失う。** 大きな単発跳躍では短長平均が同時に現在値へ寄り、差が消え得る。静止が長ければ距離平均は古い記憶を保持する。原本欠測・群境界・同秒分割にも感応し得るため、単調階段と一跳躍、無価格変更行の挿入、公開ATR変化、観測穴の人工経路で意味を確認する。

これらは将来利益の絶対保証を要求するものではない。時計を変える仮説を、単なる速さ・暖機・勾配・観測頻度の差から区別するための限定反証である。既知13期間を再利用しても未見検証にはならない。
