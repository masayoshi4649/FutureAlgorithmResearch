# 一週間再検証の独立監査計画

## 見る前に決める評価区分

1. 前回固定の NK225 `N03_R-1_L3_U1` と TOPIX `N15_R-1_A4_U0` は入口・出口・枚数・時間帯を変更しない。
2. 9/24 ナイトの 9/25 03:01 未満は 00010 までの既読部分。今回の追加部分は、境界直前の全建玉評価を差し引いて評価する。既存建玉の本来の新規位置はチャート上に残し、差分会計の擬似建値を売買マーカーには使用しない。
3. 最後の 9/25 ナイトは候補と選択方針を固定するまで未読で保留する。今回の学習側に追加する 9/25 デイを、最後の未読答え合わせと混同しない。
4. 以前閲覧した区間で時間順に選び直す診断は、計算が過去だけであっても研究全体の完全未読試験とは呼ばない。
5. 最終夜の結果を受けて勝った方式へ主候補を差し替えない。全週の集計は参考として別記する。

## 独立集計

- 最小単位は１つの開始判断から全玉を返済するまでのサイクル。２枚のうち利益側だけを独立の勝ちと数えない。格子は継続再配置が終わるまでを１サイクルとする。
- 約定価格、方向、枚数、銘柄倍率から各脚の円収支を直接再計算し、サイクル・セッションの確定利益、確定損失、純損益へ集約する。
- 同銘柄ごとに平均勝額、平均負額、勝負比、PF、勝率、最悪サイクル、最悪セッション、黒字セッション数、最大連敗を直接再計算する。
- 最大利益セッションを１つ除いた収支、さらに２つ除いた収支を感度診断にする。後者は今回の選択ルールへ事後追加しない。
- PF と平均勝負比は関連指標であり、２つの独立した証拠とは説明しない。損失未観測の PF を無限大の順位へ変えない。
- 全原本行での現金＋建玉時価から最大下落を再計算する。確定損益だけの最大下落と区別する。
- 最終夜の取引なしも明示し、勝敗評価の対象外や分母落ちへ隠さない。

## 不変性と選択の確認

- 原本と過去成果を変更していないこと、条件カタログと候補の固定記録を確認する。
- 前回固定２候補の既読期間の確定取引が変化していないか照合する。原本の過去部分が修正されている場合は、戦略変更と混同せず変更理由と差額を示す。
- すべての次セッション候補が、その前までのセッションだけで決定されたか確認する。
- 全返済時刻と新規停止時刻を確認する。デイ・ナイトのセッションを跨ぐ玉は認めない。
- 複数銘柄の円利益を１枚同士として横断順位付けしない。NT は２脚合算と端数の方向寄与を別に読む。

## 報告の順序

1. 前回固定２候補の継続検証：従来既読、今回追加、最終保留、週全体を別表で示す。
2. 試した思想ごとの結果：過去９区間での再選択と最終１区間の答え合わせ。
3. 各方式の機械的な入口・出口、保有時間、枚数、リスク管理。
4. ５分足の全取引マーカーと全建玉評価曲線。暗色背景で売買・目盛・凡例を読めるようにする。
5. セッションごとの利益・損失・収支と最大下落。
6. 過去だけで毎回選び直す時間順比較、最高区間を除く感度、監査と限界。
