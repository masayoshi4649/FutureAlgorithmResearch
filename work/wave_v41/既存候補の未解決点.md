# 既存候補の達成範囲と、残る反証

**既知データで利益を出す機械戦略は残っている。00032・00033の不採用を、H019／D273全体の無価値という結論へ広げてはいけない。** 00032は追加した回復判断とA0代替目標、00033は復元方式を選ぶ追加分岐の価値が不足した。別に、00033の注文状態記録には未修正の契約違反がある。

本メモはv37・v38の固定条件、保存集計、独立判定・監査の読取りだけで作成した。新しい損益再生、現在データの読取り、API取得、凍結コード変更は行っていない。

## 不合格・未確認を混同しないための6項目

1. **追加情報の価値には、既に明確な反例がある。** v37主案はTOPIXのDDがA0より3,500円増え、回復符号64対照のNK収支中央値にも届かなかった。v38主案は固定信号・同じB01公開を使う固定時計・逆分岐・分岐乱数中央値を一貫して上回らず、後半7の円収支は乱数64本中TOPIX56本／NK35本が主案以上。さらに既選抜`B06_RB01_F25_N1`・`B06_RB01_F50_N1`は、NK後半7で回復符号64本全てが収支以上かつDD以下だった。これらの「回復を読む／方式を選ぶ」説明は支持不足である。一方、`B00_RB00_F25_N1`は減量・回復を別々に符号変更した中央値より、全13／後7×両銘柄で収支が高くDDが小さい。時計復元の`B00_T120_F25_N1/N3`も減量符号対照中央値に同じ関係がある。**全ての追加成分が失敗したわけではない。** これらは公開機会を残した成分対照で、正式な有意確率ではない。

2. **H019共通入口の時計感度は、黒字判定だけでは隠れる。** A0の入口時計80%／120%では、TOPIX後半7の収支が+70,500／+31,000円、DDが279,000／208,000円へ悪化。最大1勝ち元組を除くと−72,500／−112,000円になる。NK80%も除外後−7,500円。v38主案もTOPIX80%／120%で同除外後−44,500／−119,500円。感度の基礎条件は通過していても、入口近傍の集中依存は解消していない。これは追加分岐以前の共通弱点であり、次の退出機構で入口問題も解けたとは説明できない。

3. **約定・遅延の単独検査は済んだが、同時悪化は未実施。** A0・既選抜8方式・v38主案について、観測価格約定、実注文伝達1／5／15秒は別々に再生済み。固定カタログは一軸変更なので「観測価格約定＋15秒遅延」の交互作用は未検査である。A0の正遅延R1比較は追加R退出予約の記憶により元影と完全同値とは限らない点も残す。これはより厳しい仮定の診断であり、ユーザーが認めた指定価格約定前提の黒字を取り消す必須条件ではない。[固定設計](../wave_v38/adaptive_design_fixed.json)、[正遅延A0の説明](../wave_v38/遅延時A0比較の補足.md)。

4. **8候補の選抜工程自体は未知データで検証されていない。** 8方式は同じ既知13セッションの309条件から選ばれている。後半7へ分け直した結果、成分乱数、再監査の多数の行数を、独立した未知実績へ数え直せない。現在の結論は「既知相場の基礎候補が残った」であり、将来優位の統計的確証ではない。追加の既知条件を増やすだけではこの不足は解消しない。ただし未知の全相場で必ず稼ぐ保証を、今回の完了条件へ新設する必要もない。

## 次の最小再生案は一つに限定する

**新しい利益最良条件を探す前に、保存済みの状態修正候補で「A0＋既選抜8方式」の通常条件と、既知の不具合条件を経済同値再検査する。** 対象は9方式×26入力に、不具合IDのL015×26入力を加えた計260入力。入口・枚数・復元条件・約定・既存採否基準は変更せず、元保存台帳／全時価／phase以外の証跡の完全一致と、正しいphaseの全行一致だけを要求する。新しい順位付けや主案差替えは行わない。

これなら、支持されなかった自動分岐を救済せず、既に黒字である候補の具体的な実装障害を一つ閉じられる。通過時の主張は**この限定範囲の実装確認が進んだ**までで、旧974条件全体の完全合格や将来優位へは昇格させない。入口時計の集中依存、未見期間の不足、未実施の複合執行条件は別に残す。

今回の読み替えは「解がない」ではなく、**基準戦略と複数の数量調整候補は既知相場で成立し、追加分岐の採用理由は不足している**、である。微小なDD差を含む全区分同時改善は追加研究目標であって、ユーザーが求めた機械性・活動・損小利大そのものと同一ではない。
