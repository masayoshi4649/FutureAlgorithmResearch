# 終了済み取引による手法配分：独立性と最小比較案

**設計案のみ。新しい売買再生・コード実装・条件凍結・現在データ取得は行っていない。**

結論は、**「過去に勝った手法を使う」だけなら既試行の再命名であり、新しい主仮説としては採らない。** 限定して未検証なのは、完結した売買組を場中に順次公開し、連続重みを「次の新規枚数」へ割り当てる運用である。板追加とは違う検査になるが、過去成績の持続性という仮説から独立した市場原理ではない。

## 実装するなら、配分方式は3本だけ

専門家を増やさず、T＝v32のH019入口、R＝v32の価格P02入口・価格撤回版、返済は両方D273へ固定する。ここでRは「反転入口」の名称であり、レンジ全般に強いことを意味しない。部分利確を含む**初回新規から完全返済までの一組**を学習単位にする。

| 方式 | 重みの規則 | 役割 |
|---|---|---|
| E：等配分 | 常にT/R＝1/2ずつ | 選択情報を使わない配分基準 |
| W：過去勝者 | 下記の累積スコアが高い枝へ全配分。同点は1/2ずつ | 過去首位の再検査用対照。新発見とは扱わない |
| X：指数重み | `w_e = exp(0.25 S_e) / Σ exp(0.25 S)`。数値計算では最大指数を引く | 今回一つだけ残す主案。学習率0.25を結果前固定し最良値を探さない |

実口座から独立したT/R影口座を各銘柄で開始から継続し、影の初回はTOPIX5枚／NK10枚、D273を変更しない。**一組が閉じるたびに、その枝だけを更新する案は採らない。** 速く閉じる利益と長く残る損失の非同期性を、方式の良さと誤認しやすいためである。

比較単位は場初から固定30分の**共通新規区間b**。初回約定時刻が同じ区間に入った全組を、T/R×両銘柄で記録する。区間終了後、その区間に属する全組が完全返済して初めて4セルをまとめて確定する。新規なしのセルは確定0とし、長く保有中のセルを0へ置き換えない。影口座を区間ごとに再初期化しない。後の区間が先に終わっても、古い未確定区間を追い越して更新しない。

尺度は区間開始以前の最新の公開ATRから`R_s,b = 影初回枚数 × ATR × 契約倍率`を固定し、両専門家で共用する。どちらかの市場で尺度が不明なら、その区間は4セルとも学習外として記録する。`z_e,s,b = clip(その区間に新規した全組の最終収支合計/R_s,b, −3, +3)`、`S_e = Σ公開済み区間 (z_e,TOPIX,b + z_e,NK,b)/2`。両銘柄へ同じ重みを使い、円額は合算しない。帳簿・報告の損益は切り詰めない。実配分0の枝も影口座を止めない。

最初のスコアは0、初期配分は等分。過去窓・忘却・損益による停止・場ごとの再初期化は加えない。これは同時刻の機会ごとの比較で、各枝の完結取引数を揃える比較ではない。D273は長く保有し得るので公開待ちが数時間続く可能性があり、場中に素早く適応するとの主張はしない。

## 公開・配分・注文を一つにつなぐ規則

1. **公開済みの完全返済だけで更新する。** 部分利確、未決済の含み損益、将来の組最終損益は更新へ渡さない。共通新規区間が終わり、4セルの全組が原本行で完全返済した時刻の60秒後を公開時刻とする。場初から1分刻みの共通時計で、公開済みかつ先行区間も確定した区間だけを一度ずつ取り込む。更新は次の各市場原本行から使用可能とし、その行で判断した新注文の約定はさらに次行以降。同秒の後続原本行や片市場の未公開結果を先取りしない。各行は前行から有効な約定・取消を先に処理し、新しい重みで遡って消さない。
2. **重みは新規準備時だけ数量へ変換する。** 実口座の総予約・保有予算をTOPIX10枚／NK20枚とし、`q_T=floor(C w_T+0.5)`、`q_R=C−q_T`。同じ新規準備時計なら双方を一括して配分する。既存玉・既存未約定注文に予約済みの枚数を先に控除し、新規は`min(その枝のq, 空き枚数)`まで。0なら見送り。買売合計をC以内にするため、片方向10／20上限も必ず守る。空きができても、見送った過去注文への途中参加はしない。
3. **保有中と未約定中の所有者を変えない。** 枝ごとに同時一組、D273の新規0.25ATR追跡、組予算・2ATR部分利確・1.5ATR始動の3ATR追跡・360分期限を、その実初回枚数で固定する。整数部分利確も既存式を維持する。重みが下がっても強制返済や取消をせず、上がっても保有玉へ増玉しない。新しい数量は次の準備にだけ使う。予約枚数は約定時に保有枠へ移し、取消確認又は返済で解放する。
4. **休止と場末を越えて抜け道を作らない。** 各枝の完全返済後5分休止を重みで解除しない。場末はデイ15:35／ナイト05:50の安全返済判断から次有効行へ全返済を予約し、新規と未約定を終了する。場内で有効返済行がなければ試験失敗とし、末尾価格の架空返済で埋めない。跨ぐのは公開済みスコアだけで、建玉・注文は跨がない。
5. **実損益は一つの全玉帳簿から計算する。** 影成績に現在の重みを掛けた合計を実績として表示しない。逆向きの玉が並ぶ場合も所有ID付きで全玉を記帳し、現金＋ネット在庫×現在値を独立検算する。費用0の相殺玉は利益の発生源ではない。未決済損を学習に使わなくても、実口座DDからは除かない。

固定T・固定Rも同じ総予算10／20、同じ所有・返済・整数規則で比較する。したがって旧v32の5／10枚の円成績をそのまま対照へ流用できない。TOPIXの部分利確端数も変わるため、単純な2倍表示は不可。等配分Eは各枝5／10で、両影口座の合計と経済的一致を検算できる基準になる。

## 最も強い反証と実装の打切り条件

| 反証 | 否定される主張 |
|---|---|
| Xを同じ総枚数のE・固定T・固定Rと比較。Wも同時に残す | Eや固定枝で収支・含み込みDDが同等以上なら、学習配分の追加価値は支持されない。単に保有量が少なくなった差は別記する |
| 同じ公開済み4セル・同じ更新時計でスコアの符号を反転／固定64seedで区間ごとにT/Rの成績ラベルを交換する | 真の過去勝敗より、数量を動かすこと自体が効いている可能性。実約定時刻・将来の勝者割合を乱数へコピーしない |
| 学習率0.20／0.30、公開追加待ち48／72秒を各単独で反証。最良値へ主案を差し替えない | たまたま組の終了境界や丸めを拾った成績ではないか |
| 未来の未完結組最終損益・価格・相手市場結果を削除／改変。同秒切断も実施 | 保存された完成台帳を早く読んだカンニングを拒否。過去の重み・数量・注文が不変であること |
| 含み損が長く残る枝、部分利確だけ先に出る枝、双方連敗、両枝同時準備、満枠、取消と約定競合を人工検査 | 勝ちだけ早く公開される選択偏り、枠の二重予約、休止解除、逆玉の利益偽装を拒否 |

全13区間は既知で、全13と旧比較と同じ後7を併記する。初期6が祝日取引中心だった偏りを理由に、今回だけ都合のよい日を学習外へ動かさない。主の両銘柄黒字、損小利大、最大勝ち組・最大黒字場を個別除外して非赤字、活動数と両枝の実新規を実行前に固定する。活動不足や実数量がずっと固定枝と同じなら、学習が有効だったとは言えない。収支・DD改善の採否数値は親の共通規則へ結び、結果後に新しい例外を設けない。

**新しい問いは「完結後に判明した相対的な勝敗が、その後の新規機会にも続くか」の一つだけ。** 公平な公開待ちにすると情報が古くなり、場中の重みがほぼ変わらない可能性もある。指数重みの理論を、保有中は数量を固定する今回の整数注文口座の利益保証や、最良固定手法に必ず追いつく保証へ転用しない。ここが失敗したら、専門家・窓・配分式の大量追加で同じ13区間を救済せず、当該仮説を未支持として止める。
