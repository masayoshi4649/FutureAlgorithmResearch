# 黒字候補の再評価と状態修正

今回は、既存の黒字候補の価値と、追加した仕組みの価値を分ける。新しい板入口が不合格だったことを、H019の黒字まで否定する根拠にはしない。一方、同じ入口を共有する多数の条件を、独立した多数の成功例とも数えない。

## 実際に行う検査

1. H019・D273・数量調整なしA0と、前回固定した改善8条件、復元方式を選ぶ前主案の未解決点を独立して読み直す。
2. v38の全974条件を、状態管理の修正を一行だけ施した別実装で再生する。取消済みの減量予約の状態が残る不具合を修正し、元の状態監査を緩めずに通す。売買条件は変更しない。
3. 注文・返済・全行の会計・数量・予約・分岐を旧結果と比較する。状態の表示以外の差があれば、元の成績を修正版の成績として扱わない。
4. 黒字10候補の各週・各セッションの利益、損失、収支、勝ち・負け・同値の決済枚数を元の全返済から再集計する。修正完了の証拠と結んで短いHTMLへ整理する。

これは**既知結果に対する実装修正と反証の追跡**である。974個の新手法を発見した検査ではなく、事前に未知の収益を確かめる検査でもない。旧v38の不合格記録は変更しない。

## 次の発見につながる調査

- 原本の板更新を公開端点の間まで読むと、減少と再増加の観測が回復するか。まず、結果で選別せず各銘柄の先頭2例を診断する。可視外の数量をゼロと見なさない。
- 場中に終了した複数手法の取引結果から、次の新規枚数だけを配分する方式は既試行と異なるか。過去首位の再命名と、実際に未検証の数量配分を区別する。

後者は遅延フィードバックを扱う学習研究とも照合した。[Joulaniほか](https://arxiv.org/abs/1306.0686)は結果の遅延がオンライン学習へ与える影響を分析し、[Korotinほか](https://arxiv.org/abs/1902.10433)は遅延した損失を用いる指数重み付けを扱う。固定手法との成績差に関する理論を、整数枚数・保有中は配分固定・注文予約上限を持つ今回の口座の黒字保証へ転用しない。実装する場合は、長く残る負けを未公開のまま早い利益だけで評価する偏りも検査する。

対象は保存済み13セッション・26銘柄セッション。全て既知。費用0、指定価格約定、TOPIXミニ換算とNKマイクロ換算、場内全返済を継続する。現在APIの追加取得、保存ライブによる調整は行わない。
