# 原本全行観測と入口の接続

`design.catalog()` は基本20方式、窓・距離32条件、執行16条件の計68条件を返す。`design.supplementary()` はF01・F02・F03の固定seed各64、計192条件を返す。合計260条件で、売買再生・採否変更はまだ行っていない。

`entry_signals.make(spec, key, inputs, bands, peer, panel=None)` は原本行の方向パルスと候補の根拠を返す。`bands` は旧 `band_cache.pkl[cache_key(spec)][key]`、`panel` は同じキーの `trial_panel.pkl` のリストである。`peer` は相手銘柄に旧価格品質の `peer_prices` を適用した辞書であり、自市場ではない。

旧F00/F05/F18/F19は旧特徴をそのまま使い、パネルを採否に使わない。他条件は `band_id` で同じ帯へ結合し、作成・試行開始/終了・終端・価格特徴が一致することを検査する。原本比率は二試行の終了公開後だけ利用できる。比率の利用可能seqは突破seqより小さくなければならない。

数量比較が可能な方式ではu1/u2の両方を必要とする。最後の比率だけ、平均、逆判定、価格だけの対応対照もこの可用性を共有する。全可視減少0、不明、未完了をゼロへ置換しない。F08/F14の「逆判定」は数量比率の増加を選ぶことで、F09/F15の「売買方向反転」と異なる。

相手情報は旧B12の価格品質・追加60秒・鮮度120秒・過去5分0.25ATRを無変更で使う。乱数は公開候補のseqを含む固定ハッシュ符号を候補方向へ掛けるだけで、候補時刻を変えない。休止や返済によって実約定が変わる可能性は残る。

## 実施した検査

- 人工1,127項目：260配線、不明/減少0、等号、二試行未完、品質差、未来利用拒否、相手境界、方向反射。
- 旧4方式×26入力＝104列の完全再現。
- 全260×26入力＝6,760列を別の条件式で再計算。
- 52個の異なる採否・母集団条件×26入力について、公開投影・未来確定比率変更を各2境界で2,704件、上下反射1,352件。
- 192方向乱数×26入力＝4,992列で候補時刻の保持を確認。

入口の公開投影は、切断までに終端が確定した帯だけを渡した場合の不変性である。原本行から比率を再集計するprefix・未来変更・反射は別の `trial_observation_audit.json` が全260セルで担当しており、二つの検査を混同しない。どちらも新しい売買損益を計算していない。

`check_entry_signals_synthetic.json` は人工のみ、`check_entry_signals_legacy.json` は旧再現のみ、`check_entry_signals.json` が全パネルとの接続まで完了した証跡である。実装・原本・パネル・別監査を参照SHAへ、全6,760明細を出力SHAへ結合している。
