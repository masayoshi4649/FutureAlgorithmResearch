# 売買前に確認した候補頻度

主F01・副F02とも、両市場で全13セッションの候補が20回に届かない。
同じ候補から繰り返し新規を作らない注文器なので、従来からの決済20回という基礎目安は、この時点で通過できない。
活動基準は変更せず、数量情報・価格対照・品質変更による損益差を調べるため、予定した260条件の再生は実施する。
候補数は実約定数・勝ち数・利益ではない。少数機会の好成績だけで採用へ進めない。
