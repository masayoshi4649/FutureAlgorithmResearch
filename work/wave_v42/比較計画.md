# 原本全行を使った同価格帯の再検査

**v40の結果とv41の観測診断を受けた追加仮説。まだ新しい収益を計算していない。** 板の「減少後の再増加」を公開端点だけで観測したために、本来利用できる情報を落としていなかったかを問う。旧帯・試行・突破時刻を固定する条件付き比較に限定する。

主案は**原本全行＋旧品質維持**で、二試行の再増加／減少比率uと価格の押し戻りbがともに弱くなった後の突破へ入る。副案として、同じ原本差分を用い、P局所品質だけに替える方式も必ず別IDで残す。可視外をゼロとする仮定はどちらにも加えない。

## 比較する20方式

| ID | 内容 |
| --- | --- |
| F00 | 旧B00：公開端点だけのu・旧品質・uとbの両方が弱化 |
| F01 | 主案：原本全行u・旧品質維持・uとbの両方が弱化 |
| F02 | 副案：原本全行u・P局所品質・uとbの両方が弱化 |
| F03 | F01と同じ数量比較可能な機会だけで、b弱化のみ |
| F04 | F02と同じ数量比較可能な機会だけで、b弱化のみ |
| F05 | 数量が不明でも、b弱化だけで入る旧B02 |
| F06 | 旧品質維持でu2<1とb弱化。u1との大小を読まない |
| F07 | 旧品質維持で平均(u1,u2)<1とb弱化。順序を読まない |
| F08 | 旧品質維持でu2>u1とb弱化。数量変化の解釈を反対にする |
| F09 | F01の売買方向を反転。時刻は候補生成から再評価 |
| F10 | F01に、旧B12と同じ60秒追加遅延の相手価格確認 |
| F11 | 旧品質維持でu弱化だけ。b弱化を要求しない |
| F12 | F06のP局所品質版 |
| F13 | F07のP局所品質版 |
| F14 | F08のP局所品質版 |
| F15 | F09のP局所品質版 |
| F16 | F10のP局所品質版 |
| F17 | F11のP局所品質版 |
| F18 | 旧B01：旧数量比較可能な機会だけでb弱化 |
| F19 | 旧B03：二試行後の突破すべて。数量・b弱化は要求しない |

F01〜04とF06〜08、F12〜14は**同じ原本比率が二つとも比較可能であること**を前提にする。u2だけ使う方式にも同じ観測母集団を適用し、情報の順序と単なる取引機会の差を混同しない。F11/F17も二試行uが必要。数量比率を使う相手確認は行わない。

## 追加反証は有限に固定する

- F01・F02・F03・F04に、準備24/36秒・試行24/36秒・離脱0.4/0.6ATR・突破1/3tickの一軸変更をそれぞれ8個、計32個。
- 同じ4方式に伝達1/5/15秒と観測価格約定をそれぞれ4個、計16個。基準の伝達0は次の原本行以降で、同一判断行の約定を認めない。
- F01・F02・F03それぞれ64seedの候補方向符号対照、計192個。候補生成時刻は保持するが、約定時刻・保有の長さ・将来収益を乱数へ渡さない。

**20基本＋32近傍＋16執行＋192乱数＝260条件**。基礎／補助を区別し、新しい主条件は68条件。旧と全く同じ条件も独立発見数には数えない。旧B00/B01/B02/B03の注文・返済・全時価は既存結果との完全一致を要求する。

## 共通出口と評価

v39/v40の1枚エンジンを変更せず使う。公表時のATRを2tick以上へ丸めたrを固定、新規は判断の次行以降、初期1r損切り・2r利確、最長30分、5分休止、場内返済。費用0、TOPIXミニ/NKマイクロ換算。これらはH019の出口とは異なり、H019の既知利益を引き継がない。

基礎活動・損小利大・最大勝ち除外・感度の数値はv40の固定規則を維持する。基礎候補を通過したかと、原本全行の数量変化が追加価値を持つかは別に表示する。主案F01はF03/F06/F07/F08/F09と乱数中央値、副案F02はF04/F12/F13/F14/F15と乱数中央値に対して両市場の合計Rを比較する。相手確認や品質変更の良かった枝で主案を救済しない。

新旧の活動差は、帯数→完了二試行→数量比較可能→条件成立→実取引の段階で示す。機会が増えても収益改善とは呼ばない。既知13セッションを後から未知と呼ばず、今回の成績を見て主案・比較相手・合格目安を変更しない。

この文書は比較範囲の草案を定めたもので、実装・入力監査・全数値を結びつけた最終凍結は売買再生前に別途保存する。現在API追加取得と保存ライブの使用は0。
