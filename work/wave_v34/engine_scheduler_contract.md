# 仮想建玉による再エントリー制御の注文器契約

旧 v33 注文器の共通 D273 をそのまま使い、新しい未約定注文を準備できる行だけを制限する。実際の損益を用いた条件選別はせず、以下を実装・合成検査の前提とする。

## API と記録

`run(ready, state, config, detail=False, context=None, width_mode=0, observed_fill=False, trail_atr=None, prepare_allow=None)`。

- `width_mode=0` は準備時の A0、`1` は保有中の At による追跡幅。初期予算・1.5 A0 始動・2 A0 部分利確などは従来どおり。
- `prepare_allow=None` は通常運転。指定する場合は原本行と同じ長さの一次元 `ndarray[bool]`。新規準備の条件だけに使う。
- `observed_fill=True` は新規・部分・全返済のすべてを条件到達後の観測価格で約定する。影と実側に同じ価格モデルを適用する。
- `trades/cycles/curve/orders/stats/atr_curve` は従来と同じ。`detail=False` での曲線省略も同じ。
- `PREPARE_COLUMNS` は `prepare_id,row,side,level,initial_atr,expiry_time,qty`。`prepare_events` は新しい未約定注文の準備だけを一行ずつ記録する。価格追跡更新では増やさない。各運転内の ID は 0 から連番。
- `ENTRY_PREPARATION_COLUMNS` は `campaign,fill_row,prepare_id,prepare_row`。`entry_preparations` は各新規約定の起点を記録する。元の `orders` にある発注元行は直前の追跡更新行になり得るため、新設行とは区別する。
- 追加二台帳は `detail=False` でも記録する。行番号は同一時刻でも原本順を区別する。

## 独立仮想運転と実側の接続

1. 各銘柄・セッションで固定 A0 の影を `width_mode=0, prepare_allow=None` で運転する。影は実側の保有・損益・At に依存せず、通常の準備・約定・部分返済・全返済・5 分休止を続ける。
2. 影の `prepare_events[:, row]` の行だけ `True` の許可列を作る。
3. 実側には同じ価格、ATR、方向、D273、価格モデルと許可列を渡し、指定した A0/At 幅で運転する。

影を全期間先に計算する実装でも、許可行はその行までの情報だけで決まる。将来の影返済時刻や損益を読んで過去の許可を作ってはならない。接続全体の prefix・未来改変を検査する。

## 境界での動作

既設注文の執行を現在行の新しい判断より先に行う。許可された準備行で約定することはなく、最短でも次の原本行から有効になる。影の約定を見てその価格を実側へ過去コピーしない。

実側が保有中、または全返済後の自身の 5 分休止中なら、影の新設を見送る。影を止めたり実側の返済に同期し直したりしない。実側が後に空いても、見送った影の保有・既存未約定注文へ途中参加しない。次の新設準備行を待つ。TTL 失効や方向変更後の新設は、新しい ID として改めて参加可能である。

逆に実側だけ先に全返済したら、影が全返済し 5 分休止を終えた後の新設まで待つ。許可が次行で False に戻っても、既に同期準備した実側の注文を取り消さない。既設の追跡更新・通常の方向不一致取消・期限切れは従来どおり。部分返済は保有継続であり、休止を開始しない。

双方の開始待機・新規締切・場末返済は共通 D273 のまま。場末の返済判断は次原本行の価格で行い、持越しを認めない。価格・ATR 欠測の扱いも旧版と同じとする。

## 今回の実装検査の範囲

通常 A0・通常 At は旧 H019 の全 26 入力について v33 の旧 6 結果と完全一致させる。A0 制御は通常 A0 の全結果と完全一致させ、許可同期の恒等対照とする。既知 At 通常の同値確認だけを行い、新しい At 制御の相場格子・損益順位は計算しない。

合成相場では実先返済、影先返済、同時返済、部分返済、自身の休止、見送り注文への途中参加禁止、新設と追跡更新の区別、同時刻、飛値、場末、欠測、指定/観測、買売反射を検算する。全約定の起点、許可された準備の価格/A0/期限/数量、全玉会計、未来情報の削除・改変にも同じ検査を行う。

この制御は、影が空いている間の任意行で実側に自由な準備を許す方式より厳しい。入口を同期させて出口と再新規の影響を分けるための固定仮説であり、成績を見て条件を緩めない。
