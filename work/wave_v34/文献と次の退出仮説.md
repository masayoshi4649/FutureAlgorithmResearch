# 文献と次の退出仮説

今回の192条件の後に、次の設計のため一次資料の抄録を確認した。今回の採否・条件・損益を変えるためには使っていない。

- [Xu・Gould・Howison：Multi-Level Order-Flow Imbalance in a Limit Order Book](https://arxiv.org/abs/1907.06230)。Nasdaqの6銘柄で、多段の注文フローと**同じ期間の**中間価格変化の関係を調べている。奥の板を加える有用性の示唆はあるが、同時点の説明力を将来予測やOSEの退出利益と読み替えてはいけない。
- [Chevalier・Hafsi・Ly Vath：Optimal Execution under Incomplete Information](https://arxiv.org/abs/2411.04616)。注文フローと観測できない流動性状態を用いた返済の制御モデル。今回確認した版は2026年8月改訂。特定モデル内の制御問題であり、今回のデータでその仮定や収益を検証した資料ではない。
- 前回から参照している [Bechler・Ludkovski：Order Flows and Limit Order Book Resiliency on the Meso-Scale](https://arxiv.org/abs/1708.02715) は、板の追加・取消と深さ・形状を時間尺度と併せて調べる。今回の補充代理に真の約定・取消識別があるという意味ではない。

独自に検証したい仮説は「小さな変動になったこと」と「既存の進行を支えるフローが崩れたこと」を分けること。ATR低下だけでは方向継続の否定にならない。板の逆向き変化に、後続の価格応答や他銘柄の同方向悪化が伴う場合だけ追跡幅を短縮する。これは文献から利益が保証される手法ではなく、次の反証対象である。

短縮する幅を `3×min(A0, At)` とし、そうでなければ `3×A0` とする案では、固定方式より遅い退出が生じないかをまず確かめる。仮想新規制御と組み合わせれば、新規を固定方式と完全に揃えられる可能性がある。成立には単調な返済線、同一の部分利確・損失予算・休止、追加や反転なし等の条件があり、合成反例と全件照合を先に行う。

[独立レビュー](次反復の条件付き追跡短縮レビュー.md) は、悪化確認がない間に線の更新自体を止める反例を指摘した。常に固定幅の候補線を更新し、条件成立時には追加で短縮する必要がある。幅の上限だけで全新規一致が保証される、と取り違えない。

反証は、価格だけの条件、板だけの条件、両銘柄条件、確認なし、無関係な確認時刻を揃えて比較する。単に短く保有しただけ、短縮回数が違うだけ、終わった波を事後に説明しただけ、を優位と数えない。次の新しい作業番号で仕様を固定してから損益を再生する。
