# 00165 独立実装レビュー

最終源105件を作者の凍結指紋と照合し、新層の敵対的人工13本を再実行して全件通過した。新しい金融再生は行っていない。

- **数量分母（解決）**：価格又は最良数量が変わる有効更新を分母とし、価格だけ変わる行の同価格回復0も含める。数量だけの更新を価格イベントに混ぜない。
- **補充壁再検査（解決）**：履歴の通過済みだけでは入らず、新規時にも現在返済側の10円通過と60秒/32価格更新期限を検査する。
- **同価格由来（解決）**：段番号でなく同価格の共通集合を照合。QuantitySupportの実価格と原行も保持する。約定消費/取消/隠れ注文とは断定しない。
- **親上限（解決）**：実保有又は新規予約の親を全方向合計5に制限。返済予約で枠を早く空けない。再参加単位はRetestID。
- **親合計半減（解決）**：自由実残量合計floor(total/2)をActualID昇順へ配賦。5枚玉2つから5枚、1枚玉2つから1枚を返す。先行元返済予約は優先する。
- **残玉資格（確認）**：実際の黒字部分返済後に存在した玉だけ資格付与。資格前MFEを流用せず、その後の正益と新しい反対状態を必要とする。
- **未知と親復活（確認）**：未知初回は元通知を維持、既知拒否/待機失効/源全返済した親は追加だけで復活しない。待機中部分返済は解放上限を下げる。
- **数量対照（確認）**：01のSource比例部分返済と12の仮想全量指示の半量写像を検査。同じ新規時刻/価格/容量を維持し空き枠増から新入口を増やさない。
- **窓対照の限界（留保）**：E08とT15は観測数も違う窓仕様の比較。価格時計しかなく実受信秒は不明。同時計の原行順を利用するが未観測後行は見ない。
- **追尾の限界（留保）**：次正常気配約定のため床は利益保証でない。+120円から追尾判断後の次板が−30円なら実損失を残す。
