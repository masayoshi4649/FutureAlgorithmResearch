# 変更後基準の敵対的確認

2026年10月14日の変更を受けた評価定義の点検。新金融・原板・NPZ・APIは0。元の固定source及び台帳は変更しない。

## 主判定

銘柄別に、手数料後の完結取引群の正損益合計をP、負損益の絶対値合計をLとする。

1. **P÷(P＋L)≥65%**。利益／損失は13÷7以上。取引群の正負を場全体で相殺してからP・Lを作らない。
2. **赤字場数÷測定済み全場数≤20%**。既知33場なら赤字は6場まで。
3. **最大赤字場の損失額≤黒字場収支の算術平均**。「平均的な黒字1場で補える」という回答に対応する。平均は黒字場の利益総額ではなく、その場の損失も含む差引収支から算出する。

活動場ごとの利益割合の単純平均は別に示す。金額合計の割合と単純平均の両方を同じ65%の必須条件にすると、確認済みの金額基準を後から変更することになるため、主判定と参考値を分ける。

## 無取引と欠測

- 無取引は黒字ではない。利益割合の単純平均へ0%や100%として代入せず、計算できる活動場だけを分母にする。
- 赤字率の全場分母に加え、活動場分母、黒字／赤字／零収支活動／無取引の件数、場収支中央値を示す。例えば赤字6／33は20%以下でも、活動7場中6赤字なら安定した利益とは言えない。
- 活動頻度の追加閾値は今回数値指定されていない。後から任意の値で候補を落とすのでなく、数値三条件の合格と、活動が乏しい問題を区別して記載する。
- 全無取引ではP＋L=0、黒字平均も定義できない。三条件合格にしない。
- 欠測・入力不適合・未完了場を無取引や収支0へ置き換えない。2026年10月13日ナイトの時計不適合は、既知33場の分母へ成功場として足さない。

## 大勝ちの除外

ユーザーは大勝ちを除いた平均的な利益を重視している。全場の数値合格と、黒字場収支上位3場を除いた頑健性を分ける。

- 除外は収支で選び、同額は固定セッション順で決める。銘柄ごとに除外対象は変わり得る。
- 対象場の取引群P・Lも丸ごと除外する。場収支だけを合計利益から引く処理は、混在した勝ち負けを再計算したことにならない。
- 除外後の利益割合、黒字平均、最大赤字、赤字率の新しい分母を表示する。33→30場なら赤字6場は20%丁度になる。
- 黒字が3場以下では、黒字上位を除いた後の黒字平均が定義できない。頑健性合格にしない。
- 除外した日の取引を実際に停止するアルゴリズムではない。過去成績への依存を点検する評価だけである。

## 候補と約定モデル

- TOPIXと日経を合算して主判定しない。同じ条件で各銘柄が合格する場合と、銘柄別に選ぶ場合を分ける。
- 同じ保存結果のaliasは別の成功証拠に数えない。今回の吸収見送りは全mask同値・介入0で、KNOWN_VETOの会計再利用である。
- IDに`PRICE`を含むことだけで理想約定と分類しない。`C_PRICE`／`R_PRICE`は価格だけで判定する入口名で、買ask・売bidを使う執行なら現実寄りの比較に含める。
- `E01_G_U_PRICE`／`L_D20_PRICE`等の最終価格約定参照は主候補と分ける。常設利確の気配到達全量約定も、実商品の待ち順位・部分約定が確認できている方式と混同しない。
- 枚数を再スケールしたと仮定せず、実測した数量と上限を示す。注文別切捨て料金や部分返済があるため、保存収支の単純倍率だけを新会計にしない。
- 完結取引群の定義は保存仕様のまま明示する。親、UID、返済注文、複数手法全体を都合よく入れ替えて利益割合を高めない。両建て・未返済損失は除外しない。
