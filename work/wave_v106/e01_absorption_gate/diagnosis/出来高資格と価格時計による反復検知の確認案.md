# 出来高資格と価格時計による反復検知の確認

## 静的に確認できたこと

**最大接触1回は、旧抽出器の数学的な制約ではない。** 旧 `input/core.py` の `apply_transitions` は価格時計の同値を許し、出来高時計の同値も非逆行として扱う。同価格・同板のまま正の公表累計差が反復し、出来高時計が価格時計以下なら、2回以上の接触を作れる。

実際に旧純抽出器へ人工JSONだけを渡したところ、末尾同価格区間で4接触・活動差24・初期数量10を構成でき、固定述語が成立した。最後の2行は価格時計が同値である。既存8sourceを変えた実験ではない。

一方、価格時計が100で停滞したまま出来高時計が101・102へ進んだ人工では、累計差6は `volume_delta_known=True` と `volume_delta_observed=6` で保持されるが、`volume_delta_usable=False`、支持用 `volume_delta=NaN` となる。価格・出来高時計が次に103へ揃った行も、直前行の不一致が残るためまだ不使用。次の104行で使用可能へ戻った。元のW60窓はbit8で未知になった。

これは**同じ原行で記録された別フィールドの時計差**である。出来高時計が現在値時計より先であることだけで、未来の原行を読んだとは断定できない。ただし、Lastが新しい出来高差と同じ約定を表すことや、全出来高差の真の買い・売り方向も確認できない。旧資格を緩めれば正しい方向票になるという結論ではない。

v2訂正は、直前の価格時計逆行bit8を追加除外するだけである。この逆行のない人工では上記の結果は変わらない。訂正関数を実素材へ再実行していない。

## 実素材の小witnessによる反証

元票が未知だった公開候補はTOPIX7・日経5で、**12件すべてreason16**（正増更新行のLast又は直前BBO不明）だった。出来高差資格不明・resetを表すreason8は0、時計・原連番のreason4も0である。

元 `votes.measure` は、選んだ窓の全原行でusableが偽又は出来高resetがあればbit8を付ける。したがって、今回適用対象となった273の**モデル上の窓、first_vote_raw_rowから公開原行まで**について、出来高資格で更新が除外されて反復1回になったという説明は支持されない。

この反証には境界がある。古い `CurrentPriceTime` のままの原行が価格時計cutoff以下と判断され、そもそも窓開始より前へ置かれた場合、その行はbit8集計にも含まれない。原行の順序は分かるが実受信時計が無いため、それらが実際の直近60秒に受信されたと補完することもできない。

独立の小射影では、接触1回のTOPIX96/99・日経96/97が、公開候補終点自身の原行だった。これは公開時点や観測同期への偏りを疑う観察材料であり、時計資格が原因だったという実証ではない。

## 必要なら次に固定する非金融測定

以下は**追加NPZ未読・根の許可待ちの案**。閾値・元8source・既金融結果は変更しない。

1. 既知33場・66個の保存派生NPZを、新しい可用性目的で各一回読む。原JSON・現在API・原paper再計算・金融は0とする。ロケータと指紋は既存の入力metadataから固定する。
2. 必要列は原連番、価格時計、出来高時計、累計、`volume_delta_known / volume_delta_observed / volume_delta_usable / volume_delta`、価格・出来高reset、場内・時計の資格、Last、両最良気配・数量。既不変の値を読むだけで、資格配列を修正しない。
3. 全原行のknown正増を分母に、usable正増とknownだが非usableの件数を分ける。非usable理由を、現在又は直前の `volume_time>price_time`、価格時計欠測・場外・逆行、原連番断裂等の交差で記録する。理由を単一原因へ無理に割り当てない。
4. 価格時計据置・出来高時計前進・正のknown差が同時にある行について、同逆側最良価格の連続区間とLast位置を保存する。ここでのLast位置は単なる観測代理で、真の攻撃側の票を復活させない。
5. 全原行における同価格区間の正増反復と、元usableでの反復を分ける。価格が同値でも、Lastと出来高差の同時性不明を別に残す。全原行の数とE01公開時点の数を混ぜない。
6. 299公開の固定witnessに対して、元モデルが選んだ窓内、同価格尾部だがその窓の開始より前、その他の過去を分ける。原行より未来の情報を足さない。価格時計外の行を「実時間で直近」と呼ばない。
7. 時計による取りこぼしが測れても、直ちに新しい方向票・入口・損益改善へ読み替えない。新資格での方向同時性・入口の規則を別に固定して初めて次段階とする。

これにより、「繰り返しが市場で無かった」「公開する時点が反復の終わりだった」「旧時計資格又は窓の切り方で見えなくなった」を分けて考える。現在までこの追加66NPZ測定は実行していない。
