# 次探索の独立批判

**追跡始動前の損失が多いことは、出口後半だけの改良に限界がある証拠であって、その損失を事前に識別できる証拠ではない。** [始動前の分解](追跡始動前の損失分解.md)は、返済行までの最大順行が1.5A0未満だった組を事後分類している。将来そこへ届かないことを判定時点へ持ち込まない。始動前に逆行してから大きく勝つ組も比較へ残す。

以下は既知の結果を見た後の設計案であり、未実装・未再生・未採用。新規損益探索、現在API、保存ライブは使っていない。

## 1. フローの大きさより「予想外だった部分」に情報があるか

**仮説:** 同方向フローの継続は既に価格へ織り込まれ、予想から外れたフローだけに追加情報がある。解放済みOFIの過去値と過去価格から次のOFIを小さな固定モデルで予測し、実際の公開後に `実測OFI−事前予測OFI` を作る。買いの中でも予想以上か、予想より弱いかを区別する。原本のOFIは真の成行売買ではないため、注文者の意図とは呼ばない。

**差と反証:** v13 N15／v23の価格応答残差は「フローに対し価格が鈍いか」。こちらはフロー自体の予測可能成分を除く点が異なる。同じ後続価格確認・同じ注文器で、素のOFIと残差を対照にする。残差が次の公開価格変化や初期損切り先着の識別を改善しない、同時点の説明だけ、入口が減った分だけDDが下がるなら棄却。モデルは前の完了区間で固定し、初期不足時はA0を維持する。

着想は[Tarantoほかの履歴依存インパクト](https://arxiv.org/abs/1602.02735)。原論文の取引符号モデルを、今回のOFI代理へ翻案する未検証仮説であり、利益予測器の既製品ではない。

## 2. 変動幅が同じでも、板の価格の空白が逆行側だけ大きいか

**仮説:** 平均的なATRでは区別できない、方向別の短期損切り到達リスクがある。公開された上位10段から、隣接気配間の空白、近い価格帯を埋める数量、反対側との非対称性を計算する。保有予定方向の逆側が薄い場合に、初回数量だけを落とす少数対照にする。欠けた段や表示範囲外は不明であり、数量ゼロの空白にしない。

**差と反証:** v23近遠の重み付き板厚やv25「少量で動いた後の脆弱性」と近縁だが、価格が動く前の離散的な価格配置を、方向予測でなく初期リスクへ使う点が追加課題。同じATR・同程度の総板厚でも、逆行側の空白が次の損切り到達に情報を加えないなら棄却。常時少量保有との対照が必須で、数量を減らしただけの利益／DD縮小は改善としない。指定価格約定は維持し、板の薄さを新たな費用やスリッページとして加算しない。

着想は[Farmerほかの板の空白と大きな価格変化](https://arxiv.org/abs/cond-mat/0312703)。別市場の結果をOSEへ移せる保証はなく、10段だけでは初期1A0先の全流動性を観測できない場合もある。

## 3. フロー状態の「終わり」を、固定窓の反転とは別に検知できるか

**仮説:** 反対フローが強くなる前に、持続していたフローの自己相関・到来頻度・価格応答の組合せが変わることがある。解放ブロックごとに、直前の持続状態が続く確率と状態が変わった確率を因果的に更新する。過去の価格／OFIをまとめた少数状態のオンライン変化点モデルで実装でき、LSTMは必須ではない。未観測、単なる0、値動きがないことを「終了」の肯定根拠にしない。

**差と反証:** v23価格CUSUM、v25長短フロー反転・10分停滞撤退と部品は重なる。追加課題は、固定の長短差でなく持続状態の履歴と不確実性を持ち、反対符号未成立でも更新すること。まず通常の停滞／反転条件に対する予測の追加価値だけを測る。状態変化が初期逆行より遅い、価格変化の同時説明に留まる、通常の休止と同じ注文になるなら新機構の価値なし。状態終了を自動的な逆方向エントリーへ読み替えない。

参考は[オンライン変化点によるフロー予測](https://arxiv.org/abs/2307.02375)。ただし[公開データから大口執行を推定する難しさ](https://arxiv.org/abs/2501.17096)もあり、検知した統計状態を特定参加者の分割注文の開始・終了とは断定できない。短い標本ではモデル過剰化の危険が特に大きい。

## 4. 約定値の往復を、気配全体の移動と取り違えていないか

**仮説:** 小さな順行確認の一部が、売買気配の間を約定値が往復しただけで生じ、初期損失を増やしている。短期入口確認だけを、同じ公開時刻の最良買い・売りの両方の移動、または中値の移動で確認する対照を置く。ATR、実約定価格、時価会計、主方向を同時に変更しない。気配欠測・ロック・交差は肯定情報にしない。

**差と反証:** v23気配方向／microprice信号は既存なので、新しい方向法の発見とは呼ばない。H入口で約定値由来の確認と気配由来の確認を一箇所だけ交換し、微細な波の観測尺度が初期誤発火を生むかを切り分ける入力診断である。確認の食い違いがほぼない、食い違った群の後続失敗が増えていない、単なる時間遅延対照を上回らないなら終了する。これは入口を変える案であり、全新規一致の退出改良とは別実験になる。

[Rollの研究](https://doi.org/10.1111/j.1540-6261.1984.tb03897.x)は約定値の往復による系列依存の考え方の参考。今回、取引費用を追加する提案ではなく、観測する価格の性質を分ける仮説である。

## 暦・比較・実装の歯止め

- [JPX公式](https://www.jpx.co.jp/news/2040/20260918-01.html)で2026年9月21〜23日の祝日取引を確認した。選択用の初期6はこの3日D/Nで、通常営業日のデイを含まない。これだけで「休日は薄い」「休日が失敗原因」とはいえない。後から休日専用の有利な枝を作るのも避ける。暦はまず層別の記述に使い、板厚・更新頻度・価格応答は過去だけで直接測る。将来通常日を学習側へ移すランダム分割はしない。
- 4案を組み合わせて巨大な格子へ戻さない。各案の基準・一機構・必要な対照を先に固定する。利益以前に、予測対象を次tick／初期損切り先着／中期継続のどれにするか決める。次tickが当たるだけで長い波に有効とはしない。
- 全学習・基準化は過去の完了区間のみ。同区間相手の未完了の正解も入れない。原本seq解放、相手追加60秒、足公開遅延、注文次行、場内返済を維持する。入力の未来変更と売買反射を合成で反証してから売買を再生する。
- 既知13区間と相関する12入口を独立標本数へ水増ししない。全損失・失った勝ち・決済枚数・組損益・純枚数時間・含み込みDDを残す。無取引や常時縮小だけを「安定化」と採らない。

優先するなら、まず4の安い観測診断で既存入口の誤発火説明を確かめ、1を一つの明確な予測仮説として検査する。2は方向別リスク、3は状態の寿命という別課題であり、1の失敗を後付けで救う部品にはしない。

## 追記：v36の出来高通過・気配維持から二方向を待つ案

[可用性レビュー](見えない補充代理の可用性レビュー.md)を読む限り、この案は先の4案とは別に**入力の追加価値を限定して検査する価値がある**。出来高増分がある一方、両側最良価格・数量と現在値が不変という組合せは、既存の「可視減少後の増加」や非ゼロOFIを要する吸収条件では取りこぼし得る。新規性はこの観測代理であり、防衛反転・突破継続という発想自体はD016/D032等と重なる。真の補充量、補充の下限、アイスバーグ、増分の全量が最後の価格で約定したことは主張しない。

**機械規則の必要条件:** 価格だけで定義できる停滞帯を、準備行の公開済み情報で固定する。接近方向が必要なら準備前の変位から決め、後の反発から逆算しない。帯の境界・準備時ATR・期限を保持し、別の解放イベントで防衛側への反発か反対側への突破を初めて確認する。最初の成立分岐を一度だけ発火させ、その後に都合の良い枝へ付け替えない。「反発しなかった」「突破後戻らなかった」は将来全部を見る条件にせず、既に経過した確認時間だけで定義する。欠測、出来高減少／リセット、出来高と価格の時刻の矛盾は不明として扱う。

最小比較は次の4主方式と、それぞれの符号反転診断で足りる。

| 主方式 | 何を分けるか |
|---|---|
| 純価格帯・自市場 | 同じ帯形成・後続分岐・期限だけ。出来高・数量維持条件を使わない基準。 |
| 追加代理・自市場 | 上記へ出来高通過と気配維持の条件だけを加え、代理の追加価値を見る。 |
| 純価格帯・両市場 | 相手追加60秒と同じ公開・期限条件で、価格確認を増やしただけの効果を見る。 |
| 追加代理・両市場 | 自市場版との違いを、相手確認による誤発火減と確認遅れへ分ける。 |

純価格帯対照を、追加代理が成立した時刻だけへ限定してはいけない。それでは代理が有利な準備時刻を選んだ価値を最初から共用する。価格で適格な全帯を共通母集団にし、代理で採用／非採用になった件数・後続分岐・全損益を残す。符号反転は準備・発火時刻を固定した方向の対照であって、逆張り側へ都合よく設計を組み直さない。両市場の確認が消えたことを反対根拠にも変えない。

注文管理は一つに固定し、部分復元は混ぜない。代理を足しても純価格帯以上の情報がない、単に開始を遅らせただけ、ほぼ未稼働、少数の祝日デイだけで改善、入力の解放遅延で消える、という結果なら今回の追加代理は支持されない。始動前損失も失った大勝ちも含めて評価し、後付けの「純価格だけなら勝てた帯」選別はしない。ここまでの追記も設計のみで、新特徴生成・売買再生・採否は未実施である。
