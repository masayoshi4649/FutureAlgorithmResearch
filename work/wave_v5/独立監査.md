# 独立監査

監査対象は全て保存済みの既知データです。通信と条件の選び直しは行っていません。

- 元データ30ファイル（足20・生板10）のSHA256が、探索前データ監査と全件一致しました。
- 主候補、系統9・18、追加出口２方式の代表を再計算し、保存取引・セッション集計・順位指標が一致しました（重複除外4条件）。
- 共通確定時刻で特徴を作り直した切断再生は、特徴50・信号200・約定200の全件で一致しました。
- 全取引が実在足で新規・返済され、セッション外価格混入の拒否10件に成功しました。
- 利益合計−損失合計＝収支、価格差損益−往復費用＝収支、２・４ティック費用、保有時間、15分以内の件数と収支を別計算で照合しました。
- 入口・微細波の感度明細も29条件で会計照合しました。
- 追加返済の単体試験14件、160切断条件、60条件の既存追跡約定互換は事前に成功しています。

## 追跡幅の比較に対する追加監査

初期損切りを全て2.5ATRに固定し、追跡幅だけを1.5・2.5・4・6ATRへ変える４条件を再検証しました。４条件の保存取引・集計・費用計算が再現しました。追跡幅4ATRは、元の基準条件と新規・返済・損益および全セッション集計が一致しています。全探索・全テストの再実行はしていません。
