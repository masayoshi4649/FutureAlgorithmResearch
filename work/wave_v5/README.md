# 再探索と収支の確認

結果は [検証結果.md](検証結果.md)、数値の正本は [セッション別利益損失.csv](セッション別利益損失.csv)。ラージ１枚、両建ては買い１枚＋売り１枚。各脚の往復２ティック控除後で、４ティック控除も別列へ保存した。

今回は保存済み５セッションだけを使用し、現在セッションAPIを取得していない。9月23日日中は前回参照済みのため、未使用データとは扱わない。元の３フォルダと旧研究成果物は変更していない。

実装は `data.py` が保存足と生板特徴を読み、`search.py` が方向検知の13,006条件を比較する。`exits.py` は初期損切りと固定利確・追跡返済を追加する。`hedge.py` は同時両建てと片側コイントス、`hedge_search.py` は108条件と各100種の対照を担当する。

プロジェクトルートで実行する。Python、numpy、pandas、matplotlibを使用する。

```powershell
python -X utf8 work/wave_v5/data.py
python -X utf8 work/wave_v5/search.py
python -X utf8 work/wave_v5/hedge_search.py
python -X utf8 work/wave_v5/tradeoff.py
```

これらは保存データを再生して各結果を再生成する。全探索は数分かかる。両建ての実装ハッシュが凍結記録と異なる場合は再実行を拒否する。比較の会計、検算、リスク評価、作図のスクリプトは同フォルダに分離している。

報告対象の全取引は `報告対象手法.json`、各方式の `*_全取引.csv`。その選定・設定・元の結果を保持したまま、`終値評価リスク.csv` が１分終値での含み損とDDを示す。`入口と微細波比較.csv` は主候補の他条件を固定した比較で、追跡幅対照の初期損切りは2.5ATR固定。

`独立監査.md` に追加返済14試験、既存互換、時系列の切断比較、感度会計の照合を記録した。両建ての９試験と全109,080セルの会計検算、時価評価の３試験と50セル照合は各担当資料に記録した。

各セッションから条件を選ぶ部分と、その条件を当該セッションから除外して検証する部分を区別する。全期間で選んだ主候補の収支は探索内成績であり、将来の利益を示す数値ではない。時系列・一セッション除外の結果も `検証結果.md` に載せた。

注文の実行は仮想再生だけ。実際の注文APIへ発注する機能は含めていない。トレーリングは１分確定後に逆指値を更新する方式で、連続監視型のAPI `trail` と同じ挙動ではない。
