# 両建てと注文単独の探索

買い１枚・売り１枚を同時に開始する108条件と、同じ新規許容価格・出口・待機条件の片側コイントスを各100種で比較した。良かった乱数種を選ばず、全種の平均と分布を残している。

両銘柄の５セッション合計が往復４ティック／脚控除後に共に正となった両建て条件は 9/108 件。これは全条件探索後の保存データ上の結果で、将来の利益保証や未使用期間での検証ではない。

各セッションの利益額合計・損失額合計・差引収支は `両建て_セル.csv` と `コイントス_セッション平均.csv` に全条件を保存した。`count` は脚の取引数、`cycle_count` は両建てなら組数である。`positive_points/negative_points` は費用控除後の各脚利益・損失の合計、`pair_positive_points/pair_negative_points` は組を合算してから利益組・損失組へ分けた値である。

NK225は円幅、TOPIXはポイントで、両者をそのまま足さない。片側は１枚の結果に加えて２枚換算を保存し、両建ての総絶対枚数２へ揃えた。ただし両建て中の価格感応度は相殺されるため、枚数を揃えても全てのリスクや必要証拠金が等しくなるわけではない。

新規は既知価格±１ATRの買い上限・売り下限を同時に満たす実在１分足始値による条件指値の約定近似である。実際の最良売買気配・同時約定・注文遅延・片脚のみ約定する危険は再現していない。各脚往復２ティックと４ティックで摩擦を比較した。元の生板はこの執行近似へ直接使っていない。

固定出口は各脚の新規に対して、同じ返済方向の利確指値と損切り逆指値を付けるIFD-OCO相当である。両建て自体を一つのOCOと呼んでいない。勝ち脚追跡は小さい固定損切りで片脚が消えた後、残る脚だけを追跡する。足の高安が確定してから追跡価格を更新し、同じ足へ遡って返済しない。再開は両脚がなくなった後だけで、増額や倍掛けをしない。

全脚明細は `両建てとコイントス_全取引.pkl.gz` の逐次pickleレコードに保存している。条件・種ごとの辞書をEOFまで順に読み込めば、全取引と全セルを再現できる。代表種は結果を見る前に固定した260925000で、勝った種ではない。100種は同じ５セッション上の乱数変動であり、100の独立した市場期間ではない。
