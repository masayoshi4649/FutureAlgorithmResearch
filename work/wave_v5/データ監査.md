# 五セッションのデータ監査

今回の対象は保存済み五セッション、二銘柄。現在ＡＰＩは取得していない。book・candle_1min・candle_5min は読み取りだけに使用し、v4を含む旧成果物は変更していない。2026-09-23_Day は既に前回の答え合わせで参照した日であり、今回は探索用の既知データとして扱う。

## 読込ＡＰＩ

`from data import load_data_v5`、`data = load_data_v5()` で `(session, symbol)` をキーとする10入力を得る。値は旧 engine.prepare と同じ one・z・times・values・positions・atr・ref・reg・r2・limit 等。旧四セッションはv4のload_dataをそのまま使用し、新日中だけv5の板特徴を用いて追加する。任意のcutoffは新日中だけに作用し、確定足終了時刻がcutoff以下の範囲を返す。

## 新日中と前回の取得との関係

前回の締切15:39までの確定一分足・確定五分足は両銘柄とも完全一致。追加は15:39開始の一分足と15:35開始の五分足の確定である。前回の15:35五分足は未確定であり、その未確定値を今回の確定値との一致判定に混ぜない。利用可能時刻が15:39以下の板特徴も完全一致した。

|銘柄|新原本の板行数|範囲外除外|時刻欠落|旧板特徴の一致分数|追加特徴分数|生板ＯＨＬＣと保存足の相違項目|
|---|---:|---:|---:|---:|---:|---:|
|NK225|54501|6|421|358|1|0|
|TOPIX|49948|7|269|374|1|3|

生板先頭に前夜の状態が含まれるため、保存一分足に対応する08:45以上15:40未満の約定時刻だけを採用する。同じ最終約定時刻が続くブロックは次の約定時刻まで解放せず、さらに一分の確定後に利用する。末尾ブロックは破棄。板に受信時刻がない限界は以前と同じで、厳密な実約定時刻を復元するものではない。

生板と足に小差がある場合、保存足を価格・約定の正本とし、生板は次時刻待ちによる板特徴として扱う。差分の時刻・価格はＪＳＯＮに全件保存した。
