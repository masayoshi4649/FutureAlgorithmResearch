# 注文執行への反証

**実データの黒字は、逆指値を観測価格約定へ変えても残った。一方、X05 の TOPIX は方向信号を１秒遅らせるだけで収支が約３分の１になる。注文器の会計不備は見つからなかったが、タイミングへの依存は大きい。**

最初に `exec_adversarial.json` の `期間集計`、次に `合成反例` を見る。再現は `python work/wave_v24/exec_adversarial.py`。旧コード・原本は変更せず、API は使用していない。

## 何を別々に変更したか

主条件は従来どおり「費用０・指定価格約定」。その集計は旧結果と一致した。補足では逆指値・追跡返済だけを、到達が判明した原本行の観測価格で約定させた。利確指値は変更していない。これは費用を追加する検査ではなく、約定価格の仮定を変える検査であり、主条件を否定するものではない。

さらに方向信号の到着だけを０・１・５・15秒遅らせた。ATR、価格観測、注文処理の遅延は加えていない。元データの約定時刻を代理時計としているため、実通信遅延の精密再現でもない。両方の変更を交差させ、２手法・26区間で416回再生した。

## 主張と反例

| 主張 | 反例・確認 | 結論 |
|---|---|---|
| 次行約定なら現在の反対信号で必ず取消できる | 前行で設置した買い逆指値と、現在行の売り信号が同時に成立すると買いが先に約定する | 未来参照ではない。既存注文→現在行の判断という順序を明示すべき |
| 新設した損切りが過去の指定値で遡及約定する | 100で買い、99.5で損切りを理論99.75・呼値丸め99.7へ縮めても、次行実価格99.5で返済した | この遡及利益は生じなかった |
| 指定値と観測値の差は常に小さい | 100→110→90という飛びで、指定モデル＋7.7pt／観測モデル−20pt | 約定モデルは構造上大きな差を作り得る。ただし今回の実経路では差は小さかった |
| 場末や損失予算で指定額以上は失わない | 場末予約の次行に飛ぶと、旧損切り指定値より市場返済を優先した | 予算・保有上限時間は返済指示条件であり、損失額や時刻の保証ではない |
| 買いと売りで注文器に有利不利がある | 全26区間を反射価格＋逆信号で比較し、行・数量・損益が104再生で一致 | 対象２戦略・両約定モデルで注文器の売買対称性を確認した |

旧注文の優先は実データでも起きている。標準 X05 では TOPIX の新規57件中７件、NK の36件中７件が、**約定と同じ原本行で新規方向が中立へ変わっている**。同じ行で反対方向へ変わった新規は０件。これは設置済み注文の約定後にその行の新しい信号を観測する仕様であり、「約定時点でも方向根拠が必ず残っている」という説明は正しくない。同時の取消と約定のどちらが先だったかは、この入力だけでは確定できない。

## 保留すべき点

１行で処理する約定は１件であり、観測の間に起きた価格経路は再構成していない。到達観測価格も実約定の保証ではなく、最良気配、注文待ち順位、執行可能数量を含まない補足モデルである。現在の反対信号より旧注文を先に処理する点は、執行と取消の通信順序を精密再現した結果ではない。

この攻撃で X05 を「利益が消える手法」とは反証できなかった。同時に、１秒の信号時刻変更で TOPIX の利益が大幅に減り、F32 に対する優劣も変わるため、「機械的に切り替えれば安定して改善する」という強い主張は支持できない。全て同じ既知期間上の診断であり、新しい期間の優位性は示していない。
