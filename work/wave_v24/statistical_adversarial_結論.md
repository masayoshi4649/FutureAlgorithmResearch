# 統計・選択過程からの敵対監査

**X05 の黒字は１件の大勝ちだけでは説明できない。一方、「切替を加えたことで F32 より安定した」とはまだ言えない。** 両者とも１枚、費用０・指定価格約定で比較した。

| 同じ13セッション | X05 収支 / PF | F32 収支 / PF | 切替による収支差 |
|---|---:|---:|---:|
| TOPIX ミニ | ＋90,000円 / 1.918 | ＋103,000円 / 2.392 | **−13,000円** |
| NK225 マイクロ | ＋18,800円 / 2.424 | ＋17,100円 / 2.379 | **＋1,700円** |

- X05 は追加360条件内の首位。元1,160条件と同じ基準で合併すると **1,520条件中４位**で、F32 が１位だった。
- TOPIX は日中で F32 より＋23,000円、夜間で−36,000円。NK の差＋1,700円は、9/28 の差＋1,900円を除くと **−200円**になる。
- X05 から最大の勝ち取引を２つ除いても、TOPIX **＋39,000円**、NK **＋8,800円**。最大の黒字開始日を２つ除いても **＋23,500円 / ＋10,000円**で、特定の一発だけに依存した黒字ではない。
- 13セッションは７開始日分。同じ開始日を両銘柄・両手法で一緒に5,000回再抽出すると、X05−F32 の95%差区間は TOPIX **−127,500〜＋98,500円**、NK **−1,800〜＋6,100円**。どちらも０を含む。これは探索後バイアス未補正の診断で、将来の利益確率ではない。
- 追加選択器を過去だけで選ぶ７区間の事後再現は＋34,500円 / ＋4,800円。ただし NK は最大勝ちを１つ除くと **−400円**。全期間を見て設計したルールを使っているため、未見検証ではない。

時系列の記録では、F32 を1,160条件の首位に選んだ後、F32 を初期・中間状態に使う選択器が設計されている。候補内での売買の先読みがないことと、設計者が全期間を見ていることは別の問題である。

1,520候補の同日再中心化・最大統計量も計算したが、７ブロック、事後設計された候補と基準、数量差があるため、**正式な多重検定補正 p 値とは扱わない**。X05 の F32 に対する一貫した改善を支持する結果ではなかった。

詳細：`statistical_adversarial.json`。原本・前回成果の変更、現在 API 取得は０回。
