# 第一巡の具体診断

**主な問題は数量政策より前にある。支持選抜が155親中151親を捨て、26場中22場を無取引にした。** 黒字だったB00/B01も4親だけで、安定して稼ぐ手法と認定できない。凍結実装と原行の再計算は166初回（完了155＋途中11）すべて支持全値一致。売買再生は追加していない。

## なぜほとんど入らなかったか

|最初に計算を止めた条件|完了155親中|
|---|---:|
|5秒窓端が想定端から2秒超古い|58|
|15秒窓端が想定端から2秒超古い|25|
|自己120秒窓内の異常気配/15秒超の空白|19|
|自己300秒窓内の異常気配/15秒超の空白|26|
|相手120秒窓内の異常気配/15秒超の空白|9|
|現在のOFI差分が成立しない|8|

既知10親のうち支持閾値で6親を拒否、採用4親。数量丸めや枠不足が主因ではない。短期窓端の2秒制限だけで未知145親の83親を止めた。

- **10/27 15:00:05 core/6**：15秒前の予定端14:59:50に対し、直前原行は14:59:42。遅れ8秒で未知→親を拒否した。失速を判別して避けたわけではない。
- **10/20 10:03:55 episode/1、10:04:27 addon/0**：10:01:03の一時異常気配が300秒窓へ残り、現在の両端価格があっても全体を未知にした。
- **10/21 12:37:14 core/4**：5秒前の予定端12:37:09に対し**12:37:03**が直前原行。端点の遅れ6秒が許容2秒を超え、後に＋58,000円となった売り親まで拒否した。

使用時計は保存資料の`CurrentPriceTime`で、独立した受信時計ではない。短期端点がないことを「実際の板もなかった」と断定できない。一方、価格比は正常な両端から計算するため、途中の一度の異常だけで5分全体を無効にする必要はない。実装の転記誤りではなく、観測条件を厳しく設計しすぎた問題である。

選抜で消えた利益は4,078,000円、消えた損失は2,296,000円。元の黒字1,782,000円を失った。B01の＋398,200円のうち10/26だけで＋338,000円。初回量は10/8が13micro、10/13が71micro、10/15が30micro、10/26が52microで、旧各20microからの変更である。

**10/13 09:13:28**：M=1、T=.714で買71micro＠67,830。新出口Q01は09:14:24に67,750へ損切りし−56,800円。旧出口B01は同じ入口から部分返済・Source追加を続け、最終＋53,300円。強いスコアは成功確率ではなく、その直前の上昇を大きく重み付けした値だった。

同額の単純縮小も重要。元S01を算術上1/5にした収支は＋387,000円、最大DD58,800円、赤字8場。B01は収支が近い＋398,200円でも最大DD228,800円、22場無取引。数量支持の優位とはまだ言えない。

## 追加・カバー・逆行回復

- **順行追加Q01→Q03は−42,700円**。差が出たのは10/26だけ。09:35:31に37microを62,810で売り、回転後09:41:10に64microを62,640で追加。最後の64microが09:41:31に62,720で損切りされ−51,200円。手前の回収＋11,100円・＋10,400円を上回った。
- **カバーQ03→Q05は−5,500円**。10/13は＋600円改善。10/15は元売30micro＠64,440に対し12:31:28に買73micro＠64,480を追加、12:31:39に56microを64,460で解除して−11,200円。その後のカバー利益＋5,100円では埋まらず、元玉−24,000円を含め−30,100円。カバーが元玉より多く、純買いへ反転した場面もある。
- **逆行20pt後の回復追加Q05→Q07は＋12,000円**。実追加は2玉だけ。10/13は−8,900円悪化、10/26は＋20,900円改善。両方とも実建値平均は改善しなかった。10/13の買18micro＠67,860は元67,830より30pt高く、平均を6.07pt悪化させ−14,400円で損切り。10/26の売25micro＠62,690も元62,720より不利で、平均を14.71pt悪化させたが、後の高リスク追撃数量を減らす経路で全体損失は減った。「有利なナンピンで稼いだ」とは言えない。
- **逆行40/60pt、逆行累計上限25→50、場内抑制Dは発火0**。未知/選抜で母数が消え、比較結果が同じだった。効果がないという証拠ではなく未測定。
- **H05/Q05、H08/Q08の最終収支は同額**。両建ての別表示だけでは利益を増やしていない。場内全玉Bid/Ask時価の差と、親内純量化は独立会計で確認する。

今回の第2巡で先に直すべき箇所は**支持の観測条件と、弱い支持を全拒否してしまう数量入口**。数量管理を検証できる母数を確保し、旧出口/新出口と固定少量対照を残す。勝った4親へ閾値を合わせて改善と称さない。
