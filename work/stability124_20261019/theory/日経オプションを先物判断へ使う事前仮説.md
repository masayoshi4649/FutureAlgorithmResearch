# 日経オプションを先物判断へ使う事前仮説

記録日：2026-10-19、日本時間。金融結果・市場本体を見ずに作成。AGENTS、調査方針、共通知見台帳の入口・継続・出口・売買の工夫を確認した。本書は未測定の事前仮説であり、有効性の発見ではない。

## 最初に確かめること

親調査からのスキーマ速報では、IV・Delta・Gamma・Theta・Vega・CalcPriceがあっても独立の受信時計がなく、CurrentPriceTime・TradingVolumeTimeがnullの銘柄や、BBOが0/nullの銘柄がある。**計算値が存在することと、それがいつ利用可能だったかは別である。** 最終的な全ファイル資格はinventoryの保存結果を正とする。

IVが34から37へ変わっても、その新値を過去の最後の約定時刻へ付け直してはいけない。現在値の時計はGreeksや板の更新時計ではない。先物とオプションの同じ行番号、ファイル名の日付、ファイルの更新日時から日中の利用可能時刻を推定補完しない。時刻が不明の行は当該セッションの因果的な方向予測・損益再生から外し、未知として件数を残す。時刻が不明であることを、情報が無意味・手法が赤字・取引ゼロだった証拠にはしない。

## それぞれ何を表すか

| 情報 | 理屈から分かるもの | そのままでは分からないもの |
| --- | --- | --- |
| IVの水準・上昇 | 将来変動とその保険に付いた価格。高いほど大幅変動への対価が高い | 次が買いか売りか、その方向の勝率 |
| 満期と距離を揃えたプット側IVの高さ | 下落側の保護が相対的に高価であること | 実際の下落確率そのもの、下落開始時刻 |
| ATM付近のC/Pの共通上昇 | 両方向の動きに備える費用が増えた可能性 | 先物が上がること。固定KのC+Pには現在地のKからの移動も混じる |
| 同じK・同じ満期のC−P | そのSQに対する合成先渡しの水準 | 異なる満期の先物との差が必ず埋まること |
| オプション板の偏り・気配の変化 | 表示されている供給・需要価格と流動性の変化 | 約定か取消か、買手の新規か返済か、参加者の意図 |
| 建玉残高・Gamma | 未決済契約数、モデル上の価格感応度 | ディーラーがどちら側を持つか、ヘッジ売買の符号 |

日経平均VIは日経225オプションから作る変動の指標で、公式算出は複数限月・OTM価格等を使う。任意の一銘柄のIVや平均を日経平均VIと呼ばない。[JPX：日経平均VI](https://www.jpx.co.jp/derivatives/products/vi/225-vi-futures/index.html)、[日本経済新聞社：日経平均VI](https://indexes.nikkei.co.jp/en/nkave/index/profile?cid=0&idx=nk225vi)。

高い保護価格にはリスク回避や保険需要が含まれる。リスク中立の価格から読み取った確率を、そのまま実際の将来頻度にしない。[FRB：オプション価格からの暴落予測](https://www.federalreserve.gov/econresdata/notes/feds-notes/2014/forecasting-stock-market-crashes-is-hard-especially-future-ones-20140507.html)。

## 最優先で試す三つの考え方

1. **オプションも同じ方向へ価格を直しているときだけ先物へ参加する。** 同一C/Pペアの合成価格変化を使い、Cの上昇だけを独立の強気情報と数えない。日経先物の価格変化を単に追っているだけかを、先物だけの対照と比較する。TOPIXへ使う場合は日経オプション・日経先物・TOPIX先物の三者一致として別に測る。
2. **保護費用・気配差が急増したとき、通常の追従を控える。** 方向を新規に当てる材料ではなく、往復損や執行悪化を減らす補助とする。ただし大きな利益の場も失うので、避けた損失と見送った利益を分ける。
3. **保有と反対へオプション価格も明確に直ったときだけ降りる。** 弱い支持の消失だけで降りると利益を逃した既知の知見を引き継ぐ。単なるIV上昇、情報の欠落、出来高減少を反対方向へ同一視しない。

## 合成先渡しの厳密な扱い

日経225オプションはヨーロピアン、SQで差金決済される。C/Pは同じ指数・K・SQで揃える。[JPX：契約仕様](https://www.jpx.co.jp/english/derivatives/products/domestic/225options/01.html)。

割引因子Dを明示して、合成先渡しの参考中心は `H = K + (Cmid − Pmid) / D`。買い側価格の区間上端は `K + (Cask − Pbid) / D`、売り側価格の区間下端は `K + (Cbid − Pask) / D` とする。Dを1に置く場合は金利ゼロの近似と明示し、実際の裁定価格とは呼ばない。金利が確定的である等の前提もある。CMEの教材は同じ権利価格・満期・原資産を条件とする。[CME：プットコールパリティ](https://www.cmegroup.com/education/courses/introduction-to-options/put-call-parity)。

オプションのSQが11月、参照先物が12月なら満期が異なる。水準差には配当・金利・期間差が含まれ、即座に戻る裁定乖離としない。異なる満期の場合も、同じC/Pペアを過去窓で固定したHの変化は測れる。ただし先物を先行予測するか、同時反応か、先物の後追いかは別に検証する。

複数Kを統合する場合は、同じ満期の有効ペアの中央値とする。途中のATM乗換えは新旧シリーズの橋渡しを記録し、乗換え差をシグナルへ入れない。各BBOの利用可能時計が不明ならHを日中の観測値として作らない。

## 必要な記録と反証

- 未来参照を防ぐため、全行に実受信時計・二市場共通連番または同等の因果上限を保存する。オプションのLast時刻と受信時刻を別列にする。
- IV・Greeks・CalcPriceは計算対象の原資産・その時計・算出時計・モデルとともに保存する。モデル入力が不明なら提供値として区別し、自前計算の正解値とはしない。
- 時刻不明・片側欠測・気配逆転・満期不明・満期違いを別々に件数化し、ゼロ値へ置換しない。必要項目がなければ「その条件は未測定」とする。
- まず予想方向の先着・到達前逆行を先物のBBO起点で測り、それから全運転の手数料後損益を測る。Hとの同時相関だけを未来予測力とはしない。
- 日経とTOPIXは別集計、買い売り別、Day/Night別、全場と上位3黒字除外を示す。最良条件の事後選択を未知データでの再現性とは呼ばない。
- 既存の先物入口が少ない場合、単なる活動減少による赤字縮小を予測精度改善としない。未知・静観・取消・約定・決済の分母を別に示す。

## 論文の結果をそのまま使えない理由

Pan・Poteshmanの研究は、買手が新規建てした出来高を識別できるデータからput/call比を構成した。今回の単純な累積出来高比だけで同じ情報を再現したとは言えない。[原論文のNBER概要](https://www.nber.org/papers/w10925)。

需要に基づくオプション価格の研究では、ディーラーと最終保有者を識別したポジションを用いている。需要が価格へ影響し得ることは、公開板から全保有の符号を復元できることを意味しない。[Garleanu・Pedersen・Poteshman：Demand-Based Option Pricing](https://www.nber.org/papers/w11843)。

未決済契約は買いと売りが一組で、建玉残高は片側だけを数える。公開OIへ一律にputはプラス・callはマイナス等の符号を付けたdealer gammaを、観測事実として使わない。[CME：出来高と建玉の定義](https://www.cmegroup.com/market-data/volume-open-interest/about.html)。
