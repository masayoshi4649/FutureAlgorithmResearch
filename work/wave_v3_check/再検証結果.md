## 長く続く波のほうが正確か

追加夜間では、結果として120分以上保有した4取引は全て利益、120分未満の4取引は全て損失だった。全保存期間では次の通り。

| 結果としての保有時間 | NK225 利益件数/件数 | TOPIX 利益件数/件数 |
| --- | ---: | ---: |
| 20分未満 | 0/0 | 0/1 |
| 20分以上60分未満 | 1/1 | 0/3 |
| 60分以上120分未満 | 0/1 | 0/3 |
| 120分以上 | 6/6 | 5/5 |

長時間の波を維持する方向には根拠がある。ただし保護返済や反転返済が損失取引を短く終わらせる構造なので、保有時間で後から分けると長い取引が有利に見える。この表は『検知時点で長く続くことを予測できる』『120分待てば精度が上がる』という証明ではない。今後の精度改善で重要なのは、TOPIXの短い反転を開始前に見分けられるかである。
