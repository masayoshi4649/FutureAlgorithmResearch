## 一分足と五分足、生板との対応

- NK225: 一分足から再集約した五分足 152 本、OHLCV・出来高完全性の相違 0 項目、五分足欠落 0 枠。
- TOPIX: 一分足から再集約した五分足 152 本、OHLCV・出来高完全性の相違 0 項目、五分足欠落 0 枠。
- NK225: 生板の CurrentPriceTime ごとの価格を一分集約したOHLCと保存一分足の相違 4 項目。
- TOPIX: 生板の CurrentPriceTime ごとの価格を一分集約したOHLCと保存一分足の相違 3 項目。

生板との相違は NK225 の18:51・翌00:02・00:03、TOPIX の21:51・翌02:45の計5分に限られ、すべて1ティック。これらの生板最終約定時刻は各分の59秒であり、分の確定処理と遅れて到着したイベントの扱いに由来する可能性がある。ただし受信時刻と収集処理がないため原因の断定はできない。新保存一分足と旧取得一分足の一致から、今回追加による過去の価格改変ではない。今回の価格評価は保存足を正本とし、生板から作り直して差し替えない。

|NK225|2026-09-23T00:02:00+09:00|low|66750|66760|

## 生板特徴と利用可能時刻

前回の book_features.py の Extractor をそのまま再利用した。板数量の偏り、OFI、気配方向、出来高方向など全列は前回と同じ定義。板の受信時刻は保存されておらず、CurrentPriceTime は最終約定時刻のため、同時刻の多数行を単純な重複として捨てない。次の約定時刻が到来してから前ブロックを解放し、その解放先の一分が終わる時刻を available_at とする。末尾ブロックは破棄する。この遅延は先読みを避けるためであり、板の厳密な受信時刻の再現ではない。

|銘柄|生板行|範囲外行|有効板更新|特徴量の分数|解放遅延 中央値/95%/最大（秒）|最終利用可能時刻|
|---|---:|---:|---:|---:|---|---|
|NK225|121169|7|116789|610|7/63/583|2026-09-23T05:55:00+09:00|
|TOPIX|121396|8|114752|707|5/38/784|2026-09-23T05:55:00+09:00|

先頭の前日中セッションの約定状態は範囲外として除外した。同一約定時刻に後から記録された板状態を、その約定時刻へ遡って利用していない。00:28より前でファイルを打ち切る再生と、全件から00:28以前の利用可能特徴を切り出す再生を比較した。
- NK225: 特徴量 398 行が完全一致、利用可能時刻異常=0 件。
- TOPIX: 特徴量 433 行が完全一致、利用可能時刻異常=0 件。

両銘柄で観測一分足時刻が一致する本数は 583 本。相手指数の確認は確定後に利用できた情報だけを結合し、将来時刻への前方補完を行わないこと。

詳細数値、相違の全項目、欠落時刻、ファイルSHA-256は 追加データ監査.json に記録。
