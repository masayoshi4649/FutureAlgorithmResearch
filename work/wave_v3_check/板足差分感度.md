# 生板と保存足の小差に対する感度検算

保存一分足を正本とした結果は変更せず、メモリ上のコピーの5分・7項目だけを監査で観測した生板OHLC値へ置換した。各変更は1ティック。出来高は変更せず、五分足は同じOHLCV集約定義で再作成し、前回の固定条件 24_0.25_1_4_1 で追加夜間全体を再生した。真値の選択や条件調整ではない。

正本の8取引は保存済み結果と完全一致。代替側との信号状態の相違は 0 枠、実売買項目の相違は 0 項目。

|銘柄|正本／代替取引数|正本通常損益|代替通常損益|差|正本／代替厳格損益|
|---|---|---:|---:|---:|---|
|NK225|3／3|470|470|0|410／410|
|TOPIX|5／5|5|5|0|0／0|

損益単位は NK225 が円幅、TOPIX が指数ポイント。通常は往復2ティック、厳格は往復4ティックを控除。

方向、新規・返済の時刻と価格、返済理由、保有時間、通常・厳格損益は全8取引で同一だった。この7項目の差では、今回の検知評価は変わらなかった。
ATRとATR単位損益を含む全取引項目も完全一致した。

変更前一分足の再集約が保存五分足に完全一致することを確認した上で代替側を作成した。代替側の五分足は 0 項目が変化。全変更明細と検算結果は 板足差分感度.json を参照。

元1分足・5分足、前回固定コード・設定、今回の正本取引結果について処理前後のSHA-256一致を確認した。外部通信は行っていない。
