# NTペアの事前設計補足

36条件の方向閾値・枚数方式・入口・出口は `NT_固定条件.json` のまま固定する。損益の閲覧前に行った実装点検で、180秒を越える素材を欠損としたとき、過去60分の全60点が常に揃う条件では9/21デイの入力特徴がすべて欠損になることを確認した。価格を補完せず、次の有効件数規則を実装した。損益の値を見て条件を合わせたものではない。

- 60分窓内で両価格が有効な過去観測を最低40点要求する。
- 60分窓内で、前分と今分の双方が有効な１分収益率を最低30点要求する。
- 今分の両価格は必ず有効であることを要求する。持続判定は15分前も有効であることを要求する。
- 欠損価格の前値埋めや、古い素材の180秒制限緩和は行わない。

主な評価単位は、ペア２脚をまとめた完了サイクルの円損益とPF・平均勝額/平均負額である。１Rは入口判断時の解放済み60分の１分収益率共分散から、実際に決めた数量の10分標準偏差を円へ換算した予定損失幅。下限は２脚の２呼値相当の二乗和平方根。保有中には更新しない。R換算も併記し、枚数の大きい取引への偏りを確認する。

合算条件による返済は、その合算値を架空の２脚指定価格へ分割しない。判断後の各銘柄の最初の生価格で個別に返済する。費用は０円。したがって損切り１Rの指示でも、遅延・判定間隔・価格変化によって実現損失は１Rと一致しない。

損益の厳密分解は入口想定元本を `A=NK数量×倍率×NK入口価格`、`B=TOPIX数量×倍率×TOPIX入口価格`、各脚の入口後収益率を `rN,rT`、NKの売買方向を `d=±1` として、次式による。

`２脚合計損益 = d×(A+B)/2×(rN−rT) + d×(A−B)×(rN+rT)/2`

前項がNT相対変化要因、後項が共通方向に残る想定元本差要因であり、厳密に合計が一致する。後項には注文時価格と実約定価格の差も含むため、純粋な整数四捨五入だけの効果ではない。β枚数では、さらに `d×A×(rN−βrT) + d×(βA−B)×rT` も併記する。βが１と違うことで意図的に残る共通方向と、ヘッジ不足を混同しない。

mini相当の倍率はJPXの[日経225mini](https://www.jpx.co.jp/derivatives/products/domestic/225mini/)の100倍、[ミニTOPIX先物](https://www.jpx.co.jp/derivatives/products/domestic/mini-topix-futures/)の1,000倍に基づく。価格系列はラージ原本を共用しているので、実miniの板・流動性・価格差を検証した結果ではない。連続枚数は整数制約の影響を見るための診断であり、発注可能な方法ではない。
