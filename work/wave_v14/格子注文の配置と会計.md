# 格子注文の配置と会計

手動の配置方法は複数の解釈が可能なため、損益を見る前に次の再現可能な定義を採用する。18思想・３幅の54条件は `格子条件_損益前固定.json` に保存した。無制限の枚数追加は行わない。

開始20分後、ATRが利用可能な最初の有効原本行のCurrentPriceを中心とする。指値型は買いを中心より下、売りを中心より上へ等間隔に配置する。逆指値型は買いを中心より上、売りを中心より下へ配置する。上下対称型は買い５枠・売り５枠、片側型は10枠で、各枠は未約定か保有のどちらかとなる。指値と逆指値を併設する条件は、上下指値各２枠と上下逆指値各２枠の計８枠とする。対向条件を自動的に取り消すOCOは仮定せず、両建てになった枚数も総保有枚数へ数える。

幅は0.5ATR、１ATR、10呼値の３通り。10呼値はTOPIX５ポイント、NK225は100ポイントである。ATR幅は中心設定時点で固定し、呼値単位へ切り上げる。NK225に５ポイントの注文を置くことはしない。

利益幅による返済後は同じ枠を再利用する。固定配置では同じ新規水準へ戻す。逆指値の前進配置では返済価格からさらに順行１段先へ新規水準を置く。新しい注文は作成した次の原本行以降だけ有効とする。

再配置時点ですでに条件成立側にいる場合、同じ価格が続くだけで同じ利益や損失を何度も計上しない。指値・逆指値とも、一度その水準の成立しない側へ戻った後、その次行以降に再到達したときだけ約定する。例えば買い指値90を損切りした時に現在値が70でも、直ちに90で買い直さず、90より上へ戻ってからの再下落を待つ。買い逆指値110の利確後に現在値が130なら、110より下へ戻ってからの再上昇を待つ。

価格条件は前行までに決めた指定値で約定する。ギャップも指定値で約定する理想条件を用い、費用・スプレッド・数量不足を控除しない。個別損切り・追跡・固定利確の更新値は次行から有効となる。時間上限、かご全体の損失・利確・利益追跡、セッション終了による返済は、条件成立の次の有効行のCurrentPriceで行う。

かごの損益は、同じ中心を設定してからの確定損益と全脚の含み損益の合計である。かご損失５段とは「１段の価格幅×５」を全脚合計へ適用する意味であり、１枚ごとに５段を許す意味ではない。かご全返済後は５分待って新しい中心を設定する。セッション損失上限は、最初に設定した段幅を基準に、セッション全体の確定・含み損益で判定する。損切り後追加禁止の条件は、１脚でも負の損益が確定した後、当該セッションの新規・再配置をすべて停止し、残脚の返済管理だけを続ける。

日中15:05・夜間05:20以降は新規を禁止し、未約定の格子を取り消す。日中15:35・夜間05:50以降の最初の有効行で全返済を予約し、次の有効行で決済する。途中データでは未返済を最後のCurrentPriceで評価する。

サイクルは「中心配置から、かご全返済・中心再設定・新規停止後の全返済・セッション終了まで」の全脚を束ねる。途中の小幅な利確と再配置だけを独立した勝ちサイクルへ分割しない。打切り時点で全脚が返済済みでも同じ中心の再配置が続いている場合、そのサイクルは未完了とする。脚ごとの利益・損失・勝率と、全玉サイクルの平均勝敗・PFを分けて表示する。

利益玉だけ返済する危険参照も、残った含み損を全行の評価損益・最大下落へ含め、完全セッションでは最後に全玉返済する。この参照方式の高い脚勝率だけを安定した利益と解釈しない。
