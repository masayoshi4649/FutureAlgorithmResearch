# NTペアの条件と端数リスク

NK225とTOPIXを逆方向に持っても、整数枚の想定元本が一致しなければ、共通の上げ下げに対する損益が残る。この問題を利益の有無と分けて確認するため、36条件を損益閲覧前に固定した。対象は既知の７完全セッションと、以前取得済みの9/24ナイト23:19未満。現在APIは呼んでいない。

## 何を試したか

| 方向を決める思想 | 過去のみで作る判定 | 閾値と売買 |
| --- | --- | --- |
| NT比の平均回帰 | log(NK価格/TOPIX価格)が過去60分の平均から何標準偏差離れたか | 1.5 / 2.0以上なら高い側を売り、低い側を買う |
| NT比の持続 | NT対数比の15分変化÷直近60分の１分NT収益率標準偏差÷√15 | 1.0 / 1.5以上なら上昇した比率を買い、下降した比率を売る |
| 回帰残差の平均回帰 | 過去60分のlog(NK)をlog(TOPIX)で回帰し、現在残差を過去残差標準偏差で割る | 1.5 / 2.0以上なら残差と反対方向 |

方向ごとに次の６枚数方式を掛け合わせる。NT買いはNK買い・TOPIX売り、NT売りはその反対。各条件で同時に保有するペアは１組だけで、保有途中の枚数変更はしない。

1. ラージNK１枚を固定し、等金額となるTOPIX枚数を四捨五入する。
2. ラージの正整数枚を合計20枚以下で探索し、相対想定元本差が最小の組を選ぶ。
3. 過去60分の１分収益率から求めたβを0.5〜2.0に制限し、その目標ヘッジ元本との差が最小のラージ整数組を選ぶ。
4. mini相当NK10枚を固定し、等金額となるmini相当TOPIX枚数を四捨五入する。
5. mini相当の整数組を合計200枚以下（ラージ換算20枚以下）で探索する。
6. NKラージ１枚と、厳密な等金額となる連続TOPIX枚数を用いる。これは発注不能な診断。

mini相当はラージの価格に小口倍率を適用した感度分析で、実miniデータの検証ではない。４〜６は診断として表示し、発注可能なラージ候補の選択から除く。注文指示時には元本が一致していても、各脚の次行約定価格が異なるため、連続枚数診断でも実際の入口元本には少量の差が残る。

## どう実行するか

毎分判定する。ただし両銘柄とも、同じ時刻の原本ブロックを次の異なる時刻が現れるまで封印し、さらに60秒待って公開する。後方asofだけで同期し、180秒を越える古い価格を使わない。過去60分中、両価格の有効点40個・有効な１分収益率30個を最低限とする。

条件成立後、各脚それぞれが判断時刻より後の最初の有効な生CurrentPriceで新規約定する。費用は０円。１Rは事前の収益率共分散と実際に決定した枚数による10分価格変動の円換算で、保有中には変えない。

- 損失が１Rに達したら返済指示。
- 利益が2.5Rに達したら返済指示。
- 最大利益が1.5R以上に達した後は、そこから１R戻したら返済指示。
- 平均回帰方式は残差がゼロを越えたときも返済指示。
- 保有120分、または日15:35・夜05:50に返済指示。新規停止はその30分前。
- 返済指示後も２脚は各銘柄の次の生価格で個別約定する。ペア合算の指示損益と実現損益が常に一致するとは仮定しない。

## 同じ方向に１％動くだけでも端数は損益になる

NKが65,000、TOPIXが4,000のとき、ラージNK１枚は6,500万円、TOPIX２枚は8,000万円。NK１枚買い・TOPIX２枚売りでは、両方が同じ１％上がるとNK＋65万円、TOPIX−80万円、合計−15万円となる。NT比は変わっていない。

この例でmini相当NK10枚・TOPIX16枚なら元本は6,500万円と6,400万円。同じ１％上昇時の端数損益は＋１万円まで小さくなる。これはリスクの縮小であり、それ自体が新しい利益源ではない。

## カンニング・会計の確認

`NT_自己監査.json` には、144通りの未来打切りで過去の特徴・確定脚・全行資産曲線が不変であることと、境界時価控除後の会計を保存した。７完全セッションには未返済を残していない。２脚合計損益は、すべての組でNT相対変化要因と共通方向の元本差要因へ厳密に分解できた。

現在後半を評価する場合、23:19より前から保有した組は、その直前の各脚時価を新たな評価基準にして、既知の含み益・含み損を差し引く。新規約定が起きたことにはしない。`split_at_boundary` は判断・注文を変えず、この増分会計だけを行う。
