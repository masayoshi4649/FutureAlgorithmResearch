# 短い板偏りによる新規・途中判断の独立監査計画

実装と候補の固定前に作成した検査計画です。仕様確定後の監査JSONとREADMEを最終根拠とします。元データ・以前の成果は変更せず、この作業の監査領域だけに保存します。

## 検査対象

- 共通5秒格子。主情報遅延5秒、感度1・15秒、鮮度30秒を想定します。
- 5・15・30・60秒の板更新窓。価格方向・板偏りの証拠は共通格子より厳密に過去から取得します。
- 二市場一致、矛盾、中立、欠測を区別した新規判断と途中の継続・返済・反転判断。
- トレーリングは保険出口。返済実約定前に反転新規を約定させません。
- TOPIXmini片方向最大10枚、NK225micro片方向最大20枚。買いは売り気配、売りは買い気配、判断後の次有効原本行で約定します。
- 新規・返済にそれぞれ注文単位切捨ての立会手数料。利益明細と損失明細をすべて計上します。

## 入口・状態の独立検査

1. 各観測終点と窓始点を別実装の逐次探索で算出します。同時刻の先頭原本行を採り、遅延境界と同時刻末尾の未来混入を検査します。
2. OFIの区間は始点を除外して終点を含めます。ゼロ分母・同一始終点・途中無効・途中リセットを別に確認します。
3. 名目5秒窓でも実際の参照時計差は同じとは限りません。始終点の実観測間隔と証拠が不足する場合の扱いを確認します。
4. 有効中立は方向証拠の不成立、矛盾は両側の逆方向証拠、欠測は証拠を取得できない状態として分けます。欠測を中立・反転の確認時間へ加算しません。
5. 有効な連続格子の方向が同じ間だけ確認時計を進め、方向変更・欠測・リセット・格子欠落で破棄します。15秒や30秒が行数でなく時計差として成立するか境界を検査します。

## 保有中・約定の独立検査

1. 新規当行の途中追跡と保険子注文の発動を禁止する仕様か、明示された順序と一致するか確認します。
2. 確認済み逆方向、確認済み中立、欠測継続、保険ストップ、保険トレーリング、保有期限、セッション撤収が同時成立する人工経路で優先順位を確認します。
3. 返済判断、返済実約定、反転新規判断、反転新規実約定の順序を全注文の判断行・約定行・原本seqで照合します。新規時の状態再確認型と古い判断予約型を区別します。
4. 反転待機中に逆方向が消える、気配が無効化する、予定撤収に入る経路で、予約取消と最大保有枚数を確認します。
5. トレールは前観測までの極値・保護線で成立を確認し、その後に当観測の極値を更新するか、凍結仕様に照合します。
6. 全返済明細の損益と料金を独立FIFOで再構成し、全注文・清算時価曲線・期間商品集計と一致させます。含み損と損失玉を隠しません。
7. 配列末尾で架空返済せず、固定セッション時刻で撤収判断します。次有効気配待ちの予定時刻超過と判断から約定までの遅れを計上します。

## 敵対的な人工経路

- 両市場一致の上昇・下落、片方だけ逆向き、板偏りだけ強く価格が進まない、短い往復。
- 一致が14/15/16秒・29/30/31秒続く境界、格子1回欠測、中立と矛盾の交互、直接逆転。
- 片側だけ更新停止、同時計に多数の板更新、同時計先頭が無効で末尾が有効、鮮度30秒境界。
- 返済待ち中に気配消失、新規約定直後に反転、返済約定時に場末、両注文が同じ時計で別seq。
- 片方だけ前セッション、日跨ぎナイト、片市場全欠測、双方空、二市場の役割交換。
- 急落・急回復、狭い気配から広い気配へ変化、価格と板証拠が逆向き。

## 未来参照と選定

人工および保存経路で片側だけの未来価格・板・品質・時計を改変し、時計と同時計途中seqで原本を切断します。変更前の共同状態、判断、注文、決済、清算曲線が一致することを確認します。切断後は未返済を許し、保存末尾で自動清算しません。

前16場の比較と後13場の固定確認を区別し、後半成績や遅延感度から代表を選び直していないか確認します。いずれも既知保存データであり、真の未見期間とは呼びません。

共通受信時計がないため、検査の因果性は最終約定時刻の代理時計上と各銘柄内の原本順に限ります。実際の両市場の受信順まで証明しません。原本の新規取得、現在API取得、実注文は行いません。
