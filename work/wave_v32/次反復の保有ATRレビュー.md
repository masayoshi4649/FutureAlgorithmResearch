# 保有中のATRを追跡幅へ使う比較の重複確認

**考え方自体は既試行。ただし、現在の12入口・D273で追跡幅のATRだけを更新する対応比較は確認できなかった。** 今回は実装・設計・保存済み条件の読取りだけで、新実装・新損益再生・現在データ取得はしていない。

## 最小の次比較案：12入口×2方式＝24条件

対象は旧12入口`H003,H011,H019,H027,H035,H043,H051,H059,H067,H075,H083,H091`の全部。選択器A/Bは組み合わせず、各入口に同じD273、TOPIX5枚／NK10枚、同じ原本13セッションを適用する。

- **固定方式**：現状どおり幅`3A0`。
- **更新方式**：幅だけ`3At`。`A0`は未約定注文を準備した時点に固定したATR、`At`は現原本行で既に利用可能なATR。確定5分足の開始＋360秒で解放する既存列を使い、下限2呼値も維持。欠損時は最後の有効値を保持し、最初はA0。

初回枚数×1A0の組損失予算、追跡開始1.5A0順行、2A0での部分利確、数量・端数処理、360分上限、休止5分、入口・注文期限・場末処理は変えない。買いの候補線は保有後最高値−3At、売りは最安値＋3At。既存線より保護が強い時だけ更新し、同じ行で遡及約定させない。更新線が既に現価格を通過していれば、旧仕様と同じく次行成行で扱う。

**追跡開始の1.5A0へ届く前には効かない。** 他の損切り線が先に効く場面でも差は出ない。ATR再拡大時に既存線は緩まないが、新しい極値に対する候補線は固定方式より遠くなり得る。値動きの縮小を「トレンド終了」と誤認し、継続波の途中で降りる反例も想定する。

比較は同じ入口どうしの全12対応組を両銘柄別に表示し、収支だけでなく含み込みDD、利益返却、取引回数、保有時間・指定波20分保有、台帳同一率を併記する。共通7セッションと全13を分け、9月29日だけで倍率・ATR期間・時刻閾値を調整しない。固定方式の旧台帳完全一致、ATR変化以外不変、未来ATR改変・prefix・上下反射・次行更新を先に監査する。

これは**既試行の発想を現在の注文構造で切り分け直す案**であり、新しい優位性の発見や解決策の確定とは呼ばない。
