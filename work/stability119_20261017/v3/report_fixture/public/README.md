# 小枚数と順行増加の比較と全セッション損益

最初に[小枚数と順行増加の比較と全セッション損益.html](小枚数と順行増加の比較と全セッション損益.html)を開いてください。全36規則の共通順位から異なる入口家族を最大3つ表示します。各条件の全40場、全比較、小枚数・全枚数・増加法の対照は折り畳みに残します。

全40場を知った後の開発です。確認13・追加3を未知検証成功とは呼びません。上限はTOPIXミニ10枚・日経マイクロ20枚。親完結netの総正負がP/Lで、無取引・零収支・未返済は勝ちに数えません。

小さく張っただけで損失が減った効果と、順行してから増やした効果を同入口・同追尾幅で比較します。増加法は追加と停止線を合わせた政策で、追加だけの独立効果とは呼びません。円リスク固定は設計上の停止線であり、飛びや費用を無視した実損失保証ではありません。合計黒字だけで採用せず、中央値・最悪・上位3黒字除外・未返済を確認します。

[data.json](data.json)は全36条件の小会計です。原結果 `合成専用/三配分.json`、SHA256 `bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb`。原結果は指定SHAで一読し、同bytesを私有保全します。実小型板の待ち順位・真受信時計は未証明です。
