# 既知時刻を避ける根拠と検証の限界

2026年10月17日に、第四対照の金融実行前に記録。

第三対照のTOPIX・共同追従増玉型では、10月2日ナイト21:26:01に2枚を4136で買い、21:29:18に2枚を4139で追加し、21:29:50に4枚を4110で返済した。初回の予定損失予算は9,110.27円、実際の純損失は110,333円だった。停止線4135.3057で売れたとは仮定していない。

[米労働統計局の2026年発表予定](https://www.bls.gov/schedule/2026/home.htm)は10月2日の米雇用統計を東部時間08:30としている。[NYSEの取引時間](https://www.nyse.com/markets/hours-calendars)は通常市場の開始を東部時間09:30としている。日本時間への変換には `America/New_York` を使い、夏時間・冬時間を固定の日本時刻で代用しない。

ただし保存価格時計の損失は発表予定の10秒前で、真の受信時刻もない。**この損失が雇用統計により発生したという因果関係は確認していない。** 発表値や発表後のニュース本文は新規判断へ使っていない。

今回の対照は、国内08:45〜09:15、ニューヨーク08:30と09:30の各前後15分を毎日保守的に避ける。特定の負けた日だけを避ける日付一覧は使わず、休日例外も追加しない。元の順方向・逆方向の双方へ同じ規則を当て、逃す利益と新たな後参加も全て計算する。

実装は既存エンジンを変更せず、窓内の足公開時に新規禁止と全返済判断を与える。したがって窓の開始秒にタイマーで返済する模型ではなく、次の正常な公開まで判断が遅れ得る。同じ原rowでは気配処理が先なので、直前の注文が窓内の最初の気配で先に約定し、その後に返済判断が出る場合も残す。入口資格を消すため、場損失予算の最初の有効幅も後ろへ移り得る。

全40場を見た後の原因対照であり、ここで改善しても未知データの成功や発表時刻回避の因果効果の証明とはしない。
