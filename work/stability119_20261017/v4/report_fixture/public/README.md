# 順逆売買と時間回避の比較と全セッション損益

最初に[順逆売買と時間回避の比較と全セッション損益.html](順逆売買と時間回避の比較と全セッション損益.html)を開いてください。共通48規則を同じIDで両商品へ適用し、異なる元入口家族から最大3規則を上部へ掲載します。全48の全40場と方向・時刻の四通り対照は折り畳みに残します。

全40場を知った後の開発です。確認13・追加3も未知検証ではありません。TOPIXミニ10枚・日経マイクロ20枚、費用後の完結親netの総正負がP/Lです。無取引・零収支・未返済を成功へ変えません。中央値・最悪・上位3黒字除外・手数料・未返済を常に併記します。

元と同じ候補公開時点のentryを順方向又は逆方向にし、実際の買ask・売bidで運転をやり直します。旧収支の符号反転ではありません。撤回条件も左右交換し、反転後の損益で出口・再参加・場停止を判定するので、実際の入口時刻の集合は一致しません。

時刻回避は日本08:45以上09:15未満と、NYの毎日08:30/09:30の前後15分です。America/New_Yorkの夏時間を使い、休日例外は設けない保守窓です。ニュースの数値は使いません。窓開始そのもののtimerではなく、その窓にある価格時計の足公開で新規拒否・待機取消・保有返済を判断します。同原行ではquoteが先なので新規が約定してから返済判断となり得ます。入場資格を消すため、場予算の最初の有効Rも後ろへずれ得ます。

[data.json](data.json)は全48小会計です。原結果 `合成専用/順逆時刻.json`、SHA256 `aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa`。指定元を一読して同bytesの私有copyを保全します。実小型板の待ち順位・真受信時計・約定遅延の再現は未証明です。
