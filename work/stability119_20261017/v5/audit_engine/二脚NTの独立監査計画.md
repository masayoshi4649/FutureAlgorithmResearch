# 二脚NTの独立監査計画

旧00009のNT検証を、両脚の現実気配、mini/microの整数数量、注文別手数料を含めて再検証する。新発明とは扱わない。完成源と正式計画の固定前は市場・保存結果を読まず、金融実行もしない。

## 因果性と数量

- 二市場の原rowは相互比較しない。共通の価格時計で既知情報を結合し、足の確定と公開の双方を条件とする。過去のモデル学習と現在の観測を分離する。
- 判断時計と同じclockの気配では各脚を約定させない。二脚は別々の次観測で約定し、先に入った脚の損益とリスクを消さない。
- 価格やβから整数ヘッジ数量を選ぶ目的関数、探索範囲、同率時の優先順を正式源で固定する。未来の価格を使って数量を再計算しない。

## 小人工で反証する点

| 素材 | 必須の結果 |
|---|---|
| 同clockの二脚、片脚だけ次clockへ進む | 同clock約定なし。先に進んだ脚だけ保有する時間が残る |
| 二脚の観測順序を交換 | 当時の情報だけで先後を処理し、約定価格を都合よく選ばない |
| 一脚が60秒以内に約定せず、後から価格が現れる | 未約定を取消し、既約定脚は仕様に定めた次気配で返済。二脚成立へ遡及しない |
| 買い・売り両方向、割り切れない数量と注文費用 | 各注文の切捨て手数料、各脚gross、合計cashを手計算と一致させる |
| 片脚だけ含み損を持つ途中、両脚成立後の乖離拡大 | 両方に将来返済料を含む清算MTMとDD。無リスクの両建てと扱わない |
| セッション末尾で気配が欠ける | 全返済できなければ未清算を明示し、仮想EOF価格で決済しない |
| 同じ過去に異なる未来を接続する、途中prefixを切る | その時点までのモデル・判断・発注・約定・MTMが不変 |
| 不正気配、古い片側時計、空足、学習幅不足 | 未知情報の補完なし。学習モデル又は新規資格を無効にし、既保有リスクを隠さない |

timeoutの決定が固定期限のタイマーなのか、期限超過を観測した時計なのかを源で固定してから期待値を作る。実装と同じ誤りを複写しないよう、少数の人工注文について時刻・現金・枚数を手計算する。

## 保存結果の独立会計

根が完成SHAを通知した後、4条件×40場＝160組の保存結果と脚別台帳を一読保全する。既所有の気配だけで各脚の約定時刻/BBO、注文費用、現金、清算MTM、親合計、場末残数量、全期間合計を照合する。新しい金融再生と候補の再選択は行わない。整合監査を新しい有効性標本へ数えない。
