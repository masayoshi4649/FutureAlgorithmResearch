# 公開後の二試行を比較する機械規則（収支計算前）

## 共通の帯を先に作る

各銘柄に同時に1帯だけを持つ。未準備時、30秒前まで連続した公開中値を使い、現在中値が0.10ATR以上上なら上側の最良売気配を抵抗帯P、下なら下側の最良買気配を支持帯Pとする。方向dは上抜け+1、下抜け−1。ATRとPは準備時に固定する。

主母集団の帯は、その絶対価格Pが過去30秒の全スナップショットで同じ側の10段内に存在し、可視数量が一度減った後に一度増えたことも要求する。価格独立対照はこの数量条件だけを外す。過去30秒の回復を、その後の試行1の成績へ混ぜない。

最大30分で帯は失効し、価格へ合わせてPをずらさない。帯消費後も、同じ側・同じPの準備は前の準備から30分以内には再度行わない。長く居座る失敗帯も母集団から消さない。

## 二つの試行

1. 帯準備の公開行から試行1を開始。30秒以上経過した最初の公開で終了。
2. その終了以後に、帯から防御側へ0.5準備時ATR以上離れることを要求する。その後、帯の1呼値以内へ再接近した別の公開から試行2を開始。同じく30秒以上経過した公開で終了。
3. 試行ごとに、固定価格Pでの可視減少量、最初の減少後の可視増加量、最大押し返し距離 `max(0, d*(P−mid))/準備時ATR` を記録する。回復比率は増加÷減少。減少0、途中の可視外、数量不正は不明で、0と扱わない。二試行の間の数量差分は加算しない。
4. 全方式は同じ二試行と初回突破を先に列挙する。主案は回復比率と押し返し距離がともに試行1より試行2で小さい時だけ採用する。価格だけは数量条件を外す。板の条件で帯の寿命・再準備時刻を変えない。
5. 試行2確定より後の新しい公開で、上抜けなら買気配がP+2呼値以上、下抜けなら売気配がP−2呼値以下になった初回だけを突破とする。その次原本行以降に新規。

試行中又は二試行を待つ間に同じ2呼値突破が起きた場合は、全共通方式で帯を消費し、早過ぎた突破として記録する。試行中の将来30秒を使って突破前へ注文を戻さない。「二試行を待たない価格突破」を独立対照として別に残す。

試行終了と突破が同じ公開行なら早過ぎた突破を優先。失効時刻と突破が同じなら失効を優先する。試行1終了行で離脱を確認してよいが、試行2開始は離脱より後の公開行に限定する。開始量から差分を積み、試行間の数量差は使わない。累積差分比は数量の往復でも変化する代理量であり、底から元の量へ戻った割合ではない。

価格時刻の非連続・最良気配不正は全共通方式の観測を中断し、その帯を中止として記録する。数量だけが不明なら価格の母集団は保ち、板比率だけを不明にする。10段外を0数量として差分へ入れない。

価格の公開品質は現在最良気配・公開ATRが有効で、公開間隔と素材遅れがそれぞれ0超60秒以下とする。旧特徴のreset総数には数量不正が混じり得るため、reset0は数量比較の品質にだけ課す。公開間の全原本価格が連続だったとは主張しない。帯生成窓は現在時刻−30秒以下の最新公開を左端とし、その時刻との差60秒以内を要求する。実際の窓長も保存する。

## 売買と対照

v39の1枚エンジンを変更せず再利用する。準備帯のATRは試行の距離にだけ使い、実際のリスク幅は新規判断行の公開ATRと2呼値の大きい方を切り上げ。次行新規、1r損切り、2r利確、最長30分、返済後5分休止、場内全返済。指定価格・費用0、伝達1/5/15秒と観測価格返済を別対照とする。

数量弱化のみ、価格弱化のみ、条件なし、最後の比率/押し返し水準、二試行の平均水準、強化判定、売買反転、相手の60秒遅延した直近5分価格一致、時間窓と距離の感度、同候補の方向乱数を比較する。価格独立対照は別の母集団なので、純粋な板追加効果の対応比較とは呼ばない。

まだ最終固定ではない。独立レビューで矛盾を除去し、人工入力・因果検査を通した後、条件一覧と採否を固定する。頻度は先に確認するが、収益を見て規則を作り直さない。
