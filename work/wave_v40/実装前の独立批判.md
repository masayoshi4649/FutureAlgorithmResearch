# 同価格への再接近と可視数量の変化：実装前の独立批判

この案は検証する価値がある。ただし問えるのは「同じ価格への再接近という価格条件に、過去の可視数量の回復順序を加える価値があるか」である。約定による消耗、同一参加者の補充、隠れた注文の防衛は、この保存データだけでは識別できない。以下は損益を見る前の仕様提案であり、新規売買・現在データ取得・閾値探索は行っていない。

## 先に塞ぐべき問題

1. **30/60秒の試行が終わる前には、最小数量・回復比率・最大押し返しは確定しない。** 第二試行の終了後に弱まりを判定し、それより後の新しい突破だけを注文対象にする。試行中に既に突破していた場合は「予兆が間に合わなかった」と残す。同じ突破へ時刻を遡って入ると先読みになる。
2. **戻って来た試行だけを集めない。** 回復せず突破した接近、観測不足、可視外へ出た接近も、価格から先に列挙した全接近の記録へ残す。成功した防衛が二回あった帯だけを示すと、強い突破を母集団から落とす。
3. **「前回より弱い」は注文の消耗だけでは説明できない。** 相場の方向、変動、接近速度、試行間隔でも数量や押し返しは変わる。価格だけの同時刻対照に対する差がなければ、板履歴による付加価値は支持されない。
4. **上位10段の外は数量0ではない。** 段から消えたことを取消・消耗と数えない。固定価格が反対側へ移った場合も、売り板と買い板を同じ待ち行列として連結しない。原本の欠損、重複価格、順序不正、交差・ロック、時刻逆行は別途拒否または欠測化する。

## 最小で明確な計測案

- **公開素材を固定する。** 旧 `legacy.parse_snapshot` の内部板は上位5段なので使わず、原本 `Buy/Sell1..10` を厳密に読む。`source_last_seq` の板を既存の解放 `seq/time_s` で公開するのか、解放行そのものの板を使うのかを一つに決める。前者を推奨し、素材と解放の両行・両時刻を保存する。後者にする場合も、その行を既存特徴の素材末尾と呼ばない。
- **帯の生成と条件評価を分ける。** 事前に決めた初回の最良売り／買い価格を固定し、価格・側・発生時刻・その時点のATRを帯IDへ記録する。後の反応で帯を選び直さない。純粋な価格対照を作る場合は、板数量条件を帯の生成にも使わない。30分の寿命とセッション末で終了し、再接近によって寿命やATRを更新しない。同時に追う帯数と重複時の優先順も先に固定する。
- **別試行の条件を数式にする。** 同じ側から固定帯へ接近した時計を開始とし、次の試行には、前試行終了後に内側へ0.5初期ATR以上離れた観測と、その後の再接近を必要とする。「内側」「接近」の価格には同じ公開中値を使い、接近許容幅は事前に固定する。同一観測を二試行へ重複所属させない。
- **数量回復は固定窓で測る。** 親草案の定義なら、試行開始数量を起点にした隣接公開間の負変化の絶対和をD、最初の負変化後の正変化の和をUとし、`u=U/D` とする。試行前や待機中の変化を混ぜない。D=0は「減少を観測せず」であり、回復0や完全回復に置換しない。これは累積可視増減の比で、底からの回復率とは違う。往復が多いと1へ寄り得るため、U/Dと併せてU・D・開始／最小／終了数量を保存する。固定価格が比較中ずっと同じ側で見えたか、標本数、最大公開間隔、素材の古さも残す。
- **押し返しは数量と独立に測る。** 売り帯では帯より下、買い帯では帯より上へ戻った最大距離を、固定ATRまたは呼値で規格化する。試行終了時以降にしか確定しない。公開板間の価格だけを使うか原本価格を使うかを明記し、主案と対照で統一する。
- **第二試行が完成した時刻で初めて比較する。** 二つの回復比率と押し返し距離、各差、公開品質を保存する。弱まり成立後の新規注文は次の有効観測以降とし、既に帯を突破した観測への遡及約定は禁止する。測定不能や先行突破も全接近表には残す。

公開間隔が2〜12秒程度なら、30秒試行に含まれる観測は少ない。数量が減って戻る過程を見逃し得るため、「公開スナップショット間の可視数量変化」と表記する。原本全行を使った数量変化と、今回の間引かれた公開列の変化は同じ指標ではない。

## 必要な対応対照

| 比較 | 共通に保つもの | 分離する問い |
|---|---|---|
| 価格だけ | 帯ID・全接近・判断時刻・公開品質・注文管理 | 押し返し低下だけで説明できないか |
| 直近試行の板だけ | 同じ二試行を終えた時点 | 履歴の差ではなく現在の薄さ／回復水準だけでよいか |
| 二試行の順序なし平均 | 同じ二試行、同じ標本と判断時刻 | 低下する順序が必要か、平均的な板水準で十分か |
| 順序反転の診断 | 現時点までに完了した同じ二試行 | 弱まりと強まりを区別する意味があるか |

比較可能な板がある接近に限定した対応比較を先に行い、全価格接近での価格対照も別表示する。これにより、板による予測と「板が見える場面に参加を限定した効果」を分ける。対照ごとに帯を作り直したり、最良の帯や入口へ差し替えたりしない。

## 損益前に確認する反例

未来の数量・価格を変えても既発行の帯／試行／判断が変わらないこと、30/60秒境界・同時刻の途中切断、価格反射、帯失効、可視外からの再出現、数量不変、減少後に全回復、分母0、試行中の先行突破を人工で確認する。主案と対照の帯ID・接近集合・測定可能集合の一致も必須とする。

まず全26入力の帯数、別試行数、二試行比較可能数、先行突破数、可視外・欠測・分母0による不成立数を損益とは別に示す。少なければ今回の素材では判断材料不足であり、板一般の無価値とはいえない。既知13セッション内の好成績は、何度も探索した後の未知相場での優位を新たに証明するものでもない。

## 親の状態機械草案への限定レビュー

[状態機械の草案](状態機械の草案.md)は、帯を同時1本、二試行前の突破を全共通方式で消費、板不明でも価格記録を保持する点で上記の懸念へ対応している。主の帯生成に事前の数量減少→増加を要求するので、その帯内の「価格だけ」は板起点を共有する条件除去である。別の純価格帯との比較は、機会が同一の成分比較と呼ばない。

固定前に、試行終了と突破が同じ公開行なら早過ぎた突破を優先すること、30分失効と同時なら失効を優先することを明記する。離脱と再接近は別公開行とし、第二試行の数量差分はその開始数量から測る。[反証条件の草案](反証条件の草案.md)の「順序なし」は価格の `b2<b1` を残すため、除いているのは板の順序だけである。試行時間30/60秒のどちらを主とするかも、両草案を一致させてから固定する。
