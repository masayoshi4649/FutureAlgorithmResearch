# 公開10段の抽出

`released_depth.pkl` は既知13セッション・2銘柄を `(session, symbol)` で参照する辞書。各値は公開イベント順の配列であり、売買や帯の検出は実行していない。

`features_depth.pkl` の `seq` と完全一致する生板原本行から、`Buy1..10` と `Sell1..10` を直接抽出した。旧実装の5段map、過去ブロックの平均数量、後続の同秒行は使わない。これは当該公開行の板であり、公開の間に存在した全注文イベントではない。

| 列 | 意味 |
|---|---|
| `seq` | 生板JSONLの0始まり原本行番号 |
| `ready_index` | 同じseqに対応するready配列の行番号。seqと混同しない |
| `time_s` | 当該原本・公開表・readyで一致するCurrentPriceTimeのUTC秒 |
| `bid_prices/ask_prices` | 公開10段の価格。shape=(公開数,10)、最良は[:,0] |
| `bid_qty/ask_qty` | 上記価格に対応する数量。欠測・可視外はNaN |
| `atr` | 同じready_indexで利用可能な既存公開ATR。補間や未来参照なし |
| `price_valid` | 最良価格が有限正値で買い<売り。数量や深い段に依存しない |
| `best_valid` | price_validかつ両最良数量が正値 |
| `depth_valid` | 全10段価格数量が有効、厳密順序、重複なし、最良数量正値 |
| `clock_quality` | 素材遅れと前公開gapがそれぞれ0秒超60秒以下 |
| `publication_quality` | clock_qualityかつcontinuity_reset_count=0。数量比較用 |
| `atr_valid` | 公開ATRが有限正値 |
| `valid` | depth_validかつpublication_qualityかつatr_valid |

価格母集団は `price_valid & clock_quality & atr_valid` として数量品質から分離できる。reset総数は数量不正等も含み得るため、価格だけの母集団へ直接課さない。初回の前公開gapは不明なので時計品質はfalse。数量0は観測された0であり、見えない価格の数量とは区別する。重複・欠測・順序不正・交差は別列として残す。

全106,451公開行の20段価格・数量を原本から別式で再照合した。全26入力で2切断ずつのprefixと未来原本・ATR改変、上下反射を検査し、原本26ファイルの開始前・終了後SHAは一致した。結果と実装指紋は `released_depth_audit.json` と `released_depth_fixed.json` に保存した。

時刻は受信時刻ではなく最終約定時刻の近似。公開間の原本価格が常に連続していたとは主張しない。数量減少から約定・取消を区別できず、数量増加から同一参加者による補充とも断定できない。
