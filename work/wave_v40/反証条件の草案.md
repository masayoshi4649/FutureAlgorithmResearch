# 同じ価格帯の試行履歴に、情報が加わるか

**未固定の設計案。売買・採否コードや既存結果は変更していない。新しい損益の計算もしていない。** [研究の出発点](研究の出発点.md)と[v38の仮説2](../wave_v38/次の独立仮説候補.md)を、価格だけでも説明できるという反対仮説から検査する。

## 先に揃えるもの

共通母集団は、固定した価格帯P、方向d、準備時の公開ATR A0、重複しない2回の完了試行、試行後の最初の突破確認までを、採否とは別に記録する。主方式が採用した帯だけを価格対照へ渡さない。比較条件が不成立でも共通帯の消費・失効・再準備を変えず、同じ帯を望む反応まで待ち直さない。

試行jの可視回復比率をu_j、帯からの最大押し返し距離をb_jと置く。主案は `u2 < u1 かつ b2 < b1` の後、別の公開行で確定した突破方向dへ入る。両試行の値は完了時に固定し、後の突破・利益を見て再計算しない。同値は弱化とせず、不明は0にも中立にも変えない。uの分母が0、同じ絶対価格を追跡不能、必要な履歴に不明区間があれば板履歴比較は不成立とする。

共通母集団を次の2層で残す。

- **価格の共通記録**：帯・再接近・押し返し・突破を追える全記録。板履歴が不明でも削除しない。
- **板履歴が比較可能な記録**：上のうちu1/u2も計算できる記録。情報成分を分ける主な対応比較はここで行い、除外数も出す。

最初の帯を板で生成する場合、この母集団内の「価格対照」は板起点を共有している。板を全く使わない価格帯生成も別に置き、純粋な価格戦略との比較と混同しない。

## 対照の最小構成

| 条件 | 主方式と揃えるもの | 変えるもの・判定 | 主張を否定する結果 |
|---|---|---|---|
| 主：回復・押し返しの弱化 | 固定帯、2完了試行、初回突破、共通出口 | u2<u1、b2<b1でdへ | 活動不足、非黒字、集中依存なら成功としない |
| 価格のみ・同じ比較可能記録 | 帯、板の可用性、b2<b1、突破時刻の候補 | uの条件だけ外す | 上回らなければ、板の弱化に収益の追加価値を確認できない |
| 価格のみ・共通記録全体 | 帯、価格試行、突破・出口 | 板履歴不明も価格が有効なら対象 | 上の差が板可用性での間引きだけかを区別する |
| 最後の板だけ | 比較可能記録、b2<b1、突破・出口 | u1との大小を使わず、u2が事前固定水準未満ならdへ | 同等以上なら、前回との変化を持つ理由が弱い |
| 順序なし | 同じu1/u2、比較可能記録、b2<b1、突破・出口 | (u1+u2)/2が事前固定水準未満ならdへ。u1/u2交換で不変 | 同等以上なら、**板の時間順序**の追加価値を確認できない |
| 板の逆判定 | 比較可能記録、b2<b1、突破・出口 | u2>u1でもdへ入る。等号は両方不採用 | 強化側でも同様なら、弱化の符号に根拠が乏しい |
| 売買方向反転 | 主案の全候補時刻・採用帯 | 成立後の方向だけ−dへ | 逆方向が同等以上なら、想定した突破方向の根拠が乏しい |
| 同機会方向乱数64通り | 主案の全候補時刻・採用帯、固定seed 0〜63 | 公開元ごとの固定符号をdへ掛ける | 主が乱数中央値を超えなければ、方向の優位を確認できない |
| 板に依存しない価格帯 | 既知期間、公開・次行規則、共通出口 | 過去価格だけで帯を作る。板数量・品質で間引かない | 帯生成を含む全体が価格だけを上回るか。ただし機会の一致した成分比較とは呼ばない |
| 相手市場の確認 | 自市場の主候補を先に固定、共通出口 | 追加60秒後に利用可能な相手価格の同方向確認だけを加える | 確認なしと同じ確認後機会の乱数を超えなければ、相手情報の追加価値は未確認 |

最後の板と順序なしの水準は、uが「回復量÷可視減少量」なら、まず自然な境界1を共通にする案とする。過去成績や発火数に合わせて閾値を調整しない。主案と採用数が一致するとは主張せず、対象数と活動数を併記する。uの定義が別になる場合は数値も起動前に決め直し、実装仕様へ明記する。

「順序なし」は板情報だけの順序を除く対照で、価格側のb2<b1は残す。この比較だけで全ての順序情報を否定したとは言わない。追加するなら、価格の順序条件も外すものを別IDにし、主対照と混ぜない。

同機会乱数と反転は**発注候補時刻**を揃える。約定後の退出・5分休止が異なるので、実際の約定時刻や取引回数まで同じになるとは限らない。相手確認の失敗を主案の失敗へ混ぜず、相手確認だけの成功でも主案を差し替えない。

## 窓・距離・執行の反証

| 感度 | 変更案 | 保持する条件・独立に記録する差 |
|---|---|---|
| 帯の生成窓 | 暫定30秒を0.8/1.2倍 | 試行時間・距離・採用式は固定。共通帯自体の入替を記録する |
| 試行の確定時間 | 暫定60秒を0.8/1.2倍 | 帯生成・距離は固定。完了時刻とu/bの変化を分離する |
| 試行を分ける離脱距離 | 暫定0.5A0を0.4/0.6A0 | 窓・入口確認距離を固定。別試行と認める回数を記録する |
| 突破確認距離 | 暫定2呼値を1/3呼値 | 時間窓と離脱距離は固定。丸め後に同じ値の条件は独立な感度件数に数えない |
| 注文伝達 | 0秒に対して1/5/15秒 | v39注文器の親注文・返済子注文へ各々適用。入力を遅らせた検査と呼ばない |
| 返済価格 | 指定価格に対して到達後の観測価格 | 費用0を維持。新規・時間返済は元から観測価格。費用追加と区別する |

各変更は一軸ずつ。少なくとも主・価格のみ・最後の板・順序なし・逆判定へ同じ変更を課し、都合のよい近傍だけを採用しない。合計だけでなく各銘柄・各感度を出す。帯・試行IDは設定間で意味が変わるのでIDの一致だけで対応させず、同じ準備原本行・帯価格・方向、同じ入口原本行の保存数を別に記録する。近い時刻だから同じ因果事象とは断定しない。

## 採否の案

**v39の1枚注文器は無変更で使用する。** 判断時公開ATRと2呼値からrを固定し、1rストップ／2r利確、約定30分後と場末に市場返済を予約、返済後5分休止。時間は予約の基準であり、次行・伝達待ちやギャップ後の約定までを保証する上限ではない。保有中の候補を蓄積しない。各市場1枚、増玉・両建て・数量調整なし。

| 判定段階 | 起動前に固定する提案 |
|---|---|
| 可用性・機械実装 | 全原本順序・公開元・売買反射・未来変更・場内完結・全玉会計を通過。帯候補数→2試行完了数→比較可能数→初回突破数→採用数→実取引数を全段階保存 |
| 基礎成績 | 両銘柄で20決済以上、6活動セッション以上、ロング・ショート各3以上、収支>0、PF≥1.2、平均利益÷平均損失≥1.2。最大勝ち取引と最大黒字セッションをそれぞれ除いても収支≥0。未定義・非有限比率は不合格 |
| 板履歴の追加価値 | 両銘柄で主の合計Rが、同じ比較可能記録の価格のみ・最後の板・順序なし・板逆判定・方向反転・主と同機会の乱数64中央値を全て上回る。円収支も必ず併記 |
| 戦略全体の価格対照 | 独立価格帯方式との合計R・円収支・DD・活動量を別欄に出す。これを上回れなければ、板履歴の局所差があっても「価格戦略より有用な全体手法」とはしない |
| 実行感度 | 主の1/5/15秒と観測返済価格の4条件で、両銘柄とも同じ基礎成績を満たす。対照にも同じ執行を適用し、情報比較が逆転した場合は隠さない |
| 窓・距離の安定性 | 上記8近傍を全表示。各銘柄で6/8以上が黒字かつPF≥1.2、全8の収支中央値が主の50%以上、最悪が主の−25%以上、を暫定案とする。活動不足の近傍を有効な成功件数へ数えない。数値は成績を見る前に親仕様で確定する |

無取引や数件の好成績は「検証不能／活動未達」であり、弱化仮説の成功ではない。基本条件を満たすほど活動があっても対照差がなければ「板履歴の追加価値を確認できない」とする。全市場・未来で無価値と証明したとは言わない。

同一候補母集団の5/15分後の方向・逆行先着を評価専用に残すと、値動きの情報と返済・休止による口座差を分けやすい。採用された取引だけを標本にせず、確認できない場末ラベルは除外理由を保存する。窓の重複を独立標本数とせず、正式な有意確率は出さない。

## 未決点と範囲

- uの正確な定義、同価格の観測欠損、試行終了の等号、帯の失効／再武装／同時両側成立は、親と入力担当の状態機械で確定する。採用条件ごとに準備経路が変わらないことを人工で検査する。
- 独立価格帯は、未来の山谷ではなく過去価格の高安などから機械的に固定する。生成式と相手価格確認式・古さ上限はまだ未確定であり、成績を見た後で選ばない。
- v40が学習を使わないなら、v39の初期2セッション除外を機械的に引き継がず、全方式で同じ13セッションを評価する。v39の11活動対象との円額比較を同一期間・同一母集団と呼ばない。
- 13セッションは全て既知。週・日中／夜間・祝日取引の内訳を表示しても、曜日や休日を後付けの売買スイッチにしない。1枚固定出口の結果から、長い波を継続保有できるとも結論しない。
- 可視数量の減少は取消と約定を分けず、増加は特定参加者の補充ではない。10段外・未公開・不明を0へ置換しない。測るのは公開スナップショットで見える同価格の変化である。

この草案には新しい損益・採用実績はない。現在API、保存ライブ、新しい売買再生は使用していない。
