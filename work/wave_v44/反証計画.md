# 順行後の減量許可：結果前の判定規則

主案は `G150_F25_N1__V000`。単一H019中央で、共通影A0が初期ATRの1.5倍順行した後、新しいB00悪化公開で25%を最大1回減量する。主35・悪化符号64・回復符号64の全163を保存する。別閾値・別配分・乱数最良へ主案を差し替えない。

この規則は新しい実相場損益を読む前に、[assessment.py](assessment.py)と[人工検査](check_assessment.json)へ固定する。[設計案](反証設計案.md)の論点を、次の判定に具体化した。

| 判定 | 固定する条件 |
| --- | --- |
| 全条件の基礎候補 | 全13／既存の後7×両銘柄の4セル全てで、収支>0、元組PF>1、平均勝ち元組／平均負け元組>1。最大1勝ち元組除外と最大1黒字場除外を別々に計算し、各非負。取引があり、買い開始と売り開始が双方ある。 |
| 主の中央改善 | 無ゲートC01比で、後7は両銘柄の円収支が厳密増益、全13は両銘柄で非減益。A0比は別の同じ比較を表示する。 |
| 実調整の作動 | 主の4セル全てで、実際の減量と復元が各1回以上。未作動の黒字をゲート機構の成功にしない。 |
| 経済研究候補 | 全監査完了＋主の基礎候補＋中央改善＋実調整の作動。 |
| 12感度の基礎 | 閾値2・入口2・悪化窓2・回復窓2・執行4について、各後7の両銘柄で収支>0、元組PF>1、平均元組勝敗比>1。全13・大勝ち除外・活動も全表示する。 |
| 入口時計の集中耐性 | 主の入口時計0.8／1／1.2全てが、上記4セルの基礎・大勝ち除外・活動を通過。元C01／A0も同じ3点を横並び表示。 |
| 耐性付き研究候補 | 経済研究候補＋12感度の基礎＋主の入口時計の集中耐性。 |
| 悪化情報の利益差支持 | 実調整が作動し、主の総RがINV・AV_ALL・悪化64の中央値それぞれに対して後7両銘柄で厳密超過、全13では非劣。 |
| 回復情報の構造保存対照超過 | 実調整が作動し、主の総Rが回復64の中央値に後7両銘柄で厳密超過、全13では非劣。復元なし対照がないため、復元すること自体の価値と呼ばない。 |
| 情報対照を通過した研究候補 | 経済研究候補＋悪化情報の利益差支持＋回復情報の構造保存対照超過。耐性は独立に併記。 |

収支と含み込みDDの全4セル同時非劣位は、強い改善の別ラベルであり、唯一の採用条件にはしない。DDが増えた場合は額を示し、増益との交換を隠さない。耐性や情報対照で未達でも、中央が黒字だった事実や旧C01の基礎候補を全否定しない。

利益・損失・勝敗決済枚数は全返済脚から集計する。PFと平均勝敗比は元組単位とし、減量・復元を別の勝ち組へ分割しない。1枚平均勝敗比、上位2勝ち元組の同時除外、指定8波の旧20分参加基準は別表示で、今回の基礎へ後付けしない。比率の分母がない場合は未確認として合格にしない。

主と中央C01／A0／INV／AV_ALL／乱数は、入口・執行が同一の場合だけ全影10指紋、影の全初回、実の全初回を照合する。初回時刻・方向・枚数・価格・初回ATR・初回Rの一致を要求し、共通の`初回枚数×初回ATR`で差Rを測る。元C01の早期返済、損失組、未調整組も全て残す。異なる入口時計・伝達遅延・観測約定を組番号だけで対応させない。

AV_ALLは到達後の方向条件を除いた全有効新公開を使い、元注文器のN1が受理できる機会で減量する。最初の1公開だけのpulseではない。符号乱数はbadとgoodを別々に変え、元の公開機会・ゲート・もう片側の情報を保持する。64全seedと中央値・順位を表示し、正式p値やゲート全体の無情報対照とは呼ばない。

比較誤差は絶対値`1e-6`。これは浮動小数の許容誤差であり、後付けの経済的許容率ではない。欠落・重複・非有限・仕様差・共通初回の不一致は合否以前の検証不備として拒否する。全163の成績を使って主を選び直さない。

全13と後7は重複し、どちらも既知である。今回の比較完了は未知市場の有効性確認ではない。一方、全相場で確実に利益を出す保証を追加の完了条件にもしない。完全な機会同率対照は未実施であり、ゲートそのものの独立した予測価値は未判定とする。
