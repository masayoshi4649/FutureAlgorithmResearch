# E01の損失抑制と方向偏りの再検証

最初に見るファイルは [E01改修のセッション損益](E01改修のセッション損益.html) です。選択した手法の全41セッションの利益・損失・収支と、その場までの累計だけを表示します。第一候補GU_Q・次善G_Qと、元E01、G、GUとの比較と、参考の観測Last模型を切り替えられます。

相対比較の第一候補はGU_Q、次善はG_Q。GU_QはTOPIX累計+267,500円・赤字18/41場、日経累計+91,000円・赤字17/41場。G_Qは平均黒字場と平均赤字場の金額バランスを改善する一方、赤字場がTOPIX21場・日経18場へ増える。

TOPIXミニ初回5枚・片方向上限10枚、日経マイクロ初回10枚・上限20枚。追加と復元なし。手数料0円、全玉を場内返済。主表示はラージ売買気配代理の次正常原行約定です。参考Lastの利益を実気配の成績へ移しません。全41場は既知開発で、未知場の安定性保証ではありません。


今回の選定は数値目標の合否ではなく相対比較です。GU_Qは両市場の方向を再確認し、米国寄付き前後15分と広い気配を避け、E01の途中判断・返済を使います。G_Qは米国寄付き前後の静観だけを外します。平均黒字場／平均赤字場の金額比は、GU_QがTOPIX1.04倍・日経0.87倍、G_Qが1.27倍・0.94倍。方向別ではTOPIXの上昇場への弱さが両方に残るため、上下への安定を完成したとは説明しません。

今回の訂正と保存会計の照合は [相対評価の記録](../../work/stability126_20261019/relative126/相対評価と訂正記録.json) を参照してください。以下の旧作業記録・敵対的レビューには、当時持ち込んだ数値目標による判定が残っています。今回の第一候補選定とは区別します。
