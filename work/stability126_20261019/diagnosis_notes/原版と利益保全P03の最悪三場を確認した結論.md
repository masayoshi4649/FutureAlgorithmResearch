## 何が損失を増やしたか

六場の負け四十五組中、三十六組は途中に正のLast清算益を持ち、九組は最高でも零だった。**「全く順行しない入口」と「少し順行した利益を返す出口」が混在**している。最高値で返済できたという意味ではない。

上表の代表組で最初に両市場の３０秒・１２０秒差が注文方向と反対になった時刻と、その時の組清算額は次の通り。

| 商品・場 | 初めての両市場反対／その時の組清算額 |
| --- | --- |
| ＴＯＰＩＸ 10/14ナイト・21:17の買い | 21:20:10／−2,500円。後のピークより前。 |
| ＴＯＰＩＸ 10/16デイ・09:52の買い | 09:54:59／0円。後のピークより前。 |
| ＴＯＰＩＸ 10/15ナイト・18:07の買い | 18:16:05／＋15,000円。利益は残っていたがＰ０３の開始額未達。 |
| 日経 10/15ナイト・18:09の買い | 18:16:22／−2,000円。＋8,000円から既に反転。 |
| 日経 9/30ナイト・22:44の売り | 22:48:49／0円。＋7,000円を返した後。 |
| 日経 10/2デイ・09:52の買い | 10:01:51／−10,000円。両市場反対の検出時点で既に赤字。 |

Ｐ０３は二リスク以上の順行と両市場反対を同時に待つ。小幅利益から反転した組は対象外で、急変時は床ができる前に元出口が発動する。反対に、利益が伸び続けた場では早く降りて後の利益を失う。入口の繰返しを抑えるＡ、場損失を止めるＬは別の作用であり、Ｐだけでは連敗を止めない。

## 予防策として残るもの

現結果で支持できるのは「同じ条件で利益保護を早めれば必ず救える」ではなく、**小幅順行からの失敗をＰ０３が対象にしていないこと**と、**損失後の停止が回復勝ちも失わせたこと**である。次の対照では、２Ｒ未満の実清算益の定着・戻り幅に合わせる保全と、失敗後に同じ根拠を再利用しない仕組みを分けて測る。今回の低い保全Ｐ０１・Ｐ０２にも全条件改善はなく、単に開始倍率を下げるだけで解決したとは言わない。

二市場反対の最初の診断時刻は、Ｐの利益条件・新規後更新条件を全て満たす実注文判断ではない。実際の床更新は診断の `new_events` の事象６、返済予約は事象７で確認した。保存情報から板補充主体、ニュース原因、トレーダーの意図までは確定できない。
