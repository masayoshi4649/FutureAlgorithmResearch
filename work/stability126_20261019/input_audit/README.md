# 00126 入力資格と非金融準備

最初に見るのは [attempt2/全四十一場の元入力と新市場特徴の非金融準備.json](attempt2/全四十一場の元入力と新市場特徴の非金融準備.json)。金融用の元入力・信号・特徴・市場状態・参考気配は同領域 `prepared126/{セッション}.pkl` の41個。

読む順序は、[入力再接続の調査](入力再接続の調査.md)、[保存入力候補目録](原版E01全四十一場の保存入力候補と時計資格.json)、[足公開・共同時計・終端の独立人工](元E01の足公開と共同時計及び終端の独立人工.json)、完成準備目録。

準備は原本・API・買売再生・影再生・ATR再生成を行わない。保存58素材と追加8場の所有consumer1分足16ファイルを、完成したattempt2では各一読・実bytes SHA照合した。元 `seq/time_s/last/atr` の82口座・11,075,351行を保持し、新しい共同Last特徴の37%・73%切断不変、追加8場の元信号生成器による未来改変・反射・同秒順を確認した。

原版と新16条件はmask0固定。元十列とvalidは旧関数で作り、共同B00も旧strict関数のまま。使用しないgate/EMAだけは「未計算の未知」sentinelであり、実測中立・実測ゼロへ解釈しない。この準備をmask0以外のアルゴへ流用しない。

旧33場の正規化済み `quotes.pkl` はLastを保存していない。原seq・価格時計・気配の対応は直接照合した。Lastの元系列同値は、`work/wave_v106/e01_reference/prepared/入力準備の完了.json` と同 `prepare.py` の当時の同一原行結合検査へ委譲する。追加8場のtapeはLastを直接検算した。参考気配は原版Last約定を気配約定に置換する指示ではない。

初回は正規化済みquotesにもLastがあるという仮定が誤っていたため `KeyError('last')` で金融前停止した。初回の完成packetは0、金融0。`prepare126_初回停止保存.py`・初回開始・停止JSON・読取履歴を残し、修正再準備をattempt2へ分けた。初回に読んだ所有CSV16・全33quotes・最初の入力/信号2の計19素材は、修正のため再読している。これを生データ追加取得や独立有効性標本へ数えない。

入力目録の先頭・末尾Last、時刻、原seq、高安、上下符号、絶対変化0.25%以上の分類は後分類用metadata。取引判断や設定選択には使わず、旧観測窓の末尾を実引け値と呼ばない。

新preparedは本担当が作成したため、親担当が別実装で入力指紋・新市場特徴・未来利用・unused sentinelを監査する。この準備完了は手法の有効性や利益達成を意味しない。
