# 診断用の対応

`attempt2/prepared126/{セッション}.pkl` の `inputs[(セッション,銘柄)]` がready。`seq/time_s/last/atr` は同長Nの元配列。`seq` は採用された元JSONLの0始まり原行番号、`time_s` は最終約定価格時計であり受信時計ではない。

測定配列のrow=iはこのreadyの配列index。元原行は `int(ready['seq'][i])`、時刻は `ready['time_s'][i]`。原seqを直接配列indexとして使わない。同一価格時計に複数の原行があるため、時刻だけで注文を一意結合しない。

| 配列 | 列順 |
| --- | --- |
| orders | row, source_row, campaign, 売買符号, qty, price, reason, is_entry |
| trades | campaign, leg, 保有方向, qty, 新規価格, 返済価格, 新規row, 返済row, 0, reason, 値幅×枚数PL |
| curve | Last時価損益, 確定損益, 買保有枚数, 売保有枚数, DD, cash, 買売net枚数, campaign |
| stats | 確定損益, 最大DD, 最大買, 最大売, 最大両側合計, 最大net, 会計誤差, 最低時価損益, 最高時価損益, 終端未返済数量, 0 |

時価・確定損益の単位は指数幅×枚数。円倍率はTOPIXミニ1,000円、日経マイクロ10円。返済脚の利益・損失はtrades[:,10]の正負を円換算する。親組の正負へ先に合算しない。

`quotes[(セッション,銘柄)]` は同じN行の `seq,time_s,bid,ask,quote_valid`。**板Buy1.Price=bid、板Sell1.Price=ask。執行価格は買いask・売りbid。** 英語原項目BidPrice/AskPriceは使わない。旧33の元83抽出は原Buy1/Sell1との直接一致を検査済みで、旧106が同原seq・価格時計・Lastの対応を検査した。旧33の正規化quotesはLast未保存のため、その同値は元検査へ委譲した。追加8はtapeのLastも今回直接検査している。

診断では当該場のpacketと完成測定NPZの再読だけを記録して使える。原市場を再抽出したり、事後の上下分類を取引判定へ戻さない。
