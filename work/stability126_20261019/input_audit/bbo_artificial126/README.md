最初に見るのは [最終源の独立人工](最終BBO源と全九出力有限性及びJITの独立純人工.json)。最終coreは `37e845db2f477b81a00402e7f42ca9c22b43f77452baa1e2851298486defe2a2`。実行源4本・条件目録・人工源3本の実SHAを証跡の `sources` に拘束した。

固定合成入力だけで1,015検査、Python348例とJIT6例を確認した。実市場本文読取・金融再生・API・実注文は0。例数は独立した相場有効性の標本数ではない。

期待値は被監査の会計核を呼ばず、実注文からFIFO玉・現金・全行BBO清算・実現部分益を独立に組み直した。買いはask、売りはbid。全九出力の有限性とPython/JITの九配列同値も確認した。
