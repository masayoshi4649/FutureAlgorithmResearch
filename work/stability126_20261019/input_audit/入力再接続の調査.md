# 原版E01へ再接続する素材

最初に見るのは `原版E01全四十一場の保存入力候補と時計資格.json`。旧結果を再計算するための素材調査であり、金融結果ではない。原本3領域・API・金融再生は使用していない。

## 採用する経路

| 対象 | 保存素材 | 使用方法 |
| --- | --- | --- |
| 旧30場・60口座 | `work/wave_v85/prepared/入力準備の完了.json` の入力対応 | `new_inputs.pkl` と `signals.pkl` をそのまま使う。元 `seq/time_s/last/atr` と入口・B00・B01を保持する。 |
| 追加3場・6口座 | `work/wave_v106/e01_reference/prepared/各場/` | 保存 `new_inputs.pkl` と `signals.pkl` をそのまま使う。 |
| 追加7場・14口座 | `work/stability119_20261017/v6_resume/legacy_root/work/v6_prepared/各場/` | 保存 `new_inputs.pkl` と `new_features_depth.pkl` を使う。信号は対応する所有CSVと同bytes旧生成器から非金融生成する。 |
| 追加10月19日デイ・2口座 | `work/stability124_20261019/e01c/legacy_root/work/v6_prepared/2026-10-19_Day/` | 上と同様。CSVは同じ `legacy_root` の旧consumer表示を使う。 |

旧30場は `old23` 合本・追加5場・追加2場の計8組のpklを使う。各保存ファイルの既存指紋・根拠JSON・現在サイズは目録に記載した。目録段階では市場派生pkl/npz本文を読んでおらず、保存指紋の再計算済みと誤表示していない。正式所有コピー時に実bytes照合が必要。

## そのまま代用しない素材

`work/stability125_20261019/prepared/` は正常BBOのある採用Lastだけから別の1分足を作り、15分ER等を計算する入力。旧E01の元足・ATR・公開時刻と同値ではない。これを使うなら別アルゴの比較であり、原版再現と呼ばない。

元E01は5分足高安・前終値から計算する指数平滑ATR（alpha=1/12、初期3本、観測ラージ2呼値以上）を、足始時から360秒後に公開する。主方向用の確定1分足は足始時から120秒後に公開し、相手の主方向はさらに60秒遅らせる。短期入口は公開板中値差を使う。これらをLastだけの1分足、公開+60秒、更新中足へ置き換えると原版ではなくなる。

## 時計・終端の資格差

- 旧33場は以前の無訂正保存入力。追加8場は価格時計高水位資格を通した所有入力。全41場が同一原資格であるとは表現しない。
- 追加8場は有限正Last、時差付き価格時計、場内 `[08:45,15:40)` / `[17:00,翌05:55)`、過去最大採用価格時計以上を要求する。不適格行の `CurrentPriceTime` だけを未使用表示にし、元原行数・seqを保つ。時計を並べ替えたり日付を推測加算しない。
- 10月19日のNK225には15:40始時の1分・5分足がある。124のconsumer表示は元CSV全行の時計資格を検査してから、この合法末尾1行ずつだけを旧窓外として除外した。すでに保存された `new_inputs.pkl` のATRを再生成して差し替えない。
- 保存された `CurrentPriceTime` は最終約定価格時計であり、板全体の受信時刻ではない。原行順は銘柄内順序、二市場の真受信順は未保存。相手参照をstrict過去へ制限しても真の受信時刻の再現証明とはしない。
- 正常気配が不足する場合、未来近傍行を補間しない。正常な次原行による約定モデルと、原版の観測Last約定モデルを分ける。ユーザー指定の手数料0は気配差を0にする指定ではない。

## 独立人工で確認する項目

1. 接続源の同bytes・固定範囲。旧30再現に使う原信号は変更しない。
2. 1分公開+120秒、ATR公開+360秒、それより前は利用不可。末尾の極端な未来足を変えても過去信号を変えない。
3. 同時計の他市場行を参照しない共同B00。異なる相手価格や長い欠測を加えても自己の過去prefixが不変。
4. 高水位資格、timezone無し、不明時計、前場価格、時計逆行、終端合法CSVと不正CSVを区別する。
5. 現在行で新設した注文を同じ行へ遡って約定させない。新規・減量・反転の玉数上限と場内全返済を独立確認する。
