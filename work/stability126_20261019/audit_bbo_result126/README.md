# BBO完成会計の独立監査

最初に見るのは [全1,312会計の独立監査](全千三百十二BBO会計と全行清算の独立監査.json)。被監査結果のSHAは `7ae07d05468c243031e798fb0e6b37192a85e0c5a904571b56d1f923264cffe1`、独立監査のSHAは `a20286d174b057bb4ba6a646140abe87456a50eaecfce5d169fb011ba077525c`。

保存入力packet41、新BBO会計NPZ82、元Last通知cache23を各一回監査読取した。原本・API・金融再生は0。注文・FIFO玉・現金・在庫・全行最新正常BBO清算・未返済・全11統計・元通知固定ATRと実親組・各場利益損失収支・方向別収支・累計が全1,312件で一致した。

実新規5枚／10枚、上限10枚／20枚、買ask・売bid、同一原行約定の禁止、実組予算予約、初回固定場risk、実赤字後の方向停止も検査した。無効気配時は以前の正常気配を時価表示に使うが、未返済を架空に清算した結果は通さない。原版E01のBBO累計はTOPIX−42,000円・日経＋48,700円、P02はTOPIX−14,500円・日経＋42,400円と独立復元した。

監査器自身は、96の人工正値と8の故意破損を使い自己反証した。初回の人工でcurve列4を現在DDと誤解したが、仕様は当行までの最大DDだったため独立期待値を修正した。訂正前源と経緯を保存している。金融源の修正や市場会計の再実行は行っていない。
