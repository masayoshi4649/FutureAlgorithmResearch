# 独立監査

最初に `全条件の独立監査.json` を見てください。続いて `追加診断対照の独立監査.json`、`実選定設定の因果検査と選定照合.json`、`両建てと減玉対照の全行監査.json` の順に読むと、会計、保険だけの切分け、選定と因果性、減玉対照の違いを確認できます。

## 合格した範囲

- 元 192 条件 × 56 口座 = 10,752 口座。全注文・役割別 FIFO 部分決済・料金・全原本行の両建て清算評価を別会計器で照合。
- 追加の保険なし 30 条件 × 56 口座 = 1,680 口座。同じ初回、元玉ストップ、トレール、全玉損失枠、期限で保険だけを除いた条件を照合。
- 期間集計は元 1,152、追加 180。利益玉の明細と、元玉・保険を統合した一組損益の両方を照合。
- 共通の初回新規行・判断行・売買方向・上限枚数が全条件で一致。
- 六管理系 × 人工 144 ケース、売買反射 144、独立子判定 18、境界 4。
- 人工の途中切断と将来変更 144 組、実原本六管理系の同検査 192 組、実選定三設定の同検査 96 組。
- 純両建て 48 対照 × 56 口座 = 2,688 口座。減玉対照を元注文だけから独立に写像し、全原本行で評価差を検算。
- 前 16 セッションだけから物理保険・その他管理の全順位と三代表を独立に再計算して一致。後半再選定なし。
- 元の凍結 9 ファイル、追加対照の凍結 5 ファイルの実バイト列 SHA256 一致。追加診断による選定変更なし。

## 会計上の要点

新規と返済は注文ごとに料金を切り捨てます。部分返済の新規料金と、複数玉にまたがる返済料金は、累積配賦額の切捨て差分で割り当てます。全量返済で元の料金と整数合計が一致します。

両建て時価は「現金＋買玉×bid−売玉×ask」です。保険玉だけの利確をもって一組を勝ちとはしません。元玉と保険玉の全損益を合算し、未返済玉の含み損益を全原本行で評価します。

同判断の減玉対照との評価差は「終了済みの余分な気配差・料金の節約累計＋残保険枚数×現在の気配差」です。方向露出自体は同じであり、純両建て側の保険を残して全返済する場面の余分な往復を省く差になります。
