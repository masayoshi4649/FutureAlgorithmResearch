# 全現行手法の外部ルール化照合

新しい戦略を選ぶ探索ではなく、既存の7プロファイルを外部TOMLへ移したときに売買が変わらないことの検証です。事前登録IDは `145_全現行手法の外部ルール化同値照合_20261026` です。

最終確認はrun02です。銘柄とIDを組み合わせたファイル名・設定名へ統一し、仮想主担当・補完担当の評価異常も発注境界へ伝える修正を入れた版で、以下の結果を再確認しました。全7個の実TOMLを読み込んでおり、実行中のソース変更はありません。

run02後のGo差分は、`TestExitDiagnosticsReadOnly`の期待値修正だけです。固定の開始幅375ptという旧表示期待を、外部式名`research.active.trail_active`と固定幅キーがないことの確認へ変更しました。本番Goと売買条件式は変更していないため、金融再生は追加していません。

## ルール配布

`conf/rules/`には`NK225_D07.toml`・`TOPIX_T06.toml`のような実TOML7個だけを初回配置します。ルールのsampleは作成しません。再配布で利用者の式を上書きせず、不足した手法ファイルだけ追加します。新名がなく旧小文字名の実ルールがある場合は、その内容を新名へ引き継ぎます。既に新名の実ファイルがある場合はそちらを保持します。

配布テストで、7ファイルの読込、全有効キーのコメント、既存全ルールの保持、1個だけ不足した場合の補完、旧名からの内容引継ぎ、設定・台帳・ログの保持、sampleを生成しないことを確認しました。
