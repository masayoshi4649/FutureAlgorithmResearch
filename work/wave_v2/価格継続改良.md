# 継続状態と新規条件の分離

## 追加探索

価格の局所高安からＡＴＲ幅だけ反転する方式と追跡価格帯方式を160設定、開始条件に対して長期回帰の反対確認を追加する方式を144設定、さらに新規だけ他指数の確認を加える方式を９設定比較した。保存３セッション・２銘柄だけによる開発であり、現在セッションＡＰＩや以前取得した現在キャッシュを参照していない。

単純なＡＴＲ反転幅を広げると夜間の波数は減るが、９月２２日のショート検知が遅れる。幅を狭めると夜間の不要な反転が増える。自指数の方向指数と60分回帰で逆転を確認し、新規を他指数の一致時に限る候補では、代表４波を捉えたまま各銘柄・セッションを１～４波に減らせた。

## 具体的な条件

１分足の過去価格を規則的な時刻軸へ配置する。欠ける分は過去終値を特徴計算へ持ち越し、実在する足以外の価格で約定を作らない。自他いずれかの最終観測から10分を超える場合は新規しない。判定は５分足が確定する５分ごと。

- 方向指数は５分足の高値・安値の更新幅から、期間８本の指数移動平均で求める。`DI=(平均上昇幅−平均下落幅)/(平均上昇幅＋平均下落幅)`。
- 自指数の `|DI| >= 0.15`、20分価格変位とＤＩが同符号。
- 自指数の直近60本の１分終値を時間で線形回帰する。60分相当の回帰変位が0.5ＡＴＲ以上、回帰の決定係数が0.2以上、方向指数とも同符号。
- 他指数の60分回帰も同符号で、決定係数0.2以上なら新規する。他指数の回帰変位の絶対閾値は設けない。
- 保有中は、自指数の上記条件が反対方向に成立するまで方向を維持する。反対成立で返済し、他指数も一致すれば反対建て、不一致なら中立として次の５分判定を待つ。
- ＡＴＲは確定済み５分足の真の値幅を係数1/12で指数平均し、下限を２ティックとする。
- 取引再生は確定後に１分余分に遅延し、その後の最初の実在１分足始値を用いる。日中15:35、夜間05:50以降の最初の実在足で返済し、閉場まで持ち越さない。新規は返済予定時刻の30分前まで。

この独立再生は、狭い追跡ストップによる分断を避けて波そのものを比較したもので、保有中の価格ストップを使用していない。ただし選択候補12波の最大逆行は最大2.866ＡＴＲであり、初期価格から固定３ＡＴＲの保護条件を加えてもこの保存データでは約定しない。追跡条件を追加した場合の結果は別途再検証が必要。

回帰変位閾値0.25～0.5ＡＴＲでは同じ結果だった。他指数の決定係数を0.4へ厳しくすると9/22の検知が遅れて４例のうち１例が不合格になる。境界に余裕のある万能な閾値とは言えない。
