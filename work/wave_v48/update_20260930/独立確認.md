# 追加デイとレポート更新の独立確認

固定4方式を2026年9月30日デイへ適用した結果を確認しました。条件・初回枚数・上限・倍率は旧台帳と全項目一致です。

- 旧14セッションの112口座と元16資料の指紋は不変。
- 全返済脚を「返済価格－新規価格」×方向×枚数×倍率で再計算し、利益・損失・収支・延べ返済枚数が一致。
- 注文と返済脚の数量を別集計し、すべての注文は判断行より後。TOPIX初回5枚／上限10枚、NK初回10枚／上限20枚以内で、最後の建玉はゼロ。
- 追加8口座は注文の現金出入りと保有枚数から全行の時価を独立復元。期末収支・最大下落・時価最小／最大も一致。全注文と返済は当該セッション内。
- 保存5分足からTRとATRを逐次計算し直し、足開始360秒後に利用可能とした全観測ATRが一致。注文準備時に固定したATRも一致。
- 更新JSONの全120口座と、HTMLの15場・第1週・第2週・全期間、全144行864数値セルが一致。勝つセッション数・平均勝ち枚利益／平均負け枚損失・連結最大下落も別集計で一致。
- 公開板特徴の元時刻・元行はすべて公開時刻・公開行より前。旧8口座の完全再現、入口／途中素材の切断・未来改変・反射・同秒順、追加8口座の二つの影を含む統合因果検査について、実装・結果・指紋の接続を確認。

原本診断では保存足と生板の足再集計は完全一致ではありません。TOPIXは1分足406/415・5分足80/83、NKは1分足414/415・5分足82/83がOHLC一致。保存足だけの時刻は両銘柄とも0です。旧仕様どおり入口は保存1分足、ATRは保存5分足、売買価格は生板CurrentPriceを使用しており、今回だけ異なる系列へ置換していません。
