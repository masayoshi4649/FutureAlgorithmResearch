# 測定と反証の事前設計

2026-10-07。観測集計と売買ルール決定の前に定める推奨設計。実際に採用した数値設定・変更点は root 側の実行仕様で別途固定し、これを実行済みの検定と記載しない。

## 期間の役割

- 先頭10場：機構候補の量・頻度・条件差を測る。正規化や閾値が必要なら、この期間だけで決める。
- 次9場：固定した方向、効果量、活動頻度が再現するか調べる。閾値や符号をここで変更したら、調整後の同区間成績は再現確認ではなく再学習になる。
- 最後4場：連敗原因を既に知った期間。既知事例での確認として別に示す。

全23場は過去研究で閲覧しているため、どの分割も真正な未見と呼ばない。固定後に新しく到着する場だけを将来検証と呼ぶ。

## 時刻・行順の扱い

現在価格時刻は受信時計ではない。同じ時刻の後続行を過去の先頭行へ集約して渡さない。板更新の物理行順は保存する。公開時刻、源時刻、最後の約定時刻を区別して記録する。

二市場を比較するときは、自市場の判断までに公開された相手情報だけを参照する。相手の次の行を補間しない。同時刻ブロックの公開待機と鮮度条件を固定し、時計不確実性による効果を調べるため、相手情報を追加で遅らせた対照を用意する。

現在までの欠測を理由とする新規見送りは可能だが、将来に欠測があることを見て都合の悪い取引を消さない。

## 価格変化を再包装しないための対照

最低限、各代理指標の次区間効果を次の順に比較する。

1. 自市場の直前価格変化だけ。
2. 1 に直前変動性・スプレッド・時間帯を加えたもの。
3. 2 に板の消費/撤退/回復代理の一つを加えたもの。
4. 3 に相手市場の既知情報を加えたもの。

板指標を価格で回帰した残差だけで十分とは断定しない。線形残差で除けない非線形関係があり、標本が小さいためである。回帰対照と、似た価格条件の群比較が同じ向きを示すかを併記する。

過去の方向・変動性が近い観測を対応させる際も、将来損益で相手を選ばない。対応する基準区間がない強い局面は、無理に比較せず比較不能の件数を残す。

## 数値の正規化

- 厚さは単純な段番号だけで比べず、最良価格からの距離/tick と数量を使う。
- 同価格の純減/回復は、その価格が連続観測範囲内にある場合に限る。10段外はゼロ扱いしない。
- 出来高増分が負なら区切り・リセット・異常として扱う。負数を売り出来高としない。
- 出来高増分全量を最終約定価格で約定したものとしない。売買符号は代理と明記する。
- 自市場内の過去尺度で標準化する。TOPIX と NK の生の出来高、pt、円の大小を共通閾値にしない。
- 全期間で求めた平均や分位を入口に使わない。先頭10場固定か、現在までの逐次尺度を使う。
- 更新回数は市場活動だけでなく配信・記録頻度にも依存する。生の件数で焦りと断定しない。

## 予測ラベルと独立性

未来 1・5・15 分の中値変化は分析用であり、入口特徴とは別に格納する。最大順行・最大逆行は平均方向より売買設計に近いが、先にどちらへ触れたかも必要である。後から都合のよいトレール幅を作らない。

1 秒ごとの観測を何万個も数えても、重なる15分先リターンを独立標本とはみなさない。集計単位は最低でもセッションとし、セッション別の効果符号・中央値・ばらつきを示す。二市場も共通要因があるため、独立サンプルが2倍になったとは数えない。

事象を複数行で数える場合は、同じ価格帯・同じ流動性消失の継続を同一事象として数える規則を固定する。同じ一波が百回の成功事例にならないようにする。

## 統計的反証

- 両銘柄で符号が同じか、日中と夜間で極端に逆転しないか、先頭10と次9で残るかを別表示する。
- 未来向け効果が、同区間説明より十分小さい場合はそのまま示す。「相関が強い」だけで採用しない。
- セッション単位の再標本化で不確実性を示す。23場未満の小標本で精密な確率を断定しない。
- ラベルの時間ずらしは、重複区間・場境界・日内季節性を壊さない対照に限る。単純全行シャッフルの有意差は採用しない。
- 多くの代理や時間幅から良いものを選んだ事実を記録する。少数の良い点だけを報告しない。
- 特定の最大勝ち場を除く、近接した閾値でも崩れないか、測定公開を遅らせても残るかを感度として示す。感度の最高値を主案へ後付け昇格させない。

## 観測不能と仮説棄却の区別

事象がほぼ出現しない場合は、仮説が間違いとは限らず、現在の代理で検証できていない。同じ現象を捉えたくて閾値を際限なく下げず、件数・欠測・除外理由を保存する。

逆に、十分な件数があって次区間の差が再現しない場合は、現在のデータと定義では予測根拠がない。心理や「プロなら読めるはず」を理由に成績を救済しない。

## 売買ルール化する前の提出項目

各機構候補について、次の一組を揃える。

`理論 → 観測代理 → 過去価格のみの対照 → 次区間の効果 → 再現した時間幅 → 失敗する状態 → 入口/維持/撤回の機械条件`

最後の条件を先に作ってから前段を理由付けしない。結果が弱い場合も、基準方式と実験方式のバックテストを通して、期待した性質が利益へ残らなかった理由を記録する。
