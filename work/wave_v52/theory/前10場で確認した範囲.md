# 前10場で確認した範囲

ここでは `先頭10場の観測.json` だけを読んだ。次9場・既知最後4場の成績は、この文書作成時点では閲覧していない。主時間は事前に固定した次5分。ATRは起点までに既知の値である。

## 過去に何が起きていたか

同じ60秒の中値変化との相関は、執行側代理が TOPIX 0.378 / NK 0.453、出来高増分なしの表示追加偏りが 0.536 / 0.557 だった。価格が上がる時は、売り提示側に分類される出来高増分と、買い側への表示追加が同時に多い。

これは価格の上昇に伴う観測であり、買い手の心理を特定したものではない。表示追加は価格が先に上がった後の追随も含む。

執行側代理が0でも、売買に分類した量が等しい場合と、全量を分類できなかった場合がある。後者を圧力の均衡・消失とは呼ばない。前10場で全量未知による0は TOPIX5起点・NK3起点あった。近接供給は板更新行を重みにした平均であり、実受信時刻による滞在時間平均ではない。

## その後にも残るか

先頭10場で求めた価格対照を引いた残差間の相関と、指標の上群から下群を引いた次5分リターン差を示す。群の境界は先頭10場の3分位。場均等差は、各場で群差を求めてから10場を同じ重みで平均した値。

|代理|残差相関 TOPIX / NK|場均等の上群−下群 TOPIX / NK|解釈|
|---|---|---|---|
|執行側|−0.011 / −0.020|−0.024 / −0.013 ATR|同区間の強い関係が次5分ではほぼ消え、僅かに逆向き。両銘柄7/10場が負。|
|表示追加|−0.023 / −0.012|−0.043 / −0.042 ATR|追加された側へ継続する根拠は弱い。平均差と場ごとの符号は必ずしも一致しない。|
|近接供給|+0.029 / −0.001|+0.115 / +0.027 ATR|TOPIX は8/10場が正、NK は5/10。二銘柄に共通する確かな方向信号とは言えない。|

執行側と同方向へ既に直前1分で進んだ状態の次5分は、方向付き平均が TOPIX −0.0142 / NK −0.0134 ATR。平均の観測最大順行/逆行は、それぞれ 0.464/0.483、0.478/0.492 ATR で、方向差は通常の振れ幅に比べて小さい。

執行側へ進まなかった状態（横ばいと逆行を含む）の次5分は +0.0103 / +0.0087 ATR。「買われても上がらないから即売る」という単純な反転規則を支持する結果ではなかった。

両市場の執行方向が、相手を60秒遅らせた参照で一致していた群の次5分は、自己の執行方向に対して −0.0159 / −0.0362 ATR。不一致群は +0.0391 / +0.0236 ATR。ただし、これは自己の価格状態を揃えた比較ではない。共通する価格の往復を執行側の効果と誤認している可能性が残る。

## 理論への反映

少なくとも今回の前10場では、既に価格を動かした執行の偏りを、そのまま次の継続波の根拠にする説明は弱い。短い価格影響が消え、均衡が戻る可能性を調べる方が観測の向きには合う。ただし逆方向の差は小さい。これを利益のある反転法則と呼ばない。

供給回復や厚さに関しては、銘柄間で方向や強さが異なる。両建て、グリッド、トレール等を加えれば自動的にこの問題が解消するという根拠もない。注文方法は、機構に合う利益/損失の経路を実現できるかという別の検証対象である。

主ルールを作る場合は、この前10場の観測と機構仮説から固定する。その後で次9場・既知最後4場・非重複起点を照合し、再現しなければ仮説を採用しない。後半で良かった方向へ符号を反転しない。
