# 事前固定後の実装修正

観測結果・将来効果を閲覧する前、2026-10-07 に実施。

1. 独立監査で10段の欠測・価格不順序・重複が実在したため、抽出側の品質列を受け、該当原本を含む直前60秒窓を現在の品質条件で除外する。利益が悪い期間の除外ではない。元の固定JSONを残す。
2. 未来経路の途中の観測空白を終点の鮮度とは別に計測し、各時間幅の最大空白秒と60秒超の件数を出力する。最大順行・逆行は観測された公開中値だけの値であり、空白中の極値を補完しない。未来空白で現在特徴を消さない。
3. `partial_corr` という列名は先頭10場の係数を固定した残差間の相関を意味する。次9場・既知4場内で再回帰して価格効果を完全に取り除いた通常の部分相関ではない。係数固定による予測誤差と機構固有の関係が混在し得るため、因果と呼ばない。
4. 固定前の構文確認で辞書キーワード `集計` の重複を `統計集計` に修正した。固定JSONには60秒窓とセッション均等統計の両方が残っている。
5. 根本の価格形成を確認するため、同ブロック・同60秒窓の数量代理と価格変化の共存関係、最終約定値のみが変化した起点数を追加した。将来予測表とは分け、価格が先に変わって板が追随する内生反応を含む記述統計とする。
6. 回復代理の「気配不変」は、数量が回復した隣接二行の最良気配が同じことを指す。減少から回復まで全期間で気配が不変という意味ではない。列の意味に合わせて表示名を修正した。

これらは理論の符号、3分位境界の作り方、主時間5分、期間分割、取引利益に基づかない設計を変更しない。
