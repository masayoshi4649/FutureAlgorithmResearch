# 独立レビュー・監査

最初に `原理観測の監査方針.md`、次に `最終特徴と原本の独立照合.json`、`観測解析の独立因果監査.json` の順に読む。

## 確認したこと

- 46原本を抽出器と別実装で全数走査。5,945,161行中の最良有効板は5,910,415行。10段の欠測は0行、価格重複・順序不正は64行だった。
- この64行を抽出担当へ報告し、深い板の数量差分・回復の連続性を切り、該当窓を観測解析で除外する修正を、成績閲覧前に適用した。最終特徴の品質件数は独立走査と全数一致した。
- 原本SHA256は別走査と抽出器で全46口座一致。
- 223,791公開特徴で、源行は公開行より前、源時計は公開時計より前、出来高時計は公開時計以前だった。約定時計より未来の出来高時計を持つ原本行も0。
- 合成原本で出来高の正・負・未知数量の保存、欠測とゼロの区別、不正板を跨がない差分、回復量の上限・期限・価格別管理を検査した。
- 合成8切断・8未来改変、実データ6口座×2切断・2改変で、公開済みの特徴が変わらないことを確認した。
- 198件の将来価格端点を別計算し、ラベルと一致した。
- 後半期間の将来ラベルだけを変更しても、先頭10場で定めた回帰係数・3分位境界・先頭期間集計は変わらなかった。
- 固定した14条件×46口座の644会計、29,638注文、14,819返済組、13,048区間を独立照合。判断の次有効行の価格で約定、場末無保有、利益・損失・枚数、返済約定行を含むMFEが一致した。
- 返済組から別に構築した時価曲線・最大下落、30分区間の含み損益を含む会計が一致した。
- 主案、追加3ゲート、価格のみ対照、出口2対照の6実口座×2切断、合計84比較で、判断・注文の未来切断／未来変更不変を確認した。
- 主案の記憶期限、同方向で期限を延長しないこと、全量不明と分類済み均衡ゼロの区別、欠測破棄、ゲート不成立でも事象を消費することを7具体例で確認した。
- 最終HTMLを実ブラウザで14手法×2商品、全644口座へ切替。67,676金額セル、各場PF・平均勝負、29,638売買マーカーを照合した。9ローカルリンクは存在し、広幅・狭幅・損益・売買図の4画像を目視確認した。

因果監査の「合格」は未来参照をしないという実装上の判定。板指標が価格を因果的に動かすことや、売買で利益を得られることを証明する意味ではない。

## 発見・修正した実装上の点

- 最初の同時刻ブロック途中で切断し、公開0行となるケースの数値型エラー。抽出担当が修正済み。
- タイムゾーン無し日時をホスト設定で解釈する問題。抽出担当が明示拒否へ修正済み。
- 最良気配は有効でも深い段に重複価格があるケース。上記64行への品質処理を追加済み。
- `source_mid_first` はブロック最初の変化後の値であり、当該ブロックへ加算した差分の起点とは一致しない。現在の解析は公開中値の過去1分／5分差を使い、この不一致を持ち込んでいない。
- 中立の約定器の返済時MFEが、返済約定行の有利な変化を含めていなかった。rootが修正済み。収支計算には影響しなかった。
- 執行方向が全量未知でも数式上の偏りが0になるため、これを圧力終了の証拠に使わないよう指摘した。主案の固定仕様は全量未知を欠測同様に破棄している。
