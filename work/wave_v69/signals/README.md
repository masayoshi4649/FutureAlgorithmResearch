# 入口の仕様

最初に `core.py` の `SIGNAL_META` を見る。次に `入口人工経路の照合.json`、必要なら `check.py` の人工経路を確認する。ここでは損益を計算しない。

## 共通の定義

- ティックは原本行数ではなく、最良買い・売り気配の中値が変わった価格イベントとする。気配を動かさない約定値の売り買い往復は、入口にしない。
- 単位は参照するラージ銘柄の呼値。ATR、EMA、将来の高安値、他セッションは使わない。
- 中値変更と、両気配の同方向変更を確認した行に方向候補を出す。同秒でも原本順に処理し、当該行より後を見ない。
- スプレッドが2呼値を超える行、不正な板、不連続、時計逆行、120秒超の時計空白で状態を破棄する。開始5分以内は発火しない。
- 120秒は予測する保有時間ではなく、古い状態をつなげないための鮮度条件。保有時間と注文方式は親の売買器で比較する。

## 8系列

| ID | 思想 | 標準・強めの条件 |
| --- | --- | --- |
| T1L0 / T1L1 | 伸びが止まり、実際に戻り始めた方向へ入る | 4/8呼値の伸び後、2/4呼値の反転を確認 |
| T2L0 / T2L1 | 押し戻しをこなし、元方向へ再開した所へ入る | 4/8呼値の伸び後、2/4呼値押し、局所極値から2/4呼値戻り、旧極値から2/4呼値以内 |
| T3L0 / T3L1 | 近い板の表示量回復で進行が止まり、戻った所へ入る | 直前8中値イベントで2/4呼値の接近、最良量の0.5/1倍以上の回復、回復後の元方向への前進が1呼値以下、2/4呼値反転 |
| T4L0 / T4L1 | 補充しても価格が通過したなら継続側へ入る | 最良量の0.5/1倍以上の回復後、その価格を2/4呼値越え、両気配も2/4呼値進み、直近16中値イベント区間の最良OFIが同方向 |

T2は同じ旧極値で繰り返し発火せず、新しい極値ができるか、逆方向へ4/8呼値進んで状態が替わった後に次の押し戻しを扱う。旧極値を飛び越える反発も発火対象とする。

## 補充の解釈

補充完了は、価格別の既知表示減少の80%以上が回復し、回復量が開始時最良表示量の25%以上である、既存の監査済み抽出結果を使う。T3/T4はさらに上記の数量条件を課す。現時点の最良価格から2呼値以内の完了だけを使う。

同側・同強度・同系統の最初の適格完了を基準とし、後続の完了で価格や時刻を延長しない。発火、120秒経過、T3の1呼値超の前進、T4の逆方向への価格帯離脱で失効する。原本抽出器の順番で最初の適格イベントを採用する。

表示の減少・回復は、約定、取消、再発注を完全に区別できない。したがって、T3は「買い手を真に吸収した」、T4は「大口が焦っている」と断定するアルゴリズムではない。それぞれ観測可能な表示変化と価格の反応を仮説として利用する。

## 検査

`python -X utf8 work/wave_v69/signals/check.py` で人工経路を確認する。確認項目は、4/8呼値後の反転、2/4呼値の押し戻し再開、極値を飛び越す再開、表示補充後の反転、補充後も進む候補の失効、OFI付き突破、上下鏡像、途中切断、未来改変、同中値行の5倍複製、固定気配、不連続、時計空白である。
