# ティックIFDの独立監査

最初に見るファイルは `全条件の独立監査.json`。192条件・10,752口座の会計と原本行の評価損益をすべて独立照合した証跡です。

読む順序は次のとおりです。

1. `ティックIFD監査計画.md`：結果を見る前に決めた時間順・料金・IFD子・含み評価の確認事項。
2. `人工経路と因果検査.json`：12人工経路、24親子保有条件の途中切断と将来変更。
3. `実原本因果検査と前半選定照合.json`：四機構の前半順位再計算、実原本32候補口座条件の因果検査。
4. `全条件の独立監査.json`：FIFO、次原本気配、全取引列、各行時価曲線、前16・後12・全28の最大下落。

監査コードは `audit_all.py`、`real_prefix_and_selection.py`、`audit_engine.py`、`independent_account.py`、`child_oracle.py`。変更・保存はこのaudit領域だけです。現在APIや実注文を使っていません。

実装の未来参照防止と会計一致を確認しています。既知の28セッションから作った仮説が将来にも有効であることや、小商品の実際の気配・数量・注文遅延は証明していません。
