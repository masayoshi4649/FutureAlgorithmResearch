# 00159 支持の検証と夜間数量政策

2026年10月28日の依頼：支持が強い時に初回から大きく入ることは希望に合う。少量固定を目的にせず、支持スコアが勝ちやすさ・利益幅・逆行の小ささを識別するかを検証し、夜間にも適した手法を作る。

## 分担と順序

1. `work/score159`：保存済み26Day155初回を再利用し、支持と初回玉単位損益・順行・逆行の関係を測る。担当・売買・前後期間を分け、時系列校正では先行完了場だけから学ぶ。
2. `work/audit159`：原資料の完全性、追加場の終端、内容指紋、旧試行との重複を確認する。
3. `work/night159`：夜間の米国前P05・後D07を現行時間枠に接続し、初回配分・追加・失速・利益保護・逆行防御を分離した候補を作る。登録前に金融再生しない。
4. root：仕様と実装を事前照合・登録し、独立監査後に金融再生。結果から具体的な負けの時刻と原因を分析し、未検証の改善だけを別登録して比較する。

## 固定する評価

- 日経mini10枚相当＝micro100枚相当、片方向の所有と予約を合算。初回量の大小そのものを善悪の基準にしない。
- 手数料0、ラージの板のみで判断。次の正常ラージ気配による約定と全残玉の清算時価を使う。実mini/microの気配性能とは区別する。
- 主評価は黒字/赤字/無取引場、通常赤字の平均・中央値、最悪収支、途中最小時価・最大下落、大勝ち3場を除く収支。昼夜・米国前後・上昇下落を分ける。
- 支持を勝率と同一視しない。確率校正と利益幅の識別を別に示す。親全体結果と初回玉結果、到達率と先着率を混ぜない。
- 過去全場は既知開発。時系列で未来ラベルを使わない検証も、世界全体として完全未見とは呼ばない。10/26Nightは21:13まで、10/27Dayは15:20まで既に観察済みで、追加は終端までの資料。追加完了版として別掲し、完全未見の場とは呼ばない。
- 生原資料と旧成果は読み取り専用。現在API、稼働アプリ、dist、設定、実注文は今回変更しない。
