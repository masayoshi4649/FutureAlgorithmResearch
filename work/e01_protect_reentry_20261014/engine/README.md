# 00108の準備版

十二条件は、元の紙上新規だけを使う方式、押し戻り後の回復、突破、現在の支持票で回復と突破を選ぶ方式と、三つの純益出口の組合せです。実枚数はTOPIXmini 10枚、NK225micro 20枚です。元の紙上運転と実親は別に保存します。

価格票は保存された正常Lastの非零更新を各一票として数えます。出来高や攻撃注文方向の票ではありません。自己は当該行まで、相手は自己の価格時計より厳密に過去の正常末端です。相手の60秒窓は選んだ相手末端時計が終点で、自己時計との差は別に60秒以内を確認します。物理的な受信順は未測定です。

正常Lastで作った押し戻り状態は、通常の非正常行では更新せず保持します。紙上新規、実返済、失効、未約定撤回は別のリセットイベントです。その時点が非正常なら次の正常Lastで初期化し、初期化行では再参加しません。窓の票が未知であることと、Lastの形状が観測できないことを分けています。

公開時に一回FAKの価格限界を固定します。最初の正常気配で約定又は失効し、後の価格で元注文を復活させません。保護・撤回の観測判断は次の正常気配で返済します。利益保護の事後極値は実保有中だけの診断であり、別の出口で取れる利益とは解釈しません。

最初に人工証跡 `十二保護と新価格票及び独立実親の人工検査_v2.json`、次に `試行計画草案.json` と `準備固定.json` を確認してください。初版の源と人工は `archive/anchor窓known分離前の初回人工` に保全しています。

準備段階では、金融・大型入力・旧台帳・APIの読取はありません。旧正式固定の入力目録と候補外比較の小射影だけを新目的で参照しています。

根による正式固定はこのディレクトリで `python -X utf8 runner.py --freeze`、登録完了後の一回金融は `python -X utf8 runner.py --root-trial-registered` です。失敗時は保存済みFalseを保持し、自動再開始しません。準備担当はこれらを実行しません。

主評価はTOPIXの損失場・無取引場を含む全33場平均の手数料後収支10万円です。全完結親の平均は参考値です。NKの円額目標は未指定で、零円の目標を代用しません。旧65%の金額割合・赤字場20%以下・最大赤字が平均黒字以下も別に確認します。
