# 00129 再試験入口の独立人工で見つけた反例

新規の数値売買を実行する前に、入口の再試験状態の欠落を発見し、修正した。

買いの固定突破線110、準備幅4を例とする。

1. 110.5で準備する。
2. 113で突破線＋0.75幅を観測する。
3. 111へ戻り、突破線＋0.25幅以内の戻りを観測する。
4. **109で固定線−0.25幅へ達する。この原行の自己価格とBBOは正常だが、相手資料が欠測する。**
5. 112に戻る。

修正前は4の取消し処理まで「全特徴が既知」の条件の中にあった。相手の市場資格が0、相手履歴がNaN、現在ATRがNaN、自己30秒差がNaNのいずれでも取消しを飛ばし、5で旧準備から発注した。売りの上下対称経路も同じである。

これは未知の価格を推定した問題ではない。**自己の正常な価格で確認できた失敗まで、別の情報の欠測を理由に無視していた**。固定境界を維持したことを根拠とする入口と矛盾する。

修正後は再試験モードだけ、未保有・未発注・正常BBOの下で、特徴全体の既知判定より先に、有限な自己価格と準備時の固定幅で境界破綻を取り消す。現在ATRの欠測でも、取消しの幅は準備時に既知である。旧モードは変えず、既に発注判断した注文は後から取り消さない。

- 修正前の失敗証拠：[108項目中8反例](再試験入口状態の独立人工_1792491009573645800.json)
- 修正後の証拠：[111項目全合格](再試験入口状態の独立人工_1792491088291691700.json)

金融成績を見て条件を選んだ変更ではなく、金融前の仕様整合性修正である。これだけで収益優位が生まれるとは言えない。別の入力の欠測が、観測できているリスク取消しまで妨げていないかを、今後の状態機械でも確認する必要がある。
