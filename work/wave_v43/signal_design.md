# H019の固定時間窓合議

H019の**完全な入口**を固定6倍率で計算し、単一3条件と合議9条件を作る。各窓の中で、中期EMA方向の保持、同倍率の相手主方向の確認、短期価格の確認、120秒の入口保持まで終えてから投票する。EMAの方向だけを多数決する方式ではない。

|構成倍率|EMA短／長|長期EMAの差分本数|短期価格秒数|
|---:|---:|---:|---:|
|0.64|10／38|2|19|
|0.8|12／48|2|24|
|0.96|14／58|3|29|
|1|15／60|3|30|
|1.2|18／72|4|36|
|1.44|22／86|4|43|

丸めは旧実装と同じ `floor(x+0.5)`。EMA間隔0.15ATR・傾き0.02ATR・短期価格0.05ATR、足の始点＋120秒公開、相手の追加60秒、開始20分待ち、入口の120秒保持は変えない。公開ATRも既存入力のものを使う。

単独窓はS080／S100／S120。合議はM2／V2／U3について中心080／100／120を設定する。構成倍率は中心×〔0.8,1,1.2〕を小数2桁に丸めた値で、中心080は〔0.64,0.8,0.96〕、中心100は〔0.8,1,1.2〕、中心120は〔0.96,1.2,1.44〕。

- **M2**：同方向2票以上。反対1票を許す。事前の主案はM2_100。
- **V2**：同方向2票以上、反対票0。
- **U3**：3票すべて同方向の非中立。

中立を分母から除かず、合議自体の保持は加えない。〔買、中立、中立〕は全方式で中立。3値の中央値はM2と同じなので別候補にしない。V2／U3や中心感度の成績が良くても事後に主案へ昇格させない。

実装は `window_signals.py`。`catalog()`は12仕様、`build(spec, inputs, features)`は原本行のint8方向辞書を返す。NPZのキーは `session|symbol`。`entries`に12入口、`members`に6構成窓を保存する。`set_root`は監査用に複写した1分足の参照先を切り替えるだけで、原本を書き換えない。

旧 `hierarchy_signals.build` は旧カタログと単一±20%だけを許すため、新倍率では新しい固定6倍率の検証後に同じ内部関数を旧と同じ順番で呼ぶ。旧コードやcatalogの一時置換は行わない。0.8／1／1.2は旧buildの再生成と旧v35保存列の双方へ全26入力で完全一致させる。

因果検査では全12×26を対象に、共通時計で実入力・公開特徴を切断し、未来の価格・ATR・板特徴・1分足を変え、価格と方向を上下反射して入口を再生成する。別に各市場の同時刻群途中を原本seqで切断する。完成済み方向キャッシュを単に短縮して検査済みとはしない。原本78ファイルと旧実装のSHAを前後照合する。

3票は同じ価格系列の異なる窓であり、独立した3つの情報ではない。方向の部分集合が成り立っても、注文・休止・返済による取引や損失の部分集合は保証しない。この段階は入力と合議の検査だけで、売買損益・未知期間の優位性は検証していない。
