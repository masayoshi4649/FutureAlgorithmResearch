# 時間窓合議の反証計画案

**主な問いは、H019 の窓を束ねることで、単一窓の時計感度と大勝ち依存を軽減できるかである。** 黒字戦略の存在、中央の収益改善、時計を動かした耐性、合議による選別の追加価値を別々に判定する。どんな相場でも利益が出る保証や、未知相場での統計的確証は今回の完了条件に加えない。

損益を見る前の設計案である。親担当の採用方針に合わせ、主格子は32条件、活動は実取引と買売双方の有無、8波は別判定、乱数間引きは今回は未実施とした。新損益、原本、現在データ、APIを使用していない。

## 1. 比較する条件を固定する

入口は単一窓 S の中心 0.8／1／1.2 と、M2／V2／U3 の各中心 0.8／1／1.2、計12本。出口は A0 と C01（B00_RB00_F25_N1）の2本を固定し、計24基礎条件とする。M2中央だけに伝達1／5／15秒・全約定観測価格の4変更×2出口を加え、全32条件とする。執行条件も別々の診断であり、全変更を同時に加えるものではない。

- M2 は3票中2票以上。V2 は2票以上かつ反対票なし。U3 は3票一致。欠測・未成熟は中立票で、母数3を減らさない。
- 合議の倍率集合は中心0.8で〔0.64,0.8,0.96〕、中心1で〔0.8,1,1.2〕、中心1.2で〔0.96,1.2,1.44〕。同じ倍率の入口は共有してよいが、個々の窓の保持状態は独立に計算する。方向3値の中央値はM2と同じなので追加条件に数えない。
- 旧H019の主EMA方向・同窓の相手方向・短期価格・入口保持まで完結した3方向を合議する。合議後の保持は追加しない。相手追加60秒、公開遅延、ATR計算、入口閾値、注文管理は変更しない。
- 主案は出口別の「M2・中心1」。V2／U3や中心変更の最良結果へ差し替えない。出口も結果を見て一本選ぶ運用にしない。A0だけ／C01だけに効果がある場合は、その出口に依存する結果と表記する。
- C01のB00悪化・回復窓は固定したまま。影のA0も当該入口で動かし、旧H019の影へ新入口を混ぜない。合議による入口撤回を、追加の成行返済条件へ転用しない。

金額はTOPIXミニ／NK225マイクロ、初回5／10枚、片方向上限10／20枚、費用0・指定価格約定、全玉場内返済という旧条件を維持する。単一中央のA0／C01は、状態記録を修正済みのv41と注文・損益を一致させる。

## 2. 期間・単位を変えない

全13セッションと、既存と同じ後半7セッションをそれぞれ集計し、両銘柄で4セルを作る。全13と後7は重複しており、両方とも既読である。後7を今回新たな未見検証と呼ばない。

元組は一度のA0新規からその終了まで。C01の減量・復元・部分利確を、独立した勝ち組へ分割しない。入口が違う条件間では組の集合も異なるため、同じ組番号を機械的に対応させた差分を作らない。円収支・時価DDは同銘柄内で直接比較し、総Rも補足する。総Rの改善を円収支の改善へ読み替えない。

各期間には、利益・損失・収支、勝ち／負け／同値の決済枚数、元組PF、平均元組勝敗比、1枚平均勝敗比、取引組数、稼働場数、時価DDを必ず残す。日中／夜間／開始日による週別・指定8波も全件表示する。毎日又は全ての波で黒字という条件は設けない。

## 3. 採否を分ける固定案

### 基礎候補

旧v38と同じ経済基礎を、各条件の全13／後7・各銘柄へ適用する。

1. 収支が正、元組PFが1超、平均勝ち元組額／平均負け元組額が1超。
2. 最大1勝ち元組を除いた収支が非負。最大1黒字セッションを除いた収支も非負。この2除外は別々に計算する。
3. 各4セルで実際の元組取引があり、買い開始・売り開始の元組が両方ある。稼働場数・取引組数・保有時間と単一窓との差は表示するが、半数場や基準の何割といった新しい活動下限は設けない。負け枚数が多くても金額で損小利大なら、その事実をそのまま評価する。

分母なしの比率は未確認とし、無損失・無取引を無限大の優秀な成績へ変換しない。保存値の非有限・欠落・重複は検証不備として拒否する。1枚平均勝敗比は別ラベルで1超かを表示し、元組の損小利大と混同しない。上位2勝ち元組を同時に除く検査も表示するが、今回の基礎条件へ後付けしない。

指定8波は旧定義の「正方向ネット保有20分以上」を維持し、目的適合は8/8かを独立に判定する。波内の金額損失があるだけで、この参加判定を不合格へ変えない。中心変更・執行変更でも8波を全件表示し、基礎黒字と波の捕捉を別に残す。基礎が通って波が不足する場合は「黒字基礎は通過、要求した波の参加は未達」と明記し、波を無視して全目的達成とは呼ばない。

### 中央の追加改善

出口別にM2中央と単一中央を比較し、次を固定ラベルにする。

|判定|条件|意味|
|---|---|---|
|収益の追加改善|後7では両銘柄とも円収支差が正、全13では両銘柄とも非負。両条件とも基礎候補の検査を併記。|中央を束ねた今回の収益増。DD改善まで含めない。|
|収益・DDの同時改善|4セルとも収支差が非負、DD差が非正で、少なくとも1項目に厳密差。|旧同様の強い改善ラベル。これだけを黒字候補の唯一の必要条件にしない。|
|交換又は混在|上記以外で、収支又はDDに正負が混在。|増益に対するDD増、又は収益を減らすDD削減の交換を具体額で示す。|
|同値／対照優位|全値同じ、又は単一中央が4セルで収支・DDの両方を非劣位にする。|合議による追加改善は支持しない。|

小さなDD増だけで「戦略が無価値」とはしない。一方、増益だけを示してDD悪化を隠さない。浮動小数誤差の比較許容値を固定し、経済差を許す後付けの許容率は導入しない。

### 時計中心への耐性

出口別のM2について、中心0.8／1／1.2の全てが、上記の基礎候補条件を通ることを「今回の3中心で耐性支持」とする。つまり今回は、中心を変えた条件にも最大1勝ち組／最大1黒字場の除外と活動下限を接続する。旧v38の感度判定は収支・PF・平均元組比だけで、大勝ち除外は表示だった。この変更は既知の未解決点を直接検査するためのもので、旧採否を無効にするものではない。

比較表には単一窓側の3中心も同じ基準で判定し、中心別の収支、DD、大勝ち除外後収支、活動、8波を横並びにする。合議の3点中の最悪収支・最大DD・最悪除外後収支も残す。全ての時間窓や市場状況への耐性という主張には広げない。

「合議による収益増と時計耐性を備えた研究候補」は、中央の基礎、収益追加改善、3中心耐性、実装監査の全てを満たす場合に限る。指定8波と4執行はそれぞれ別ラベルで必ず併記する。どれか不足した場合も、基礎黒字候補やDD削減という個別の達成は消さない。例えば中央が減益だが3中心が安定した場合は「時計耐性との交換」とし、収益追加改善とは呼ばない。

中央M2の執行4変形は、旧感度と同じ後7・両銘柄の収支正／元組PF>1／平均元組勝敗比>1を執行基礎として判定する。活動・最大勝ち除外・全13も全表示し、執行基礎だけの合格を集中依存の解消と読み替えない。

## 4. 見送り効果を分ける最小の補助案

M2は単一中央の間引きだけではない。中央が中立でも両隣が同方向なら新しい入口を作り、中央と逆方向を選ぶ場合もある。したがって、単一中央から同じ数の取引を削るだけの対照は完全な対応対照にならない。

**今回は実施せず、将来の切り分け案としてだけ残す。合議固有の予測追加価値は今回判定しない。** 必要になった場合は中央の2出口だけに次を追加し、V2／U3や各中心へ補助格子を増やさない。

1. **中央選別だけの対照G**：単一中央が非中立でM2と同方向の行だけ単一中央を許可し、その他は中立。M2−Gは「中央にはない方向・時刻も許可する経路」を含む差、G−単一中央は「中央の見送りを変える経路」を含む差として示す。注文状態も変わるため、損益を足し算できる独立成分とは扱わない。
2. **過去率による乱数間引き64本**：当該セッション開始より前に完了した場だけから、単一中央の非中立時間に対するGの非中立時間の比率qを銘柄別に求める。過去不足はq=1。単一中央の方向が新たな非中立の連続区間へ入った時、その開始seq・session・symbol・固定seedで一度だけ公平一様数を作り、q未満ならその区間を許可する。区間の未来の長さを使わず、同じ区間の再エントリーで引き直さない。A0／C01で同じ間引き列を使用する。

これは**過去の許可率を合わせた因果的な機会削減対照**であり、現在の非中立時間・約定回数・保有時間まで完全に同率ではない。厳密に現在セッションの合議採用数へ合わせて後から削ると、未来の活動情報が入り、運用戦略として不適切になる。非中立時間と実約定回数のずれを必ず表示する。

この補助を実施するなら、GとM2それぞれについて後7の両銘柄の円収支が64本の中央値を厳密に上回るかを表示し、全13も併記する。最良seedは採用せず、正式なp値と呼ばない。上回らない場合は「単に参加を減らす対照に対する合議選別の追加価値は未確認」とし、黒字・時計耐性そのものを取り消さない。上回っても活動時刻・取引経路が完全一致しないので、合議の純粋な因果効果が証明されたとはしない。

追加する場合の実施条件は、その追加結果を見る前に別途固定する。今回の結論は「見送り量対照未実施」で、合議情報の追加価値の判定は保留する。

## 5. 必須の完全性と、今回で証明しないこと

32条件・13場・2銘柄の集合、方向3票の27通り、中央値=M2、買売反射、接頭部・未来変更、原本行と解放時刻、注文の次行以後と伝達遅延、全決済・枚数上限、金額と枚数、全時価DDを独立検算する。単一中央2出口の旧台帳再現と、同一倍率の方向同値を確認する。3窓を3個の独立予測や3市場分の証拠とは数えない。

既存の観測価格約定・伝達遅延の結果は、合議で新規時刻が変わる今回の条件へ自動継承できないため、M2中央で再検証する。観測価格と15秒遅延の同時変更や、全中心・全投票規則の執行感度までは今回含めない。指定価格約定という今回の許容前提の黒字と、実約定への頑健性は分ける。

v41では旧974条件の状態修正再生が完了し、既知12行以外の注文・損益は同値だった。状態記録の旧障害と、今回の収益性・時計感度を混同しない。新しい合議条件を作ること自体は、既知13場の選択バイアスや未知期間の不足を解消しない。ただしその不足を理由に、有限の実装・比較検証を永遠に未完とすることもしない。
