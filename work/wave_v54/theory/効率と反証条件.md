# 効率と反証条件

ここでいう効率は、少額の損切りを何度も行えたことでも、最大利益額でもありません。**入口で引き受けた1Rのリスクに対して、平均してどれだけ返ってきたか**を主指標にします。機会費用は主な最適化対象にしません。

## 比較の単位

各組について、方向を `d`、入口価格を `E`、固定失敗線を `S` とし、価格単位のRを `d×(E−S)` で定めます。Rが非正になる約定を小さな正数へ隠して変換せず、入口時の想定崩れとして別に記録することを提案します。通常のリスク下限を使う場合は、実際の距離と計算用Rを両方残します。

`組のR収益 = 全返済脚の合計損益 ÷ (初回枚数 × 商品倍率 × 入口時R)`

部分返済しても分母は最初に引き受けたリスクです。途中の利益脚だけで勝率や平均勝ちを数えません。平均R収益と、全損益を全初期リスク金額で割った値は異なる重み付けなので、混同せず併記できます。

| 必須の評価量 | 意味 |
|---|---|
| 平均R収益 | 1回のリスク当たりの平均的な成果 |
| 平均勝ちR／平均負けR | 勝った組と負けた組の大きさの比。回数も必要 |
| 取引した組数・場数 | 極少数の成功を安定と呼ばないための分母 |
| +2Rと−1Rの先着、期限終了 | 予想した非対称な経路が発生したか |
| 固定線への距離、確認待ち時間 | 待つ間に有利な値幅を使い切っていないか |
| 銘柄別・前後期間別・昼夜別 | 共通規則が片方だけの性質に依存しないか |
| 最大利益場を除いたR・損益 | 一度の成功に支配されていないか |
| 全玉時価ドローダウン | 未返済の損失を消していないか |

費用0で、必ず+2Rか−1Rのどちらかに正確に到達して終わるなら、期待R収益は `2p−(1−p)=3p−1` です。その特殊な条件では勝率が1/3を超えれば正です。時間切れ、分割、ギャップ、条件変更による返済があればこの式をそのまま使えず、全取引の実現R平均で判定します。どちらにも到達しなかった取引を分母から落としてはいけません。

## 狭いストップは無料の改善ではない

失敗線が近いと、同じ順行幅が大きいRになります。一方で小さな逆行でも損切りになり、勝ちに至る確率が下がります。「目標は損切りの2倍」という配置だけでは、確率まで改善していません。方向性のない連続価格過程でも、遠い利益目標へ先に到達する確率はその分だけ低くなります。

効率がよいというためには、近い失敗線で退出した後に回復する機会を失う影響を含めても、平均R収益が改善する必要があります。遠い入口を単純に除くと取引集合も変わるため、同じ接触事象から近い時点・遠い時点のどちらを採用したかを対応させて記録します。

## 正規化で消せる差と消せない差

| 正規化 | 消せる主な単位差 | 消えない性質 |
|---|---|---|
| 価格差÷当時のATR | ポイント単位と変動幅の大きさ | 継続・回帰の傾向、ジャンプ、方向非対称、変動の変化速度 |
| 呼値で測った線からの距離 | 最小刻みの尺度 | 刻みが変動幅に占める比率、約定価格の離散性 |
| 買売数量の差÷合計 | 表示枚数の水準 | 取消、補充、参加者構成、隠れ数量、偏りの持続時間 |
| 注文フロー÷近接厚さ | フローが供給へ与える相対的な大きさ | 供給の回復速度、気配間の空白、順序依存性 |
| 当場の過去活動度との比 | 静かな時間と活発な時間の規模差 | 活動の増加が継続を示すか消耗を示すか、将来の活動 |

一定の正数で価格変化を割っても自己相関の符号は変わりません。ATRが時間変動しても、それが異なる市場の条件付き分布を同じにする保証はありません。米国株の研究でも呼値構造によって注文イベントの影響に異なるモデルが必要でした。[Eislerほか](https://arxiv.org/abs/0904.0900)

したがって、同じ入力単位と閾値を使えることと、同じ期待利益が出ることは別です。金額合算で片方の失敗を隠さず、まず両銘柄それぞれで同じ規則の符号と安定性を確認します。

## 反証を先に決める

| 反証 | 否定される主張 | その後の扱い |
|---|---|---|
| 継続・回帰のどちらも平均R≤0 | 境界反応に収益として使える情報がある | 今回の機械化を不採用。売買方向だけを成績で反転させない |
| 一方の銘柄だけで持続的に正 | 銘柄を問わない共通優位性 | 共通手法として採用しない。差の説明は仮説として残す |
| 入口後の方向差がなく、出口設定で順位が大きく入れ替わる | 入口で条件付きの方向情報を得た | 入口の効果と管理の分布変形を区別する |
| 近い線での入口が遠い入口より平均Rを改善しない | 小さい構造リスクを利用した効率化 | 距離制限の効果は未確認とする |
| 確認待ちの間だけ動き、確認後は進まない | 確認しても利益余地が残る | 待機コストを計測し、待てば安全とは言わない |
| 板・相手を足すと平均R又は総Rが悪化 | 追加観測が価値を足す | 確認層を不採用。板全般が無価値とは結論しない |
| 最大利益場を除くと負、期間で符号反転 | 安定した共通の性質を捉えた | 再現未確認とする |
| 無取引・極少数しか残らない | 実用的な頻度で優位性を確認した | 成功とは数えず、件数不足を明記する |

「平均R≤0」は当該試験で期待した成果がなかったという判定です。少数標本から母集団の期待値が必ず負だと証明した意味ではありません。逆に平均R>0だけで高確度の正期待値とも言えません。独立性は取引ではなくセッションに近いため、信頼区間を計算するならセッション単位の再標本化を用い、上限・下限と標本数を併記します。

## 比較を条件探索に変えない

主案は両分岐を使う一つの状態機械に固定します。継続だけ、回帰だけ、線外の定着を待たない、近接制限を外す、余地制限を外す、板拒否を加える、相手拒否を加える、両方を加える、固定目標をトレールへ変える、といった対照は、どの仮定が必要だったかを調べるものです。

条件数を増やす場合も各比較の問いを一つにし、最高利益の組合せへ主案を置き換えません。目標倍率・窓・確認本数を多数走査した後の最良点を、原理から導いた規則と呼びません。今回の保存履歴は既読なので、数値固定後の照合であって厳密な未見試験ではありません。
