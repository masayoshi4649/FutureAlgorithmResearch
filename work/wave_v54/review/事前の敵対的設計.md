# 作業 00051：実測前の敵対的設計

新しい損益を見ずに記した監査案です。最終的な主規則と対照条件は実装担当が固定し、この提案だけを採用済み規則とは扱いません。旧成果・API・原本は変更しません。

## 主張を分ける

支持抵抗の突破が続く場合と、失敗して戻る場合では、同じ時点・同じ注文で両方に勝てません。価格が線のどちら側に残るかを観察し、確認を待つ代わりに入口が遅れる、という交換条件が主仮説です。

「両市場で同じ規則を実行できる」と「両市場で利益が出る」は別です。ATRや活動度で標準化しても、値動きの持続性・提示数量・参加者・スプレッド等の分布まで同じになるわけではありません。銘柄名による分岐をなくすのは普遍性を試す条件であり、その証明ではありません。

## 状態機械で固定すべき点

1. **境界線を後から引き直さない。** 現在足を除いた過去高安から線を決め、突破イベントが発生した時点で線・反対側の線・尺度を保存する。価格が進むにつれて線も追従すると「定着」の反証が消える。
2. **尺度をイベント途中で変更しない。** 反発や逆行でATRが上がり、それまで失敗だった値幅を許す仕様にしない。入口イベントの判定幅とその期限には開始時の尺度を使う。
3. **状態を相互排他的にする。** 待機→突破観測→定着または失敗→消費済み、の順とする。始値や高安が両側へ触れただけで、同じ一本の順序を復元しない。
4. **確認はその後に公開された情報だけを使う。** 例えば確定終値二本が必要なら、二本目が公開された行以降にだけ判断する。「しばらく定着した」と判明した後、最初の突破値で入ったことにしない。
5. **寿命を延長しない。** 再接触や同方向の小突破で時計を再始動させず、古いイベントを際限なく使い回さない。次の新規機会に必要な解除・再武装条件も明記する。
6. **失敗線は現在の建玉方向に対して損失側。** 追従なら境界の内側、反復なら観測済み突出端の外側など、仮説を否定する価格を先に置く。線が遠すぎるなら見送りとし、恣意的に手前へ切って『構造線で守った』とは説明しない。
7. **欠測は根拠を消す。** 板の不明を均衡と扱わない。長い時間欠落を挟んで定着二本を数えない。活動度の準備不足は低活動とも高活動とも判定しない。
8. **両銘柄同一の関数を使う。** 銘柄名・過去損益・この場の最終高安は条件へ渡さない。呼値・乗数等の契約情報と当場の既知情報は利用可能。

## 管理を簡素にする理由

主試験は、一つの反証ストップ、必要なら一つの利益追跡、場内全返済で十分です。最初から半減・逆転・増玉・連敗停止・複数期限・板による幅変更を全投入すると、入口仮説を支持したのかが分かりません。

反復の目標は、観測済みのレンジ中央や反対端などに固定できます。ただし「目標まで2Rある」は予定値幅であり、実現期待値ではありません。目標まで近すぎる入口を見送るなら、その除外条件も主試験前に固定します。

追従と反復で出口を変えること自体は可能ですが、最初は共通の単純出口でも比較します。出口まで同時に変えた結果だけで「状態判定が有効だった」と結論しません。

## 十条件以上を部品反証にする案

以下は例であり、主案に存在しない部品を検査数のために追加しません。数値を多数振って最良を採る探索にはしません。

| 比較 | 変更するもの | 問うこと |
|---|---|---|
| 主案 | 定着と失敗を同一規則で選ぶ | 両市場で仮説全体が成立するか |
| 即時追従 | 同じ境界の最初の突破で入る | 確認を待つ費用を上回る改善があるか |
| 即時逆張り | 同じ突破で即座に逆へ入る | 失敗確認がなくても同じ結果ではないか |
| 定着だけ | 反復側を取り除く | 利益が追従だけに依存していないか |
| 失敗だけ | 追従側を取り除く | 利益が反復だけに依存していないか |
| 板確認なし | 価格の状態遷移を残す | 板に価格以上の追加性があるか |
| 活動度確認なし | 同じ価格・板条件を残す | 活動度による見送りが役立つか |
| 板も活動度もなし | 価格の状態遷移だけ | 二部品の相互作用を分けられるか |
| 幅の見込みによる除外なし | 主案にある場合だけ | 狭い利益余地の見送りが役立つか |
| 固定目標返済 | 入口は主案、単純な目標で返す | 追跡で利益を残せているか |
| 利益追跡なし | 入口は主案、反証線と固定期限のみ | 入口の方向判定だけに価値があるか |
| 方向反転対照 | 主案の判断時刻と初期Rを固定して方向だけ反転 | 方向選択に価値があるか |

方向反転対照は、逆方向にも同じ反証の意味があるとは限りません。これは主候補へ採用するための別戦略ではなく、方向と注文管理の寄与を分ける負の対照です。条件により保有時間や再入場機会が変わるため、売買損益の差だけを部品の純粋な因果効果とは呼びません。同じ候補イベントの、その後の方向応答も併記すると解釈しやすくなります。

## 事前に定める評価の単位

- **片方の利益で片方の損失を隠さない。** 各銘柄の収支・PF・平均勝ち一枚／平均負け一枚・1R当たり成績を別々に出す。合算金額を共通性の主基準にしない。
- **1Rを後から変えない。** 原則は実際の新規約定値から当初の反証線までの距離×数量×乗数。途中のストップ短縮やATR変化では縮めない。分割する場合も当初の組リスクで合計を評価する。
- **ギャップを消さない。** 判断から次行約定までに反証線を越えた場合、過去へ遡って『入らなかった』ことにしない。実際にどの注文時点で取消できるのかを仕様化し、約定後ならその損失を記録する。初期Rが非正になる事例を小さな正数へ置換して効率を水増ししない。
- **効率を複数で確認する。** 合計R、平均R／組、利益R／損失R、中央値と最大損失R、時間当たり成績を分ける。保有時間を短くするだけで時間効率が大きく見えるため、これだけで順位を決めない。
- **集中を確認する。** 最大利益の一組除外と最大利益の一セッション除外を両方示す。片方だけでは集中を捉えきれない。
- **場を標本単位として扱う。** 取引数が多くても同一場内の取引は相関する。黒字場数、前後期間、日中と夜間を比較する。結果を見た後に都合のよい分割を主評価にしない。
- **不参加を隠さない。** イベント数、準備不足・曖昧・板不明・利益余地不足などの見送り数、取引数、活動した場数を示す。機会費用を罰点にはしないが、一件だけの偶然を安定性とも呼ばない。

## 合格と保留

共通規則の最低条件は、同一の主規則で両銘柄それぞれが黒字、1R評価も正、最大利益場を除いても黒字であることです。それに達しても、既読二十三場の中で選んだ規則なので『安定した普遍則を確立した』とは結論しません。

平均勝負比が1未満で利益が出る場合は、別の有用性はあり得ますが、ユーザーの希望する一枚当たりの損小利大を満たしたとは書きません。最良だった対照へ後から主案を差し替えず、主案の反証と残った部品を区別して報告します。

## 実装後の独立検査

状態遷移の手作り反例、確定前の山谷禁止、未来切断・改変、価格の倍率と平行移動に対する標準化の整合、銘柄名の入れ替えに対する判断一致、数量と組会計、場末全返済を検査します。
