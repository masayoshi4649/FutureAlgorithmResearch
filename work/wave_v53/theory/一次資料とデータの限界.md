# 一次資料とデータの限界

資料は手法を発想・定義する根拠です。日本の株価指数先物で今回の数値設定が儲かることの証拠は、今回の因果的な再生結果から判断します。

| 一次資料 | 確認した内容 | 今回への適用と限界 |
|---|---|---|
| [Lo・Mamaysky・Wang、テクニカル分析の自動化](https://www.nber.org/papers/w7613) | 主観的なチャート形状を機械的に定義し、条件付き収益分布を評価する枠組み | チャート読みを再現可能な条件へ置き換える発想を採用。対象は米国日次株価であり、今回の分足での優位性は別途確認が必要 |
| [Osler、支持抵抗と注文の集中](https://www.newyorkfed.org/research/staff_reports/sr125.html) | 大手為替銀行の注文を調べ、利確とストップ注文の集中が反転・突破後加速を生む機構を検討 | 同じ線でも反発と突破の両仮説を比較する理由になる。今回の板から当該注文の種類や所有者は特定できない |
| [John Bollinger本人の使用規則](https://www.bollingerbands.com/bollinger-band-rules) | 帯への接触だけは売買信号ではなく、強いトレンドでは外側を進む。20期間・2標準偏差は既定値 | 帯外からの復帰を入口候補にする。2σを正規分布の95%保証として使わず、複数価格指標の重複にも注意する |
| [TA-LibのRSI定義](https://ta-lib.org/functions/rsi.html) | 上昇幅・下落幅のWilder平滑に基づくRSIの計算 | 14期間と30/70の復帰を機械化する。計算式が正しいことと売買の有効性は別問題 |
| [TA-LibのKAMA・効率比定義](https://ta-lib.org/functions/kama.html) | 終点間の変化と途中の総変動から効率比を計算 | ER15を過去の進行/往復の要約に利用する。0.4・0.25は今回固定した仮説であり、資料が推奨・証明した閾値ではない |
| [Interactive BrokersのVWAP定義](https://www.interactivebrokers.com/campus/glossary-terms/volume-weighted-average-price-vwap/) | 対象期間の売買金額を出来高で割る平均取引価格 | 価格の基準として用いるが、公正価値や必ず戻る水準と解釈しない。今回は約定代金を完全再構成しない近似値を用いる |
| [Contほか、注文フローと価格変化](https://arxiv.org/abs/1011.6402) | 最良気配の注文フロー不均衡と短い同区間価格変化の関連を分析 | 執行・供給変化を測る動機。ただし同区間価格との関係から、その後の収益予測ができるとは結論しない |

## 提供VWAPを直接使わない理由

今回確認した原本では、デイ開始時のVWAPと累積出来高に前ナイトが含まれていました。例えば `book/TOPIX/2026-10-06_Day.jsonl` の08:45:01付近では累積出来高17,208、提供VWAP4172.4032でした。直前ナイトの開始17:00:01付近では累積出来高21、VWAP4168.0から始まっています。デイ開始後もOpeningPriceTimeが前日17:00:01の行があり、当該デイだけの平均とはみなせません。

NK225も10月6日08:45:01付近で累積出来高9,462、提供VWAP70039.0509であり、同様に当該デイだけの値として採用しません。これらは確認例であって、全ファイルのフィールド仕様を断定したものではありません。

今回の実装は、当該セッションで公開された正の出来高増分に、そのブロックの源最終価格を掛けて累積し、累積出来高で割る近似VWAPです。最初に記載された累積出来高をそのまま足さず、場を跨ぐ値を持ち込みません。複数価格で成立した数量を一つの源最終価格で代表させるため、正確な約定代金VWAPとは異なります。

出来高欠測又はリセットを含むブロックは加算せず累積を再始動し、再始動時刻と回数を記録します。その場合は厳密にはセッション開始からの平均でなく、再始動後の平均です。この情報を隠して「当日全量VWAP」と説明しません。

## 板読みで分かる範囲

表示数量の減少は、約定・取消・変更の複数の原因で生じます。出来高増分と直前気配から執行側の代理を作れても、ブロック内の全約定を個別分類したものではありません。全量不明なら偏り0でも中立とは言えません。

同価格の数量回復は、同じ参加者の再補充、別参加者の新規注文、取消後の再提示などで同じ観測になります。今回の「固定気配での回復」は回復した隣接2行の気配が同じという条件で、減少から回復まで全期間の気配固定ではありません。隠れ注文や大口の意図を特定した名称に置き換えません。

板の受信時刻はなく、原本のCurrentPriceTimeは約定の時計です。行順序は保存できますが、同じ時計に束ねられた板変更の実際の発生間隔は復元できません。60秒の板集計や30秒の回復窓はこの時計に基づく代理です。相手銘柄についても厳密な市場間先行遅行を証明するデータではありません。

今回、板確認が利益を改善しても、それだけで「参加者の心理を読めた」「買いが焦っていた」とは言えません。価格・平均・時間による選別と板の追加情報を4層比較で切り分けます。
