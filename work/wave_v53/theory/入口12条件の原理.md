# 入口12条件の原理

最初に読む資料は本書です。次に「4層比較と自動選択.md」、必要な場合に「一次資料とデータの限界.md」を読んでください。

本書は売買結果を見る前にまとめた原理・実装対応表です。各指標は入口候補を作る道具であり、利益が出る根拠が確認されたという意味ではありません。実際の条件は `../signals.py`、保有・返済は `../engine.py`、公開順序は `../測定仕様.json` を正とします。

## 共通の読み方

判断に使う足は、そのセッションの原本から作った中値の確定1分足です。次の時間区間の原本行が来てから直前足を公開し、発注判断より後の有効原本行の最終価格で約定させます。同じ足の中で高値と安値がどちらから生じたかを都合よく決めません。

`A` は公開済み確定5分足のATRです。最初は4本から開始し、14本まで増やした後は直近14本のTR平均です。短い準備期間のATRが成熟したATRと同じ精度とはみなしません。EMAは8分・21分、RSIは14分、ボリンジャー帯は20分平均±2標準偏差、支持抵抗は現在足を含まない過去20分高安です。

以下は買い側の説明です。売り側は大小と方向を反転します。表の「失敗線」は入口の仮説に関係する線です。初期ストップは資金保護のため0.5～1.5Aの距離に制限するため、実際のストップが常にその線と一致するわけではありません。

| ID・名前 | 何を仮定するか | 機械的な入口 | 仮説が外れる場面・失敗線 |
|---|---|---|---|
| T01 支持抵抗での反発 | 直近の下端を超えて売る意思が弱く、下値に供給される買い注文が価格を戻す | 現在足安値が過去20分安値の0.1A以内に接触し、終値がその線より0.1A以上内側、前足終値より上。既知レンジ中央まで0.25A以上残る | 相場全体の値直しでは過去の端は支えにならない。線と接触足安値の低い方−0.1Aが失敗線 |
| T02 突破後の戻り試し | 一度越えた抵抗が下値支持へ変わる | 過去20分高値を0.1A超えて引けたら線を保存。次の足以降10分以内にその線付近を試し、線の0.1A上を保ち陽線で引ける | 反対注文が復活すると戻り試しから崩れる。再接触足安値−0.1Aが失敗線 |
| T03 開始30分レンジ突破 | 最初の価格探索を終え、従来の合意範囲外で取引が続く | セッション開始から30本の連続した確定1分足の高安を固定。前終値が高値以下、現在終値が高値の0.1A上を越える | 薄い注文による一時的な飛び出し。開始レンジ高値−0.25Aが失敗線 |
| T04 VWAPからの乖離回帰 | 一時的な売りで当場平均から離れ、売りの勢いが弱まる | 前終値が前の近似VWAPより1A超下、現在終値が上昇に転じ、現在近似VWAPまで0.25A超残る | 新情報によって平均自体が古くなる。直近2本安値−0.1Aを失敗線、判断時VWAPを回帰目標に固定 |
| T05 VWAPの回復 | 平均取引水準を上回る値直しが、短期トレンドと一致する | 前終値が前の近似VWAP以下、現在終値が現在VWAP上。EMA8>EMA21、EMA21が5分前より上、VWAPが5分前以上 | 平均付近の往復では交差が増える。直近2本安値−0.1Aが失敗線 |
| T06 移動平均への押し戻し | 上昇中の一時的な押しが終わる | EMA8>EMA21かつEMA21が5分前より上。前終値は前EMA8以下、現在終値が現在EMA8上へ戻る | 上昇終盤の反転を押し目と誤認する。直近2本安値−0.1Aが失敗線 |
| T07 RSIの極端域から復帰 | 売りの継続が弱まり、価格も戻り始める | RSI14が30未満から30以上へ戻り、現在終値が前終値より上 | 強い下落中の小休止。直近2本安値−0.1Aを失敗線、判断時20分平均を回帰目標に固定 |
| T08 ボリンジャー帯の内側へ復帰 | 直近分布からの下方逸脱が縮小する | 前終値が前の下側帯の外、現在終値が現在の下側帯の内側へ戻る | 帯が動いて内側へ入っただけの場合もある。直近2本安値−0.1Aが失敗線、判断時20分平均が回帰目標 |
| T09 突破失敗からの逆方向 | 下抜けを追った注文が価格を維持できない | 過去20分安値を下抜けた線を保存し、後の足が5分以内にその線の0.1A上へ戻る | 本当の下落の途中に短い買戻しがある。失敗確認足安値−0.1Aが失敗線、確認時に既知の20分レンジ中央が目標 |
| T10 確定した高安構造の突破 | 安値を切り上げる買いと高値更新がそろう | 左右2本で確定した直近2組の高値・安値が共に上昇。直近確定高値を終値で上抜く | 確認が遅く残る値幅が小さい、または往復相場。直近確定安値−0.1Aが失敗線 |
| T11 板の回復と価格反転 | 同じ価格で買い数量が回復し、価格も下げ止まる | 品質を満たす直前60秒で買い側の同価格回復偏り≥0.1、近接供給偏り≥0。前足は陰線、現在終値は前終値より上 | 補充が続いても売りに押し切られる。直近2本安値−0.1Aが失敗線、判断時20分平均が目標 |
| T12 強い執行偏りの直後に逆張り | 一時的な執行偏りの価格影響が後で戻る | 品質を満たす直前60秒の売り執行代理偏りが0.6以上で、現在終値も下落した時点で買う | 持続する値直しなら逆張りが連続して負ける。直近2本安値−0.1Aが失敗線、判断時20分平均が目標 |

T12の0.6は今回の両銘柄共通の固定値です。旧作業C02の銘柄別閾値をそのまま再現した条件ではありません。

T08は価格の戻りと帯そのものの移動を区別しない通常の定義を採用しています。したがって「必ず価格が反発した」と説明してはいけません。T09の失敗線・目標は失敗を確認した時点の既知値であり、突破時の極値・レンジ中央を保存する別案とは異なります。

## 事後情報を使わないための固定事項

- 高安線を当日終了後の高安から引かない。現在足が線を作りながら同時にその線を突破したことにしない。
- 戻り試し・突破失敗の線は突破を観測した時点で固定する。後の足で都合のよい線へ置き換えない。
- スイングの中心足は右側2本が確定するまで使わない。確認時刻と発生時刻を分ける。
- 回帰目標は入口判断時に保存する。後から動いた平均へ合わせて過去の目標利益を書き換えない。
- VWAPの出来高累積が欠測などで再始動した場合、再始動前後を跨いだ交差・5分傾きは使わない。
- データ欠損を反転・執行終了・中立の証拠にしない。使える情報がない場合は、その条件の入口は不成立とする。
- 終了後の上昇日・下落日という分類を入口選択へ使わない。

入口の多くは一度だけ発生する交差条件です。次の足で入口信号が0になっても、保有根拠が消えたことにはなりません。保有は構造線、進捗、保有期限、反対方向の新しい生信号で判断します。
