# 4層比較と自動選択

12種類の入口それぞれに同じ4種類の管理を組み合わせ、48条件で比較します。狙いは「よい入口を見つけた後に複雑化すればよい」と決めつけず、確認・管理を足すことで何が改善し、何を失うかを分離することです。数値は成績を見て最適化した値ではありません。

| 層 | 入口 | 保有・返済 |
|---|---|---|
| A 基本保護 | 元の入口候補 | 共通の損失制限・トレール・時間返済 |
| B 高度管理 | Aと同じ入口候補 | 進捗、構造、板、時間、分割返済、連敗休止を追加 |
| C 板・相手の確認 | 候補に追加確認を適用 | Aと同じ基本保護 |
| D 確認＋高度管理 | Cと同じ追加確認 | Bと同じ高度管理 |

初回はTOPIXmini5枚、NK225micro10枚。増玉せず、片方向保有上限10枚・20枚を下回る共通サイズで比較します。新規から全返済までを一つの組とし、分割した返済脚の勝率を組の勝率へ読み替えません。全場でセッション内返済を行います。

## 基本保護

入口判断価格から失敗線までの距離を0.5～1.5ATR5へ制限し、初期ストップを置きます。遠い構造線より手前に置かれる場合は「構造が壊れた」という判定でなく、資金保護のための早期撤退です。次行約定による価格差があるためRは約定価格とストップの方向付き距離から決まり、計算上の下限は入口ATR5の0.1倍です。判断時の幅を実際の最大損失保証とみなしません。

1R順行後は最高到達値から1R幅でトレールします。最長30分、反対方向の新しい生信号、セッション内返済期限でも返します。確認を足した層でも返済に使う反対信号は確認前の生信号とし、入口確認の有無だけで返済条件まで変えません。

## 高度管理を足す理由と反例

| 追加要素 | 期待する効果 | 悪化し得る理由 |
|---|---|---|
| 5分で最大順行0.25R未達なら全返済 | 値幅が進まない建玉を長く抱えない | 立ち上がりの遅い大きな波を捨てる |
| 0.5R順行後、状況別ATRトレール | 利益が出た後の大きな戻しを抑える | 小さな押しで降り、その後の大波を逃す |
| 15分・30分経過後に幅を短縮 | 時間経過で利益を失う建玉を減らす | 時間だけでは勢いの低下を意味しない |
| 公開された確定スイングで保護線更新 | 高安構造が壊れた時に撤退する | 確定が遅く、浅いスイングで過敏になる |
| 回帰目標到達又は板悪化で一度半減 | 得られた利益を残しつつ伸びる余地を残す | 勝ちの大きさも半減する。板信号が価格と重複する可能性 |
| 追従90分・反復15分・不明30分上限 | 仮説ごとに時間の使い方を変える | 過去状態が後で変わり、長短の判定が外れる |
| 全返済した組で2連敗後15分休止 | 合わない短い局面への連続参入を避ける | 次の勝ちも逃し得る。連敗だけで次も負ける証拠はない |

トレールは常に既存ストップを有利な側へだけ更新し、後から緩めません。追従が維持される時の幅は`max(0.5×現在ATR5, 0.5R)`、それ以外は`max(0.3×現在ATR5, 0.25R)`。15分、30分経過時にそれぞれ0.75倍、板が反対なら上限0.3R、最小幅0.15Rです。1R順行後には少なくとも建値まで保護線を上げます。これらは管理仮説の固定値であり、理論上の最適幅ではありません。

部分返済は現在価格で0.5R以上順行している時だけ、一度実施します。TOPIXは2枚を返して3枚、NKは5枚を返して5枚を残します。回帰目標が実約定価格から0.5R以上の有利な側にある場合だけ、その到達を部分返済根拠にします。全組の連敗判定は残玉も返した後の合計損益で行います。

保有上限の基準時刻は初回約定時刻です。状況変化に伴って期限を短縮することはありますが、後から追従判定へ変わったことを理由に期限を延ばしません。

## 入口に追加する確認の意味

追従入口では、執行代理又は提示価格の変更が候補方向に整合し、近接供給が強く反対へ偏っていないことを確認します。反復入口では、候補側の同価格数量回復、又は執行代理と実際の価格反転の整合を確認します。相手銘柄が明瞭に逆方向へ進んでいれば入口を拒否します。

板不明は確認成立にしません。相手不明を一致と数えず、相手が明瞭に反対のときだけ拒否します。相手データは自己の判断より少なくとも60秒前までの公開情報を用いるため、現実の同時点の両市場を完全再現した比較ではありません。執行の全量が分類不明なのに偏り0だった場合、それを均衡・執行終了と解釈してはいけません。

追加確認は同じ判断時点での除外条件です。「あとで条件がよくなったから過去の入口を復活させる」という操作は行いません。確認により平均損失が減っても、捨てた勝ちの方が大きければ不採用です。

## 自動選択

主案はセッション内だけのER15、EMA8とEMA21の乖離、近似VWAPに対する現在位置で手法群を選びます。

- 追従: ER15≥0.4、EMA乖離≥0.25ATR5、価格のVWAPに対する側がEMAの方向と一致。突破後の戻り試し→EMA押し戻し→VWAP回復→確定高安突破→開始30分突破の固定順で、追従方向の入口を探す。
- 反復: ER15≤0.25。支持抵抗反発→帯内復帰→VWAP乖離回帰→RSI復帰の固定順で入口を探す。
- 不明: 上記以外。突破失敗だけを候補にする。

ERは過去15分の終点間変化を総移動量で割った比率です。高ければ過去は一方向に効率よく動いたという意味で、未来が追従相場である保証ではありません。状態の変更自体が市場に注文を出す理由にもなりません。その時点で新しい入口候補が成立する必要があります。

同時に成立した候補は上記固定順で一つを選ぶため、後からその日最も儲かった手法へ差し替えません。統合2条件は、同じ状況選択に基本保護だけを適用する `AUTO_A` と、確認・高度管理を適用する `AUTO_D` です。個別48条件と合わせて50条件を比較し、この選択法へ管理を重ねる意味を確認します。

補助的な別設計として、同じ状態が3回連続した場合だけモードを変更する方式も考えられます。これは切替の遅さと往復の少なさを比較する案です。今回の50条件には含めず、未検証案として残します。

## 結果の読み方

同じ入口についてB−A、C−A、D−B、D−Cを銘柄別・セッション別に比較します。Dが最良でない場合も全層を残します。管理で早く退出すると次の入口を取れるため、総損益差には出口の改善に加えて機会集合の変化も含まれます。「同じ取引の損益だけが改善した」とは限りません。

利益・損失・収支と勝ち枚数・負け枚数に加え、入口候補数、拒否数、全返済した組の勝率、平均勝ち/平均負け、最大損失場、最大ドローダウンを併記します。取引が極端に少ないことや無取引を安定して稼げた証拠にはしません。

先頭10場、次9場、最後4場で符号・損小利大が再現するかを比較します。全期間は過去の調査で既読なので、期間を分けても厳密な未見試験と呼びません。今回の条件を成績で差し替えない比較として扱い、選抜後の確信度を過大にしません。
