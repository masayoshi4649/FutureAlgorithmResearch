# 00012 の短い報告構成

成果フォルダ：`アルゴリズム調査/00012_状態切替と柔軟な建玉管理`。
最初に見るファイル：`状態切替と柔軟な建玉管理.html`。

先頭は次の４点だけを中心にする。

1. 銘柄・手法の選択と手法名／ID。
2. 日本語で２行程度の説明。
3. 各10セッションの利益・損失・収支。金額と返済した仮想枚数を併記。
4. 週合計も同じ金額・枚数の形式。

利益枚数・損失枚数は返済単位の累計。収支欄の枚数差を表示する場合は、利益枚数−損失枚数と明示する。
同値返済枚数は損失へ含めず、詳しい集計条件へ記載する。
勝ち枚数が負け枚数以上であることを、損小利大の合格条件にはしない。

金額は元データのラージ価格倍率による参考値。0.1倍／0.01倍は仮定換算として円額だけを変える。
仮想枚数をmini/microの実板による約定実績とは説明しない。保有上限は買い100・売り100。

長い研究説明、パラメータ、監査、再現手順は閉じた詳細へ置く。
全10セッションは既読で、新しい未読試験ではないことを短く明記する。
ブラウザーURL拒否は既知なので再試行せず、自作HTMLの構文・数値・切替処理のローカル確認に留める。

結果が確定するまで全体索引は変更しない。00011の成果は変更しない。
