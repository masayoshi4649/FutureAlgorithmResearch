# 主方向信号の定義と因果性監査

保存データのみ。新たなAPI取得なし。３候補の閾値は損益計算前に固定。

- **M1 確定足の持続方向**：確定１分足のEMA8−EMA30が±0.15ATR以上、EMA30の３本変化が同方向0.03ATR以上。２本連続で一致すると主方向を設定・反転する。弱まるだけなら従来の主方向を維持する。足開始＋120秒で解放。
- **M2 板注文フローと価格の一致**：解放済み板の過去300秒OFI合計／絶対OFI合計が±0.05以上、同じ５分の中値変化が同方向0.3ATR以上。１分ごとの２回確認で主方向を設定・反転する。弱まるだけなら従来の主方向を維持する。
- **M3 両銘柄の持続方向一致**：自銘柄M1と60秒遅らせた相手銘柄M1が同方向。１分ごとの２回確認で主方向を設定・反転する。一時的な不一致では従来の主方向を維持する。

方向が弱くなっただけでは中立・反転させない。２回連続の反対根拠で主方向を反転する。建玉の停止・カバー・反転は別の注文器で管理する。

20セルを各３時点で途中打切りし、足指標・板集計・主方向を最初から再生成した60ケースが全一致。
このうち別途6ケースは原本JSONLを途中打切りして板特徴から再抽出し、状態も全一致。

板の特徴解放行 seq より source_last_seq は厳密に小さい。主方向とATRを使った注文は次行以降に有効とする。

受信時刻がないため CurrentPriceTime を代理時刻に使用。保存データの再現性監査であり、実配信の遅延・順序まで保証するものではない。
