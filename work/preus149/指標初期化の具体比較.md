# 指標の全初期化で何が変わったか

**全初期化は、待ち時間を増やすだけでなく「どこから上がった・下がったとみなすか」を変え、同じ時刻の売買方向まで反転させる。** 今回の25夜では指標維持のS02が後半+1,143,000円、全初期化のS03が+424,000円。差は719,000円。ただし維持が良かったのは13夜、初期化が良かったのは11夜、同額1夜であり、全初期化が毎夜悪いという結果ではない。

日経mini・上限10枚・手数料0円。S02/S03は前半の取引・米国開始15分前の全返済・後半の新しい売買状態・主担当22分／補完30分の開始時計が同じ。異なるのは、後半に17時以降の指標を使うか、米国開始から作り直すかだけ。以下は保存約定と、その注文に保存された判断時の指標を読んだ診断であり、新しい金融再生ではない。時刻は日本時間。

### 1．23:00の同じ板で、買い5枚と売り5枚に分かれた

両方とも主担当の通常入口がまだ発動していないため、30分後の補完入口Z04が動いた。判断原行は共通の82573行、約定は次の正常原行82574行。秒表示は両行とも23:00:00であり、同じ行の価格で判断・約定したわけではない。

判断時の板は売り気配68,990／買い気配68,980、中値68,985。保存された `signal.evidence.observation.MidHistory` は次の通り。

| 23:00:00の方向判断に使った値 | S02 指標維持 | S03 全初期化 |
| --- | ---: | ---: |
| 日経の開始基準中値 | 68,755（17時から） | 69,155（米国開始から） |
| 現在中値−開始基準 | +230 | −170 |
| TOPIXの公開済み終値−開始基準中値 | +30.25 | −5.00 |
| 日経20分変化 | −55 | −55 |
| TOPIX20分変化 | 0 | 0 |
| 採った方向 | 買い | 売り |

`cores.go::extraDirection(style=1)` は最初に「日経の開始基準比の符号＋TOPIXの開始基準比の符号」を投票する。そのため維持版は+2票、初期化版は−2票となる。`source143.go::z04` の逆方向への置換には二市場の5分・20分・120秒がすべて逆向きにそろう必要があるが、ここではTOPIX20分が0なので置換されない。直前20分の見え方は同じでも、始点の違いだけで注文方向が反転したことが保存指標から直接確認できる。

| 手法 | 新規 | 返済 | この親の収支 |
| --- | --- | --- | ---: |
| S02 | 23:00:00 買5枚 @69,000 | 23:04:46 売4枚 @69,060、23:39:28 売1枚 @69,250 | **+49,000円** |
| S03 | 23:00:00 売5枚 @68,980 | 23:02:18 買5枚 @69,080（損切り） | **−50,000円** |

この1親で99,000円差。ATRも維持77.25／初期化96.63と変わり、初回の停止幅も80／96.63に変わった。つまり、全初期化は開始基準・入口方向・停止幅を同時に変える。

### 2．22:59の買いに入れず、その後の再参加の経路も変わった

追加・独立担当の入口には、二市場の40分帯を含む24項目すべての既知判定が必要。維持版は後半開始直後22:30:01から準備済みだが、全初期化版は**23:12:15までそろわない**。15分待つ設定でも、この担当が15分後から通常どおり参加できるわけではない。一方、上記Z04は20分履歴を使うため23:00に先行して動ける。

| 取引 | S02 | S03 |
| --- | --- | --- |
| 最初の追加担当 | 22:59:06 買2枚 @69,060、23:09:58 買1枚 @69,190 → 23:33:36に@69,310で全返済、**+62,000円** | この時間帯は40分特徴が未知。新規なし |
| 最初の独立担当 | 22:59:06 買1枚 @69,060、23:07:40 買1枚 @69,140 → 23:33:36／23:53:13返済、**+20,000円** | 23:21:58 売1枚 @69,170 → 23:24:34 買戻し@69,280、**−11,000円** |

S02の追加担当は最初の返済後、23:53:26の売りから再参加・ドテンを繰り返し、初回+62,000円に後続+152,000円を積み増した。S03の追加担当には後半の新規が一度もなかった。

`active145.go` の再参加・ドテンは `ClosedContext=true`、つまり当担当が一度保有して全返済したことを前提にする。初回を逃したS03ではこの経路も開かず、通常入口の準備を待ち続ける。単に最初の買いの利益を逃しただけでなく、後の参加経路を変える構造である。ただし、保存されていない全見送り行の内部状態まで新たに再生したわけではなく、S03が後の通常入口を毎回見送った個別理由をすべて断定するものではない。

残る主担当4,000円差は、共通の23:57:51売5枚@69,070に対し、部分返済4枚がS02では00:16:06 @69,030、S03では00:16:09 @69,040となった分。両方の残1枚は01:17:11 @69,000で同じ。全初期化によるATR等の差は入口だけでなく、その後の利確水準にも残る。

## C00とS04の12,000円差：2026-10-01だけ

25夜中24夜は収支同額。10/01だけC00が+109,000円、S04が+97,000円。指標を維持していても、米国開始時に売買状態を新規化すると**連敗回数も消える**ことが原因。

| 追加担当の経路 | C00 継続 | S04 米国開始で新規状態 |
| --- | --- | --- |
| 米国前 | 20:14:42 売2枚 @68,580 → 20:37:36 買2枚 @68,670、−18,000円 | 同じ |
| 米国後最初の親 | 23:08:31 買2枚 @68,290 → 23:13:10 @68,210、23:22:06 @68,130で1枚ずつ返済、計−24,000円 | 同じ |
| 23:22返済後の連敗数 | 2回（米国前の負けを保持） | 1回（米国前の負けを忘れる） |
| 次の準備可能時刻 | 23:37:06（900秒待機） | 23:24:06（120秒待機） |
| 次に実際に入った売り | 23:52:52 売2枚 @68,040 | 23:31:37 売2枚 @68,130 |
| その返済 | 23:58:09 買2枚 @68,170、**−26,000円** | 23:39:52 買2枚 @68,320、**−38,000円** |

`active145.go::filled145` が完結親の赤字で `Lost` を増やし、`NK225_D07.toml` の `addon.cooldown` が2連敗以上を900秒、それ以外の赤字を120秒にする。S04は23:31時点で再参加でき、C00は停止中だった。この1親の差だけで12,000円を説明でき、その後の01:06:46買2枚→02:30:10返済+74,000円は同じ。

## 判断

- 「米国前に全返済する」と「それ以前の相場の記憶まで消す」は別の変更。今回のD07では、**全返済・売買状態の新規化を行っても、指標履歴は維持するS02/S04の方が良い**。
- 全初期化版も後半25夜で+424,000円であり、利益が出せない方式ではない。09/21はS02−45,000円に対してS03+100,000円と逆の例もある。基準点を変える効果を、単なる悪化防止策とは扱えない。
- 「米国後の方向を独立して測る」目的なら、17時基準の履歴を消さず、米国開始比を別特徴として持ち、両者が食い違うときの判断を独立して検証するのが次の候補。**この併用判断は今回未検証であり、成績改善を確認したものではない。**
