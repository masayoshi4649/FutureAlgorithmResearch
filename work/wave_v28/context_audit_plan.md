# 第4反復：入口と保有撤回の独立監査計画

新しい成績を読む前に監査項目を固定する。現在API・取得済み現在スナップショットは使用しない。原本、旧エンジン、固定済み信号は変更しない。新エンジンは通常名 `engine_context` で読み、別名によるNumbaキャッシュを作らない。

## 2入力の意味

`entry` は新しい取引機会、`context` は保有中の主方向を示す。両者は -1/0/+1 で、同じ原本行に対応する。

| 決定 | 参照入力 |
|---|---|
| 初回新規、未約定新規の取消、追加玉、連敗方向の解除 | entry |
| 保有中の方向撤回返済、保有反転、主方向再開時のカバー返済、中立継続時間 | context |
| 価格ストップ、追跡、部分利確、時間上限、場内返済、セッション損失予算 | 既存の価格・時間・会計条件 |

汎用エンジンの反転には、カバーの昇格と不足枚数の補充新規（理由23）を含む。補充も保有反転の一部としてcontextに従うため、「全ての新規がentryだけに従う」とは説明しない。今回の288管理条件では反転・カバー・増玉を使わないので、この例外は探索では作動しない。

## 結果前に固定する検査

1. **コード差分**：旧 `simulate` に対し、新引数・入力検証と指定された保有判定だけが変わったか確認。新規、未約定取消、増玉、連敗解除の参照が紛れて変わっていないか全出現箇所を見る。
2. **旧互換**：`context=entry` なら旧エンジンと返済・売買組・資産曲線・注文・検算値が完全一致する。合成の多分岐と、旧固定信号/代表管理による既存26入力で照合する。成績比較・順位付けはしない。
3. **新規と撤回の分離**：entry=0/context=+1だけでは新規しない。entry=+1から新規後、entry=0/context=+1なら中立撤回を始めない。entryが維持されてもcontext=-1なら設定済みの方向撤回を次行で行う。context=0の中立時間はentryの点滅でリセットされない。
4. **未約定・連敗の分離**：未約定の取消と同方向連敗の解除はentryで判断する。contextの反転だけで未約定の入口が消えたり、停止した方向の新規が解除されたりしない。解除価格条件は従来通り独立に確認する。
5. **原本行と次行**：2入力とも、その行で約定へ遡及しない。注文決定元行より約定行が必ず後になる。同一時刻でも原本行順は保つ。未来のentry/context/価格/ATR改変とprefix切断で、切断以前の確定約定・会計曲線が変わらない。
6. **上下対称**：正の基準価格を中心に価格を反射し、entry/contextの符号を同時反転すると、枚数・時刻・理由・損益は一致し、売買符号は反転する。長短の連敗制限、部分利確、予算停止も含める。丸め境界は整数呼値で構成する。
7. **部分利確の会計**：奇数枚なら整数の部分返済数量を検算。利確済み部分と残玉の元建値・数量を保ち、利益を二重計上しない。部分利確しただけで売買組の連敗状態を更新しない。残玉も場内で返済する。
8. **連敗と損失予算**：売買組全体の確定損益で方向別の連敗を更新する。含み損を含むセッション予算を割った行で新規停止し、次行返済後も当該セッションは再開しない。単なる部分利確や価格反発で予算停止を解除しない。
9. **時価・数量恒等式**：各行の資産=現金+ネット枚数×価格、実現損益+全残玉含み損益とも一致する。注文台帳から買い/売り枚数と現金を別計算する。返済数量は新規数量を超えず、買い・売りそれぞれの上限を守る。
10. **優先順位と終端**：価格条件が同時成立する場合の既存優先順位を保持する。予算停止、場内返済、方向撤回、中立撤回の上書き関係を合成で確認。末尾の返済用原本行を用意し、セッションを跨がない。
11. **中期入力の対応**：v27の96Hから入口種を除いた24主方向へ対応させる。同じ主方向・時間倍率・相手確認の4入口はcontext完全一致、主方向のみ入口はcontextと完全一致。相手は公開時刻+60秒、足は解放済みだけを使う。
12. **不足情報の明示**：CurrentPriceTimeは受信時刻ではない。記録順に対する因果性と実受信順の完全再現を混同しない。損失予算は指示した金額で必ず止まる保証ではなく、次行の価格差により超過し得る。

## 判定と扱い

未来参照・旧互換違反・会計/数量違反・入力の役割違反は停止事項として実装担当とrootへ即時連絡する。監査側の入力不足や数値許容の問題と実装不良は区別する。修正は実装担当が行い、修正後に同じ項目を再実行する。

検査は成績の探索を行わず、会計恒等式と同値性の内部照合だけに損益値を使う。新手法の収支を集計・表示・比較しない。監査通過は収益性や未知期間の安定性を保証しない。
