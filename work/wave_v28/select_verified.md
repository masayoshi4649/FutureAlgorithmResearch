# 検証付き研究候補選抜

最初に `選抜整合ガードの固定.json`、次に `select_verified_test.json` を読む。

採用閾値・順位・最大2案・EMA同思想化は変更しない。凍結済み `research_selection.py` の前段で資料を照合し、合格した場合だけ元の `select()` を呼ぶ。

- 全探索から一次予定を再計算し、一次の全候補・全変形・26区間明細・カテゴリ合否を照合する。
- 乱数の予定候補を再計算し、2方式×64seedの一意128実体と全要約を照合する。
- 一次通過全候補と固定比較の4波×2銘柄を確認し、重複・欠落・20分判定と要約の不一致を拒否する。
- 実装と資料のSHAを確認し、検算から選抜までの変更及び来歴のない選抜結果の再利用を拒否する。

波の保有分そのものを約定台帳から再積分する処理ではない。記録された保有分と固定区間・判定・要約を照合する。波計測自体の検算と最終候補の独立会計監査は別に扱う。

正常2件（一次通過が本当に0件である空資料を含む）を受理し、不足・重複・偽要約・候補/SHA不一致・非有限数の17反例を拒否した。検査は全て合成資料を使用し、新探索損益・現在データを参照していない。

実行順序:

1. `python -X utf8 work/wave_v28/select_verified.py --prepare`：ガード仕様とコード指紋だけ固定する。
2. 全一次・乱数・波の資料完成後、`python -X utf8 work/wave_v28/select_verified.py`：整合検査後に研究候補を選抜する。
3. `研究候補の固定.json` と `選抜整合の監査.json` を確認する。

現在APIを取得する機能も、現在セッションを再生する機能も含めない。
