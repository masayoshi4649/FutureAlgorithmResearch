# 二入力化を評価するときの留意点

固定済みのコードと管理条件を読み、成績を見ずに整理した。

1. **二入力そのものの効果は別の対照が要る。** 今回の288管理は、退出信号なしと中期反転/中立退出を比較する。ここには退出条件を増やす効果も含まれる。同じ `signal_exit` / `neutral_min` を保ったまま `context=entry` に戻す対応対照があれば、短期入口から保有判定を分離した効果を調べられる。探索条件を後から変える必要はなく、採用候補の部品対照として扱える。

2. **部分利確が残玉の許容損失を必ず縮めるわけではない。** 初期枚数で決めた売買組全体の損失予算は、部分利確後も維持される。例えば利確した分の利益を残玉の損失へ充てられるため、残玉1枚あたりの損切り距離は広がり得る。全玉を合算して予算を保つ設計であり、利益だけ残して損失を隠す会計ではない。一方、部分利確を単純なリスク削減とは呼べない。

3. **停止予算は実現損失の厳密な最大値ではない。** 実現と含みを合算して予算到達を判断し、次の原本行で返済する。価格が飛べば予算を超過する。到達行の古い価格で遡って返済したことにはしない。

4. **中期方向の中立には複数の原因がある。** 主方向そのものの根拠消失だけでなく、相手確認つきでは相手との不一致も0を作る。中立10分の撤退は、このいずれにも反応する。相手市場の悪化と自市場の方向反転を同じ現象として説明しない。

5. **入口と保有の時間軸は分かれても、再開停止は入口側のまま。** 同方向連敗の解除には短期入口の反対信号、または既存の価格回復条件を使う。中期contextが反対になっただけでは解除されない。この境界は意図した仕様であり、独立合成監査で確認した。
