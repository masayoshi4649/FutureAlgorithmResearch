# 過去成績から手法を選ぶアルゴリズム

最初に `selector_past_specs.json`、次に `selection_events.json` を見る。実装は `selector_past.py`、選択後の原本行方向は `selector_past_directions.pkl`。

各セッションの開始前に、既に終了したセッションの「元５８信号＋G00固定１枚」の成績を比較し、そのセッションで使う方向手法を機械的に決める。選んだ手法の方向はセッション内で更新される。別の共通返済条件で実売買を新しく再生するため、元候補の収支を後から継ぎ合わせる処理ではない。

比較条件は８種類。過去全区間／直近３・５区間、自銘柄だけ／両銘柄で弱い側、PF／収支÷時価最大下落、１手法／上位２・３手法の重み付き合議を固定条件で比較する。PFの次は収支÷DD、その次は１組平均NetRで順位を決める。収支÷DD型では平均NetR、PFの順。同点は元手法IDの昇順。

最初の２セッションと、最低２取引組を満たす候補がない場合はF32を使う。成績に現在セッションや未完了セッションを含めない。２銘柄比較もそれぞれの無次元比率を使い、円額を合算しない。

数値条件は `selector_past_fixed.json` に別途固定した。既知の１３セッションを見た後に設計した方法の再現であり、未見期間の成績とは扱わない。新しい現在データの取得は行っていない。
