# E01の基準を再現するための同定

ユーザーが継続的に参照してきたE01は、00044の `F50_NONE__E11 → E01` である。`work/wave_v49/early/run.py` のE01は、元の通常影の新規時刻・方向・価格・準備時ATRを保ち、出口影の初期損失予算だけを1ATRから0.75ATRに変更したもの。現在のGoアプリを既定設定で再生することと、00044の金額を再現することは別の比較になる。

## 入口・指標

| 要素 | 元E01の仕様 |
| --- | --- |
| 主方向 | 確定1分足のEMA15・EMA60。差÷ATRが+0.15超、EMA60の3本差÷ATRが+0.02超で買い方向。売りは符号反対 |
| 方向保持 | 開始後、EMA差が反対符号になるまで保持。開始時の傾き条件を毎回満たす必要はない |
| 二指数 | 自市場と相手市場の保持方向が一致した場合だけ許可。相手方向は追加60秒遅延 |
| 足の公開 | 1分足は開始+120秒、5分足ATRは開始+360秒。未確定足を使用しない |
| ATR | セッション内の確定5分足TR。最初のTRを初期値とし、以後 `ATR=(11×前ATR+今回TR)/12`。3本目から公開、最低2ラージ呼値。通常の初期12本単純平均を使う定義とは異なる |
| EMA初期化 | 各セッションの最初の終値から再帰計算。EMA60の有効化と3本差の計算には通常63本必要 |
| 短期支持 | 公開済み最良気配中値の30秒変化が許可方向へ0.05ATR超なら支持を120秒保持 |
| 待機注文 | 準備価格から、買いは以後の追跡安値+0.25ATR、売りは追跡高値−0.25ATR。買いは上方向、売りは下方向へ呼値に丸める |
| ATR固定 | 新規準備時に固定。その後の待機・保有では更新ATRへ置き換えない |
| 取消 | 支持方向が消失・逆転した場合、又は準備後300秒。前行で既に設定した条件の判定と、現在行での取消計画の更新は区別する |
| 枚数 | TOPIXミニ換算5枚、NKマイクロ換算10枚。片方向上限10/20だが、増玉・復元をしないため実保有は初回以下 |

短期支持は同一約定時刻ブロックの最後の板中値を、次の約定時刻ブロックで公開した系列から計算する。元レポートの時間代理は最終約定時計と原本連番。実運転Python/Goは受信時計を使い、取得した確定足の利用開始も実受信後へ制限する。両者の条件式が同じでも、入力の到着順まで同じとは限らない。

## 途中・出口

1. 通常影は初回枚数×1ATRの損失予算、出口影は初回枚数×0.75ATRの損失予算を持つ。実口座はさらに初回枚数×1ATRの追加損失予算を監視する。
2. 出口影の損切り線は、固定した組損失予算・影の確定利益・残枚数から毎回計算する。初回だけなら建値±0.75ATRだが、部分利確後もその距離を固定するルールではない。
3. 2ATR順行で元枠の半分（TOPIX2/NK5）を利確。悪化減量で既に閉じた枠は重ねて返済しない。
4. 通常影の最高順行が1.5ATRに達した後、新しく公開された2分・30秒の逆行が両方閾値を満たせば、残す元枠を一度だけ約半減する。閾値は `max(0.25ATR,2ラージ呼値)` と `max(0.1ATR,1ラージ呼値)`。少なくとも1元枠は残し、復元しない。
5. 1.5ATR順行で幅3ATRのトレールを開始。3ATR順行した後は幅0.75ATRへ短縮。保護線は緩めない。
6. 最大保有360分。元レポートはデイ15:35・ナイト05:50に返済を指示し、後続有効原本行で返済。新規はその5分前まで。
7. E01が早く全返済しても通常影は継続する。通常影の終了+5分後の次の準備まで新規を待つ。

**1.5ATRで追跡開始することは、1.5ATRの利益を保護することではない。** 幅3ATRなので、開始時の追跡線は建値より1.5ATR不利側。初回0.75ATR損切り線を改善し始めるのは、部分利確がない単純ケースで約2.25ATR順行後。3ATR到達時の短縮で追跡線が概ね+2.25ATRへ移る。利益を削られる問題を調べるなら、この段階構造を分解する必要がある。

## 注文の順序

前行までに設定済みの条件だけを現在観測へ適用する。現在行で作った保護線・悪化減量・組予算返済は次行から有効。

- 明示的な場末・組予算超過・保有期限の返済予約があれば、現在観測価格で返済する。
- 複数の既設価格線を同じ観測で跨いだ場合、前観測価格から最も近い条件を選ぶ。同距離は損切り→トレール→部分利確の順。
- 新設時点で既に成立した価格線は成立フラグを持ち、次観測価格で返済する。過去の有利な線へ遡らない。
- 実口座では出口影の注文を最優先し、次に実口座の1ATR損失予算、最後に悪化減量。影の部分利確は、実口座の組予算予約を失わせない。

この順序は `work/wave_v38/engine_shadow_plan.py`、`work/wave_v47/exit_partial_integrated.py`、00045の `papertrade/strategy.py`、Goの `internal/strategy/engine.go` で確認した。

## 事前の理屈から固定する改修仮説

以下は今回損益から勝ち条件を選んだ提案ではない。各部品単独と組合せを同じ売買価格・費用で比較する。

1. **保持方向の鮮度を再確認する。** EMA差の符号だけで長く保持すると、既に流れが弱った場面でも120秒残る短期支持で入れる。自・相手の現在の長期EMA傾きがともに入口と反対でないこと、又は両市場の直近5分変化が入口と矛盾しないことを準備条件へ追加する。0.15ATR開始条件の再充足を要求する方式も対照にする。
2. **待機中の大きな逆行を準備失敗と認める。** 現行の0.25ATR反発待ちは、準備後に大きく逆行しても300秒以内の小反発だけで入れる。準備価格から0.5/1ATR以上不利に動いたら取消し、新しい支持を待つ。過去の負け玉を削除せず、取消後の新しい準備も全再生する。
3. **利益保護の段差を平滑化する。** 現行は1.5ATR開始後も幅3ATRで、3ATR到達時に急に狭まる。1/1.5/2ATR到達後に組全体の損益下限を建値付近又は小幅黒字へ引き上げる対照、又は段階的な追跡幅短縮を置く。全入口で最初から極小ストップにする案とは区別する。利確線は約定利益の保証ではなく、実気配・次行遅延・費用を残す。
4. **伸びない保有を時間と失敗根拠で閉じる。** 15/30分で最大順行0.5ATR未達、かつ新しい2分・30秒反応が逆向きなら準備仮説が続いていないと判断して返済する。時間だけで無条件に切る対照も置き、通常の押し戻しまで切り過ぎるかを確認する。
5. **二指数の不一致と直進性で追従幅を切り替える。** 直近の両市場方向が一致し直進性が高ければ通常の利益延長を続け、往復が多い又は相手市場が逆向きなら利益が出た後だけ幅を短縮する。急角度の観測自体を新規の根拠にせず、00063で強い既成の動きが続伸を保証しなかったことを踏まえる。

入口だけを強くする・ストップだけを狭める・上位の利益条件だけを選ぶのではなく、各部品が損失原因と結び付いているかを反証し、変更なし対照を必ず残す。
