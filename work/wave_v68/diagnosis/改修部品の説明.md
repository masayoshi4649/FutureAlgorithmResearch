# 損失低減部品の機械的な説明

全条件で、初回ATRは建てた時点の尺度に固定。判断後の次の保存行で返済し、早く返済しても元E01の新規時計を待つ。売買方向を事後に選び直していない。

| 部品 | 実際の判定と行動 | 利点 | 欠点 |
|---|---|---|---|
| T05H | 建てて5分以降、そこまで0.5ATRも順行せず、現在0.25ATR以上逆行していれば一度減量。TOPIX5枚中2枚、NK10枚中5枚を返済。 | 失敗の金額を減らし、残玉で遅れて始まる波にも参加できる。 | 5分より早い急落は救えず、後で回復する玉の利益は減る。 |
| T05X | T05Hと同じ条件で全返済。 | 進まない失敗玉を残さない。 | 一時的な押しから回復する波も捨てる。返済後すぐ入り直す仕様ではない。 |
| S50 | 初期の組損失線を0.75ATR相当から0.5ATR相当へ縮める。 | 時間を待たず失敗の金額を抑える。 | 押し・戻りに耐える幅が減り、勝つはずだった波も切る。 |
| S375 | S50より更に狭い0.375ATR。 | 一回の失敗を更に小さくする。 | 最もノイズに敏感で、利益の取り逃しが増える可能性が高い。 |
| A50 | 実際の部分決済・残玉の含み損益・発生済み料金を合算し、初回数量×ATRの0.5倍まで悪化したら全返済。 | 名目の価格線ではなく、実口座で失った金額を制御する。 | 気配飛びや次行までの変化で予算を超え得る。早期利確があれば残玉に広い値幅を許す。 |
| B15H | まだ1.5ATR順行しておらず、現在0.25ATR以上逆行し、新しいB00逆行根拠が公開されたら一度減量。 | 元E01の1.5ATR未到達の失敗にも悪化判断を働かせる。 | B00逆行は勝ち途中にも現れ、回復時の利益を減らす。 |
| P2T | 実際に全返済した組が料金後2連敗したら、30分新規を休止。 | 向かない相場で続けて資金を失う速度を落とす。 | レンジ終了直後の波を逃し得る。待機時間の30分を最適と証明したものではない。 |
| P2E | 料金後2連敗で、そのセッションの新規を終了。 | それ以降の損失をなくす。 | その後の回復利益もすべて捨てる。 |
| D2R | 完了した組の料金後損益を各組の初回数量×ATRで割って累積し、−2Rで新規終了。 | 相場に応じた尺度で、その場の損失許容量を管理する。 | 後の波は捨てる。−2Rは円の損失上限ではなく、尺度の異なる組Rの合計である。 |

B00は板の厚さ・補充量の判定ではなく、板中値が2分全体でその時点の公開済みATRの0.25倍以上かつ最低2呼値、直近30秒でも0.10倍以上かつ最低1呼値、同じ逆方向へ動いたことを示す。欠測・鮮度不足は根拠としない。「板読みで需給を直接特定した」とは説明しない。

半減は元E01の一度だけの減量枠を前倒しで使い、枚数を復元しない。早期返済した枠は、後の2ATR部分利確で再度返済されない。残玉の出口は元E01を維持する。

S50とA50は同じ0.5ATRでも異なる。S50は料金を除いた元の仮想組損失線、A50は実際の建玉と料金込みの損失予算で判定する。
