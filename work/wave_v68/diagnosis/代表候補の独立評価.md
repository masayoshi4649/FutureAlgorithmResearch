# 代表候補の独立評価

指定されたE01_T05X・E01_P2T・R01_P2Tだけを比較した。入口原本行で組を対応付け、元と新の全台帳から組損益を独立集計して、保存済み集計と一致を確認した。T05Xは全299入口が共通。P2Tは元の入口の一部を休止し、新しく生じた入口はなかった。

## 5分の失敗全返済は、TOPIXでは回復利益を切り過ぎる

E01_T05Xは、前16では負け組損失をTOPIX13.5%・NK19.6%減らし、勝ち組利益を84.8%・87.1%維持した。一方、後12ではTOPIX損失を15.7%減らしたものの利益は58.8%しか残らず、収支＋112,443円が−148,070円へ悪化した。後12の元の勝ち26組のうち8組が負けへ変わった。NK後12では損失21.5%削減・利益90.4%維持で、収支＋56,920→＋95,020円だった。

成立時点の原本行で確かめた例は以下。先に条件が成立した行で判断し、返済は次の原本行で行われている。同じ秒の行であっても原本行番号は前後する。

| 銘柄・入口 | 早期判断時点 | 元の組収支→改修 | 意味 |
|---|---|---:|---|
| TOPIX 10/01 Day 10:12:42買い | 10:17:42、5分経過、過去最大順行0.320ATR・現在−0.320ATR | ＋95,084→−12,918円 | 小さな初期押しの後に回復した大きな利益を失った。 |
| TOPIX 10/08 Night 18:09:19買い | 18:15:12、5.88分経過、過去最大順行0.060ATR・現在−0.300ATR | −35,418→−12,918円 | 初期失敗の損失を22,500円減らせた。 |
| NK 10/02 Day 09:52:34買い | 09:59:29、6.92分経過、過去最大順行0.227ATR・現在−0.284ATR | −14,220→−5,220円 | 初期失敗の損失を9,000円減らせた。 |
| NK 09/29 Day 09:51:41売り | 10:01:33、9.87分経過、過去最大順行0.380ATR・現在−0.271ATR | ＋35,280→−5,220円 | 売り方向は後で成功したが、その前の戻りで降りた。 |

初期停滞を失敗と見なす考えは一部で有効だが、0.5ATR・5分・0.25ATR逆行の組合せで回復と失敗を両銘柄共通に分けられたとは言えない。

## 30分休止は「損失の回数」を減らす

R01_P2Tは同じ入口での損益を一円も変えていない。全28でTOPIX18組・NK11組の入口を休止し、それらを除いた分だけ利益・損失・手数料が変わった。

| R01への追加 | TOPIX | NK |
|---|---:|---:|
| 全28の負け組損失削減 | 10.1% | 8.8% |
| 全28の勝ち組利益維持 | 90.8% | 96.1% |
| 全28収支 | ＋615,981→＋570,992円 | ＋235,140→＋257,060円 |
| 後12の負け組損失削減 | 8.4% | 7.4% |
| 後12の勝ち組利益維持 | 90.1% | 93.1% |
| 後12収支 | ＋142,528→＋117,283円 | ＋44,940→＋43,540円 |

元E01へのP2T追加も全28の組損失をTOPIX13.7%・NK12.1%減らしたが、利益維持は90.7%・87.0%。後12の収支は両銘柄とも元より低い。休止は損失を減らす行動として作用するが、収支改善が両銘柄・前後半で揃ったわけではない。

R01_P2Tが回避した損失の例は、TOPIX09/30 Nightの21:52:54買い−22,918円（21:47:32〜22:17:32休止）と、NK09/30 Dayの11:26:19買い−9,220円（11:11:14〜11:41:14休止）。一方、NK10/08 Nightの翌01:54:13売り＋22,280円も、01:47:11〜02:17:11の休止で失った。

## 休止しても一発の損失幅は小さくならない

R01_P2Tの全28最大組損失はTOPIX−40,418円・NK−14,220円で、元R01と同じ。新規を減らす操作なので、参加した建玉の損切り線や一発の損失幅は改善しない。

TOPIX後12の最大場内下落は、元R01の111,507円からR01_P2Tの128,762円へ増えた。原因を10/05 Nightに特定した。

- 20:02:42から30分休止し、20:13:36買いの元利益＋43,584円を失った。
- 別の休止で22:50:50売りの元損失−15,418円を回避した。
- 翌03:15:40買いの元利益＋583円も失った。
- 合計差は−28,749円。場収支は−100,013→−128,762円、当該場内下落は108,844→128,762円。

従って「損失総額が減った」ことと「最大下落や最悪損失が改善した」ことを混同してはいけない。P2Tは利益を比較的保った損失回数制御の候補であり、損失制御が完成したとする根拠にはならない。

確認資料は `指定候補の独立比較.json` と `代表例の成立時点照合.json`。後者は代表9例の新規・制御成立・休止開始終了を原本時刻で確認している。全28は既知のため、これを未見検証とは呼ばない。
