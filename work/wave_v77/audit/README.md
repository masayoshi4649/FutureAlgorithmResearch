主492条件、固定遅延感度44条件、固定後の追加1場22条件、合計558条件を検算しました。31,132口座、94,935組、96,980建値決済明細、191,915注文、1,553,094会計項目の比較で不一致はありません。全口座の全行清算時価・内部最大下落・期間最大下落も独立に再構成しています。

## 判定と限界

- 主目標は同商品内の全建値決済明細で、手数料後の利益／（利益＋損失）80%以上、PF4以上です。追加玉の負けを他玉と相殺して隠しません。一組は初回新規から全返済までとし、組勝率は別指標です。二商品の円を混ぜて判定しません。
- TOPIXminiは片方向10枚、NK225microは20枚。新規・追加・返済の各注文を数量別に料金切捨てし、一括返済の料金を各建値へ累積枚数比の切捨て差分で配賦します。買いは次の有効原本行の売気配、売りは買気配です。
- 全条件で追加判断・追加約定の各2,045証跡を検算しました。実約定後の損失枠超過140件は即返済判断と次有効行の実返済を確認しています。将来の気配を見て追加注文を恣意的に取り消していません。
- 予定撤収時刻を超えた返済は条件の重複を含め216件、最大240秒。全件が保存監視終端より前に実返済しています。判断から次有効原本行までの最大待ちは37秒です。予定時刻で必ず約定する保証ではありません。
- 前16場だけで代表と対照を固定し、既知の後13場・遅延感度・新追加場で選び直していません。既往29場は真の未知検証ではなく、新しい2026-10-09ナイトだけを固定後の追加確認として分離しています。独立監査はその追加場の保存台帳を読み、再生していません。
- 現在特徴が価格として有効でも、全板・OFIが不足する場合は別に扱います。値動き総和と直前高安は同時計先頭だけで計算し、直前高安へ現在の行を含めません。準備済み価格の全行有限という入力契約を実データ全60口座で確認しました。
- 共通受信時計がないため、最終約定代理時計の厳密な過去参照・同時計先頭・原本行順を検査しています。実受信因果の完全保証ではありません。検査合格は計算・会計・因果の整合性を示し、目標達成や将来収益の証明ではありません。
- 原本取得・API取得・実注文は0。添付生板サンプルと準備指紋を参照し、凍結済み研究コード・入力・過去成果を変更していません。
