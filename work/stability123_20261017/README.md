公開入口は[途中利確なしの新規間隔比較](../../アルゴリズム調査/00123_途中利確なしの新規間隔比較/途中利確なしの新規間隔比較.html)です。

初回距離と追加間隔を分離した19条件。初回3pt・間隔3ptの40会計は00122から引用し、新18条件×40場＝720会計だけを測定しました。元板・現在API・実注文は使用していません。

- [固定計画](固定計画.json)：実行源・入力40本・旧会計・独立人工のSHA256。
- [全条件と全場の完成会計](途中利確なしの十九間隔と全四十場.json)：720新会計と40引用を区別。
- `measurement/`：各場の新規・途中時価・代理終端玉の保存配列。通常返済は0件。キーの条件番号2は保存引用なので追加配列なし。
- [独立期待線人工](adversary/初回と間隔の独立発火線及び旧基準同値.json)：43人工・340確認。
- [実行プロセスの人工確認](実行プロセスの期待線と通常高速確認.json)：実データ直前に正常・高速版と外部期待線を確認。
- `audit/`：戦略を再運転せず、保存注文・玉・時価・費用と数量上限を照合。
- `publisher/`：監査済み会計の表示処理。新金融は行わない。

`金融前の引数と既存局所変数の衝突/`は不採用の人工段階です。初回距離引数を既存の損益局所へ上書きする誤りを独立人工で発見し、実データ投入前に修正しました。旧人工の通常・高速一致を意図の検証合格と扱いません。

全て同じ既知TOPIX40場の開発比較です。予定15:45／06:00の精算は直前6分以内最終BBOによる代理会計で、実引け約定ではありません。日経は今回は未検証です。既存会計を増やす再実行や、結果から各場の間隔を選び直す運用は行っていません。
