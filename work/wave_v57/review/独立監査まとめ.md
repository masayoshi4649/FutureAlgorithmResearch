# 独立監査の結論

実装と会計に、今回の黒字・赤字の符号を説明する不一致は見つかりませんでした。ただし、最後値で約定できるという評価では全12条件・両市場が黒字なのに、同じ注文を中値で評価すると全24組が赤字です。買いを売気配、売りを買気配で評価すると損失はさらに増えます。

これは手数料を加えたための悪化ではありません。いずれも手数料は0です。板が動いた後の判断に、既に気配と離れた最後の約定価格を使って売買できるという仮定が、成績の符号を変えています。したがって、最後値の黒字だけから、補充を読む利益があるとは判断できません。

新規後の追跡基準は約定行の中値、出口も中値です。評価用の約定価格を変更しても損益を理由とする途中判断はないため、今回の価格再評価は同じ規則をその約定価格で再生した結果と一致します。将来の約定価格を使って過去の入口を選んでいるわけではありません。

## 解釈の限界

同じ価格の表示回復が、同じ参加者・隠れ注文・本当の約定相手によるものかは識別できません。出来高と代金から得る平均価格の側判定も代理です。原本時計は受信時刻ではなく、同じ時計の行も原本順で処理しています。今回の保存46口座には時計逆行がありません。新たな時計逆行入力は特徴では状態を消しますが、売買判断側が拒否します。

12条件は回復回数と幅の感度比較で、補充観測を除いた対照実験ではありません。この結果が否定するのは今回実装した3構成と注文評価の組み合わせであり、板読み全般の無効性ではありません。保存済み23場は過去研究で既読のため、未来漏洩がないことと未知期間で利益が再現することは別です。
