# 補充3案の設計時レビュー

2026-10-07。新しい売買結果を見る前の記録。3類型×回復2回/3回×始値割合0.05%/0.10%の12条件を比較する予定で、各類型の主条件は回復2回・0.05%。結果が良い条件へ主条件を差し替えない。詳細な定義は親実装の固定仕様を正とする。

## 3類型に共通する確認事項

- 保存板の数量減少→同価格の数量増加は観測できるが、減少原因が約定か取消か、補充者が同一か、隠れ大口かは分からない。「回復」と「約定の吸収」を区別する。
- 回復回数は独立した減少→回復周期として定義する。一回の減少残へ小刻みに加算された数量を、無制限に2回・3回へ増やさない。周期が完了した後に新しい減少が始まる必要があるかも固定する。
- 減少の大きさ、回復割合、周期の期限、価格移動時の扱い、深板不正時の初期化は実装前に固定する。1枚の揺れと厚い供給の維持を、説明で勝手に同一視しない。
- 現在の最良より有利側から消えた価格と、遠方10段外へ出ただけの価格を分ける。後者の量は不明であり、ゼロでも補充切れでもない。
- 原本順を保ち、回復が確認できた行より前へ信号時刻を戻さない。同じ最終約定時刻に何回も板が更新されるため、原本行数を秒数や独立した参加者数として読まない。
- 新規判定後の次の有効原本行で約定する。判定を作った数量回復と、その後の約定価格を混同しない。中値と最後値の差が見かけの収益へ寄与し得る点を残す。

## 類型ごとの反証

| 類型 | 成立してほしい性質 | 反例・失敗し得る状況 |
| --- | --- | --- |
| 吸収後反転 | 片側の供給が繰り返し回復して進行を止め、後に反対側への価格変化が続く | 回復しても最後に供給が尽きれば、止めていた方向へ抜ける。回復だけでは反転を予測できない |
| 補充切れ突破 | それまで価格を止めた供給がなくなり、次の価格帯にも進む | 一瞬の板撤退だけで、再供給や反対側注文によりすぐ戻る。「切れた」の確認時には進行が終わっている場合もある |
| 補充位置追従 | 回復する価格帯自体が一方向へ動き、反対方向へ崩れにくい | 過去の価格移動を別の言葉で表しただけで、確認後の余地がない。売買利益だけでは回復情報の追加価値を証明できない |

## レポートで混ぜないもの

「回復を観測した」「入口後に方向が続いた」「次行約定と返済を含めて利益が出た」は別の段階。局所的な説明、予測、実行会計をそれぞれ区別する。主条件以外の高収益は探索上の比較結果であり、事前の主案が合格したという説明へ置き換えない。

同一類型でも回復回数と幅が変わると、新規の集合・保有時間・次の機会が変わる。損益差を「回復を1回増やしただけの因果効果」や「出口だけの改善」と言わない。

費用0、TOPIXミニ5枚/NK225マイクロ10枚、追加なし、片方向上限10枚/20枚、全玉場内返済という今回の条件を明記する。上限枚数と実際の初回枚数を混同しない。ATRは使用しない。

## 根拠

[JPXの先物取引方法](https://www.jpx.co.jp/derivatives/rules/trading-methods/) は、価格と時間の優先順位で相手注文と対当する仕組みを説明している。[Eislerほかの板イベント研究](https://arxiv.org/abs/0904.0900) は、約定だけでなく指値追加・取消を価格形成に含める。これらは補充を観測する動機であり、今回の3案の利益を保証する研究ではない。

[Contほかの研究](https://arxiv.org/abs/1011.6402) が扱う同区間の板変化と価格影響を、確認後の将来予測と取り違えない。今回の23場も過去に閲覧した資料であり、新たに条件を固定したことだけで未知データの検証とは呼ばない。
