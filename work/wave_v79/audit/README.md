6. [診断と防止策の敵対確認.json](診断と防止策の敵対確認.json)・[防止信号の人工境界と未来不変監査.json](防止信号の人工境界と未来不変監査.json): 理論上の注意点、24人工経路・6,240配列比較。

8. [公開HTMLと会計と描画の最終内容監査.json](公開HTMLと会計と描画の最終内容監査.json): HTMLの18条件・1,080口座が監査済み会計と完全一致。18取引の描画5,168点は原本110,220行に実在し、5秒区間の両極値を保持。READMEの主数値、旧組番号と表示番号、E0_X1/E0_X2に限定した結論を確認。

対象基準は `J2_F0_B0_H0_R0` です。F1付きへ入れ替えていません。最悪3場は基準の損益で先に固定し、商品別の残27場と、両商品の診断対象5場を除いた残25場を区別して検算しました。

J2は両板の支持必須ではなく、十分な観測の明確逆OFIを除外する入口です。ただし最悪場では両OFI支持でもTOPIX6組中5敗、日経7組中6敗でした。支持不明の通過だけが根本原因という説明は成立しません。OFIはJ2追加5秒格子の証拠であり、従来価格入口15秒格子の情報とは分けています。

全30場は既知データです。監査合格は計算と過去参照が保存資料内で一致したという意味で、将来利益の証明ではありません。最終約定時計を代理時計として使用しており、現実の共通受信順序、ミニ・マイクロ自身の板、取消や補充の個別原因は保証しません。
