# 次入口の設計案

本書は独立批判用の案であり、数値条件の最終固定ではない。新しい信号実装・売買再生・損益読取り・現在データ取得は行っていない。v44の成績で入口又は数量管理を選び直す用途には使わない。

**主仮説は、価格が動いた総距離で平均線の記憶を進めると、固定した時間窓より持続方向の判断が安定するか、である。** 距離時計自体に将来方向の偏りがあるとは仮定しない。短長距離 `(1,4)` を主案とし、`(.5,2)/(2,8)/(4,16)` は速さの機構比較にする。最良の距離幅へ事後に主案を差し替えない。

## 採用しない初期校正

[入力診断](../wave_v44/価格時計の入力診断.json)では、初20分のATR有効部分は末尾約4分に偏り、NK225の9月21日ナイトは59秒・価格変更1回だった。したがって、初20分の距離を20分で割る速度校正は採用しない。有効59秒で割り直しても代表性の問題は解決しない。後から公開されたATRで寄り付きの距離を補完する処理も行わない。

以下の距離幅は、その日の校正値や後続の変動量によって変えない。参照した[文献メモ](../wave_v44/文献再確認と次の入口仮説.md)は着想の整理であり、本案は論文の売買成績を再現する実装ではない。

## 入力と更新順

入力は既知13セッションの `ready.seq/time_s/last/atr/tick/start/limit` と、旧短期価格確認を使う場合の公開済み `features_depth`。銘柄ごと・セッションごとに初期化し、前場の建玉又は指標状態を次セッションへ持ち越さない。

原本行を `seq` 順で一度ずつ読む。価格は両時計とも同じ `last`。距離の分母は**直前原本行までに公開済みのATR**とし、当行の値動きによって新たに公開されたATRを当行の距離へ遡及適用しない。ATR下限は既存入力・注文側と同じ2呼値を候補とし、新しい下限を銘柄別に合わせない。初期損切りや注文の入口ATRは旧管理器の契約のままにする。

有限・正の価格と直前公開ATRが初めて揃った行で `u=0, E短=E長=p` とする。初期化前の価格差は積まない。以後、隣接する有効行について、

```
Δu_i = abs(p_i − p_(i−1)) / max(直前公開ATR_i, 2×呼値)
u_i = u_(i−1) + Δu_i
α_i(L) = 1 − exp(−Δu_i/L)
E_i(L) = E_(i−1)(L) + α_i(L) × (p_i − E_(i−1)(L))
```

当行の公開ATRは更新後に保存し、次行の距離に使う。数量だけの更新、同じ価格の反復は距離ゼロ。同一 `time_s` の価格変化も、自己市場では到着済み原本順に積む。原本行数を時計にしない。

価格欠測、ATR欠測・非正、時刻逆行、直前観測から60秒超の穴では方向を0にし、平均と距離履歴を再初期化する案とする。穴の両側の価格差だけを足して連続観測と扱わない。ATRは未来の次の有効値で補間しない。これらの閾値は利益を見る前に確定する。

## 方向、暖機、勾配

主方向の開始閾値は旧H019に合わせ、`(E短−E長)/現在公開ATR > 0.15`、かつ長平均の正の変化が `0.02ATR` より大きければ買い、両方負なら売りを第一候補とする。買い保持は平均差が負になるまで、売り保持は正になるまでとし、ゼロの扱いも旧H019と同じにする。逆方向の開始条件が成立すれば反転、品質不適格なら中立。機械学習は不要である。

距離勾配は `g=0.4×短距離L` を暫定案とする。履歴から `u_j <= u_i−g` を満たす最後の過去行を探し、`(E長_i−E長_j)/現在公開ATR` を測る。同値距離では当時までの最後の行を使う。現在値と未来値の間を補間しない。跳躍が大きく実測距離がgを超える場合はその実距離を記録し、ちょうどgの変位と説明しない。

- 開始20分経過、ATR有効、初期化後の距離が長距離L以上、勾配参照行あり、を暖機の暫定条件とする。初期値の長平均への重みは最大 `exp(−1)` 残るため、「十分に収束した」とは呼ばない。距離不足で取引しない時間も結果へ残す。
- 最新有効観測が古い場合には0。距離勾配の参照が極端に古い問題には、参照行からの物理時間を最大30分とする案を置く。60秒の観測穴規則とは別である。この追加上限で活動が減る可能性を固定前の入力診断で数える。
- 平均の時計と勾配の時計を一緒に変えれば、効果はその組合せである。主距離 `(1,4)` には、平均は距離時計・勾配だけ過去180秒に戻す対応対照を設け、距離勾配を平均時計の改善と混同しない。

上記の暖機、0.4、30分は未確定候補。距離不足や鮮度不足の頻度だけは結果前に確認できるが、少ない取引を黒字にするため後から緩めない。

## 相手市場と短期確認

4距離幅それぞれについて、相手方向あり／なし、旧短期価格確認あり／なしの4通りを対応比較する。主候補は旧H019に近い「両方あり」を提案するが、最終固定前の判断事項とする。相手なし・短期なしを後付けの救済候補にしない。

相手確認は、相手自身で計算した**自己主方向**だけと一致させる。互いに相手確認済みの方向を参照して循環させない。原本に真の受信時刻がないので、相手の同一 `CurrentPriceTime` 群の末尾を、その時刻の最初から既知としてはならない。次の異時刻が観測されて群が完了した時点で末尾状態を公開し、さらに60秒遅延して自己側へ過去asofで渡す。群末尾の内容を確定できない終端は公開しない。

参照する相手方向は、追加60秒後の公開から120秒以内を暫定鮮度とする。原本 `seq` は銘柄間で比較しない。両市場の距離uが揃う将来を待って過去へ対応させない。この方式も実受信同期の保証ではなく、保存資料から定義した保守的な公開モデルである。

短期確認ありは旧H019の処理を維持する。公開中値の過去30秒差が主方向へ `0.05ATR` を超えた公開イベントで入口方向を発火し、支持から120秒又は主方向撤回で解除する。公開 `seq` より前には出さず、同時刻後続イベントも順序を守る。短期なしは有効な主方向をそのまま返し、短期確認の成功がないことを欠測として扱わない。発火・保持・解除は初めから両時計へ同じ処理をかける。

## 同原本の物理時計対照と旧方式

距離方式だけ原本の全更新へ変え、旧H019の1分足と比較するだけでは、時計と観測頻度の違いが混ざる。物理時計対照も同じ原本価格、初期化、品質、方向閾値、相手処理、短期確認を使う。

物理平均は `α=1−exp(−Δt/τ)`。時間幅は、1分EMA15本の減衰に対応する `τ15=−60/log(1−2/16)` 秒を基準に、距離 `(s,4s)` に対して `(sτ15,4sτ15)` 秒とする案を置く。これは全日の距離速度を推定した値ではなく、既存15本EMAから取った事前の参考速度である。長時間幅 `4τ15` は60本EMAの正確な時定数とわずかに異なるため、旧H019と完全一致とは呼ばない。物理勾配は `0.4sτ15` 秒の過去asofとする。

同じ `time_s` の更新では物理時計のΔtは0。距離時計は価格変化なら進む。この差は保存時刻モデルの影響も受けるので、同秒変動の寄与を記録する。価格を未来から補間して両者を人工的に一致させない。

時計の対応比較では、距離幅ごとにその距離方式の暖機可否を物理方式へも共通適用し、片方だけ早く参加できる差を抑える。ただし、この物理対照も距離による参加制限を共有するため、独立の実用物理方式の評価ではない。その点は明記し、中央幅だけは距離暖機を外し物理時間による暖機へ置き換えた独立対照も分けて残す案とする。旧H019は完全な旧入口をそのまま再現し、新しい暖機をかけない。

|方式|既試行との違い・位置付け|
|---|---|
|旧H019|確定1分足のEMA15/60、3本勾配、相手60秒、30秒価格確認。既存配列と完全一致させる基準。|
|同原本の物理EMA|原本の不規則な時刻間隔で減衰。距離方式と更新価格・品質を揃えるための対照。|
|距離EMA|当時のATRで割った総移動距離で減衰。単調な変位だけでなく往復も距離へ加える。|
|旧N03|ER10とKAMA(10,2,30)、5分変化0.2ATR等。往復が増すとERが下がり反応を抑える。今回の「総距離が増えると記憶を進める」と作用が異なる。|
|旧N05|確定終値が追跡極値から0.8ATR反転した時だけ通知。確認前の極値へ遡らない。全absΔpを平均更新へ使う本案とは別。|

旧N03/N05は[ソース](../wave_v13/new_signals.py)の仕様差を確認しただけで、今回その経済成績を新たに比較していない。適応平均や非時間時計の概念自体を新発見とはしない。

## 固定する管理と棄却できる反例

数量管理は **A0／元C01** の二つだけを固定する。TOPIX5枚・NK22510枚の既存管理、元の初期損切り・部分利確・追跡・予算・場内返済を変えない。v44のG150が良い／悪いという結果で管理を切り替えない。注文は当行情報で決めた後、旧管理器の次行以降の仕様で処理する。

1. 同じ単調経路に細かな往復を加えると距離だけ増え、方向反転や再準備が増え得る。総距離・純変位・同秒距離・方向時間・取引回数を分ける。
2. 大跳躍では両平均が現在価格へ寄って差が消え得る。ジャンプを分割した経路とも同一指標になるとは限らない。
3. ATR拡大後は同じ価格差でも距離が小さくなる。距離時計の速度が常に実変動へ速く適応するとは限らない。
4. 静穏時や大きいLでは暖機・勾配が不足し、取引を減らしただけの改善になり得る。損益だけでなく共通参加区間と独立参加区間を分ける。
5. 生価格の細かな更新を使った効果が全てなら、同原本の物理時計も改善するはずである。旧H019だけへの勝利を固有時計の証拠としない。

実装前には、全prefix・同時刻途中切断・未来価格/ATR/相手値変更・上下反射、無変動行追加、ATR初回公開、穴の再初期化、巨大跳躍を検査する。人工的に `Δu=Δt/τ15` とした入力では、対応する両平均の係数と更新値が一致する。距離／時間勾配のasofが異なる実経路まで完全一致と要求しない。

主案の方向反転、活動時点を維持する符号乱数、幅近傍、執行遅延も結果前に反証へ固定する。ただし本書では売買条件の最終件数や採否の数値を追加しない。新規13セッションではなく繰り返し見た既知期間なので、もし改善しても未知相場での安定利益を確認したとは呼ばない。
