# 50%版を固定してから反証する

主案は `G150_F50_N1__V000`。00039で発見した既知成績の探索副案を、次の検査対象として固定する。主案25%版を過去に遡って変更しない。価格が共通影A0の初期ATRの1.5倍順行した後、新しく公開されたB00悪化で残存枠の50%を最大1回減量する。初回枚数、入口、回復、初期1R予算、部分利確済み枠の退役、期限、場内返済は変えない。

この反証は、未実施だった50%版の局所感度と情報対照を埋める最小限の組合せとして妥当である。主25条件は既知11条件と新14条件、補助128条件を合わせ全153条件とする。既知11は元の26入力の完備成果を経済仕様・指紋で照合して引き継ぐ。新しい売買再生は142条件であり、既知286入力を新しい独立標本や新発見と数えない。

- 既知比較：A0、無ゲートC01、直前25%主案の各入口時計0.8／1／1.2と、同50%無ゲート中央、50%主案中央。
- 新12感度：順行閾値1.2／1.8、入口時計0.8／1.2、悪化窓0.8／1.2、回復窓0.8／1.2、伝達遅延1／5／15秒、全約定の観測価格。
- 新2機構対照：悪化方向の反転、到達後の全有効新公開から方向条件を外すAV_ALL。
- 新128補助：悪化符号64、回復符号64。公開機会とゲートを保ち、片側の符号だけを変更する。

主要な問いは、既知中央の増益が新しい12感度でも黒字・損小利大を保つか、入口時計の最大勝ち依存が残るか、50%にした後も悪化・回復方向に付加価値があるかである。中央の利益を事前に知っているため、中央改善が再び確認できても独立の追試とは呼ばない。

採否は[反証計画](反証計画.md)に明示し、00039の式を易しくしない。元C01比の中央改善を維持し、A0・直前25%主案・同50%無ゲートとの関係も別に表示する。増益とDDの交換、経済基礎、感度、情報価値を分ける。全セルParetoだけを唯一の採用条件にせず、未知の万能性も要件として追加しない。

同50%無ゲートとの比較は配分を揃えたゲートの全組経路差になる。ただし調整時刻、復元、予算返済も変化するので、ゲートのみの純粋な予測価値とは断定しない。乱数も機会情報を残す構造保存対照で、正式p値ではない。N3・1 ATR・2 ATRなどの既知副案へ再選択しない。価格距離で時計を作る別仮説は[繰延メモ](次入口の設計案.md)に留め、今回は実装・再生しない。

これらを完走すれば今回の限定反証は完了する。未達項目を記録し、中央黒字を消さず、別の条件を次々に足して全環境の確証を要求することもしない。
