# 利確した他玉の利益で、一枚だけを残す

第三巡の事前仕様。金融成績はまだ評価していない。

- 対象は日経miniの一つの源。元の入口・追加・部分返済通知を、当時の判断原行で受け取る。
- 元が**全返済**を判断し、その理由が `2`・`70`・`1437` の利益追尾なら、最古の利益玉一枚を残せるか判定する。損切り・静観・場末・支持破綻の返済は変えない。
- 残す一枚を除いて、現在の返済側気配で清算した純益が正なら、その一枚を除いた枚数を発注する。未発注の管理判断を変えるのであり、既に出した注文は取り消さない。
- 他玉が次の正常な原板で返済した後、実現純益を再確認する。全新規手数料と返済済み手数料を引き、残玉の含み益は加えない。実現純益が正でなければ、残玉もさらに次の正常原板で返済する。
- 残玉の許容損失は実現純益の50%又は100%。残玉の将来返済手数料を含む価格の床と、2R又は3R追尾の高い方で守る。Rは初回発注判断時の公開ATRと8呼値の大きい方で固定する。
- 追尾の最高値は予算が確定した時点から記録する。元の利確前の高値を後から流用しない。
- 先に部分利確して最後の一枚だけになっている場合は、過去の実現純益で資格を判断する。他玉の今回返済がなければ、予算はその判断行で確定し、新たな約定は作らない。最初から一枚だけで過去の利確がない親は不適格。
- 残玉の保有中に届く次親は初回通知で全体を見送る。将来の利益を見て残玉を消すことも、見送った親へ途中から便乗することもない。残玉返済後に初めて通知される新しい親は採用できる。
- 残玉は米国開始前後15分、昼15:35・夜05:50の既存返済時刻で全返済する。03時は保有率の評価境界であり、返済時刻ではない。

実現予算は約定保証ではない。次の板が価格の床を飛び越えれば、親全体が赤字になる場合もある。その実損益を切り詰めず保存する。残玉の長期化で消えた後続親の利益も評価対象とする。

人工試験は、H00同値、四条件の鏡像・未来変更・入力打切り不変、既発注返済の優先、最後一枚の資格、全新規費用の控除、手数料の注文単位切捨て、予算不足後の次行返済、気配の飛び越え、場末・静観を確認する。これらは有効性を示す金融試験ではない。
