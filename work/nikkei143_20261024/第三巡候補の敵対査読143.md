# 第三巡候補の査読

**TG04を、参加時間と損益の両立を重視する研究第一候補にする判断は妥当。ただしF1を全指標で上回ったわけではない。** 全50場は開発に使った既知資料で、以下は保存注文・判断記録の再集計。新しい金融再生はしていない。

TG04は三担当、PP04・PG04は二担当。PP04は構成の少なさを比較する対照として有用だが、TG04より赤字場数が少ないわけではなく、最大・平均赤字は大きい。PG04はPFと通常の赤字額が良いが、参加時間と赤字場数ではTG04に劣る。

TG04の保有率は昼70.63%・夜28.43%の単純平均49.53%。時間加重なら45.81%。**夜も約半分保有できた、厳密に50%達成、とは言えない。** 平均保有枚数は全場1.52枚で、常時10枚の運用でもない。F1より赤字場は3場増えているため「負け場も減った」という説明も誤り。

## TG04で何が改善したか

残玉を使わない同配分TG00との差は **+354,903円**。全50場・全親の差分と保存判断記録を照合した。

| 変化 | 件数 | 増減 |
| --- | ---: | ---: |
| 同じ親の残玉管理が改善 | 33親 | +945,004円 |
| 同じ親の残玉管理が悪化 | 32親 | −596,000円 |
| 残玉保有中に勝ち親を見送り | 13親 | −348,941円 |
| 残玉保有中に負け親を見送り | 17親 | +354,840円 |

同親の変化が+349,004円、後続見送りは+5,899円。**見送れば勝てる仕組みを発見した、とは言えない。** 残玉65親のうち改善33・悪化32で、金額の非対称性が利益を作っている。実約定後の予算不足による即返済は今回0件だったが、人工検査では急変時に起きることを確認済み。

予算確定後の残玉管理では、65親のうち8親が最終的に152～230円の赤字（合計1,603円）になった。呼値刻みと次板約定で利益予算の床を越えるためであり、これらも損失へ計上済み。「他玉の利益で賄うので親全体は必ず黒字」という保証ではない。

源別には、主枠CGの残玉化は **−94,460円**、小枠CSの残玉化は **+449,363円**。CGは延長自体+74,004円だが、後続見送り−168,464円で逆転する。CSは延長+275,000円、見送り+174,363円。改善の中心はCSであり「全担当の出口を改善した」と一括りにしない。CGを残さずCSだけ残す運用の有効性は、この査読では評価していない。

TG00から赤字場は19→18へ減った一方、赤字平均は37,583→43,821円、中央は36,536→42,304円へ悪化。昼の改善+326,065円に対し、夜は+28,838円。夜は同親延長+70,002円を、見送り−41,164円が削っている。

赤字集合の変化だけが平均悪化の理由ではない。両版とも赤字の同じ18場では、損失合計が684,008→788,779円に増えた（8場悪化・2場改善・8場不変）。10/16ナイトの−30,068→+15,932円だけが黒字へ転換し、黒字から赤字へ転落した場はない。残玉化は主として利益側を伸ばした改善で、既存の負け場を広く浅くした改善ではない。

TG04夜全体は上位3場除外でも黒字だが、**各源が単独で同じ頑健性を持つわけではない**。CG夜の買いPF1.139・売り5.593に対し、A3夜は買い4.843・売り0.279。組み合わせには偏りの相殺があるが、因果的な独立性や将来の相殺まで証明したものではない。

TG04全体は上昇24場でPF2.264、下落26場で1.986。売買別は買い1.709・売り2.712で売りが強い。昼の買いは1.566、昼の下落場は1.849。夜は上昇場PF2.397・下落場2.454と近いが、上昇12場の6場、下落13場の4場は赤字だった。**上下どちらでも合計黒字であることと、全場安定又は方向偏りゼロは区別する。**

判断は「既知50場で、複数の価値観を最も近く満たした研究候補」。未見成績、実約定遅延への耐性、将来の毎場利益までは主張しない。
