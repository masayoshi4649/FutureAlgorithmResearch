# 診断の読み方の補足

V030/V060で古くするのは入口・保有撤回に渡す方向列だけである。新規の0.25ATR反発・反落追跡、約定判定、ストップ、部分利確、追跡高安、ATRは引き続き現在までに観測できた値を使う。したがって、古い方向でも収益が維持されたとしても「現在情報が不要」「予測を全く使わず注文手法だけで利益を出せる」という結論にはならない。

VとWは初回の方向情報が解放される時点を揃える補助対照であり、初回約定時刻・方向・非0の活動時間・保有時間・再エントリー回数までは揃えない。V−Wはそれらを含んだ運用上の差で、鮮度だけの純粋な因果効果ではない。最初の待機中に生じた違いが、その後の追跡水準・返済・再参入へ残る点も含む。

中期方向が長く続く時間帯では、30分・60分前の方向と現在方向が同じ場合もある。古くしても結果が変わらない理由は「予測が無力」だけでなく「方向情報の寿命が長い」でも説明できる。逆に悪化も、方向を古くした影響だけでなく、最初の参加機会を失ったことを含む。L000は保有撤回にC/Sを使わないため、その比較は入口側の変更が中心になる。C/Sを実際に使うL001〜L006とは分けて読む。

420条件は同じ既知13セッションに対する診断の網羅性を表す。420個の独立した相場・独立仮説ではない。既存黒字候補の実装上の説明は増やせても、未知相場の利益の確証は増えない。遅延が良かった日だけ後から選ぶことや、遅延最良へ採用候補を差し替えることは行わない。

完備ガードは、事前固定した全件が揃い、会計・集計・資料指紋が整合しているかを検査する。診断完了を、投資上の採用合格や利益保証と読み替えない。
