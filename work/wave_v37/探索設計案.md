# 悪化時の減量と、新しい肯定情報による数量復元：探索設計案

**同じ固定 A0 組の一部を悪化時に返済し、減量約定後に公開された正方向の根拠で戻す。戻す時点の損益は条件にしない。** 元の入口・退出期限・利確枠を揃え、単に小枚数にした効果と、悪化・回復を判定した効果を分ける。

これは実装前に作成し、親担当の仕様決定を反映した設計最終案である。その後の注文器実装・合成と旧A0同値は [別の監査記録](partial_engine_audit.md) に保存した。新方針の実相場損益の再生、採否判定、現在 API 取得、保存ライブ参照は行っていない。既知 13 セッションで次に比較しても未見検証にはならない。既存の両建て・カバーを新手法と数え直すものでもない。

## 1. 主仮説と、最初に試す一つ

親担当の指定に従い、主案は **H019 の A0 組＋B06 の悪化で半量減量＋減量後の新しい B06 肯定で復元、1 組につき減量約定 1 回まで** とする。B06 は両市場の価格方向の一致、窓は 120 秒。板を加える B08 は同じ数量操作の対応対照に置く。主案の指定は性能の採用・優位性の主張ではなく、正式な実験凍結もまだ行わない。

狙いは、細かな悪化で全返済して大きな波を逃すことを減らしつつ、悪化区間の保有数量を落とすこと。ただし「減量した後にもっと高く買い戻す」なら、買いの基準比損益はその区間で悪化する。肯定確認ができたことと、数量を戻すことに経済的価値があることは別に検査する。

主案は 1 段階の減量・復元とし、最大 3 回の反復は別の機構比較へ置く。永久に片側の含み損を保持する方式、利益になったカバーだけを閉じる方式、反対方向への主玉転換は入れない。

## 3. 枠番号で、減量・元利確・復元を一意にする

初回の同方向玉に `1..q0` の枠番号を付ける。影の 2 A0 利確は **小さい番号から floor(q0/2) 枠**を永久終了させる。TOPIX は 2 枠を閉じて 3 枠残り、NK は 5 枠を閉じて 5 枠残る。

各枠は「影が生存しているか」「実玉があるか」「調整で空いた復元可能枠か」を分けて保存する。

1. 通常状態の減量では、現在の影生存数 n に対し `h=min(n−1, max(1, floor(f×n)))` 枚を、小さい生存枠番号から選ぶ。f は 25% 又は 50%。最低 1 枚のコアを残す。減量が約定した枠だけが復元可能になる。
2. 主案 f=50% は初回 TOPIX 2 枚、NK 5 枚を減らす。元利確後に初めて減量する場合は、残 3 枚から 1 枚／残 5 枚から 2 枚となる。割合と整数枚数を両方表示する。
3. 影が部分利確する行では、その対象枠に実玉があれば返済し、空なら売買も架空利益も作らず復元資格だけを消す。実の残数量をもう一度半減しない。
4. 復元数は「調整で空き、なお影が生存している枠」の数。元利確・元全返済で終了した枠は二度と戻さない。枠の途中復元・別枠への付替えは行わない。
5. 部分利確により空き枠が全て消えたら、復元なしで通常状態へ移る。ただし実行済みの減量回数は消さない。減量前に元利確が起き、調整が取消になっただけなら回数は消費しない。

**重複例:** NK10 枚の枠 1〜5 を減量後、元の 2 A0 利確が成立した場合、枠 1〜5 の復元資格を消し、実の枠 6〜10 の 5 枚は保持する。TOPIX5 枚なら枠 1〜2 を減量し、元利確でその資格を消し、枠 3〜5 の 3 枚を保持する。復元が先に終わっていれば、元利確は復元玉の実建値に対して損益を計上して閉じる。

この枠配分は元利確対象を優先して減量する案である。コア側を先に減らす別配分は結果を変え得るため、今回の格子へ混ぜない。

## 4. 新情報、状態遷移、行内の優先順位

使う 8 入力は既存の B00/B01（自市場価格）、B02/B03（自市場板フロー）、B06/B07（両市場価格）、B08/B09（両市場価格＋OFI）。偶数は 120 秒、次の奇数は 600 秒。既存の価格幅・OFI 閾値・有効性・相手追加 60 秒遅延は変更しない。B06 だけでは板数量の価値を測れない。

状態は **通常 → 減量予約 → 減量済み → 復元予約 → 通常**。全返済済みは旧組内の終端とする。

- 悪化は採用した入力が `−d`。組開始後に公開された根拠で通常状態から減量を予約する。最初の悪化根拠も組開始行より後の公開行を要求する。
- 復元は採用した回復入力が `+d` かつ、その `source_row` が減量約定行より後。0、欠測、古い値の保持、失効は肯定ではない。復元価格、調整の実現益、含み益は見ない。
- **v35 の source_row は ready 配列の行番号であり rawseq ではない。** 比較は同じ配列の行番号で行い、証拠に rawseq、公開時刻、素材参照上限、相手参照も併記する。同時刻でも行順を守り、後の公開行だけを新しい情報とする。
- 両市場入力では最新の自市場公開行が減量後であることを要求する。相手は既存の遅延・鮮度を満たす範囲で再確認するが、相手の素材まで減量後とは限らない。「両市場に新しい素材が到着した」とは説明しない。
- 反復を許す条件も、復元約定行より後の新しい悪化根拠を必要とする。同じ source_row の持続で直ちに再減量しない。最大回数は実行済み減量の回数とし、組をまたいで枠や回数を持ち越さない。
- 悪化用と回復用が異なる場合、新しい回復 `+d` があれば復元を許す。別の悪化入力がまだ `−d` であることを隠れた拒否条件にしない。矛盾状態での復元件数は別に記録する。主案の同一 B06 ではこの矛盾は生じない。

行 i では、前行まで有効だった元 A0 の市場返済予約・価格注文を元の順序で評価し、次に追加の実口座予算による全返済予約、最後に調整予約を処理する。元の価格注文同士の到達順序は変えない。追加予算の予約と元価格条件が競合した場合は、元 A0 の旧条件を優先して約定価格を記録する。元部分利確が先に成立して実残玉がある場合、追加予算の全返済予約は消さず次の有効行へ持ち越し、その間も元全返済条件は有効とする。影の独立計算は変えない。元全返済・元部分利確が成立する行は減量・復元より優先する。

元部分利確が成立する行は、調整予定枠との重複の有無によらず、調整予約を全量取消とする。残った復元資格を使うにも、その部分利確行より後の新しい肯定を待つ。部分利確を見た同じ行に数量を組み直して過去価格へ執行しない。元注文で売買した行には新しい調整予約を作らず、以後の行で判断する。元注文がなければ前行の調整を約定し、その行に逆の調整を予約しない。

**A0 より後に保有しないため、元 A0 の有効な全返済条件を前行から実側にも並行設置する。** 影の全返済を後から見て、その次行に実返済を送る方式は不合格。同じ行に成立済みの旧条件で返済するのであって、影の未来約定をコピーする方式でもない。

## 5. 調整損失の累積を打ち切る

実口座の組内損益 `e = その組の全実現損益 + 現在の全実玉の含み損益` を毎有効行で計算する。`e <= −初期R` なら、その行で全返済を予約し、次の有効原本行で残玉を返済する。元 A0 の返済条件はこの予約中も並行して有効とする。全返済予約後は復元しない。

これは**退出を始める固定予算**であり、R 円以内の損失保証ではない。減量・復元を反復した実現損失も分母 R も消さず、次行の価格飛び、欠測を挟む執行、既存市場返済の優先により超過し得る。最大超過額・超過回数・予算到達から返済までの秒数を保存する。元の価格ストップだけでは、減量して買い戻した損失の積み重ねを制限できない。

## 7. 評価と、棄却すべき解釈

各銘柄を別々に、各セッション・週・全13・後7の利益／損失／収支、利益枚数／損失枚数／同値枚数を出す。復元で返済脚が増えるため、**脚別PFと勝ち枚数だけでは改善判定しない**。同じ元組の全実現＋最終返済の合計、時価DD、1組平均利益／平均損失、初期R当たり損益、純枚数分を併記する。

全元組を一対一対応し、少なくとも次を集計する。

- 減量・復元回数、減量だけで終わった組、元利確で消えた復元枠、競合による取消、数量を落としていた時間・枚数分。
- 同じ元組内の損益差。数量減少中に避けた逆行と、取り逃した順行を両方数える。各減量枠から次の復元／枠終了までの基準差を積み上げ、実台帳差へ一致させる。
- 元組の最大利益除去、最大利益セッション除去、日中／夜間、初期6／後7の偏り。初期6は祝日取引期間に偏るため、そこで新しい回復器を学習・選抜して通常日にも効くとはしない。
- R超過、終端での全脚ゼロ、復元後の即損切り、相場に参加しなかった時間、上限遵守。金額を銘柄間で単純に足して優劣を決めない。

低数量対照でも説明できる、無関係復元と差がない、回復がほとんど実行されない、利益の増減が少数の組だけで決まるなら、回復情報の価値を支持しない。損失を減らしても長い順行で利益をさらに削るなら交換条件として報告する。旧75/80基準を無断で今回の必要条件にせず、採否基準は次の凍結時に主張へ対応させる。この設計自体は成績を改善する証拠ではない。

| 費用0の同約定カバー | 純数量方式と現金＋時価、純在庫、最終組損益が全行一致。脚別の見栄えの差は利益源としない。 |
| 未来切断／未来価格・板・出来高・相手方向変更 | 切断以前の判断・約定・枠状態・根拠seqが不変。乱数対照も接頭部不変。 |
| 場末・期限・欠測・飛値・同時刻 | 既存因果約定規則を継承し、保有・復元権・注文が次セッションへ残らない。最終行で架空の過去価格へ返済しない。 |

両建て同値は同じ時刻・価格・数量・終了規則を揃えた場合の比較である。元利確でカバー中の枠が終了する際にも、両脚を同じ価格で終了させる会計対照を用いる。片脚だけ次行に送る等の実装差がある場合は同値と主張せず、その差を別に記録する。

## 9. 決定済み事項と、実装凍結までの残件

主 B06 半量・新しい B06 肯定・1回、主比較309条件、回復符号64件を別補助とする構成、二つの小数量型の枠・共通退出線・共通Rは親担当が決定した。旧案の「小数量型の扱いは未決」「371条件に乱数を混ぜる」は採らない。

行内優先と復元資格の実装・合成、旧A0同値は別監査へ進めた。親担当の `partial_design.py` は主309、診断54、別補助64を列挙しており、実行対象の正本とする。残件は、回復の新しい自市場公開行と相手の素材時刻を区別した独立監査、全依存の凍結、採否の主張を結果前に確定すること。相手の素材まで減量後とする条件を追加するなら別機構となる。新方式の性能改善を示すものではない。
