# 数量減量・復元の独立会計

主363条件と補助64条件の全件が合格した。主9,438入力・補助1,664入力、合計11,102入力の1,251,897,815原本行を同じ監査規則で照合した。成績による対象の除外や監査実装の事後改訂は行っていない。

注文の約定価格・方向・数量から現金と純建玉を再構成し、返済明細から実現損益を別計算した。全行時価、最大下落、全セッションと全13/後7の必須集計項目が保存結果と一致した。損失玉・同値決済も含む。

枠イベントから、生存・保有・復元資格を全行で再構成した。元2ATR利確による枠の退役、実際の復元建値、新しい公開根拠、予約すべき行の脱落、元注文優先、元Rによる予算予約の保持、影終了以前の返済を確認した。

純数量の減量・復元を同約定の反対玉・反対玉解消へ写像すると、全行の現金・純在庫・時価が一致した。カバー中の枠が退役する場合は元玉と反対玉を同価格で終了する。途中の実現/含み内訳や脚別PFの一致は要件としていない。

全保存配列は再生結果の形状・型・内容指紋と一致する。会計・主要状態は独立式で検算したが、全ての補助表示列を別式で導出したという意味ではない。例えば調整イベントの減量回数表示列は配列再生一致で確認し、管理状態の減量回数と回数上限は別式で検算している。

結果前の人工1,236入力と破損・欠落49件拒否を含む固定規則を使用した。主・補助とも監査固定SHA256は `f6e046341d2a27c7417a010989437cd2664a1c51c6cdc78301c381244efa854a`。原本78と参照実装の前後SHAは不変で、現在API・保存ライブを使用していない。

監査合格は将来利益や研究上の採用を意味しない。代表入力の未来改変・上下反射と全指定波は別の監査資料へ接続し、固定主案の経済判定と分離する。
