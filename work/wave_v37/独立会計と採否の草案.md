# 独立会計と採否の草案

**検証価値は、同じA0組の数量を減らすことと、減量後の情報で戻すことを分離できる点にある。両建て自体、新しい組へ損失を移すこと、利益玉だけの決済を利益源とはしない。** 本文は新しい実データ損益を見る前の設計レビューであり、まだ採否の正式凍結ではない。現在API・保存ライブは使わない。

## 最新の対象を一つに揃える

主格子は309条件。情報による調整256、減量のみ16、120秒時計復元32、固定コア小数量2、通常半分利確型小数量2、元A0が1。診断54を加え主再生363、回復の符号対照64は別集計し、計427条件を検証する。主仮説はH019、B06悪化、50%減量、新しいB06肯定による復元、減量約定1回まで。最良IDへ事後に差し替えない。

診断54は、残り11入口×A0/主案/減量のみの33、入口時計±20%×5方式の10、観測価格5、悪化窓±20%×主案/減量のみの4、回復窓±20%×主案の2。入口時計と情報窓の変化を混同せず、各変形のA0・減量のみ等を正しい対応対照へ接続する。

両小数量型は元のA0価格条件・元q0のR・終了期限を使う。独自の小枚数D273とは呼ばない。

| 型 | 25%減量相当 TOP / NK | 50%減量相当 TOP / NK |
|---|---|---|
| 固定コア | 4→3枚 / 8→5枚 | 3→3枚 / 5→5枚 |
| 通常半分利確型 | 4→2枚 / 8→4枚 | 3→2枚 / 5→3枚 |

通常型は元利確枠から小番号 `floor(q_small/2)` 枠と、元残枠から大番号の残りを初回に持つ。動的な比率丸めへ置き換えない。二つの小数量型は、初回枚数が同じでも2ATR以後の保有量が異なるため、同じ対照として合算しない。

## 因果性・執行で落ちやすい箇所

- **前行の計画を実が独立評価する。** 影の全行計画をあらかじめ計算しても、実が行iで使えるのはi−1までに有効になった情報だけ。影の将来の終了行・約定行一覧を売買判断に使わない。元A0価格線のヒットを現在価格から実も判定し、影終了後の次行返済や終了行の事後コピーにしない。
- **優先順は元A0の市場予約・価格注文→実口座予算予約→調整予約。** 元部分利確が成立したら、調整対象枠と非重複でも全調整予約を取消す。新たな調整にはその行後の新根拠が必要。実予算の全返済予約は取消さず、残玉に持続する。この競合では予算返済が更に1行遅れるので、「必ず次の1行で全返済」とは説明しない。
- **予算は元Rで組全体を測る。** 全実現＋全残玉時価が `−q0×A0` 以下になれば全返済を予約。復元時も過去の損失を消さない。価格飛びと元注文優先による超過を記録する。Rは始動条件と比較尺度であり、損失上限の保証ではない。
- **source_rowはreadyの行番号。** 減量は組開始・直近復元より後、復元は減量約定より後、部分利確後はその行より後の公開を要求する。原本seqとは別に保存する。同時刻の行順を保持し、欠測・0・古い肯定の保持を回復にしない。
- **時計対照は公開時刻で区切る。** 120秒経過時の現在時刻だけでなく、採用する公開source自体が減量約定の120秒後以降であることを要求する。119秒の公開を保持して120秒に使う方式とは区別する。0方向でも有効な自市場公開を使え、相手同意は要求しない。
- **回復64は元B06方向×公開イベント別符号。** `v37|seed|session|symbol|source rawseq` から決め、同source中に引き直さない。反射時は元方向と組方向が共に反転し相対肯定が不変。非0の有効公開機会は残る。v36の共通30分符号とは違い、別イベント・別銘柄の方向関係を保つとは説明しない。

## 最小の合成会計仕様

価格単位で検算し、円換算は最後にTOP1000円・NK10円を掛ける。全ケースで現金＋純在庫×原本価格を注文から再構成する。損失脚・同値脚・終了時の全枠を省略しない。

| 検査 | 必須の期待値・拒否条件 |
|---|---|
| A0と調整不発火 | 旧全台帳・時価・元組・注文の厳密一致。新しい予算監視だけで既存A0を変えない。 |
| 初回5枚、100で新規、2枚を98で減量、101で復元、元2枚利確120、残3枚返済140 | A0は160、実は154、差−6。差は `2×(98−101)`。復元玉の建値を100に戻す実装を拒否。 |
| 同じ減量後、復元せず元利確120、残3枚返済140 | 実は116、A0比−44。空の元利確枠から架空の利益40を作らない。 |
| 復元前に元利確 | 空の枠1〜2（NKなら1〜5）を退役し、以後の肯定でも復元しない。退役は売買件数に数えない。 |
| 復元後に元利確 | 復元玉の実建値で利確を記帳。元E、A0、期限、極値、Rは変更しない。 |
| 利確後の初めての減量 | TOP残3枚の半量は1、NK残5枚は2。最低コア1枚。25%の整数丸めも両銘柄で確認。 |
| 元部分利確と調整予約の同時成立 | 重複・非重複の双方で全調整を取消。回数を消費せず、次の新根拠まで再予約しない。 |
| 元全返済と調整の同時成立 | 元返済が勝ち、実もその行までに全枠終了。旧組内へ再参加しない。 |
| 古い肯定、0、欠測、同source持続 | 復元しない。後続行の新しい肯定だけが次行注文を生む。 |
| 復元後も古い悪化が継続 | 同じ根拠で直ちに再減量しない。1回/3回上限は約定した減量回数で確認。 |
| 部分利確で空き枠が消える | 通常状態に戻っても、既に実行した減量回数は保持。 |
| eがR境界に一致 | `e<=−R` の一致を含め予約。閾値直前では予約しない。次行飛びによる超過を隠さない。 |
| e到達後の元部分利確・反発 | 予算予約は残り、元利確後の次有効行へ持ち越す。含みが回復したという理由で予約を取り消さない。 |
| 予算全返済後も影が存続 | 実は終端。肯定が来ても旧組で復元せず、次の影新規だけを待つ。 |
| 固定コアと通常小数量 | 上表の全8数量経路、保持枠番号、共通R/価格線を厳密一致させる。 |
| 場末・期限・データ途切れ | 元A0と同じ完了時点以前に実の全枠・全注文を終了。架空の終端時刻を足さない。 |
| 同時刻切断・未来改変・上下反射 | 入口、元計画、悪化、回復、source、価格の未来を変えて過去の全注文/枠状態が不変。同seed反射で相対肯定も不変。 |

同約定両建ては、実の減量を反対玉、復元を反対玉解消へ写像する。**元利確でカバー中の枠が退役する際は、元玉と反対玉を同価格で終了**させ、純数量版で空の枠が退役するのと同じ現金変化0を作る。全行の現金・純在庫・時価・最終元組損益・DDが一致すべきで、実現/含みの内訳、返済脚数、脚別PFは一致する必要がない。

これは同約定を揃えた経済同値検査である。実際の注文APIで両脚を同時に閉じられることの証明とはしない。片脚を次行に送る方式を試す場合は別の執行モデルとして扱う。

## 保存しないと反証できない情報

元組IDと枠ID、初期R、元E/A0、各枠の実建値、影生存/実保有/復元資格、減量回数、状態、全予約と取消理由、判断行/約定行、根拠ready行とrawseq・公開時刻を保存する。減量・復元・元利確・予算返済・元全返済を別理由にする。

全元組を対応させ、最終差を「空いた枠で避けた逆行・失った順行」「復元後の損益」「早い予算終了」に分解して台帳差へ一致させる。予算超過円/回数/予約から返済までの秒、純枚数分、実保有が元A0終了を超えないことも全行で検算する。

## 採否草案：三つの主張を分ける

対象は固定主案のみ。全13と共通後7を両銘柄別の4セルとして評価し、他308・診断54・64seedの最良を代用しない。

1. **研究上の基礎条件。** 両期間・両銘柄で収支正、同じ元組単位の利益/損失比と平均勝ち/平均負けが1超、最大1勝ち元組・最大1黒字セッションをそれぞれ除いて非負。無損失など比率未定義は未確認として別表示。減量と復元が両銘柄で実行されなければ、その機構の有効性を支持しない。全8波も元組の正方向保有で検査するが、コアを残す設計で保有分が維持されても予測精度向上とは呼ばない。
2. **先行A0の代替としての改善。** 4セルすべてでA0比の収支が非劣位・時価DDが非劣位、全体の最低1項目が厳密改善なら「同時改善」。一部の収支とDDを交換した場合は「交換」として示す。75%/80%などを新たに加えない。この改善目標未達を、手法全体無価値やユーザー要件全体未達と同一視しない。
3. **回復情報の追加価値。** 同減量・復元なし、同減量・120秒復元、二つの同初回小数量を対応比較する。単純対照に4セルの収支/DDで支配されるなら追加機構を支持しない。回復64の各セル中央値に収支/DDで非劣位かつ最低1項目厳密改善を確認する案。中央値対照は正式p値ではない。復元なしより収支が増えDDも増えるだけなら、保有量を戻した交換を明記し、それだけで予測力を認定しない。

採用目安は、全独立検査、基礎条件、A0同時改善、単純対照での非支配、回復64対照を満たす場合に限る案とする。比率・最大勝ち除外・4セル比較は全数値と併記し、合否だけの報告にしない。金額/勝敗決済枚数/同値枚数はユーザー指定どおり全セッション・開始週・全13・後7で出すが、**脚の切り分けで変わる枚数PFを両建てと純数量の独立利益源判定には使わない。**

入口時計・悪化窓・回復窓・観測価格の主案7変形は、後7両銘柄の黒字・元組PF1超・平均元組勝敗比1超を採否の必須条件とすることで合意した。感度の最大勝ち除外は全表示するが、採否条件には追加しない。基礎条件が崩れる変形を、最良変形の採用や中央値だけで隠さない。残り11入口は機構の一般性を診断する対応比較であり、相関の高い同一期間を独立11標本と数えない。正式な数値・実装契約は `partial_assessment.md` と `partial_assessment_fixed.json` に一本化する。

この採否は改善機構についての結果前の研究基準であり、未知相場の利益保証ではない。既知データ内で研究基準に届かなくても、既存A0の黒字等の根拠を取り消さない。
