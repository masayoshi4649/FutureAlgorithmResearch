# 部分調整の入力

旧14入口と8観測方向はv35の保存物・監査SHAを再利用する。新規はB06窓96/144秒だけで、悪化と回復へ別指定できる。短窓・段階窓も同率になり、peer遅延と鮮度は60秒のまま。

source_rowはreadyの配列行でありrawseqではない。根拠のrawseqはready.seq[source_row]。timerはpublication_validを併用し、有効中立は許すがinvalid・staleは許さない。peer同意はtimerに要求しない。

乱数回復は元B06の非0機会を保ち、公開元rawseqごとの固定符号を元方向へ掛ける。素材の意味・発火時刻の情報は残る。配列末尾や将来イベント数を使わず、同時刻でも公開順を守る。

全新窓の切断・未公開peer改変・反射、全64seedの接頭部と反射を検査。新損益、売買再生、API、保存ライブは使用していない。
