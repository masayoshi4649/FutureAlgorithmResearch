# 板圧力推定の契約

`fit_model.build(events_by_key, inputs, lag=3)` は、キー `(session, symbol)` ごとの推定配列と学習履歴を返す。入力イベントは `release_minutes.build` の出力。全キー集合は原本入力と一致させる。売買と未来価格ラベルは作成しない。

予測対象は公開区間の規格化OFIを符号付きlog1pへ変換した値。各銘柄で、対象セッション開始前に観測を完了した同銘柄の過去セッションだけを使う。対象セッション、未来セッション、相手銘柄は係数学習へ使わない。最初の2セッションは学習専用で、その後も共通有効標本が40行未満なら予測しない。

ラグ1・3・6の全方式で、最大ラグ6の連続した有効区間を共通母集団とする。説明変数は指定ラグ本数の過去OFI、直前区間の価格変化とスプレッド。区間を削除して時間的に離れた行を接続しない。母標準偏差による標準化、ゼロ分散の尺度1への置換、切片非罰則の `meanSE + 0.01 * 係数二乗和` を使う。切片・係数・標準化値・残差RMS・素OFI RMSは、対象セッション開始前に固定する。RMS下限は1e-6。

返り値の第1辞書には以下の列がある。

| 列 | 意味 |
| --- | --- |
| indices / seq / time_s / minute | 原本配列行、原本seq、区間公開時刻、分番号 |
| observed | 現在区間で観測した規格化OFI。将来価格ではない |
| prediction / residual | 過去だけから予測したOFI、観測値から予測値を引いた値 |
| residual_rms / raw_ofi_rms | 過去訓練内の尺度をセッション中固定。後者は予測成分を引く前の同じOFI尺度であり、原枚数ではない |
| common_valid | 最大ラグ6の共通有効区間 |
| forecast_valid | 共通有効かつ過去2完了セッション・40標本を満たす区間 |

無効区間の予測と残差はNaN、学習不可のセッションは尺度もNaN。学習可能なセッションの尺度は無効区間にも固定値を保持するため、入口判定には必ず `forecast_valid` を使う。第2辞書は学習に使った各セッション・完了時刻・公開最終行・標本数、係数と尺度、内容指紋 `model_sha256` を保存する。

訓練残差の尺度は、モデルを当てはめた標本自身に対するRMSである。これを未学習誤差の保証とは呼ばない。現セッションの誤差は観測区間ごとに保存するが、当該セッション中の再学習・閾値再標準化には使わない。

監査は人工の独立最小二乗解、零分散、非有限・39標本等の拒否、未完了・完了時刻等号の拒否、他銘柄・当該・未来の除外を確認した。実データでは3ラグ×26入力、156の過去切断、156の未来改変、78の上下反射が一致した。全ラグの有効マスクも一致。`モデル学習の固定.json` に実装・入力監査・全推定出力をSHAで接続した。売買損益の評価は未実施。
