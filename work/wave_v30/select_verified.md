# 第6反復の研究候補選抜

実行は `python -X utf8 work/wave_v30/select_verified.py`。資料の完全性検査が成功した場合だけ、固定済み `research_selection.select()` を呼ぶ。現在保存データの読取り・再生・API取得はしない。

全12入口×7管理＝84候補について、最低基準や一次検査の合否で対象を絞らず、一次反証の全明細、乱数64seed×2方式、指定4波×2銘柄を要求する。固定比較4件も含む波明細は704行。一次通過が0でも乱数・波の空資料を許可しない。

採用規則は既存の数値を維持する。最低基準、全一次反証、乱数2方式の各64seed、指定8波を通過し、両銘柄それぞれで、旧主案 H019__D273 と同入口 L000 の両方に対して収支75%以上・含み損込み最大下落80%以下を必要とする。同入口 L000 は黒字かつ最大下落が正であることも必要。最大2案を固定順位で選び、EMA両系列は一思想とする。なければ候補なしとし、良い近傍へ交換しない。

ガードは固定カタログの直積・ID重複・全予定集合、実装SHA、一次反証の全変形と合否再計算、同入口 L000 対照の集計と台帳指紋、128乱数実体と要約、波の区間・重複・20分判定・要約を確認する。選抜前後の資料SHAも照合する。

結果前の合成検査では正常2件を受理し、不正20件を拒否した。一次通過0でも全対照を残した正常例を含む。別に、凍結した元選抜関数の旧主案／同入口の等号境界、黒字・DD正値、片銘柄だけの未達、乱数・波・思想統合の23境界を確認した。

記録は `選抜整合ガードの固定.json`、`select_verified_test.json`、`selection_boundary_test.json`。ガードは保存された保有分を台帳から再積分するものではなく、波の計測コードと明細・要約の整合を確認する。実際の保有分と全玉会計は独立診断で補完する。

これは既知13セッションの第6反復であり、整合性や反証を通過しても未知相場の収益を保証しない。入口配列が同じでも、早い返済と5分休止によって後の再エントリーは変わるため、収支差を出口だけの価値と断定しない。
