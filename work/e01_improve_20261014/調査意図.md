# 両商品の達成条件へ向けたE01の改善

2026年10月14日の追加依頼。パラメータ差を許容し、両商品で金額利益割合65%以上、赤字場20%以下、最大赤字≦平均黒字1場を満たすアルゴリズムへ改善する。利益上位3場除外、昼夜、方向、活動、保有中の逆行も確認する。新たな最低活動率の数値条件を勝手に追加しないが、無取引を勝ちとせず、ほぼ休止する条件を安定利益の成功とはしない。

## 比較元と分離する問題

- 00104でB03は同じ既知33場の数式三基準を両商品で満たしたが、活動7／8場・15取引中13ナイト・2票7件・途中清算逆行3,166／1,566円。
- より緩いB01はTOPIX9黒字1赤字23無、日経16黒字0赤字17無。TOPIX唯一の負けは9/30ナイト21:35:19、20票・釣合い0.7でも公開ask4,132.5から4,133へ不利に買い、−4,082円だった。
- 公開値に対する新規約定価格の制限を、方向の資格と別に検査する。未来の次気配を見て過去の公開を拒否したことにしない。
- 気配幅の拡大は価格の悪化と異なる。買askが同じでbidだけ下がれば、買い上限内でも清算の初期損失は拡大する。今回の一次条件へ追加の幅ガードを混ぜない。
- 最低4方向票は2票・3票の双方を拒否する。20票で負けた反証があるので、票数の増加を将来成功率の保証とはしない。

## 結果前に固定する18新条件

| 部品 | 候補 |
| --- | --- |
| 入口票 | 既知・方向票2以上で釣合い0.25／0.5／0.75、又は方向票4以上で釣合い0.5 |
| 新規 | 公開ask以下で買い／公開bid以上で売りの一回指値（FAK0）、1観測呼値だけ不利を許す一回指値（FAK1） |
| 利確 | 初回受理q×観測1呼値×倍率の純目標、又は初回受理q×公開ATR×倍率の0.25倍 |
| 途中と損失 | 元E01の判断・場の損失予算TOPIX5,000円／日経2,000円を維持 |

四入口×二新規×二利確の16条件に、最低4票・釣合い0.5の元成行×二利確の2条件を加える。元成行の残る三入口×二利確の6条件は保存結果を再利用する。実商品はTOPIXミニ／日経マイクロ、上限10／20枚、各新規5／10枚以下のリスク数量。料は注文別floorの41.8／11円を両側へ課す。

新規は公開時に限界価格と予定qを固定する。公開後の最初の正常気配で、価格内ならその当時気配で予定全量、価格外なら未約定失効という模型。失効しても初回受理の目標尺度は保持し、紙上の元判断と後の実参加は続ける。実ミニ／マイクロ板の待ち順位・部分FAK・到着時刻・5秒最悪約定を再現した模型ではない。

## 実行管理と成功の扱い

- 原板・ローソク足を変更しない。API・現在データ再取得・実注文・ライブApp変更は0。00103での現在一回取得は消費済み。
- 正式条件・source・入力指紋・8部品・比較理由を固定し、根で重複照合・登録してから一回だけ金融を開始する。Falseは保持し、自動再開しない。
- 予定は保存input33各1読、旧6対照台帳396各1読、その同GUペア198の再利用、新GU594、新政策1,188。旧GUと旧会計の同値確認は新たな有効性の証拠としない。
- 利益・損失は手数料後の完結実親net正負。場の先相殺、無取引の勝ち計上、見送った親だけの削除は禁止。
- 商品別パラメータを選んだら固定する。場の結果を見てその日の条件を選ばない。選択が同じ既知33場に基づくことを明記する。
- 未達なら赤字場と失った回復の勝ちを具体時刻で調べ、次の一部品へ進む。未約定の初受理アンカーが利確尺度を変える可能性も、今回の結果で初めて測ってから別の対照にする。
