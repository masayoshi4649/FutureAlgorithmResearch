# 板の性質を理解するための固定観測

最初にこのファイルを読み、数値を確認する場合は [価格応答との重複.json](価格応答との重複.json)、[市場性質結果.json](市場性質結果.json)、[品質件数.json](品質件数.json) の順で参照する。

**今回確認できたのは、板の圧力指標が「直前に価格が動いた方向」をよく説明すること。価格の動きを考慮した後も、次の方向を安定して説明するかは確認できなかった。** 板全般が無価値だという結論ではない。注文戦略の追加・ランキング・閾値最適化はしていない。

## 原理と観測方法

最良気配の数量が減ったり、価格段階が切り替わったりすると、価格形成に関係する変化が板に現れる。一方、既に動いた価格に追随する変化まで将来予測と扱うと判断が遅れる。そこで、直近120秒の板変化と同期間の価格変化、さらにその後1・5・15分の変化を分けて調べた。

板変化は最良気配の注文フロー不均衡（OFI）、価格に近い板の数量変化、近接板の数量偏りを使用した。OFIは最良気配・数量変化の指標であり、買い成行と売り成行の実約定量の差ではない。価格変化は、その時点で計算できたATRで割った。

[条件固定.json](条件固定.json) を計算前に保存。各場の開始30分後から15分間隔で観測し、結果区間の重複を避けた。公開から60秒超・源板時刻から60秒超・窓内連続性異常等を除外した結果、1,678候補のうち774点（TOPIX399、NK225375）が残った。将来端点の欠測で比較数はさらに減る。最初の30分や品質除外された相場の性質まで代表する分析ではない。

## まだ分からないこと

固定定義の強圧力（絶対OFI0.20以上）はTOPIX18点・NK2258点のみ。「強い圧力なのに価格が停滞」は0点、60秒遅延の両市場強圧力同調も0点だった。吸収や同調が存在しない証拠ではなく、この定義と標本では評価できない。結果を見て閾値を緩めてはいない。

板の減少が約定消費か取消か、増加が同じ参加者による補充か、同じ注文が繰り返されているかは識別できていない。受信時計がなく、原本のCurrentPriceTimeは最終約定時刻なので、特に細かい先行・追随や瞬間的な補充の評価に限界がある。短い反応を今回の15分間隔観測で捉え切ったとも言えない。

偏相関は全期間を使った説明統計で、将来予測モデルの成績ではない。非線形な追加情報、因果関係、係数の安定性を証明しない。全23場は既に閲覧したデータであり、追加4場も真正未見ではない。独立標本を仮定したp値や信頼区間は出していない。
