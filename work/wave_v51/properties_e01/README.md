# E01の性質の確認

最初に読むファイルは[性質の要点.md](性質の要点.md)。

1. [性質の要点.md](性質の要点.md)：損小利大の成立条件、入口の遅さ、影待機の役割。
2. [数理補足.md](数理補足.md)：成功率の式、条件付きで無方向な価格、両建て会計。
3. [性質の数値.json](性質の数値.json)：全46口座の収支再構成、旧期間と追加期間の分布、影待機。
4. [analyze.py](analyze.py)：既存台帳から数値を再現する処理。

新条件探索・追加API取得はゼロ。既に実行した時計変更の比較と、保存済みE01台帳だけを分析した。MFE等の事後情報を入口判定に使えるとする検証は行っていない。
