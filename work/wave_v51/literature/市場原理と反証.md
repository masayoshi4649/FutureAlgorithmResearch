# 新方式に使う市場原理と反証

参照日: 2026-10-07。これは新方式の設計根拠であり、利益の証明ではない。現在 API は取得していない。

## 先に固定する結論

- 売買は常に買い手と売り手の対で成立する。「買いが多い」は参加者数ではなく、売り指値を消費する強さと、それを補充する強さの差として定義する。
- 板の厚さは待機意思、約定は実際の消費、板の中値上昇はすでに起きた価格変化である。この三つを同じものとして扱わない。
- E01 の既存特徴量は最良気配中値の動きを使い、個々の約定・注文の追加・取消を識別していない。「板読み全般が無効」とは結論できない。
- 遅い二市場方向一致は、二市場が同時に転換しても遅れて一致し続けうる。新方式は方向の一致に加え、直近の進捗と失敗を確認する。
- 今回の追加4場は連敗を知ったうえで研究している。過去19場と分けても、新方式の真正な未見検証とは呼ばない。

## 一次資料5件

### 1. 板の増減は、厚さの一枚絵より説明力を持つ

Cont, Kukanov, Stoikov, *The Price Impact of Order Book Events*。
[著者公開論文](https://arxiv.org/abs/1011.6402)

最良買気配・売気配の価格と数量の変化をまとめた OFI と、同じ短区間の中値変化との関係を調べる。市場深度が薄いほど同じ需給変化で価格が動きやすい。対象は米国株であり、主結果は同区間の説明である。これをそのまま次の数十分の予測力と解釈しない。

今回の提案: 板 OFI を入口の補助情報にするなら、集計区間を完全に終了させてから次の区間を予測する。OFI を深度で正規化する。板を使わず直近価格だけを使う対照と比べ、追加価値を確認する。

反証: 同区間は説明できても、1分後・5分後・15分後の方向／実トレード利益を改善しなければ、長い波の入口には採用しない。

### 2. 板の厚さに予測力があっても時間軸を分ける

Gould, Bonart, *Queue Imbalance as a One-Tick-Ahead Price Predictor in a Limit Order Book*。
[著者公開論文](https://arxiv.org/abs/1512.03492)

最良気配の数量不均衡は Nasdaq 10銘柄の「次の中値変動方向」の予測に寄与し、大きい呼値の銘柄ほど改善が大きかった。次の1回の中値変化を当てることと、損切り幅を超える継続波を取ることは別である。

今回の提案: 板不均衡は新規価格を少し有利にするか、逆行中の入口を待つ用途を優先する。二市場の中期方向判断に上書きしない。

反証: 1tickの的中率だけ上がり、損益・最大逆行・15秒遅延時の結果が改善しなければ不採用。特徴量を5〜30秒遅らせても改善が残るかも検査する。

### 3. 補充の前後には取消や一時的な空白もある

Bonart, Gould, *Latency and liquidity provision in a limit order book*。
[著者公開論文](https://arxiv.org/abs/1511.04116)

市場注文の到着前後に、板の純流入が異なる複数の段階を観測する。補充だけでなく、先行する取消・反対側の変化や応答遅延がある。補充を単純に強い支持・抵抗とみなす説明だけでは十分ではない。

今回の提案: 同一価格の板が減って戻る回数だけでなく、その間の累積約定量と価格進捗を合わせる。「消費が多いのに価格が進まない」を吸収候補とする。進捗が始まった場合は吸収仮説を撤回する。

反証: 正確な市場注文時刻・方向がない現データでは真の補充率は計測できない。代理値だけを検証し、「隠れ注文を検出した」「同じ業者の補充を検出した」とは呼ばない。

### 4. 板の動きは現在の板状態に依存する

Huang, Lehalle, Rosenbaum, *Simulating and analyzing order book data: The queue-reactive model*。
[著者公開論文](https://arxiv.org/abs/1312.0563)

指値追加・取消・市場注文の発生を板の状態に依存する過程としてモデル化する。一定の中値区間内の板変化と、価格水準が変わる局面を分ける。厚い板があるだけで次の価格が一意に決まるわけではない。

今回の提案: 「進む局面」と「消費されても進まない局面」を分け、前者は追従、後者は見送り／早期撤退を基本にする。反復売買は別候補として独立に採否を決める。

反証: モード選択による改善を、常時追従・常時反復・同じ取引数だけ無作為に休む対照と比較する。モード判定の往復で損失が増えるなら、判定を複雑化するより見送り条件へ縮小する。

### 5. 既知の連敗を直しても将来の安定性は証明できない

Bailey, Borwein, López de Prado, Zhu, *The Probability of Backtest Overfitting*。
[著者公開論文](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

候補を繰り返し比較して選ぶと、偶然の高成績を拾う。時系列の一部を除いても、その期間の特徴を知って設計した場合は情報を使っている。試行数と選択手順も検証対象に含める必要がある。

今回の提案: 試した全候補・選択指標・各場損益を保存する。過去19場で選び追加4場で確認する形式は「既知追加場での再検証」と表示する。前進選択、閾値の隣接値、最大勝ち場除外、符号反転・無作為入口との比較を併記する。

反証: 良い閾値が一点だけ、追加4場だけ改善して過去全般を悪化、数場の大勝ち依存、少しの遅延で消失するなら採用を見送る。

## 現データでできること・できないこと

ローカル確認箇所: `book/TOPIX/2026-10-06_Day.jsonl` の冒頭2行、`App/E01/internal/strategy/features.go` の `release` と `OnBook`、`work/wave_v50/update_20261007_added/独立入力監査.py`。

|対象|扱い|
|---|---|
|最良気配・10段の価格と数量|観測できる。売りは Sell1、買いは Buy1 を使う。APIの BidPrice/AskPrice 名だけで経済的な売買方向を決めない。|
|累積出来高の増分|観測できるが、負の差はセッション切替・値リセットとして除外する。増分全量が最終価格で成立したとはみなさない。|
|個別約定の買い主導・売り主導|正確には不明。最終約定価格と過去気配から作る符号は代理推定に限る。|
|同じ価格で板が減って戻る|観測順序上の純変化は計測できる。注文IDがないため、取消・約定・別注文・同じ注文の補充を識別できない。|
|板更新の実時刻|CurrentPriceTime は最後の約定時刻であり板の受信時刻ではない。同時刻の後続行を、その時刻の入口にまとめて使わない。|
|二市場の完全な同時性|受信時計がないので断定できない。既存の公開待機・as-of参照を保持する。|
|距離による重み付き厚さ|買い側と売り側それぞれを価格距離/tickで重み付けできる。段番号ではなく同じ価格を追跡する。|
|隠れ玉、業者識別、将来の買戻しエネルギー|直接識別できない。出来高は開閉玉の区別を示さず、後の買戻しを保証しない。|

## 直ちに機械検証できる設計仮説

以下は文献をヒントにした独自仮説であり、論文がこの閾値や利益を証明したものではない。

1. **入口の鮮度**: 遅い方向 d と、直近1・3・5分の変化を比較。両市場で速い向きが d と逆なら新規を待つ。片側だけ逆なら「不一致」として区別する。
2. **動きの効率**: ER = 絶対の始終変化 / 各足変化の絶対値合計。ERが低く方向反転が多い局面は追従を見送る。足はすべて判定前に確定したものだけ使用する。
3. **入口の行き過ぎ**: 過去の移動平均や直近レンジ端からの距離をATRで正規化。遠くまで進んだ直後の同方向エントリーは、小反発だけで再開せず休む。
4. **途中の進捗期限**: エントリーから10/20/30分で最大順行が0.25/0.5ATR未満なら返済。短期が逆向きなら早める。効果が単なる保有時間短縮なのかも比較する。
5. **失敗後の再武装**: 同方向損切り後、直近高値/安値を越す、または短期方向が一度中立化後に再成立するまで再エントリーしない。固定休止だけとの比較を置く。
6. **状態変化で出口を狭める**: 含み益が出たあとER低下・二市場不一致・価格が進まない状態でトレールを短縮。出口の更新は次の観測から有効にし、同一足高安を都合よく並べない。
7. **日内の損失予算**: 初期ATRで定義した R の累積損失到達で当場の新規を停止。これは損失の上限化であり予測力改善とは別に評価する。止めた後の回復機会損失も示す。
8. **板の追加価値**: 1〜6の価格のみ版に対し、公開済みOFI／距離加重厚さ／吸収代理を一つずつ追加する。追加して初めて改善した部分だけを板の効果として計上する。

## 共通の採否検査

- 全候補は同じ枚数上限・返済時刻・理想約定条件で比べる。
- 勝率だけでなく、利益額/損失額、平均勝ち/平均負け、連敗損失、最大下落、1枚当たり平均損益を出す。
- 最良場を除いても残るか、全日中/全夜間/直近追加場で符号が極端に変わらないかを見る。
- 二市場合計だけで採用せず、TOPIX・NK225を別々に判定する。利益単位の差をATR基準Rと1枚指標で補う。
- 未来の行を切り落としても同じ時点までのシグナル・注文が同一かを確認する。
- 再調整した今回の成績は研究内成績である。真正な将来検証は、条件を固定した後に新しく届くセッションから開始する。
