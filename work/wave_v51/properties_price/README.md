# 価格過程の性質を先に確かめる

**現在の動きが整っていることと、その先を取りやすいことは別だった。固定した性質だけで、安定した将来挙動までは確定していない。** 売買戦略は増やさず、利益によるパラメータ選択も行っていない。

最初に本書、主要数値は `要点.json`、全条件表は `状態別集計.csv` / `状態別集計.json`。個々の観測は `現在状態.csv` と `観測点と将来経路.csv`、場ごとの分布は `セッション別性質.csv`。再現コードは `analysis.py`、独立確認は `verify.py`。

## 機構から言えること

効率比ERは「過去30分の純変化÷その間の総移動距離」。高ければ過去が一方向、低ければ過去に往復が多かったという分類である。それ自体は未来の継続や、平均線へ戻ることの保証ではない。二市場が同方向でも、同じ要因で同時に動いている可能性があり、独立した二票とは扱わない。

方向が最終的に合っていても、その前に0.75ATR逆行すればE01型の損切りに掛かる。だから終値の方向だけでなく、最大順行MFE、最大逆行MAE、先にどちらへ到達したかを分けた。

## 観測結果

両市場の30分方向が一致し、両方ER≥0.30だった時点から、次30分を測った。方向はその時点の過去30分方向に固定。

|対象|観測点数|終値も同方向|終値変化の平均|平均MFE / MAE|
|---|---:|---:|---:|---:|
|TOPIX・全時間|114|49.1%|−0.052ATR|1.166 / 1.149ATR|
|NK225・全時間|112|50.9%|−0.101ATR|0.982 / 1.075ATR|
|TOPIX・デイ|48|66.7%|＋0.590ATR|1.383 / 0.793ATR|
|NK225・デイ|48|72.9%|＋0.326ATR|1.024 / 0.856ATR|
|TOPIX・ナイト|66|36.4%|−0.519ATR|1.009 / 1.408ATR|
|NK225・ナイト|64|34.4%|−0.421ATR|0.951 / 1.239ATR|

この集計では昼夜差がある。ただし、時間区間の重複をなくすと昼は各4点、夜は各5点しかなく、昼夜別ルールとして確定する材料には足りない。50%前後という継続率だけで有効性を否定してはいない。重複なしの全時間では終値平均がTOPIX＋0.045ATR・NK＋0.131ATRに変わるなど、評価が揺れている。

|全時間の高効率状態|＋1.5ATR先着|−0.75ATR先着|双方未到達|到達した例内の＋1.5先着|
|---|---:|---:|---:|---:|
|TOPIX|22.8%|50.9%|26.3%|31.0%|
|NK225|15.2%|55.4%|29.5%|21.5%|

未到達を含む比率を33.3%等の損益分岐と比較しない。有限時間の未到達例には終了時点の価格があり、全例を二つの価格で決済する取引とは違う。MFEとMAEも別々の事後最大値であり、同時に獲得できる利益・損失ではない。

低効率状態から平均線方向へ30分動く率は、先頭10場でTOPIX58.0%・NK58.4%、次9場では47.2%・47.8%、最後4場は52.8%・47.7%。「低効率だから平均回帰すればよい」という関係も、この区分だけでは期間を通じて安定していない。

## 状態は先も同じか

現在・30分後の両方を分類できた同一母集団を用いた。高効率状態の98点では30分後も同じ状態なのは7.1%。ただし、その母集団全体の行先が高効率である基準率も9.5%にすぎない。低効率への遷移65.3%も、無条件で低効率になる59.7%／59.6%との差は小さい。したがって、この結果だけを「高効率から低効率への転換を予測できる法則」とは呼ばない。

この表は**状態名の持続**で、価格が最初と同じ方向へ進んだ率ではない。遷移分類可能98点と、価格経路だけ評価可能114／112点も別の母集団。15分先の状態には現在の30分窓との重複がある。全5状態の遷移表と母集団との差は `状態遷移集計.json`。

## 未確証と測定範囲

5分刻みの候補5,356点から2,280点を採用した。開始後の足数不足272点、連続30分の足不足2,284点、現在価格が60秒より古い451点、公開足が古い69点を除外。9月21日デイはこの連続データ条件を満たす点がなく、主表は観測できた22場を含む。静かな時間ほど欠損になりやすい可能性があり、市場全体への一般化に制約がある。除外は `観測被覆.json` と `除外観測点.csv` に全件保存した。

5分点は重複した区間を測っており、独立標本数ではない。セッション開始から60分刻みの非重複起点でも再集計し、場単位の中央値・四分位・最小最大も記録した。高効率状態の30分評価は非重複では各銘柄9点。この不足を、重複した114点に見せかけて強い結論へ変換していない。

ER0.20/0.30・方向0.5ATRは以前のR04等の閾値をそのまま流用し、今回の結果に合わせて変更していない。1分足は開始から120秒後に公開したものだけを用い、ATRは既存の確定5分足公開キャッシュを継承。未来の足・価格・ATRを変えても現在の分類が変わらないことを確認した。未来を使う箇所は評価ラベルと状態遷移の行先だけである。

再実行は `python work/wave_v51/properties_price/analysis.py`、`python work/wave_v51/properties_price/verify.py`、`python work/wave_v51/properties_price/report.py`。APIやアプリには触れない。
