# 失敗価格帯での同方向再試行を制限する24条件

最初に [選択.json](選択.json)、次に [詳細結果.json](詳細結果.json)、全候補は [全候補結果.json](全候補結果.json) を見る。

実際に採用した売買が全返済で赤字になったら、同方向の次回注文を一時制限する。期限内は、前回の新規価格から0／0.25／0.5ATR以上進んだ価格で計画される場合だけ認める。期限は30／90分。買いと売りは別管理し、実際に採用しなかった仮想売買の損益は判断に使わない。

K00・K04・K20・K24の4つの仮想時計は維持する。実口座で見送っても影口座は返済まで進めるため、通常の「損切り後に何分か待ち、どの瞬間からでも再開する」方法とは異なる。成功を先に知って解除することはない。過去の制限水準は期限満了又は次の採用損失組で更新する。

前10場だけで選んだ第一候補は **A04_D000_T30**。しかし結果は次のとおりで、採用できる安定性は確認できなかった。

|期間|TOPIX mini換算|NK225 micro換算|
|---|---:|---:|
|選択に用いた10場|+420,000円|+115,900円|
|次の9場|−208,500円|−74,200円|
|既知追加4場|−196,000円|−21,800円|
|全23場|+15,500円|+19,900円|
|最大勝ち1場を除いた全期間|−80,000円|−15,600円|

24条件のどれも、既知追加4場で両銘柄同時黒字を達成していない。再試行制限は悪い入り直しを減らす一方、損失後の回復を取る取引も落とした。とくに第一候補は、前10場での改善が次9場に続かなかった。

TOPIXは初回5枚・片方向上限10枚、NK225は初回10枚・上限20枚。大きい商品の保存価格をmini/microの倍率へ換算し、費用ゼロ、元台帳の約定条件を継承する。

`research.py` の `Rearm.on_plan` と `Rearm.on_cycle_close` は、それぞれ現在の計画と現在完了した組だけを受け取る。原本行順に損益を公開する実装と、組ごとの別実装を比較した。576条件口座、1,152途中切断・未来損益改変に合格した。会計・時価最大下落・場末返済も確認している。

この研究は連敗結果を閲覧した後の既知データ研究であり、真正未見の検証ではない。前10場だけの選択と、その後の期間比較を分けて保存している。
