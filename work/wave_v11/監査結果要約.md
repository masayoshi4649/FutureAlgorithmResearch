# 独立監査の結果

最終実装と保存された全売買の照合は一致した。原本データへの書込みと、この監査からの現在 API 取得は行っていない。最終 `orders.py` の SHA256 は `0b3cbd247d1d62a928d3dce525e2aa03ec21d025460f5573b0f1bb106e6e9bb3`。監査対象の実装・入力ファイルのハッシュは `全数損益と学習選択の独立監査.json` に保存した。

| 検査 | 結果 |
| --- | --- |
| 単建玉の新規・時間返済・目標返済・最大順行 | 14手計算、68打切り再生が一致 |
| 複数建玉・両建て・指値条件・数量共有 | 38手計算、600打切り再生が一致 |
| 含み損込み資産曲線の手計算 | 確定２件と未返済１件の全行評価・費用倍・最大下落が一致 |
| 全条件の独立再集計 | 1,598条件、19,176セル、109,117脚、349,344集計属性が一致 |
| 学習期間だけでの順位と採用 | 共通条件・銘柄別を含め56選択が一致 |
| 未来と対象外銘柄の成績の改変 | 36選択で全順位・採用が不変 |
| 原本からの打切り再構築（信号担当による別監査） | 12打切り、24信号系統、333確定取引、14,088属性が一致 |

全数再集計では注文器の集計関数を呼ばず、新規・返済の差分配列から全生気配時点の保有数量と清算評価を作り直した。実約定価格、全脚費用、未返済損益、最大順行、同一気配の新規と返済が共有する数量、通常費用・費用倍の最大下落、事前枚数上限での除算を確認した。CSVの往復で最下位桁だけ変わる実質同点の下位候補は、得点の個別一致を確認したうえで順位交換を許容した。採用条件は一致している。

両建ての監査では、利益脚だけを返済して確定収支がプラスでも、残る損失脚を含めるとマイナスになるケースを明示的に検査した。指値条件については、条件価格を通過した後に相場が反転すれば、後続行の不利な気配価格で約定する。価格保証を仮定していない。

漏洩監査が示すのは、記録した情報の解放時刻と注文順序に従って過去を再生できること。このデータにない受信時刻・実取引の約定順位・市場インパクトまで検証したものではない。

統計診断は `独立統計診断.md` を参照。共通３思想と、結果を見た後に追加した銘柄別３思想を一群として補正した比率は、６政策すべて1.0。５既知セッションの共同符号反転による最大値探索比率は、共通1,598条件で1.0、銘柄別3,196組で0.84375となった。独立性・対称性を仮定する少数標本の補助診断であり、既知の相場を繰り返し見た設計の影響を消すものではない。有望な収支と、統計的に確認された収益性を区別する必要がある。

現在セッションの一回照合は、この保存データ監査とは別に、条件を凍結した後の追加区間として評価した。18凍結ファイル、各１回の６要求、27条件×２銘柄の54セル、289脚、2,242集計属性が独立会計と一致した。00:02直前と01:53末尾の全脚清算価値差を再計算し、新旧起源の増分合計、全行最大下落、価格・費用・最大順行、同一気配の共有数量も確認した。記録は `現在照合_会計独立監査.json` にある。

追加取得には最終約定時刻が古いまま追記された行があり、00:02という時計境界と旧保存行境界で３セルに差が生じた。主評価は凍結した時計境界を維持し、+１万円・+１万円・−0.5万円の差を `現在照合_旧保存行境界の補足.csv` に分離している。NK225の組合せ主候補の追加−９万円は変わらない。これは受信時計がない制約の具体例である。
