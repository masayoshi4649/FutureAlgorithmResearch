# 固定利確・固定損切りのコイントス対照

新規約定後、同じ返済方向の利確指値と損切り逆指値を監視するIFD-OCO相当。利確は指値価格、損切り飛び越しは不利な始値。両方接触は損切り。指値新規の足で利確が新規後か不明なら、その足の利確を認めない。

３組を先に固定し、各100種の公平な方向を使った。採用条件と同じ新規方法・待機時間で、方向は30分ごとに決めた。勝率は往復２ティック控除後の利益件数から計算する。
