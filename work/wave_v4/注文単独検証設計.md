# 注文手法だけで利益が出る仮説の検証

方向に予測力がなくても、値幅・持続時間・約定条件によって損益の分布は変わる。トレーリングは小さい損失と大きい利益を組み合わせられるが、それだけで期待利益が正になるとは限らない。価格が条件付きで公平なコイントスに相当し、自己資金・取引回数・保有時間が有限なら、売買方向と決済時刻を変えるだけで控除前の期待利益を保証できず、売買コストは期待利益を減らす。今回の検証では実データに持続性や非対称性があるか、注文がそれを利用できるかを調べる。

## 比較する注文の考え方

| 系統 | 新規条件 | 返済条件 | 調べる効果 |
|---|---|---|---|
| 固定時刻の無作為方向 | 事前に固定した乱数で売買方向を決める | トレーリング | 方向の予測を使わない基準 |
| 固定時刻の交互方向 | 買いと売りを交互にする | トレーリング | 乱数の偏りを減らす基準 |
| 上下の一定幅離脱 | 基準価格の上下で逆指値を監視 | トレーリング | 離脱後の継続性 |
| 上下の変動幅比例離脱 | 上下の距離を過去の ATR で決める | トレーリング | 変動率への適応 |
| 直近価格帯の離脱 | 過去の高値・安値を超えた側へ入る | トレーリング | 価格帯からの継続性 |
| 両方向の反発・反落 | 追跡安値から反発した買い／追跡高値から反落した売り | トレーリング | 折り返しの持続性 |
| 無作為方向の押し戻し指値 | 乱数で方向を決め、一定幅押した価格を待つ | トレーリング | 有利な新規価格と未約定の影響 |
| 無作為方向の継続逆指値 | 乱数で方向を決め、同方向の進行を待つ | トレーリング | 新規約定条件による選別 |
| 無作為方向の追跡新規 | 乱数で方向を決め、反発・反落を待つ | トレーリング | 追跡新規条件による選別 |
| 固定損失・利益幅 | 方向基準を変えて新規 | 損失逆指値と利益指値、または時間返済 | トレーリングによる分布変化との対照 |

上記は仮説の分類であり、実行済みの条件数は別の比較結果に記録する。利益の出た条件だけをこの一覧へ載せることはしない。

AGENTS.md の `oco` は「同じ売買方向の２条件」である。上下の買い／売り逆指値を片方約定時に取り消す仕組みは、API の `oco` 一つとは異なる。独立した新規注文と取消・照合を組み合わせる合成方式として区別する。１分足で両方の条件に接触する場合、先後を想像して有利な方を選ばない。約定順序の不明な足は別集計し、不利なケースを使う。板に取消・照合の完了時刻がないため、運用時の重複約定を再現できない制約を残す。

## 無作為方向との対照

- 乱数種は結果を見る前に `260923000` から `260923099` の 100 個へ固定する。
- 各種で比較対象と同じ新規方法・待機時間・トレーリング幅・取引停止時刻・コストを使う。
- 利益となった種の割合、損益の中央値と 5・95 百分位、平均、種間の標準偏差を報告する。
- 無作為方向で取引頻度が変わり得るため、取引数、損益／取引、無取引セッション数も併記する。
- 100 個は独立した市場期間ではない。同じ保存データを使う乱数のばらつきであり、100 日分の標本数や市場での信頼区間とは呼ばない。

## コイントス価格経路との対照

- １分足を直前の終値からのギャップと足内部の値動きに分解し、足単位で全体を確率 1/2 で反転する。
- 反転時は高値と安値も入れ替えて反映し、常に `安値 ≤ 始値・終値 ≤ 高値` を守る。出来高と観測時刻は保持する。
- 各銘柄の同じ時刻には同じ符号を使い、両指数の同時点での符号関係を可能な範囲で残す。元の連続した方向の持続性は壊す。
- これは１分終値の方向の連続性を壊す代理実験である。足内の形やギャップと足内変動の関係は残るため、全ての時点で完全なマルチンゲールになる価格過程とは主張しない。
- ５分足は変換後の１分足だけから再構築する。元の５分足や元の板の方向を混ぜない。
- 板数量・注文フローはこの変換だけでは整合する価格経路を構築できないため、価格条件と注文単独の条件に対象を限る。
- 乱数種は `260924000` から `260924099` の 100 個へ固定する。実行した条件と除外した条件を残す。
- 元の損益以上の経路数を数え、比較順位を `(1 + 元の損益以上の経路数) / 101` とする。これは固定した１条件についての参考順位である。

## 条件探索による過大評価への対応

過去データで一番良かった条件は、無作為な市場でも良く見える可能性がある。採用条件を後から固定して 100 経路と比較しただけでは、探索した全条件の中で勝者を選んだ偏りは取り除けない。正式に探索全体を検定するには、各無作為経路で同じ全条件探索と選定を再実行し、勝者同士を比較する必要がある。計算量や板整合性の制約で省略する場合は、検定済み・統計的優位があるとは結論しない。

保存セッションが少なく、同日の両銘柄にも依存がある。取引を独立標本と仮定した通常の信頼区間や、銘柄間のポイントを足した損益は採用しない。銘柄別の価格単位と ATR 単位を併記し、日付／セッション別の損失と検知回数を残す。

## 波を検知したと認める条件

指定区間の方向と保有方向が一致するだけでは、数時間前から持ち続けた建玉まで新しい波を検知したように見えてしまう。開発データの初回比較でこの問題を確認したため、現在データを見る前に合格条件を厳しくした。

従来の「開始から60分以内に20分以上の同方向保有があり、指定時間の60%以上を同方向で保有し、指定区間の値幅の40%以上を往復２ティック控除後で捕捉」を `coverage_pass` として保存する。最終の `passed` には、さらに波の開始30分前から開始60分後までに新規し、指定区間で20分以上その方向を保有する取引が必要である。以前からの建玉の区間損益は消さずに記録するが、それだけで新しい波を検知したとは判定しない。

`detection_delay_min` は従来の区間内保有開始の遅れ、`fresh_detection_delay_min` は上記を満たす実際の新規時刻のずれである。後者の負値は波の開始に先行した新規を示す。この先行許容30分は「頃」という指定ラベルの曖昧さを扱う評価上の設定であり、検知器には与えない。

## 実装・データ上の公平性

- 確定済みの情報のみを使い、条件成立後の実在する足から約定を判定する。
- 指値の接触は約定を保証しない。接触だけの楽観結果と、１ティック以上通過を必要とする保守的な結果を区別する。
- 逆指値の飛び越しは注文価格でなく、不利な実在始値で約定する。
- 新規と損切りが同じ足で接触する場合も、不利な約定順を使う。
- トレーリングの追跡値更新と同じ足の逆行を、都合のよい順番に並べ替えない。
- 返済期限と新規停止時刻を固定し、セッションを跨いだ含み損の繰越しは行わない。
- 勝率だけで採用しない。検知回数、指定された長い波の捕捉、損益、コスト増加時の損益を同時に評価する。
