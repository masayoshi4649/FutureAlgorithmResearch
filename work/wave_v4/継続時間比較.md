# 評価期間と方向判定の正答率

同じ因果信号を10・20・40・60・120分後に評価した。長く観察するほど正答率が一律に上がるとは限らない。保存４セッションだけを使用し、現在セッションと採用条件の再選定には使っていない。

24系統それぞれ感度1.0で、非ゼロ方向の最初の判定を採り、その参照新規時刻から30分以上空けて次の最初の非ゼロ判定を採った。同方向継続中の再観測も含む。分mの情報は確定後に使い、m+2以降の最初の実在１分足の始値を参照新規価格とした。

10・20・40・60・120分後それぞれの最初の実在１分足始値を返済参照価格とし、全５期間がセッション内返済期限までに揃うイベントだけを全期間で共通に使った。方向付き値幅が往復２ティックを超えたものを正答とした。これは指値注文の実約定やトレーリング返済の成績とは別の、信号方向の診断である。

## 解釈の範囲

長い波を後から選んで検知率を測ると、将来の持続時間を使って正解を選ぶ偏りが入る。この診断は将来の波の長さでイベントを選んでおらず、同じ信号の評価期間を変えている。したがって『本当に長く続く波なら事前に見分けやすい』ことを直接証明するものではない。短期の急変と長期の緩やかな変化を速度別に分離した比較でもない。

120分後まで評価できる集合に揃えたため、引け前のイベントは全期間から除いている。価格観測のない分は次の実在足まで待つため、名目の評価期間より長い場合がある。最大の追加待機は参照新規で 8.0 分、返済参照で 15.0 分だった。

４セッションの方向や値動きに強く依存し、同一系統の120分評価も30分おきに重なる。24系統・両銘柄を独立した検証期間と数えたり、この勝率を将来の保証に使ったりはしない。正答率が高い評価期間を新たに採用し直しておらず、採用の返済方法も変更していない。
