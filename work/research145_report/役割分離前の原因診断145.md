# 残玉・部分利確後の改善と悪化

対象は日経 mini、片方向最大 10 枚（基本 5・追加 3・別入口 2）、手数料 0 円、判定の次の正常な原板行の売買気配で約定する既知 50 場。以下は保存済み結果の分析であり、追加の売買再生ではない。

| 条件 | 累計収支 | 黒字／赤字場 | 基準との差 |
|---|---:|---:|---:|
| R00：TG04 基準 | 3,800,000 円 | 32／18 | ― |
| P01：基本の部分利確後、残玉の最高含み益から 50% 戻りで全返済 | 3,816,000 円 | 35／15 | +16,000 円 |
| P03：同じ段階から固定初期 R の逆行で全返済 | 3,780,000 円 | 35／15 | −20,000 円 |
| P02：同じ段階から 30% 戻りで全返済 | 3,348,000 円 | 35／15 | −452,000 円 |
| P04：部分利確価格の逆行と 120 秒逆行が 15 秒継続 | 3,348,000 円 | 34／16 | −452,000 円 |

P01 は基準の 3 赤字場を黒字へ変えたが、累計の改善は小さい。基本の一部利確後の残り 3 枚を守ることには効果がある一方、途中の反発で降りたあと再び順行した場面を取り直せていない。P 条件の早期全返済後は同じ親への追加を止め、次の新しい親は許す。したがって「同じ波へ積極的に取り直す方法」まで検証したと説明してはいけない。

## 実際に防げた損失

**2026-10-13 デイ**：09:50:15 に 67,690 で売り 5 枚。10:28:31 に 67,480 で 2 枚を買い戻した。基準は残り 3 枚を 13:24:06 の 67,790 まで持ち、残玉で 30,000 円失った。P01 は 11:10:30 の 67,470 で残り 3 枚を返済し、残玉 66,000 円を得た。この親では 96,000 円改善。ただし午後の別の買い親を早く降りて 30,000 円減ったため、セッション全体は −82,000 円から −16,000 円への改善だった。

**2026-10-20 デイ**：10:07:12 に 64,310 で売り 5 枚。10:18:03 に 64,090 で 2 枚を返済。基準は残り 3 枚を 10:28:35 の 64,440 まで持ち、39,000 円失った。P01 は 10:18:57 の 64,180 で残りを返済し、39,000 円の利益。セッションは −49,000 円から +29,000 円へ変わった。

## 同じ操作で逃した利益

**2026-09-28 デイ**：10:09:19 に 66,310 で売り 5 枚。11:58:50 に 66,020 で 2 枚返済。P01 は 13:10:42 の 66,150 への反発で残り 3 枚を返済。その後の下落に同じ親で再参加せず、基準の 15:35:00・65,630 返済と比べて 156,000 円減った。場の収支は +180,000 円から +24,000 円。利確基準だけ厳しくすると、このような「戻してから続く下落」で不利になる。

**2026-10-22 デイ**：P02 は 11:38:55・64,140 の反発で残り 3 枚を返済した。基準は 13:59:29・63,510 で 2 枚、15:35:00・63,140 で 1 枚を返済した。P02 は 226,000 円減った。戻し許容量を 50% から 30% へ狭めるほど良いわけではない。

## 残り 1 枚を消すことと、新候補を解放することは別の効果

R01～R11 は基本と別入口の両方を変更した。全体収支はいずれも基準より悪化したが、**基本 CG の収支差は全 11 条件でプラス、別入口 CS の差は全 11 条件でマイナス**だった。

| 条件 | 基本 CG の差 | 別入口 CS の差 | 合計差 |
|---|---:|---:|---:|
| R05：残玉の追尾幅を最大 16 刻み | +272,000 円 | −431,000 円 | −159,000 円 |
| R06：反対の新候補で残玉返済、待機 0 秒 | +214,000 円 | −405,000 円 | −191,000 円 |
| R11：反対候補＋60 秒再評価＋利益床・追尾上限 | +258,000 円 | −436,000 円 | −178,000 円 |

**2026-09-29 デイの R06**：15:21:02 に残りの売り 1 枚を 65,430 で返済し、その次の正常原板行で新しい買い 5 枚へ移った。新親で 107,000 円を得て、旧親の損失回避も含めセッション差 +121,000 円。15 分待つ R09 ではその親が終了し、条件不成立のまま新規は出ず、改善は +14,000 円だけだった。固定待機は有効な転換を逃す場合がある。

**2026-10-15 デイの R06**：別入口は 09:07:30 に 66,110 で売り、部分返済後に 1 枚を保持した。R06 は 09:21:40・65,720 でその残玉を閉じた。基準の 15:35:00・64,600 返済と比べ、ここだけで 112,000 円減少。さらに新しい買い候補を解放し、09:28:23・65,650 の買い 2 枚を 09:32:19・65,520 で返済して 26,000 円損失。その後も買い候補へ入り、場の差は −162,000 円となった。最初の再参加判断時点では 30 秒方向は +0.179 R、120 秒方向は 0 R で、指定した短期確認を満たしていた。短期の上向き確認だけでは、大下落中の小反発と大きな反転を区別しきれない。

日中 CS の入口は「固定帯を外れた後、帯内へ回復する動き」を狙うため、残玉を長く残している間は、次々出る小反発の買い候補を抑える効果もある。利確を早める変更は、単に一枚の利確価格を変えるだけでなく、**後続の逆張り候補を解放する**。この作用を分けずに基本と別入口を同じ変更で扱うと、役割の違いを壊す。

基本 CG だけ変更し CS04 を維持する構成は、この 16 条件には含まれない。上記の役割別差は機構診断であり、別構成の正式評価には事前の条件固定・登録と再統合が必要。

## 証跡と実装上の区別

- 原板の該当行は `改善悪化の原板時刻診断145.json` に保存。原板行番号・バイト位置・行 SHA と実際の JSON を持つ。表示時刻は価格時計で、独立した受信時刻ではない。同秒の判断と約定も原板の行順は分離した。
- 全 800 会計で次正常気配、片方向 10 枚以内、手数料 0 円、場内返済を検査済み。R00 は全 50 場で旧 H04 の基本・別入口の注文配列と完全一致。
- R04／R11 は残玉化時の含み益が正ならその 50% を床とし、非正なら建値 0 pt を床として次正常気配で早期返済する対照。P 群は、部分利確が実約定した後の最高含み益が正の時だけ利益床を有効にする。両者は基準が違う。
- 最後の集約時に受領書の相対パス変換で停止したが、全場の売買・会計・保存は完了済みだった。`finalize_saved145.py` が保存 SHA と約定検査を再確認し集約だけ復元した。金融再生・会計再計算はしていない。
