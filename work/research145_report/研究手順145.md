# 00145 値動きの大きい場面の利益保護と再参加

1. 全保存50場と、10月26日午前の部分資料を指紋照合。完了。
2. 保存TG04の全親取引を原板へ照合し、利益返しの原因と継続成功の反例を確認。新しい取引を作らない診断。
3. 追加担当の短期利益保護・部分回転・再エントリー・ドテンと、基本/別入口の残玉・部分利確後保護を分けて事前固定する。
4. 公式試行照合ツールで照合・登録後、手数料0の基準と全候補を再生する。費用が内部の判断に入る部分も再計算する。
5. 会計・次正常気配・片側10枚・未来入力非参照を独立検査。失敗した条件を全場の具体的な時刻から問い直す。
6. 各担当の組合せも検証する。全場既知の開発比較と、前半30場で選び後半20場へ固定した比較を区別する。
7. 最低10項目の自問・反証を、実測結果と採否付きで記録する。手法別全場の利益・損失・収支・累計をxlsxへ保存する。

対象は日経mini・片方向10枚。保有率に合否線を置かない。最高値/最安値での約定や、その場の最終方向による入口選択は使わない。

組合せ選択は、前半30場の赤字場が少ない順、同数ならセッション収支中央値、合計収支、最大赤字額の順で比較する。追加担当と残玉担当をそれぞれ基準と組み合わせた結果から独立に選ぶ。昼夜別選択も同じ優先順位を用いる。全体の赤字頻度・利益損失比・回転回数・極端利益除外を併記し、この順位だけで万能としない。

先行研究の参照は設計上の論点の確認に限る。Glynn/Iglehartは確率過程の仮定の下で追尾幅と利益・保有時間を分析しており、実際の日経で一定幅が有利な証明ではない。[Trading Securities Using Trailing Stops](https://pubsonline.informs.org/doi/abs/10.1287/mnsc.41.6.1096)。価格過程や取引費用を条件として退出規則を扱う考え方も参照した。[Andrew W. Loの関連研究一覧](https://alo.mit.edu/topic/risk-management-and-systemic-risk/)。
