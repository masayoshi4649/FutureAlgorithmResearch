# 時間帯の理由と当時使える予定

**最初に使えるのは、祝日と市場の開閉時刻。ニュースは「予定されていた時刻」と「起きた後の説明」を分ける。時刻だけで買い・売りは決めない。**

金融再生は0回。対象は既知の43場（22日中・21夜間）。ニュース取得ツールから、22営業日すべての当日朝の予定記事と週末見通し4本、計26本を取得した。時刻付き予定236件のうち217件が保存場内に該当する。記事がない項目を「発表なし」とは扱わない。

## 最初に固定できる区分

| 区分 | この標本の日本時間 | 何が変わるかという仮説 |
| --- | --- | --- |
| 日本現物休場 | 9/21・9/22・9/23・10/12 | 先物は動くが国内現物の注文・裁定経路が通常日と異なる |
| 日本現物の寄り前／前場 | 08:45～09:00／09:00～11:30 | 寄り前に蓄積された現物注文と先物の価格発見が合流する |
| 日本の昼休み／後場 | 11:30～12:30／12:30～15:25 | 国内現物の連続売買が休止・再開する。先物は止まらない |
| 日本の引け受付／引け後 | 15:25～15:30／15:30以降 | 終値の板寄せへ注文が集まり、その後は国内現物の連続価格更新がない |
| 欧米主要現物の重複 | 22:30～翌00:30 | 欧州と米国の通常取引の注文が同時に流れる |
| 欧州主要現物終了後 | 翌00:30～04:50 | 欧州の主要現物の連続取引が終わり、米国中心へ移る |
| 米国引け前／引け後 | 翌04:50～05:00／05:00以降 | 米国の引け需給が表れ、その後は主要現物の連続取引が終了する |

これは参加者・制度の違いから導いた**観測区分**であり、「この時間は逆張りが儲かる」等の成績の結論ではない。ニュースを理由に全日停止すると各場参加を満たせないので、時計は追従・回帰・規模の切替の説明変数として扱い、当時の方向と価格応答を別途観測する。

日中22場中、通常の日本現物開場日は18場、休場日は4場。[9月の事前通知](https://www.jpx.co.jp/news/2040/20260918-01.html)と[10月の事前通知](https://www.jpx.co.jp/news/2040/20261009-01.html)で先物の祝日取引を確認した。TOPIXの旧無取引9/21・10/12は、診断担当が相手30秒資料のNaNによる入口拒否を確認している。祝日という分類だけで無取引の原因を説明してはならない。

日本現物の[立会時間](https://www.jpx.co.jp/equities/trading/domestic/01.html)と[引け制度](https://www.jpx.co.jp/equities/trading/domestic/04.html)を参照。15:25～15:30は注文受付であって現物の連続約定期間ではない。保存先物は15:39頃まで、既存返済限界は15:35。公式の市場時刻と保存データの終端は区別する。

米国主要現物は[NYSE公式](https://www.nyse.com/trade/hours-calendars)の09:30～16:00米東部時間、引け需給期間は15:50から。欧州は[Xetra主要市場](https://www.cashmarket.deutsche-boerse.com/cash-en/trading/trading-calendar-and-trading-hours)と[LSE主要市場](https://www.lseg.com/en/media-centre/press-releases/2026/london-stock-exchange-to-launch-lse-24)を代表時計とした。欧州の開始16:00は保存ナイト開始17:00より前。00:30は主要連続取引の終了境界であり、終値オークション・時間外を含む欧州全市場の停止ではない。

## 事後ニュースから言えることと、言えないこと

[事後記事2本](事後記事_方向入力不可.json)は診断参考として分離した。10/14のCPI市場反応記事704763は21:57:35公表、22:06:02に取得元が収集。10/2の雇用統計反応557792は22:05:28公表、22:06:37収集。したがって、どちらも21:30の発表直後の方向入力に使えない。報じられた説明はインフレ／雇用→金利期待→ドルや株の再評価という仮説を立てる資料にはなるが、日経・TOPIX先物の全値動きの因果を証明しない。

具体的には、前作の10/14ナイト日経01:36:57売りの損失は、CPI予定21:30から**4時間6分57秒後**。発表直後のノイズとして一括除外する根拠はない。欧州主要現物終了00:30の1時間6分57秒後という時計上の区分はできるが、それだけで負けの原因とはならない。実際の突破・逆流・再参加価格の診断を引き続き必要とする。

## 先読みを防ぐ実装条件

1. 日本の現物休日と先物取引日を別に持つ。対象の日付ごとの買い・売り方向や損益を予定表へ埋め込まない。
2. `America/New_York`・`Europe/Berlin`・`Europe/London`を別々に変換する。この標本は全て夏時間だが、2026年10/26週は欧州だけ冬時間、11/2週から米国も冬時間となる。[米国制度](https://www.nist.gov/pml/time-and-frequency-division/popular-links/daylight-saving-time-dst)・[英国制度](https://www.gov.uk/when-do-the-clocks-change)を確認し、3日分の人工時計を通した。
3. 当日予定の利用開始は少なくとも公表時刻・取得元収集時刻の遅い方以後。現在の版IDが当時取得版と同一だったか、原板とニュースを同時に実受信できたかは未検証。現段階でニュース売買の実時間再現を実証したとは言わない。
4. 予定発表後の実績値や見出しを、その日の発表前へ埋め戻さない。予定資料のない場を「イベントなし」と断定しない。
5. 時間の境界前後の損益で幅を総当たりしない。制度上の境界を先に固定し、同じ境界で勝ちを削る反例・資料欠測率・全場参加率も比較する。全43場は既知開発資料であり、この区分を作って再比較しても未知検証にはならない。

## 次に見る観測量は2つ

**現物開閉前後の「二市場の価格応答と資料鮮度」**。共通方向に進む量だけでなく、自己・相手のLast更新間隔、BBO更新回数、気配差、出来高増分を同じ時計区分で比較する。反応が消えたのか、単に片市場の記録が止まったのかを分ける。祝日を一律排除せず、観測可能な板に適応する根拠を作る。

**予定後の「新しい価格帯を維持したか」**。発表時刻を知っていることと方向を知っていることは別。予定前の既知価格帯を固定し、予定後の両市場がどちら側へ抜け、反対圧力が来てもその側を維持するかを順番に測る。発表内容を後付けせず、値動きで再価格形成の成立／失敗を判定する。伸び切った後の高値買い・安値売りを避けられるか、伸び続ける勝ちを失わないかが対照となる。
