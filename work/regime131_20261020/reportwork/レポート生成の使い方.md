# レポート生成

実金融再生は行わず、完了した各巡の `全条件の会計.json` と `区分別の比較.json` を読みます。旧00130の会計も引用します。公開HTMLの最終生成は結果確定後に実行してください。

```powershell
python work/regime131_20261020/report131.py --rounds round1_final --conclusion 結論.json
```

第二巡以降を追加する場合は `--rounds round1_final round2` のように並べます。同じIDが複数巡にあっても、内部では `round1_final::R01` のように区別します。未収録は0円へ補完しません。

外部結論JSONの例：

```json
{
  "headline": "結論は未確定です。",
  "finding": "短い結論をここへ。",
  "defaults": {
    "Day": {"TOPIX": "旧::DV07", "NK225": "旧::DV05"},
    "Night": {"TOPIX": "round1_final::R01", "NK225": "round1_final::R01"}
  },
  "links": [
    {"label": "市場時計とニュース", "href": "../../work/regime131_20261020/news/ニュース予定根拠の確定.json"}
  ]
}
```

`title`、`finding`、`defaults`、`links` は省略できます。裸の `R01` も一意なら受け付けますが、複数巡に存在するIDは巡名付きで指定してください。`links`を省略するとニュース・日中診断・原板照合追補・夜間診断のリンクを表示します。

出力は公開00131の「時間帯と値動き状態を切り替える手法の全セッション損益.html」。表示用数値と参照SHAは本領域へ時刻付きで保存します。`--output`で別位置を指定する場合も、公開00131又は本 `reportwork` 配下に限ります。旧会計・金融核・登録文書は更新しません。
