# 時間区分で使う候補の土台

**日中は「両市場で確認した方向を追い、継続的な逆行で撤退」、夜間は「米国開始後の価格帯突破を確認する」手法が土台。** いずれも買いと売りは上下対称。同じ日にどちらが儲かったかを見て切り替える仕組みではない。

今回の旧核は、過去に保存・監査した**実行注文をその時刻順に再利用**する。旧手法を新しく一から再現実装したものではない。新しく動かすのは、予定時刻まで未参加の場合の一回追加担当。旧注文の将来の有無を、この担当の判断には使わない。[接続実装](../baseline131.py)／[合算実装](../run_portfolio131.py)

## 日中：DV07（TOPIX）／DV05（日経）

**狙い：二市場に共通する方向へ追従し、一時的な押し戻りと、続いてしまう逆行を区別する。** 2手法の差は、追加撤退を判断する継続時間だけ。

| 段階 | 機械的に行うこと |
|---|---|
| 入口 | 元 E01 の方向と短期確認を使う。両市場の確定1分足 EMA15−EMA60 が売買方向へ0.15ATR超、EMA60の3本前からの変化が同方向へ0.02ATR超という開始条件も再確認する。買いは追跡安値から0.25初期ATR反発、売りは高値から同幅反落を待つ。準備期限は5分。 |
| 入口の追加確認 | 発注時の両市場30秒現在値変化が、それぞれ売買方向に対して−0.05ATR以上。強い追い風までは要求しないが、明確な反対と必要資料不明は見送る。気配差と現在値から約定側気配への不利な差は各0.5初期ATR以下。 |
| 途中 | 元 E01 の「順行後、新しい短期反対が出たら一度半減」を残す。通常の仮想保有が1.5初期ATR進んだ後、板中値の2分・30秒の反対変化を確認する。減らした枚数は戻さない。 |
| 出口 | 元 E01 の0.75ATR初期停止、2ATR部分利確、1.5ATRから幅3ATRの追尾、3ATR進行後の幅0.75ATRへの短縮、360分期限を残す。加えて、実現済みと残玉評価を合算した組の損失枠を、ATR縮小時だけ初期1リスクから最小0.75リスクへ狭める。一度狭めた枠は広げない。 |
| 追加撤退 | 実際の新規約定時に記録した自己・相手の価格から、**両方が各初期ATRの0.25倍以上逆行**し続けたら全返済。TOPIXのDV07は120秒、日経のDV05は60秒。反対条件の解消・必要資料不明・15秒超の原行間隔で継続時計をリセットする。通常の損切りはこの時間を待たない。 |

実玉を早く返しても、元 E01 の通常の仮想保有が終わり、その後5分待つまで次の準備を始めない。**同じ仮想保有中の再参加はしない。** この待機は連続損失を減らす一方、反転後の回復を逃す原因にもなる。

「板」は主に価格の変化を使う。厚い買い板や補充量を直接判定する方式ではない。継続時間も保存価格時計上のもので、受信が60秒・120秒連続したことを保証する値ではない。

## 夜間共通：米国開始後の価格帯突破

夜間の価格単位は **`1R = max(準備時の公開ATR, ラージ4呼値)`**。準備後に固定する。日中の「枚数込みの組リスク」とは単位が異なる。

米国開始前後15分は静観し、新しい準備は開始22分後から。過去20分を隔てた21個の確定1分終値で帯を作り、一方向への進み方の効率が0.35以上なら突破を検討する。効率は「20分の始終点の差の絶対値 ÷ 途中の終値変化の絶対値合計」。その時点の帯の境界を固定し、後から動く帯へすり替えない。

**共通出口：** 1R逆行で停止。返済できる気配で1R順行したら、最高順行から0.75R戻りを追尾する。固定突破線の内側へ0.25R超戻り、相手の20分方向も反対なら途中撤退する。全返済から5分後に、新しい突破を一から検討する。部分利確はしない。

### NV01：突破後の継続確認（TOPIXの基本核）

**入口：** 帯を突破し、相手の5分・20分方向も同じなら準備する。60秒以上経過し、固定線から0.25R以上進み、両市場の30秒方向が同じ、120秒変化が各0.05ATR超、相手の5分・20分方向もまだ同じなら入る。準備中に突破線の内側へ0.25R超戻れば取消し。30分を超えた準備も更新する。

**理屈：** 自分だけの一瞬の突破より、他市場も追随した突破を選ぶ。観測価格は現在値。出口は上記の共通出口。

出典：[NV01固定条件](../../visual_pdca129_20261020/第一巡条件.json)／[実際に使用した核](../../daynight128_20261020/night5.py)／[観測価格・厳密な過去接続](../../visual_pdca129_20261020/features129.py)

### NV25：突破→押し戻り→再進行（日経の基本核）

**入口：** NV01と同様の突破準備後、固定線から一度0.75R以上進み、後の行で固定線付近の0.25R以内へ戻り、さらに別の行で押し戻り極値から0.25R再進行するのを待つ。両市場の30秒方向と相手5分・20分方向も同じことを要求する。観測価格は気配中値。

120秒方向が両市場とも0.25ATR超逆なら、発注資格が揃った候補でも古い準備を捨てる。120秒方向が未知の場合はこの「強い反対」とはみなさない。自己価格が固定線の内側へ0.25R以上戻った時も準備を捨てる。

**理屈：** 直線的な上昇・下落の先端を追う頻度を落とし、一度押し戻されても突破が維持された事実を待つ。一直線に進む相場は取り逃す。出口は共通出口。

出典：[NV25固定条件](../../visual_pdca129_20261020/第七巡条件.json)／[再試験と準備破棄の実装](../../visual_pdca129_20261020/night_retest129c.py)

### W07：逆向き約定代理に負けない価格反応（TOPIXの比較核）

**入口：** NV01の発注条件に、直近30秒の出来高・価格反応を加える。買いなら「気配中値が上昇し、出来高増加があり、売り約定の代理量が買い代理量より多い」、売りなら上下対称を要求する。不成立・未知なら準備を全取消しし、やり直す。

**理屈：** 売りが出ても下がらない、買いが出ても上がらない価格反応を、反対注文を吸収している可能性として使う。代理量は公表出来高増分と直前気配から推定するため、真の成行売買量や板補充の直接測定ではない。出口はNV01と同じ。

## 今回の新担当：予定時刻まで未参加なら一回だけ

旧核が**その時刻までに一度も新規約定していなければ**、過去情報で方向を選んでTOPIX5枚・日経10枚を一回だけ追加する。方向は、二市場の20分変化を各1票、5分変化を各0.5票とする案と、二市場の始値からの方向を優先する案を比較する。同点時の優先順位もコードで固定している。

| 時刻案 | 日中 | 夜間 |
|---|---|---|
| 早期 | 開始45分後 | 開始45分後 |
| 中盤 | 12:30 | ニューヨーク09:30の30分後 |
| 後半 | 14:00 | ロンドン16:30 |

欧米の夏時間は各地域で別々に変換する。祝日の日中12:30は機械的な予定時刻であり、現物市場の再開を意味しない。

追加部分の1Rは `max(当時ATR, 過去20分帯の幅÷2, 8呼値)`。1R逆行で停止し、1.5R順行から幅1Rで追尾、場内で全返済する。必要資料が不明なら回復を待ち、場末10分前以降は新規を出さない。**全場参加を無条件に捏造する仕様ではなく、実結果で無取引ゼロを別途確認する。**

後から旧核が参加しても、先に出した追加注文を取り消さない。両担当が同方向なら合計TOPIX10枚・日経20枚まで、逆方向なら長短の上限を別々に管理する。

## 共通の読み方

判断資料はラージ、損益換算はTOPIXミニ・日経マイクロ。旧核は通常5枚・10枚で、追加・復元はしない。買いは売り気配、売りは買い気配を使い、通常の新規・返済判断は後続の正常原行で執行する。場末は既定時刻の日中15:35・夜間05:50からの返済を優先する。旧核に保存された場末の注文時計も今回変更しない。

手数料は片道1枚TOPIX41.8円・日経11円、注文ごとに1円未満を切り捨てる。部分利確を個別の勝ちにせず、ひとつの新規から全返済までの合計で利益・損失を数える。ラージ気配を小型商品の約定代理としており、実商品の板数量や約定待ち順までは再現していない。
