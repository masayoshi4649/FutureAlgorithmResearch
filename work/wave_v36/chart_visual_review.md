# 5分足図の表示確認

全104画面の切替を、事前固定した3枚の描画ごとに操作した。表示収支・全返済数・価格準備の参考件数がJSONと一致し、元HTMLは変更されていない。

画像を目視し、暗色の背景、足と目盛の可読性、買い・売り・全返済マーカー、固定A0と参考At、価格線、折畳み明細、方式・銘柄・セッションの選択が読み取れることを確認した。

- [主Q034・TOPIX・9/22夜](表示検査_0.png): 3返済、図の収支表示+7,000円。
- [主Q034・NK・9/22夜](表示検査_1.png): 4返済、+55,000円。部分返済が同じ新規点から分かれている。
- [旧H019・TOPIX・9/29昼](表示検査_2.png): 2返済、+25,000円。旧方式へ今回の価格準備を割り当てていない。

画像は成績で選んでおらず、表示対象を事前に固定した確認例。図の損切り線が部分利確後に広がる場合があるのは、既存注文器の組予算を保つ設計によるもので、画像の補間で損失制限を保証する意味ではない。価格準備は注文の初回準備とは区別し、注文所有への推測帰属は行っていない。

全操作と画像指紋は [chart_visual_check.json](chart_visual_check.json)、事前対象は [chart_visual_fixed.json](chart_visual_fixed.json)。全足・売買・独立価格線・ローカルリンクの値照合は別の `chart_data_audit.json` に保存する。外部通信は不通プロキシと背景通信無効化、現在API・保存ライブ使用0。
