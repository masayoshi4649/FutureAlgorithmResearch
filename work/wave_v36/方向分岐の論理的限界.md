# 価格帯で反転・突破を選ぶ方式の限界

結果未読の批判メモ。新しい条件や損益探索を加えるものではない。

**この方式は、停滞から先に観測された価格反応を分類する。板が防衛された原因や、その先の継続を直接証明するものではない。** 小さく反転してから大きく突破する経路では最初の反転を採り、その逆もある。これは後から大きかった波を選ぶカンニングを避ける代わりに引き受ける誤判定である。

1. **準備と入口で二段階に価格を待つ。** 準備中値からの確認に加え、注文器で追跡入口の反発・反落を待つため、早い転換を捨てる場合がある。確認幅と注文幅は参照する価格・ATR・時刻が違うので、単純に「0.5ATR遅れる」とは言えない。短い波を取り逃すだけでなく、大波の途中で入る価格が変わり、同じ返済規則でも損小利大が変わる。
2. **120秒の信号寿命は根拠の鮮度と機会を交換する。** 失効しても、入った建玉の方向を撤回する規則ではない。未約定注文も原本の次の行で取消判定され、既存注文の約定判定が先に来る。反応がゆっくりなら見送りが増え、急変ならギャップを伴う次観測で入る場合がある。取引数の減少だけを精度向上と呼べない。
3. **気配維持は真の補充の同定ではない。** 区間の出来高すべてが最後の価格・側で成立したとは限らず、両端の数量が同じでも途中で消失・復帰している可能性がある。小さい最良数量ほど比率が大きくなる。全量Q016と純価格Q007は必要な対照だが、採用数が違うため損益差だけで補充の予測力が証明されたとは言えない。
4. **相手市場の60秒遅延は独立の先行指標ではない。** NKとTOPIXの共通変動を確認している場合も、既に終わった短い進行を参照している場合もある。反対拒否は有効中立を通す一方、データの欠測を落とす。単市場との差には方向情報だけでなく、相手が観測可能だった時間帯の選別も混じる。
5. **再武装規則にも取捨選択がある。** 準備を一度消費した後の別行false→さらに別行trueは重複発火を抑えるが、最初の小反応が失敗した直後の大きな波を同じ準備から採り直せない。停滞が続くほど再準備できる、という規則でもない。今回の狙いを「全ての継続波を取る」と広げない。

反証として重いのは、主Q034が価格だけのQ007や全量Q016を安定して上回らない、又は窓・約定モデルの変更で追加情報の優位が崩れる場合。黒字でも採用がごく少ないなら、多様な場面で使える証拠は弱い。逆に黒字が続いても、この13セッションは繰り返し使った既知標本で、原理の普遍性までは示さない。

この批判を受けて結果後に確認幅や寿命を動かしたり、良かった枝へ主仮説を差し替えたりはしない。まず固定した対応比較と、全注文・全損失・指定波への参加をそのまま確認する。
