# 部分調整の最小仕様批判

**検証価値はある。新しい点は、同じA0組の中で、減量後に公開された肯定情報により、損益を条件にせず数量を戻すこと。両建て自体や利益玉だけの決済を新しい利益源とは扱わない。**

この文書は設計批判のみ。新注文器・新しい損益計算・現在データ取得は行っていない。既存の詳細は [前回レビュー](../wave_v35/部分調整の次仮説レビュー.md) を参照する。

## 最低限、固定すべき状態

1. **A0組を時計とする。** 組ID、方向、初回A0、元建値、初期R、2ATR利確、追跡極値・線、期限を固定。実数量の減量・復元で更新しない。組開始だけを同一にし、追加の復元注文まで「新規一致」とは言わない。
2. **予定数量と復元資格を別管理する。** 初期の玉を番号付きの枠として扱い、A0が利確・返済した枠は永久に復元不可。実の減量で空いた枠のうち、まだA0が保持する枠だけを戻せる。悪化の各行で繰り返し減量せず、最初は一段階の減量と一段階の復元に限定して機構を分ける。
3. **回復は減量約定後の新しい観測に限る。** 非0の明確な主方向肯定を、減量時とは異なる公開seqで要求する。0・欠測・TTL失効は回復ではない。古い肯定が残っているだけで即復元させない。復元価格やカバー損益の正負は拒否理由にしない。
4. **発注、取消、約定を分ける。** 通常→減量注文中→減量→復元注文中の状態を保存。判断行から次行以降に発注し、全体返済・2ATR利確・期限・場末を調整より優先する。全返済時は復元注文を取り消し、旧組の枠を次組へ持ち越さない。

## 二つの仕様上の落とし穴

**影の全返済を見てから実の返済を発注すると、一行遅れる。** 「A0より後まで保持しない」は、A0の既に有効な全返済条件を実にも並行して置くことで実現する。影の約定を事後に知り、その行の価格へ遡って約定させてはいけない。観測価格モデルも同じ順序で比較する。

**初期Rを記録し続けるだけでは、損失を初期R以内に抑えられない。** 悪化時に安く売り、回復時に高く買い戻す往復損失は累積する。復元後も元の価格ストップだけなら、組損失がRを超え得る。固定Rを比較尺度にするのか、組の実現＋含みで別の全返済を始動するのかを先に決める。後者も次行・ギャップで超過し得るため、損失保証とは書かない。

2ATR利確との重なりも重要。NK10枚から5枚を減量した後、影が5枚を利確する場面で、実の残5枚を機械的にさらに半減する方式と、既に閉じた枠を影利確へ充当する方式は違う。**最小案は枠番号と影の利確対象を固定し、減量も同じ対象枠から行う。影が閉じた枠の復元資格を消す。** これなら「元の利確分を買い直す」抜け道を防ぎ、同時イベントも一意にできる。違う枠配分を試すなら別の機構比較である。

## 必須対照と、失敗と判断する条件

- 同じA0組・数量の基準、同じ減量で戻さない方式、最初から小数量の方式。少枚数化だけで収支とDDが縮んだ効果を分ける。
- 同じ調整約定を使う純数量減少と反対玉の方式。全行の現金＋買売在庫時価、純枚数分、最終組損益が一致すること。脚別PF・実現益だけの改善は根拠にしない。
- 回復情報の対照は、活動可能時刻を守った無関係な肯定、又は事前に決めた解除時計。最良の解除条件を後から選ばない。
- 同じ組ごとに、減量で避けた損失、取り逃した上昇、復元後の利益・損失を出す。買いでは減量価格より高く復元するだけで、その数量の機会損失が確定する。
- 復元が0回、ほぼ全て期限に妨げられる、旧A0と同値、又は低数量対照で説明できる場合は、回復予測の有効性を支持しない。一方向相場の細かな揺れで減量・高値復元を繰り返す場合、費用0でも失敗する。
- 入口時計±20%と初期の損切りを継続診断する。利益局面の調整が改善しても、初期方向判定や長期下落への適応を解いたとは言わない。

結果前に、減量割合・再調整を何回まで許すか・回復情報・枠配分・組損失の扱いを少数に固定する。将来利益の保証や任意の75/80基準を新たな必要条件には加えず、同じ組における利益と下落の改善か交換かを示す。
