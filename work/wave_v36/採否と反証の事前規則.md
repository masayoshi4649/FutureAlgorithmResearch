# 採否と反証の事前規則

対象はQ034のみ。主91条件を成績順に並べても、最良の別IDへ主仮説を差し替えない。固定した各価格準備から、後続の最初の反応を読んで売買方向を機械的に選ぶ。

## 採用候補の必要条件

1. 全13と後半7のそれぞれで、両銘柄とも黒字、総利益/総損失>1、勝ち1枚の平均額/負け1枚の平均額>1。比が定義できない場合は未確認。
2. 全13で7セッション以上、後半7で4セッション以上取引する。最大勝ち組1件と最大黒字セッション1件をそれぞれ除いても非負。
3. 同じ窓・分岐・相手条件の純価格Q007と全出来高Q016の双方に対し、全13/後半7×両銘柄の4セルで、収支を減らさず時価最大下落を増やさず、少なくとも1項目を改善する。板一般の有効性ではなく、今回の気配維持代理の追加価値の判定。
4. 主Q034の時計0.8倍と1.2倍でも、後半7の両銘柄が上の基礎条件を満たす。観測価格約定は別ストレスとして必ず表示するが、ユーザー指定の約定仮定と異なるので採用必要条件へは加えない。
5. 指定4波×2銘柄で、正方向の純建玉を20分以上持つ従来の波診断を満たす。全波を取れる一般保証ではない。
6. 以下の方向対照と、全注文会計・入力因果性・注文次行・場内返済・枚数上限の監査を通過する。

旧H019との比較は必ず出すが、別入口・別機会の収支とリスクの交換を一律に棄却しない。今回の研究上の採用候補になっても、未知相場の有効性や統計的有意性は未確認であり、反復探索の到達点と断定しない。

## 方向の対照

Q034の非ゼロ時刻を保ち、セッション開始から30分単位で**元方向へ共通±1を掛ける**。seed=0〜63、同じセッションの両銘柄には共通の乗数を使い、`sha256("v36|seed|session|block")` の先頭8byteをlittle-endian整数にした偶奇で±1を決める。**ブロック内の元方向反転と両銘柄の相対方向関係は保つ。絶対方向を共通コイントスへ置換する対照ではない。** 将来価格を使わず、最良seedも選ばない。全方向反転1本も追加する。主364とは別の65条件として記録する。

主条件の全13/後半7×両銘柄の全4セルで、収支が64乱数の中央値以上、時価下落が中央値以下であることを要求する。そのうえで、**全体で最低1項目が厳密に優れる**ことを要求する（4セルのそれぞれで厳密改善する必要はない）。全方向反転が元条件を全4セルで支配するか完全同値なら、方向情報の根拠は不十分とする。これらは正式p値や多重探索補正ではない。乱数化で実際の新規・返済・保有時間は変わるため、その差も記録する。

この方向対照は、上記の時間内変化と銘柄間関係を保持したまま、30分ごとの向きを崩す検査である。全ての方向情報を消去した無予測対照とは呼ばず、元条件が優れても保持した情報と崩した情報の寄与を完全には分離できない。保持情報のない別の乱数方式を実施したことにはしない。

## 検査の範囲

新しい注文管理は作らず、旧D273固定A0を使う。旧H019の4変形は前回と全26入力の注文・返済・組・時価曲線が一致することを要求する。新しい全364＋補助65では、注文から現金・買売在庫・時価・返済損益を別計算し、全観測行を照合する。入力のprefix/未来改変/買売反射と、既存注文器への接続のprefix/未来改変/買売反射は混同しない。数量を増やしているだけで良く見せず、金額・返済枚数・純枚数時間を分ける。

結果の良い条件だけを検査しない。未発火は機序の否定ではなく未測定に近い結果として数え、同一方向列・同一台帳の重複数を示す。無取引や、価格対照と全く同じ売買を、気配維持を読む優位性に数えない。
