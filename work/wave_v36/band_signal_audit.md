# 価格帯信号の実装監査

**実装者側の全検査に合格。売買再生・新損益の読取・現在データの使用はしていない。** 成績の良否を示す監査ではなく、固定した情報と時刻で方向が機械的に決まるかの確認である。

- 90条件×時計3種類×既知26入力＝7,020出力の準備区間、公開参照、代理量の大小、JSON保存を確認。共通の価格準備母集団156組は、出来高代理・反応枝・相手の扱いを変えても同一。
- 代表18条件について全26入力を両銘柄共通時刻の30%・70%で切断し、方向・準備ID・確認原本seqの3列を照合。接頭部2,808列と未来価格・ATR・出来高改変2,808列が一致。
- 同じ代表18条件の全26入力で上下を反射し、方向だけ符号反転、証拠2列は同一となる1,404列比較を確認。
- 人工13項目で、別解放後の初回反応、反対枝先着の消費、期限等号の失効優先、出来高凍結、解放seq上限、欠測と停滞崩れの区別、相手の60秒遅延、採用だけによるTTL更新を検査。

当初の銘柄別行数割合による切断は、両市場の切断時計が異なり、正当に使えた相手の過去情報を片側だけ削っていた。その比較を採用せず、両市場共通時刻へ直して全検査を実行した。

出来高代理の累積和差には、窓外0.3・窓内気配維持2の例で、全量が1.9999999999999998・維持量が2となる人工反例を認めた。閾値は変えず、窓内の正比率だけを `math.fsum` で合計する形へ修正し、全検査を新ソースでやり直した。旧版と理由は [数値境界改訂](代理スコアの数値境界改訂.json) に保存している。

信号ソースSHA256は `a4b6322c97287a8af90ced23516ad5bffc4e5c9330906f6da150fd1eca89dd83`。ソース・入力指紋は監査前後で不変。全7020出力に未来改変を行ったと誤読しないよう、共通母集団の全件確認と、代表18の因果確認を区別する。

読む順序: [入出力契約](band_signal_contract.md) → [実装者の全記録](band_signal_audit.json) → [別担当の独立因果監査](band_signal_independent_audit.md) → [採用準備の部分集合監査](band_subset_audit.json)。出来高素材そのものの因果性は [抽出監査](volume_quote_audit.json) に分離している。
