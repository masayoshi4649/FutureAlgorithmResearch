# SessionTrader

全5商品を一つのWeb画面からOFF／DryRun／ONへ切り替えるGoアプリです。日経3商品の標準は日中`NK225_D164_15`、米国開始15分前まで`NK225_P164_06`、前後15分の静観、開始15分後から`NK225_U165_03`です。TOPIXは日中T06・夜間T04を維持します。

1. [Windows版](dist/windows-amd64/Web/README.md)又は[Linux版](dist/linux-amd64/Web/README.md)の`Web`フォルダを使用します。
2. 実行ファイルを引数なしで起動します。同じPCは **http://localhost:8090/**、別PCは`http://起動PCのIPアドレス又はホスト名:8090/`を開きます。初期設定で全インターフェースから接続できます。
3. 商品ごとの⚙でQtyと時間帯ごとの手法を変更します。日中・夜間の中を複数の枠に分け、各枠に手法又は静観を指定できます。

初期状態は全商品OFFです。DryRunは仮想売買、ONは実トレードです。OFFでは未約定注文を取消・照合し、保有玉は決済せず管理対象から外します。商品オプションはOFF時に変更でき、画面の変更は`conf/web-ui.toml`へ保存します。

新標準3手法と旧S01・P05・D07・TG04・PG04・T06・T04・U06の条件はExprで評価し、`conf/rules`の手法別TOMLで編集できます。T06は日経用とTOPIX用に分けた計12ファイルです。rules内にsampleは置きません。起動時に全式を型検査し、適用した条件の指紋を注文根拠に残します。建玉ID管理・約定照合・上限枚数・場内返済はGo側で管理します。

旧標準のS01・P05・静観・D07の4枠と新旧の標準式が一致する日経商品だけを新3手法へ移行します。独自時間枠・数量・モード・接続先・改変式は保持します。移行版`settings_version=2`は通常保存で記録し、その後の明示的な旧手法選択を再移行しません。読込だけで元ファイルは書き換えません。 新3手法の実TOMLも配置してください。

売買管理の確定損益は当セッション分です。終了時には6列の売買履歴を`log/{商品}/{セッション}.csv`（仮想は`_dryrun.csv`）へ、商品・モード別の集計を`log/sessionPL.csv`へ保存します。「セッション損益」タブは集計CSVだけを読み、削除した履歴は復元しません。この終了レポートは手数料前、売買管理カードは手数料後です。

SessionViewer用に`log/sessionviewer.resources.json`と、商品・場・実／仮想ごとに1個の`*.trades.jsonl`を出力します。確認済み約定と管理外移管だけを保存し、手法別コピーや毎ティックの状態ログは作りません。Viewerで一覧を開けば、日付・手法・raw／分足を選んで確認できます。[Viewer連携](docs/Viewer連携.md)。

旧モード別フォルダの詳細CSV・旧約定JSONL・`session_summary*.csv`と、`trace.jsonl`の自動出力・起動時再生成は廃止しました。既存の旧ファイルは自動削除しません。SQLiteの記録と所有管理、Webの`操作.jsonl`は維持し、詳細が必要な場合だけ診断ZIPを書き出します。
