# セッションビューアー

銘柄・日付_セッション・手法IDを選び、価格・売保有枚数・買保有枚数・累積確定損益・含み損益を同じ時間軸で確認します。損益の縦軸はそれぞれ中央0・正負対称です。

## 起動

Windowsは`dist/windows-amd64/SessionViewer/session-viewer.exe`、Linuxは`dist/linux-amd64/SessionViewer/session-viewer`を実行し、`http://localhost:8091/`を開きます。引数は使いません。別PCからは起動PCのIPアドレスで接続します。

`conf/viewer.toml`でポート、原板ルート、資料ルート、最初に開くリンク列挙ファイルを変更できます。配布フォルダを移しても、設定のルートが実データを指していれば使えます。Linuxでは2つのルートを実際のマウント先へ変更してください。

初期資料は`アルゴリズム調査/00169_セッションと売買経路の可視化/比較.resources.json`です。画面のファイル選択・ドロップ、又はサーバー上のパス入力で別の列挙ファイルも開けます。ホイールでズーム、ドラッグで移動。5段の時間範囲とカーソルは連動します。取引一覧を押すとその約定を確認できます。

一覧に登録された銘柄・日付_セッション・手法IDを個別に絞り込めます。同じ組合せに複数資料がある場合はリソース欄で選択します。損益資料のない場は「価格だけ」から選択できます。

SessionTraderの`log/sessionviewer.resources.json`も開けます。「全手法（合計）」と新規手法別で同じ約定ファイルを共用し、別手法による返済も保持します。OFF等の管理外移管は返済・利益として数えません。別PCへログをコピーした場合は「サーバー上の一覧ファイル」にコピー先のパスを指定してください。

AI向けには`/api/chart.png`・`/api/chart.svg`で5段の画像、`/api/chart`・`/api/data`で同じ範囲の数値と参照パスを取得できます。[画像APIと取得例](docs/画像API.md)を参照してください。機械用仕様は`/api/openapi.json`です。画像は要求時だけ作り、保存ファイルを増やしません。

足の単位は`raw／1分／5分／15分`。rawは価格線、分足は原板から集計したOHLCローソクです。保有・損益は各区間の最後値を区間終了時刻に表示します。カーソルでも区間と末値を確認でき、表示範囲の「5分／15分」ボタンとは独立して切り替えられます。

## 保存容量

- 原板は既存の`future/{NK225|TOPIX}/{セッション}/book.jsonl`を直接読みます。原板コピー、ディスクキャッシュ、トレース、DBは作りません。
- 標準の損益JSONLは約定と所有建玉IDだけです。買い玉はラージBid、売り玉はラージAskで含みを計算します。実約定価格はJSONLを使います。
- 全原行を読みながら表示範囲の極値・約定・欠測境界を残し、画面に必要な点へ縮約します。生データは変更しません。細部はズームで再取得します。
- 分足も原板から表示時に集計し、足別ファイルや保有・損益の中間データは保存しません。
- 応答キャッシュはメモリだけに置き、設定値を超えれば破棄します。64MBは完成応答のLRU上限であり、解析中の作業メモリや必ず保持する約定・欠測境界の量は別です。`.jsonl.gz`も読めます。
- `dist/`と実行時ファイルはGit対象外です。既存の研究データの削除は行いません。

データの必須項目とREST APIは[データ仕様](docs/データ仕様.md)を参照してください。未知の値や時計内の不明な順序を0や推測の損益で埋めません。

## 開発・配布

Go 1.24以降で、このフォルダから実行します。

```text
go test ./...
go vet ./...
go run .
go run ./cmd/build-dist
```

画面は実行ファイルへ埋め込みます。CGO・MinGW・Node・CDNは実行時に不要です。配布再生成時は既存の`conf/viewer.toml`を保持し、最新のコメント付き設定例を`viewer.toml.sample`へ配置します。

既存の研究保存結果からは、売買を再生せず約定のみ抽出できます。元の確定損益と原板約定行の一致を検査します。

```text
go run ./cmd/export-research -input 保存結果.json -method 手法ID -output 未作成.trades.jsonl -point-value 10
```

この変換ツールは現在の研究JSONの`Actual.Events/Lots`用です。実運用ログの自動推測変換はしません。
